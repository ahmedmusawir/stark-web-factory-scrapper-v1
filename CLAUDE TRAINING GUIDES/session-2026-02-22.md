## Key Insights for Manual Creation

### Architectural Patterns (From VidGen)

1. **File-based state management**
   - Zero database overhead
   - Self-contained projects (portable)
   - Human-readable state
   - Resume-ability via file existence
   - **Manual topic:** State management patterns for Python apps

2. **Sequential pipeline with approval gates**
   - Linear flow (stage → approval → next stage)
   - Approval separate from file existence
   - User control at each stage
   - **Manual topic:** Pipeline architecture patterns

3. **Module independence**
   - Each `src/*.py` is standalone (file in → file out)
   - CLI and GUI call same functions
   - Easy to test in isolation
   - **Manual topic:** Module design patterns

4. **Config-driven everything**
   - Model selection via config.json
   - Voice selection via config.json
   - No hardcoding in code
   - **Manual topic:** Configuration management best practices

### Integration Patterns (From VidGen)

1. **Vertex AI model selection**
   - Flash for speed/cost (default)
   - Pro for quality (optional upgrade)
   - Config-driven model switching
   - **Manual topic:** Vertex AI model selection guide

2. **Chunking for API limits**
   - TTS has 5000 byte limit
   - Split at paragraph boundaries
   - Measure in bytes, not characters
   - Leave buffer (4500 for 5000 limit)
   - **Manual topic:** Handling API limits

3. **GCS fallback for large files**
   - Speech-to-Text requires GCS for >10MB
   - Auto-upload, transcribe from bucket
   - **Manual topic:** Google Cloud Storage integration patterns

4. **Long-running operation polling**
   - Speech-to-Text can take 10-30 minutes
   - Use operation.result(timeout=3600)
   - **Manual topic:** Async operation handling

### Testing Patterns (From VidGen)

1. **Hybrid testing strategy**
   - Unit tests: Mock APIs (fast, free)
   - Integration tests: Real APIs (slow, costly)
   - Manual tests: Full pipeline (subjective quality)
   - **Manual topic:** Testing strategies for AI applications

2. **Cost-aware integration testing**
   - Mark with @pytest.mark.integration
   - Run selectively (not on every push)
   - Estimate ~$0.12-0.24 per run
   - **Manual topic:** Cost management for AI testing

### Decision Patterns (From VidGen)

**Key decision framework observed:**
1. **Simplicity over scalability** (file-based, sequential)
2. **Single-vendor over best-of-breed** (Google Cloud ecosystem)
3. **Quality over cost** (Studio voices, Imagen)
4. **Speed of development over perfect UX** (Streamlit, fixed aspect ratio)

**Manual topic:** Decision-making framework for MVP vs production
