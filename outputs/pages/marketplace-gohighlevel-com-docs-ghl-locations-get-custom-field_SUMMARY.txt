## STRUCTURED API SUMMARY

### 1. ENDPOINT NAME:
Get Custom Field

### 2. CATEGORY:
Custom Field (Sub-Account / Location)

### 3. HTTP METHOD:
GET

### 4. ENDPOINT URL:
`/locations/:locationId/customFields/:id`

### 5. FULL URL:
`https://services.leadconnectorhq.com/locations/:locationId/customFields/:id`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters:**
    *   `Version` (string): API Version. Possible values: [`2021-07-28`]
*   **Path Parameters:**
    *   `locationId` (string): Location Id. Example: `ve9EPM428h8vShlRW1KT`
    *   `id` (string): Custom Field Id or Field Key (e.g., "contact.first_name" or "opportunity.pipeline_id"). Examples: `id`, `field_key`, `00NhGCcN1tlO8ZHcu7Wb`, `contact.first_name`

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** `bearer`
*   **Bearer Format:** `JWT`
*   **In:** `header`
*   **Description:** Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account.

### 9. RESPONSE FORMAT:

*   **200 OK (Successful response)**
    *   **Content Type:** `application/json`
    *   **Schema:**
        *   `customField` (object)
            *   `id` (string): Example: `3sv6UEo51C9Bmpo1cKTq`
            *   `name` (string): Example: `pincode`
            *   `fieldKey` (string): Example: `contact.pincode`
            *   `placeholder` (string): Example: `Pin code`
            *   `dataType` (string): Example: `TEXT`
            *   `position` (number): Example: `0`
            *   `picklistOptions` (string[]): Example: `["first option"]`
            *   `picklistImageOptions` (string[]): Example: `[]`
            *   `isAllowedCustomOption` (boolean): Example: `false`
            *   `isMultiFileAllowed` (boolean): Example: `true`
            *   `maxFileLimit` (number): Example: `4`
            *   `locationId` (string): Example: `3sv6UEo51C9Bmpo1cKTq`
            *   `model` (string): Model of the custom field. Possible values: [`contact`, `opportunity`]. Example: `opportunity`
    *   **Example (200 OK):**
        ```json
        {"customField":{"id":"3sv6UEo51C9Bmpo1cKTq","name":"pincode","fieldKey":"contact.pincode","placeholder":"Pin code","dataType":"TEXT","position":0,"picklistOptions":["first option"],"picklistImageOptions":[],"isAllowedCustomOption":false,"isMultiFileAllowed":true,"maxFileLimit":4,"locationId":"3sv6UEo51C9Bmpo1cKTq","model":"opportunity"}}
        ```
*   **400 Bad Request**
    *   **Schema:** `statusCode` (number), `message` (string)
    *   **Example:** `{"statusCode":400,"message":"Bad Request"}`
*   **401 Unauthorized**
    *   **Schema:** `statusCode` (number), `message` (string), `error` (string)
    *   **Example:** `{"statusCode":401,"message":"Invalid token: access token is invalid","error":"Unauthorized"}`
*   **422 Unprocessable Entity**
    *   **Schema:** `statusCode` (number), `message` (string[]), `error` (string)
    *   **Example:** `{"statusCode":422,"message":["Unprocessable Entity"],"error":"Unprocessable Entity"}`

### 10. PURPOSE:
This endpoint retrieves the details of a specific custom field within a sub-account by its ID or field key.
