Here's a structured summary of the HighLevel API documentation for updating a user:

---

### 1. ENDPOINT NAME:
Update User

### 2. CATEGORY:
Users

### 3. HTTP METHOD:
PUT

### 4. ENDPOINT URL:
`/users/:userId`

### 5. FULL URL:
`https://services.leadconnectorhq.com/users/:userId`

### 6. REQUIRED PARAMETERS:
*   `Version` (string): API Version. (In Header)
    *   **Possible values**: [`2021-07-28`]

### 7. OPTIONAL PARAMETERS:
*(All body parameters are optional for an update operation unless explicitly marked as 'required', which none are individually. The `Body` itself is required.)*
*   `firstName` (string): User's first name.
    *   **Example**: `John`
*   `lastName` (string): User's last name.
    *   **Example**: `Deo`
*   `email` (string): User's email. **Deprecated**: Email update is no longer supported due to security reasons.
    *   **Example**: `john@deo.com`
*   `password` (string): User's password.
    *   **Example**: `*******`
*   `phone` (string): User's phone number.

### 8. AUTHENTICATION:
*   **Scope(s)**: `users.write`
*   **Auth Method(s)**: `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s)**: `Agency Token`, `Sub-Account Token`

### 10. PURPOSE:
This endpoint allows you to update the profile details, roles, permissions, and assigned scopes for an existing user within the HighLevel platform.
