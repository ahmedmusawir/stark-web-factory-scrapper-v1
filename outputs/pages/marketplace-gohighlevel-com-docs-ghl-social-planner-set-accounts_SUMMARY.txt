Here is a structured summary of the API documentation for "Set Accounts":

---

### 1. ENDPOINT NAME:
Set Accounts

### 2. CATEGORY:
Social Planner (specifically CSV operations within Social Planner)

### 3. HTTP METHOD:
POST

### 4. ENDPOINT URL:
`/social-media-posting/:locationId/set-accounts`

### 5. FULL URL:
`https://services.leadconnectorhq.com/social-media-posting/:locationId/set-accounts`

### 6. REQUIRED PARAMETERS:

*   **Header:**
    *   `Version` (string): API Version. Possible values: `2021-07-28`
*   **Path:**
    *   `locationId` (string): Location Id
*   **Body:**
    *   `accountIds` (string[]): Account Ids
    *   `filePath` (string): File path (of the previously uploaded CSV)
    *   `rowsCount` (number): Entries Count. `rowsCount` must be between 1 and the number of posts in the CSV.
    *   `fileName` (string): Name of file

### 7. OPTIONAL PARAMETERS:

*   **Body:**
    *   `approver` (string)
    *   `userId` (string): User ID

### 8. AUTHENTICATION:

*   **Scope(s):** `socialplanner/csv.write`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`

### 9. RESPONSE FORMAT:

*   **Successful Response (201 Created):**
    ```json
    {
      "success": true,
      "statusCode": 201,
      "message": "Accounts Set Successfully"
    }
    ```
*   **Error Responses:**
    *   **400 Bad Request:**
        ```json
        {
          "statusCode": 400,
          "message": "Bad Request"
        }
        ```
    *   **401 Unauthorized:**
        ```json
        {
          "statusCode": 401,
          "message": "Invalid token: access token is invalid",
          "error": "Unauthorized"
        }
        ```
    *   **422 Unprocessable Entity:**
        ```json
        {
          "statusCode": 422,
          "message": ["Unprocessable Entity"],
          "error": "Unprocessable Entity"
        }
        ```

### 10. PURPOSE:
This endpoint is used to associate specified social media accounts with a previously uploaded CSV file for the purpose of scheduling social media posts within a given location.

### 11. TAGS:
Social Planner, CSV, Set Accounts, Social Media Posting, Location, Account Management, Post, Upload, HighLevel, API, Marketing Automation.

Code examples are available for cURL, nodejs, python, php, java, go, ruby, and powershell. A cURL example is explicitly provided in the documentation.
