Here's a structured summary of the "Get Accounts" API documentation:

### 1. ENDPOINT NAME:
Get Accounts

### 2. CATEGORY:
Social Planner (sub-category: Account)

### 3. HTTP METHOD:
GET

### 4. ENDPOINT URL:
`/social-media-posting/:locationId/accounts`

### 5. FULL URL:
`https://services.leadconnectorhq.com/social-media-posting/:locationId/accounts`

### 6. REQUIRED PARAMETERS:
*   `Version` (string): API Version. Possible values: [`2021-07-28`] (Header Parameter)
*   `locationId` (string): Location Id. Example: `ve9EPM428h8vShlRW1KT` (Path Parameter)

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:
*   **Scope(s):** `socialplanner/account.readonly`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** Bearer (JWT format in header)

### 9. RESPONSE FORMAT:
**Status Code:** 200 (Successful response)
**Content Type:** `application/json`

**Schema:**
```json
{
  "success": boolean,
  "statusCode": number,
  "message": string,
  "results": {
    "accounts": [
      {
        "id": string,
        "oauthId": string,
        "profileId": string,
        "name": string,
        "platform": string, // One of: google, facebook, instagram, linkedin, twitter, tiktok
        "type": string,
        "expire": string, // Date-time string
        "isExpired": boolean,
        "meta": object
      }
    ],
    "groups": [
      {
        "id": string, // Group Id (required)
        "name": string, // name of group (required)
        "accountIds": string[] // Array of account IDs (required)
      }
    ]
  }
}
```

### 10. PURPOSE:
This endpoint retrieves a list of connected social media accounts and associated groups for a specific location.
