Here is a structured summary of the API documentation:

### 1. ENDPOINT NAME:
Deleting an existing integration

### 2. CATEGORY:
Payments - Custom Provider

### 3. HTTP METHOD:
DELETE

### 4. ENDPOINT URL:
`/payments/custom-provider/provider`

### 5. FULL URL:
`https://services.leadconnectorhq.com/payments/custom-provider/provider`

### 6. REQUIRED PARAMETERS:
*   **Version** (string, header): API Version. Possible values: `2021-07-28`
*   **locationId** (string, query): Location id. Example: `Lk3nlfk4lxlelVEwcW`

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:
*   **Scope(s):** `payments/custom-provider.write`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** `bearer`
*   **Bearer Format:** `JWT`
*   **In:** `header`
*   **Description:** Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account.

### 9. RESPONSE FORMAT:

**200 OK (Successful Response)**
*   **Content Type:** `application/json`
*   **Schema:**
    *   `success` (boolean, required): Whether the custom provider config is disconnected or not. `true` represents config is disconnected.
*   **Example:**
    ```json
    {"success": true}
    ```

**400 Bad Request**
*   **Content Type:** `application/json`
*   **Schema:**
    *   `statusCode` (number): Example: `400`
    *   `message` (string): Example: `Bad Request`
*   **Example:**
    ```json
    {"statusCode":400,"message":"Bad Request"}
    ```

**401 Unauthorized**
*   **Content Type:** `application/json`
*   **Schema:**
    *   `statusCode` (number): Example: `401`
    *   `message` (string): Example: `Invalid token: access token is invalid`
    *   `error` (string): Example: `Unauthorized`
*   **Example:**
    ```json
    {"statusCode":401,"message":"Invalid token: access token is invalid","error":"Unauthorized"}
    ```

**422 Unprocessable Entity**
*   **Content Type:** `application/json`
*   **Schema:**
    *   `statusCode` (number): Example: `422`
    *   `message` (string[]): Example: `["Unprocessable Entity"]`
    *   `error` (string): Example: `Unprocessable Entity`
*   **Example:**
    ```json
    {"statusCode":422,"message":["Unprocessable Entity"],"error":"Unprocessable Entity"}
    ```

### 10. PURPOSE:
This API deletes an association for a custom payment provider app and a specific location (sub-account).
