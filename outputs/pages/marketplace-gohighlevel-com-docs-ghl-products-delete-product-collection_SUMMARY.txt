## STRUCTURED SUMMARY OF API DOCUMENTATION

### 1. ENDPOINT NAME:
Delete Product Collection

### 2. CATEGORY:
Products

### 3. HTTP METHOD:
DELETE

### 4. ENDPOINT URL:
`/products/collections/:collectionId`

### 5. FULL URL:
`https://services.leadconnectorhq.com/products/collections/:collectionId`

### 6. REQUIRED PARAMETERS:
- Version (string): API Version. Possible values: [`2021-07-28`]
- collectionId (string): MongoId of the collection. Example: `65d71377c326ea78e1c47df5`
- altId (string): Location Id. Example: `6578278e879ad2646715ba9c`
- altType (string): The type of alt. For now it is only LOCATION. Possible values: [`location`]. Example: `LOCATION`

### 7. OPTIONAL PARAMETERS:
Not specified in documentation (All listed parameters are required).

### 8. AUTHENTICATION:
- **Scope(s):** `products/collection.write`
- **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
- **Token Type(s):** `Sub-Account Token`
- **Scheme:** `bearer`
- **Bearer Format:** `JWT`
- **In:** `header`
- **Description:** Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account.

### 9. RESPONSE FORMAT:
**Status Code:** `200 OK`
**Content Type:** `application/json`

**Schema:**
- `status` (boolean): Status of api action. Example: `true`
- `message` (string): Success message. Example: `Successfully created`

**Example:**
```json
{
  "status": true,
  "message": "Successfully created"
}
```
*(Also includes error responses for 400 Bad Request, 401 Unauthorized, and 422 Unprocessable Entity)*

### 10. PURPOSE:
This endpoint deletes a specific product collection identified by its `collectionId`.
