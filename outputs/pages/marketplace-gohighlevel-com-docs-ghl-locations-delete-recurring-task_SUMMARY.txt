Here is the structured summary of the API documentation for "Delete Recurring Task":

### 1. ENDPOINT NAME:
Delete Recurring Task

### 2. CATEGORY:
Sub-Account (Formerly location) / Recurring Tasks

### 3. HTTP METHOD:
DELETE

### 4. ENDPOINT URL:
`/locations/:locationId/recurring-tasks/:id`

### 5. FULL URL:
`https://services.leadconnectorhq.com/locations/:locationId/recurring-tasks/:id`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters:**
    *   Version (string): API Version (Possible values: `2021-07-28`)
*   **Path Parameters:**
    *   id (string): Recurring Task Id (Example: `sx6wyHhbFdRXh302Lunr`)
    *   locationId (string): Location Id (Example: `sx6wyHhbFdRXh302Lunr`)

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:
*   **Auth Method(s):** OAuth Access Token, Private Integration Token
*   **Token Type(s):** Sub-Account Token
*   **Scheme:** Bearer (JWT)
*   **In:** Header (Authorization header)
*   **Description:** Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account.

### 9. RESPONSE FORMAT:
**Successful response (200 OK):**
*   **Content Type:** `application/json`
*   **Schema:**
    ```json
    {
      "id": "string",  // Recurring Task Id (Example: sx6wyHhbFdRXh302Lunr)
      "success": "boolean" // Success (Example: true)
    }
    ```
*   **Example:**
    ```json
    {"id":"sx6wyHhbFdRXh302Lunr","success":true}
    ```

**Error Responses:**
*   **400 Bad Request:**
    ```json
    {"statusCode":400,"message":"Bad Request"}
    ```
*   **401 Unauthorized:**
    ```json
    {"statusCode":401,"message":"Invalid token: access token is invalid","error":"Unauthorized"}
    ```

### 10. PURPOSE:
This endpoint allows you to delete an existing recurring task within a specific sub-account using its recurring task ID and location ID.
