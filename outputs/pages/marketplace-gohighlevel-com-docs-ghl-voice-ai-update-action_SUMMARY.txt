Here's a structured summary of the "Update Agent Action" API documentation:

### 1. ENDPOINT NAME
Update Agent Action

### 2. CATEGORY
Voice AI / Actions

### 3. HTTP METHOD
PUT

### 4. ENDPOINT URL
`/voice-ai/actions/:actionId`

### 5. FULL URL
`https://services.leadconnectorhq.com/voice-ai/actions/:actionId`

### 6. REQUIRED PARAMETERS

*   **Header Parameters:**
    *   `Version` (string): API Version. Possible values: [`2021-04-15`]
*   **Path Parameters:**
    *   `actionId` (string): Unique identifier for the action
*   **Body Parameters (top-level):**
    *   `agentId` (string): Agent ID to attach the action to
    *   `locationId` (string): Location ID
    *   `actionType` (string): Type of action. Possible values: [`CALL_TRANSFER`, `DATA_EXTRACTION`, `IN_CALL_DATA_EXTRACTION`, `WORKFLOW_TRIGGER`, `SMS`, `APPOINTMENT_BOOKING`, `CUSTOM_ACTION`, `KNOWLEDGE_BASE`]
    *   `name` (string): Human-readable name for this action
    *   `actionParameters` (object): Action parameters - structure varies by `actionType`.
        *   **If `actionType` is `CALL_TRANSFER`:**
            *   `triggerPrompt` (string): When to trigger this action during the call
            *   `transferToType` (string): Type of transfer destination. Possible values: [`number`]
            *   `transferToValue` (string): Phone number to transfer to.
            *   `triggerMessage` (string): Message to tell the caller before transferring
        *   **If `actionType` is `DATA_EXTRACTION`:**
            *   `contactFieldId` (string): ID of the contact field to be updated with the extracted data
            *   `description` (string): Description of what data to extract
            *   `examples` (string[]): Example values to help Agent understand the expected format (at least one, max 5).
        *   **If `actionType` is `IN_CALL_DATA_EXTRACTION`:**
            *   `contactFieldId` (string): ID of the contact field to be updated with the extracted data
            *   `description` (string): Description of what data to extract
            *   `examples` (string[]): Example values to help Agent understand the expected format (at least one, max 5).
        *   **If `actionType` is `WORKFLOW_TRIGGER`:**
            *   `triggerPrompt` (string): When to trigger this workflow
            *   `triggerMessage` (string): Message to tell the caller
            *   `workflowId` (string): Workflow ID to trigger
        *   **If `actionType` is `SMS`:**
            *   `triggerPrompt` (string): When to send the SMS
            *   `triggerMessage` (string): Message to tell the caller
            *   `messageBody` (string): SMS message content to send
        *   **If `actionType` is `APPOINTMENT_BOOKING`:**
            *   `calendarId` (string): Calendar ID to book appointments in
            *   `daysOfOfferingDates` (number): Number of days ahead to offer booking dates
            *   `slotsPerDay` (number): Number of available slots per day
            *   `hoursBetweenSlots` (number): Hours between available slots
        *   **If `actionType` is `CUSTOM_ACTION`:**
            *   `triggerPrompt` (string): When to call the custom API
            *   `triggerMessage` (string): Message to tell the caller
            *   `apiDetails` (object): API endpoint configuration
                *   `url` (string): API endpoint URL
                *   `method` (string): HTTP method. Possible values: [`POST`, `GET`]
                *   `headers[].key` (string): HTTP header name (within `headers` array)
                *   `headers[].value` (string): HTTP header value (within `headers` array)
                *   `parameters[].name` (string): Parameter name (within `parameters` array)
        *   **If `actionType` is `KNOWLEDGE_BASE`:**
            *   `triggerPrompt` (string): When to query the knowledge base
            *   `knowledgeBaseId` (string): Knowledge base ID to query

### 7. OPTIONAL PARAMETERS

*   **Body Parameters (`actionParameters` properties, depending on `actionType`):**
    *   **If `actionType` is `CALL_TRANSFER`:**
        *   `hearWhisperMessage` (boolean): Whether to play whisper message to the receiving party. Default value: `false`
    *   **If `actionType` is `DATA_EXTRACTION`:**
        *   `overwriteExistingValue` (boolean): Whether to overwrite existing field value if already set. Default value: `false`
    *   **If `actionType` is `IN_CALL_DATA_EXTRACTION`:**
        *   `overwriteExistingValue` (boolean): Whether to overwrite existing field value if already set. Default value: `false`
    *   **If `actionType` is `CUSTOM_ACTION` (within `apiDetails`):**
        *   `authenticationRequired` (boolean): Whether authentication is required. Default value: `false`
        *   `authenticationValue` (string): Authentication token or API key (required if `authenticationRequired` is true)
        *   `parameters[].description` (string): Parameter description (within `parameters` array)
        *   `parameters[].type` (string): Parameter type (within `parameters` array)
        *   `parameters[].example` (string): Example parameter value (within `parameters` array)
        *   `selectedPaths` (string[]): Selected response paths to extract from API response. Required: at least 1 value if the method is GET. Should be empty if the method is POST.

### 8. AUTHENTICATION

*   **Scope(s):** `voice-ai-agent-goals.write`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** Bearer (JWT)
*   **In:** Header (Authorization header)

### 9. RESPONSE FORMAT

*   **Successful Response (200 OK):**
    *   `id` (string): Unique identifier for the updated action.
    *   `actionType` (string): Type of action.
    *   `name` (string): Human-readable name for this action.
    *   `actionParameters` (object): Action parameters, reflecting the updated configuration based on `actionType`. This object will contain properties specific to the chosen `actionType` (e.g., `triggerPrompt`, `transferToType`, `transferToValue` for `CALL_TRANSFER`).

    *Example (for `CALL_TRANSFER` actionType):*
    ```json
    {
      "id": "507f1f77bcf86cd799439011",
      "actionType": "CALL_TRANSFER",
      "name": "Transfer to Manager",
      "actionParameters": {
        "triggerPrompt": "When the caller asks to speak to a manager",
        "transferToType": "number",
        "transferToValue": "+12345678901",
        "triggerMessage": "Let me transfer you to a manager right away",
        "hearWhisperMessage": true
      }
    }
    ```

### 10. PURPOSE
This endpoint allows developers to update an existing action for a Voice AI agent, modifying its behavior and configuration within the HighLevel platform.
