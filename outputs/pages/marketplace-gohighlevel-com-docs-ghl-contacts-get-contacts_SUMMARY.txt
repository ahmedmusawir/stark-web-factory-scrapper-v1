Here is a structured summary of the provided API documentation:

### 1. ENDPOINT NAME:
Get Contacts

### 2. CATEGORY:
Contacts

### 3. HTTP METHOD:
GET

### 4. ENDPOINT URL:
`/contacts/`

### 5. FULL URL:
`https://services.leadconnectorhq.com/contacts/`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters**:
    *   `Version` (string): API Version. Possible values: `2021-07-28`
*   **Query Parameters**:
    *   `locationId` (string): Location Id

### 7. OPTIONAL PARAMETERS:
*   `startAfterId` (string): Start After Id
*   `startAfter` (number): Start After
*   `query` (string): Contact Query
*   `limit` (number): Limit Per Page records count. Will allow maximum up to 100 and default will be 20. (Default value: `20`)

### 8. AUTHENTICATION:
*   **Scope(s)**: `contacts.readonly`
*   **Auth Method(s)**: `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s)**: `Sub-Account Token`
*   **Scheme**: `bearer` (bearerFormat: `JWT`) in `header` (name: `Authorization`)

### 9. RESPONSE FORMAT:
*   **Status Code**: 200 (Successful response)
*   **Content Type**: `application/json`
*   **Structure**: An object containing:
    *   `contacts` (array of objects): Each object represents a contact with fields such as `id`, `locationId`, `email`, `timezone`, `country`, `source`, `dateAdded`, `customFields` (array of objects), `tags` (array of strings), `businessId`, `attributions` (array of objects), and `followers` (array of strings).
    *   `count` (number): The total count of contacts.

### 10. PURPOSE:
This endpoint retrieves a list of contacts associated with a specific location, offering options for pagination and filtering. *Note: This endpoint is deprecated. Users are advised to use the [Search Contacts](https://highlevel.stoplight.io/docs/integrations/dbe4f3a00a106-search-contacts) endpoint instead.*
