Here is a structured summary of the API documentation:

### 1. ENDPOINT NAME:
Delete Business

### 2. CATEGORY:
Business

### 3. HTTP METHOD:
DELETE

### 4. ENDPOINT URL:
`/businesses/:businessId`

### 5. FULL URL:
`https://services.leadconnectorhq.com/businesses/:businessId`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters:**
    *   Version (string): API Version. Possible values: `2021-07-28`
*   **Path Parameters:**
    *   businessId (string): Example: `5DP4iH6HLkQsiKESj6rh`

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:
*   **Scope(s):** `businesses.write`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** Bearer (JWT)
*   **Description:** Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account.

### 9. RESPONSE FORMAT:
*   **Successful Response (200 OK):**
    *   **Content Type:** `application/json`
    *   **Schema:**
        ```json
        {
          "success": boolean
        }
        ```
    *   **Example:** `{"success": true}`

*   **Error Responses:**
    *   **400 Bad Request:**
        ```json
        {"statusCode":400,"message":"Bad Request"}
        ```
    *   **401 Unauthorized:**
        ```json
        {"statusCode":401,"message":"Invalid token: access token is invalid","error":"Unauthorized"}
        ```
    *   **422 Unprocessable Entity:**
        ```json
        {"statusCode":422,"message":["Unprocessable Entity"],"error":"Unprocessable Entity"}
        ```

### 10. PURPOSE:
This endpoint allows an authenticated application to delete a specific business (sub-account) within the HighLevel system.

Business, Delete, Remove, API, Sub-Account, CRM, HighLevel
