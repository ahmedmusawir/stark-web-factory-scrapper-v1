Here's a structured summary of the API documentation:

### 1. ENDPOINT NAME
Import Courses

### 2. CATEGORY
Courses

### 3. HTTP METHOD
POST

### 4. ENDPOINT URL
`/courses/courses-exporter/public/import`

### 5. FULL URL
`https://services.leadconnectorhq.com/courses/courses-exporter/public/import`

### 6. REQUIRED PARAMETERS
*   **Version** (string, Header): API Version. Possible values: [`2021-07-28`]
*   **locationId** (string, Body): The ID of the location (sub-account).
*   **products** (object[], Body): An array of product objects to import.
    *   **products.title** (string): The title of the product.
    *   **products.description** (string): The description of the product.
    *   **products.categories** (object[], Body): An array of category objects within the product.
        *   **products.categories.title** (string): The title of the category.
        *   **products.categories.visibility** (string): The visibility status of the category. Possible values: [`published`, `draft`]
        *   **products.categories.posts** (object[], Body): An array of post objects within the category.
            *   **products.categories.posts.title** (string): The title of the post.
            *   **products.categories.posts.visibility** (string): The visibility status of the post. Possible values: [`published`, `draft`]
            *   **products.categories.posts.contentType** (string): The content type of the post. Possible values: [`video`, `assignment`, `quiz`]
            *   **products.categories.posts.description** (string): The description of the post.
            *   **products.categories.posts.postMaterials** (object[], Body): An array of post material objects.
                *   **products.categories.posts.postMaterials.title** (string): The title of the post material.
                *   **products.categories.posts.postMaterials.type** (string): The type of the post material. Possible values: [`pdf`, `image`, `docx`, `pptx`, `xlsx`, `html`, `dotx`, `epub`, `webp`, `gdoc`, `mp3`, `doc`, `txt`, `zip`, `ppt`, `key`, `htm`, `xls`, `odp`, `odt`, `rtf`, `m4a`, `ods`, `mp4`, `ai`, `avi`, `mov`, `wmv`, `mkv`, `wav`, `flac`, `ogg`, `png`, `jpeg`, `jpg`, `gif`, `bmp`, `tiff`, `svg`, `odg`, `sxw`, `sxc`, `sxi`, `rar`, `7z`, `json`, `xml`, `csv`, `md`, `obj`, `stl`, `woff`, `ttf`]
                *   **products.categories.posts.postMaterials.url** (string): The URL of the post material.
        *   **products.categories.subCategories** (object[], Body): An array of sub-category objects within the category.
            *   **products.categories.subCategories.title** (string): The title of the sub-category.
            *   **products.categories.subCategories.visibility** (string): The visibility status of the sub-category. Possible values: [`published`, `draft`]
            *   **products.categories.subCategories.posts** (object[], Body): An array of post objects within the sub-category.
                *   **products.categories.subCategories.posts.title** (string): The title of the post.
                *   **products.categories.subCategories.posts.visibility** (string): The visibility status of the post. Possible values: [`published`, `draft`]
                *   **products.categories.subCategories.posts.contentType** (string): The content type of the post. Possible values: [`video`, `assignment`, `quiz`]
                *   **products.categories.subCategories.posts.description** (string): The description of the post.
                *   **products.categories.subCategories.posts.postMaterials** (object[], Body): An array of post material objects.
                    *   **products.categories.subCategories.posts.postMaterials.title** (string): The title of the post material.
                    *   **products.categories.subCategories.posts.postMaterials.type** (string): The type of the post material. Possible values: [`pdf`, `image`, `docx`, `pptx`, `xlsx`, `html`, `dotx`, `epub`, `webp`, `gdoc`, `mp3`, `doc`, `txt`, `zip`, `ppt`, `key`, `htm`, `xls`, `odp`, `odt`, `rtf`, `m4a`, `ods`, `mp4`, `ai`, `avi`, `mov`, `wmv`, `mkv`, `wav`, `flac`, `ogg`, `png`, `jpeg`, `jpg`, `gif`, `bmp`, `tiff`, `svg`, `odg`, `sxw`, `sxc`, `sxi`, `rar`, `7z`, `json`, `xml`, `csv`, `md`, `obj`, `stl`, `woff`, `ttf`]
                    *   **products.categories.subCategories.posts.postMaterials.url** (string): The URL of the post material.
    *   **products.instructorDetails** (object, Body): Details of the instructor.
        *   **products.instructorDetails.name** (string): The name of the instructor.
        *   **products.instructorDetails.description** (string): The description of the instructor.

### 7. OPTIONAL PARAMETERS
*   **userId** (string, Body): The ID of the user.
*   **products.imageUrl** (string, Body): The URL for the product image.
*   **products.categories.thumbnailUrl** (string, Body): The URL for the category thumbnail image.
*   **products.categories.posts.thumbnailUrl** (string, Body): The URL for the post thumbnail image.
*   **products.categories.posts.bucketVideoUrl** (string, Body): The URL for the video stored in a bucket.
*   **products.categories.subCategories.thumbnailUrl** (string, Body): The URL for the sub-category thumbnail image.
*   **products.categories.subCategories.posts.thumbnailUrl** (string, Body): The URL for the sub-category post thumbnail image.
*   **products.categories.subCategories.posts.bucketVideoUrl** (string, Body): The URL for the video stored in a bucket for the sub-category post.

### 8. AUTHENTICATION
*   **Auth Method(s)**: OAuth Access Token, Private Integration Token
*   **Token Type(s)**: Sub-Account Token
*   **Scheme**: Bearer (JWT)
*   **Parameter Name**: Authorization (in header)

### 9. RESPONSE FORMAT
*   **Success Status Code**: 201
*   **Structure**: Not explicitly detailed beyond the status code, implies successful creation.

### 10. PURPOSE
This endpoint allows importing courses into a sub-account through public channels using a specified data structure.
