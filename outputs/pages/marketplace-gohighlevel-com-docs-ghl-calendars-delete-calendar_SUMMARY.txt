Here is a structured summary of the API documentation for the "Delete Calendar" endpoint:

### 1. ENDPOINT NAME:
Delete Calendar

### 2. CATEGORY:
Calendars

### 3. HTTP METHOD:
DELETE

### 4. ENDPOINT URL:
`/calendars/:calendarId`

### 5. FULL URL:
`https://services.leadconnectorhq.com/calendars/:calendarId`

### 6. REQUIRED PARAMETERS:
*   **calendarId** (string): Calendar Id. Example: `ocQHyuzHvysMo5N5VsXc`
*   **Version** (string): API Version. Possible values: `2021-04-15`

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:
*   **Scope(s):** `calendars.write`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** Bearer (bearerFormat: JWT)
*   **In:** Header

### 9. RESPONSE FORMAT:

*   **200 OK - Successful response:**
    *   Content-Type: `application/json`
    *   Schema:
        ```json
        {
          "success": boolean // Example: true
        }
        ```
    *   Example: `{"success":"true"}`

*   **400 Bad Request:**
    *   Content-Type: `application/json`
    *   Schema:
        ```json
        {
          "statusCode": number, // Example: 400
          "message": string // Example: "Bad Request"
        }
        ```
    *   Example: `{"statusCode":400,"message":"Bad Request"}`

*   **401 Unauthorized:**
    *   Content-Type: `application/json`
    *   Schema:
        ```json
        {
          "statusCode": number, // Example: 401
          "message": string, // Example: "Invalid token: access token is invalid"
          "error": string // Example: "Unauthorized"
        }
        ```
    *   Example: `{"statusCode":401,"message":"Invalid token: access token is invalid","error":"Unauthorized"}`

### 10. PURPOSE:
This endpoint is used to delete a calendar by its ID.
