Here's a structured summary of the "Get Duplicate Contact" API documentation:

---

1.  **ENDPOINT NAME:** Get Duplicate Contact

2.  **CATEGORY:** Contacts (specifically under Search)

3.  **HTTP METHOD:** GET

4.  **ENDPOINT URL:** `/contacts/search/duplicate`

5.  **FULL URL:** `https://services.leadconnectorhq.com/contacts/search/duplicate`

6.  **REQUIRED PARAMETERS:**
    *   `Version` (string): API Version. Possible values: [`2021-07-28`] (Header Parameter)
    *   `locationId` (string): Location Id. Example: `sadadya1u12basyhasd` (Query Parameter)

7.  **OPTIONAL PARAMETERS:**
    *   `number` (string): Phone Number - Pass in URL Encoded form. i.e +1423164516 will become `%2B1423164516`. Example: `+1423164516` (Query Parameter)
    *   `email` (string): Email - Pass in URL Encoded form. i.e test+abc@gmail.com will become `test%2Babc%40gmail.com`. Example: `abc@abc.com` (Query Parameter)

8.  **AUTHENTICATION:**
    *   **Scope(s):** `contacts.readonly`
    *   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
    *   **Token Type(s):** `Sub-Account Token`
    *   **Scheme:** Bearer (JWT format), passed in the `Authorization` header.

9.  **RESPONSE FORMAT:**
    *   **200 OK:**
        *   The documentation indicates a `200` status for a successful response but does not provide a specific schema or example for its body.
    *   **400 Bad Request:**
        *   `statusCode` (number): Example: `400`
        *   `message` (string): Example: `Bad Request`
        *   Example JSON: `{"statusCode":400,"message":"Bad Request"}`
    *   **401 Unauthorized:**
        *   `statusCode` (number): Example: `401`
        *   `message` (string): Example: `Invalid token: access token is invalid`
        *   `error` (string): Example: `Unauthorized`
        *   Example JSON: `{"statusCode":401,"message":"Invalid token: access token is invalid","error":"Unauthorized"}`

10. **PURPOSE:** This endpoint retrieves duplicate contact information based on location settings; if `Allow Duplicate Contact` is disabled, it uses a global unique identifier, otherwise, it prioritizes search by email then phone.

11. **TAGS:** Contacts, Search, Duplicate, Get, Read, Phone, Email, Location, API, HighLevel.
