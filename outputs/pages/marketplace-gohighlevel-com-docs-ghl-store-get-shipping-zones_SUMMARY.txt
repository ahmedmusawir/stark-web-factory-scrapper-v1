Here's a structured summary of the "Get Shipping Zone" API documentation:

### 1. ENDPOINT NAME:
Get Shipping Zone

### 2. CATEGORY:
Store, Shipping Zone Management

### 3. HTTP METHOD:
GET

### 4. ENDPOINT URL:
`/store/shipping-zone/:shippingZoneId`

### 5. FULL URL:
`https://services.leadconnectorhq.com/store/shipping-zone/:shippingZoneId`

### 6. REQUIRED PARAMETERS:
*   `shippingZoneId` (string): ID of the item (shipping zone) that needs to be returned.
*   `altId` (string): Location Id or Agency Id.
*   `altType` (string): Type of the altId. Possible values: [`location`]

### 7. OPTIONAL PARAMETERS:
*   `withShippingRate` (boolean): Include shipping rates array in the response.

### 8. AUTHENTICATION:
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** Bearer (JWT)
*   **In:** Header
*   **Description:** Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account.

### 9. RESPONSE FORMAT:
*   **Successful Response (200 OK):**
    *   **Content Type:** `application/json`
    *   **Schema:**
        *   `status` (boolean): Status of API action (e.g., `true`)
        *   `message` (string): Success message (e.g., `Successfully created`)
        *   `data` (object): Contains the shipping zone details.
            *   `altId` (string): Location Id or Agency Id.
            *   `altType` (string): Type of the altId. Possible values: [`location`]
            *   `name` (string): Name of the shipping zone (e.g., `North zone`).
            *   `countries` (array of objects): List of countries included in the zone.
                *   Each object has:
                    *   `code` (string): Country code (e.g., `US`). (Schema states `number`, but example and possible values indicate `string`).
                    *   `states` (array of objects, optional): List of states for the country. If empty, all states are available.
                        *   Each object has:
                            *   `code` (string): State code (e.g., `VA`).
            *   `_id` (string): The unique identifier for the shipping zone.
            *   `shippingRates` (array of objects, optional): Array of shipping rates under this shipping zone, included if `withShippingRate` is `true`.
                *   Each object has:
                    *   `altId` (string)
                    *   `altType` (string)
                    *   `name` (string)
                    *   `description` (string, optional)
                    *   `currency` (string)
                    *   `amount` (number)
                    *   `conditionType` (string): Possible values: [`none`, `price`, `weight`]
                    *   `minCondition` (number)
                    *   `maxCondition` (number)
                    *   `isCarrierRate` (boolean)
                    *   `shippingCarrierId` (string)
                    *   `percentageOfRateFee` (number, optional)
                    *   `shippingCarrierServices` (array of objects):
                        *   Each object has `name` (string) and `value` (string).
                    *   `_id` (string): Unique identifier for the shipping rate.
                    *   `shippingZoneId` (string): Unique identifier for the parent shipping zone.
                    *   `createdAt` (string): ISO 8601 format.
                    *   `updatedAt` (string): ISO 8601 format.
            *   `createdAt` (string): ISO 8601 format.
            *   `updatedAt` (string): ISO 8601 format.
*   **Error Responses:**
    *   **400 Bad Request:** `{"statusCode":400,"message":"Bad Request"}`
    *   **401 Unauthorized:** `{"statusCode":401,"message":"Invalid token: access token is invalid","error":"Unauthorized"}`
    *   **422 Unprocessable Entity:** `{"statusCode":422,"message":["Unprocessable Entity"],"error":"Unprocessable Entity"}`

### 10. PURPOSE:
This API allows retrieving details for a specific shipping zone by its unique identifier.
