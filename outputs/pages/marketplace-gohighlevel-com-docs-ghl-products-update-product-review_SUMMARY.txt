## STRUCTURED API SUMMARY

### 1. ENDPOINT NAME
Update Product Reviews

### 2. CATEGORY
Products -> Reviews

### 3. HTTP METHOD
PUT

### 4. ENDPOINT URL
`/products/reviews/:reviewId`

### 5. FULL URL
`https://services.leadconnectorhq.com/products/reviews/:reviewId`

### 6. REQUIRED PARAMETERS
*   **Header Parameters:**
    *   `Version` (string): API Version. Possible values: [`2021-07-28`]
*   **Path Parameters:**
    *   `reviewId` (string): Review Id. Example: `6578278e879ad2646715ba9c`
*   **Body Parameters:**
    *   `altId` (string): Location Id or Agency Id. Example: `6578278e879ad2646715ba9c`
    *   `altType` (string): Possible values: [`location`]
    *   `productId` (string): Product Id. Example: `6578278e879ad2646715ba9c`
    *   `status` (string): Status of the review. Example: `approved`
    *   **Conditional Required Parameters (if `reply` array is provided and contains objects):**
        *   `reply[].headline` (string): Headline of the Review. Possible values: `<= 200 characters`. Example: `Amazing product with great quality`
        *   `reply[].comment` (string): Detailed Review of the product. Possible values: `<= 5000 characters`. Example: `This product exceeded my expectations in terms of quality and performance. Highly recommended!`
    *   **Conditional Required Parameters (if `reply[].user` object is provided):**
        *   `reply[].user.name` (string): Name of the customer. Possible values: `non-empty` and `<= 100 characters`. Example: `John Doe`
        *   `reply[].user.email` (string): Email of the customer. Example: `example@example.com`

### 7. OPTIONAL PARAMETERS
*   **Body Parameters:**
    *   `reply` (object[]): Reply of the review.
        *   **Optional Parameters within `reply[].user` (if `reply[].user` is provided):**
            *   `reply[].user.phone` (string): Phone no of the customer. Example: `+1-555-555-5555`
            *   `reply[].user.isCustomer` (boolean): Is the person an admin or customer. Example: `true`
    *   `rating` (number): Rating of the product. Example: `4.5`
    *   `headline` (string): Headline of the Review (top-level, distinct from `reply[].headline`). Example: `Amazing product with great quality`
    *   `detail` (string): Detailed Review of the product. Example: `The product is for sure a must and recommended buy`

### 8. AUTHENTICATION
*   **Scope(s):** `products.write`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** Bearer (JWT)
*   **In:** Header (Authorization header)
*   **Description:** Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account.

### 9. RESPONSE FORMAT
*   **Successful Response (200 OK):**
    ```json
    {
      "status": true,
      "message": "Successfully created"
    }
    ```
    *   `status` (boolean, required): Status of API action.
    *   `message` (string): Success message.
*   **Error Responses:**
    *   **400 Bad Request:**
        ```json
        {
          "statusCode": 400,
          "message": "Bad Request"
        }
        ```
    *   **401 Unauthorized:**
        ```json
        {
          "statusCode": 401,
          "message": "Invalid token: access token is invalid",
          "error": "Unauthorized"
        }
        ```
    *   **422 Unprocessable Entity:**
        ```json
        {
          "statusCode": 422,
          "message": ["Unprocessable Entity"],
          "error": "Unprocessable Entity"
        }
        ```

### 10. PURPOSE
This endpoint allows you to update the status, reply, and other details of a specific product review.
