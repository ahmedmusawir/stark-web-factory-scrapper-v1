### 1. ENDPOINT NAME:

### 2. CATEGORY:
Opportunities

### 3. HTTP METHOD:
GET

### 4. ENDPOINT URL:
`/opportunities/:id`

### 5. FULL URL:
`https://services.leadconnectorhq.com/opportunities/:id`

*   **Version** (string): API Version. Possible values: `2021-07-28`

### 7. OPTIONAL PARAMETERS:
