Here is a structured summary of the "Update Conversation" API documentation:

### 1. ENDPOINT NAME:
Update Conversation

### 2. CATEGORY:
Conversations

### 3. HTTP METHOD:
PUT

### 4. ENDPOINT URL:
`/conversations/:conversationId`

### 5. FULL URL:
`https://services.leadconnectorhq.com/conversations/:conversationId`

### 6. REQUIRED PARAMETERS:

*   **Header Parameters:**
    *   Version (string): API Version. Possible values: `2021-04-15`
*   **Path Parameters:**
    *   conversationId (string): Conversation ID as string. Example: `tDtDnQdgm2LXpyiqYvZ6`
*   **Body Parameters:**
    *   locationId (string): Location ID as string. Example: `tDtDnQdgm2LXpyiqYvZ6`

### 7. OPTIONAL PARAMETERS:

*   **Body Parameters:**
    *   unreadCount (number): Count of unread messages in the conversation. Example: `1`
    *   starred (boolean): Starred status of the conversation. Example: `true`
    *   feedback (object): Not further described in the body parameters but present in the example.

### 8. AUTHENTICATION:

*   **Scope(s):** `conversations.write`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** Bearer (JWT)

### 9. RESPONSE FORMAT:

*   **Status Code:** 200 (Successful response)
*   **Content Type:** `application/json`
