Here is a structured summary of the API documentation for "List Calendar Resources":

### 1. ENDPOINT NAME:
List Calendar Resources

### 2. CATEGORY:
Calendars

### 3. HTTP METHOD:
GET

### 4. ENDPOINT URL:
`/calendars/resources/:resourceType`

### 5. FULL URL:
`https://services.leadconnectorhq.com/calendars/resources/:resourceType`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters:**
    *   `Version` (string): API Version. Possible values: `2021-04-15`.
*   **Path Parameters:**
    *   `resourceType` (string): Calendar Resource Type. Possible values: `equipments`, `rooms`.
*   **Query Parameters:**
    *   `locationId` (string): The ID of the location to filter resources by.
    *   `limit` (number): The maximum number of resources to return.
    *   `skip` (number): The number of resources to skip (for pagination).

### 7. OPTIONAL PARAMETERS:
Not specified in documentation (all request parameters are marked as required).

### 8. AUTHENTICATION:
*   **Scope(s):** `calendars/resources.readonly`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** `bearer`
*   **Bearer Format:** `JWT`
*   **In:** `header` (e.g., `Authorization: Bearer <TOKEN>`)

### 9. RESPONSE FORMAT:
*   **200 OK (application/json):**
    *   **Description:** Calendar resources listed.
    *   **Schema:** An array of Calendar Resource objects.
        *   `locationId` (string, required): Location ID of the resource.
        *   `name` (string, required): Name of the resource. Example: `yoga room`.
        *   `resourceType` (string, required): Type of the resource. Possible values: `equipments`, `rooms`.
        *   `isActive` (boolean, required): Whether the resource is active.
        *   `description` (string, optional): Description of the resource.
        *   `quantity` (number, optional): Quantity of the resource.
        *   `outOfService` (number, optional): Indicates if the resource is out of service. Example: `0`.
        *   `capacity` (number, optional): Capacity of the resource. Example: `85`.
        *   `calendarIds` (string[], required): An array of Calendar IDs associated with the resource. Example: `["Jsj0xnlDDjw0SuvX1J13","oCM5feFC86FAAbcO7lJK"]`.
    *   **Example:**
        ```json
        [
          {
            "locationId": "string",
            "name": "yoga room",
            "resourceType": "equipments",
            "isActive": true,
            "description": "string",
            "quantity": 0,
            "outOfService": 0,
            "capacity": 85,
            "calendarIds": ["Jsj0xnlDDjw0SuvX1J13", "oCM5feFC86FAAbcO7lJK"]
          }
        ]
        ```
*   **400 Bad Request (application/json):**
    *   **Schema:** `statusCode` (number, e.g., `400`), `message` (string, e.g., `Bad Request`).
*   **401 Unauthorized (application/json):**
    *   **Schema:** `statusCode` (number, e.g., `401`), `message` (string, e.g., `Invalid token: access token is invalid`), `error` (string, e.g., `Unauthorized`).

### 10. PURPOSE:
This endpoint retrieves a paginated list of calendar resources (rooms or equipment) for a specific location, filtered by the resource type.
