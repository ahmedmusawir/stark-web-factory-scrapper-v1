Here is a structured summary of the API documentation for "Get an schedule":

---

### 1. ENDPOINT NAME:
Get an schedule

### 2. CATEGORY:
Invoice Schedule

### 3. HTTP METHOD:
GET

### 4. ENDPOINT URL:
`/invoices/schedule/:scheduleId`

### 5. FULL URL:
`https://services.leadconnectorhq.com/invoices/schedule/:scheduleId`

### 6. REQUIRED PARAMETERS:
*   **Version** (string): API Version
    *   Possible values: [`2021-07-28`]
    *   Location: Header
*   **scheduleId** (string): Schedule Id
    *   Example: `6578278e879ad2646715ba9c`
    *   Location: Path
*   **altId** (string): location Id / company Id based on altType
    *   Example: `6578278e879ad2646715ba9c`
    *   Location: Query
*   **altType** (string): Alt Type
    *   Possible values: [`location`]
    *   Location: Query

### 7. OPTIONAL PARAMETERS:
Not specified in documentation for request parameters. All listed request parameters are marked as required.

### 8. AUTHENTICATION:
*   **Scope(s)**: `invoices/schedule.readonly`
*   **Auth Method(s)**: `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s)**: `Sub-Account Token`, `Agency Token`
*   **Scheme**: Bearer
*   **Bearer Format**: JWT
*   **Location**: Header
*   **Description**: Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account.
