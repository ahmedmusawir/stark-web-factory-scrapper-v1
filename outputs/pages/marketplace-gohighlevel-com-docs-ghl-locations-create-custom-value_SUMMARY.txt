## STRUCTURED SUMMARY: Highlevel API - Create Custom Value

### 1. ENDPOINT NAME:
Create Custom Value

### 2. CATEGORY:
Sub-Account (Formerly location) / Custom Value

### 3. HTTP METHOD:
POST

### 4. ENDPOINT URL:
`/locations/:locationId/customValues`

### 5. FULL URL:
`https://services.leadconnectorhq.com/locations/:locationId/customValues`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters:**
    *   Version (string): API Version. Possible values: [`2021-07-28`]
*   **Path Parameters:**
    *   locationId (string): Location Id. Example: `ve9EPM428h8vShlRW1KT`
*   **Body Parameters:**
    *   name (string): Name of the custom value. Example: `Custom Field Name`
    *   value (string): Value of the custom value. Example: `Value`

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:
*   **Scope(s):** `locations/customValues.write`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** Bearer
*   **Bearer Format:** JWT
*   **Description:** Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account.

### 9. RESPONSE FORMAT:
*   **Status Code:** `201` (Successful response)
*   **Content Type:** `application/json`
*   **Schema:**
    ```json
    {
      "customValue": {
        "id": "string",
        "name": "string",
        "fieldKey": "string",
        "value": "string",
        "locationId": "string"
      }
    }
    ```
*   **Example (201 Successful Response):**
    ```json
    {"customValue":{"id":"rWQ709Pb62syqGLceg1x","name":"Custom Field","fieldKey":"{{ custom_values.custom_field }}","value":"Value","locationId":"rWQ709Pb6dasyqGLceg1x"}}
    ```
*   **Error Responses:**
    *   `400 Bad Request`
    *   `401 Unauthorized`
    *   `422 Unprocessable Entity`

### 10. PURPOSE:
This endpoint allows creating a new custom value for a specific sub-account (formerly location) within the Highlevel platform.

### 11. TAGS:
Sub-Account, Location, Custom Value, Create, POST, HighLevel API, GHL, Marketplace Modules

Code examples are available for `curl`, `nodejs`, `python`, `php`, `java`, `go`, `ruby`, and `powershell`.
