Here is a structured summary of the provided API documentation:

### 1. ENDPOINT NAME:
Bulk Delete Social Planner Posts

### 2. CATEGORY:
Social Planner

### 3. HTTP METHOD:
POST

### 4. ENDPOINT URL:
`/social-media-posting/:locationId/posts/bulk-delete`

### 5. FULL URL:
`https://services.leadconnectorhq.com/social-media-posting/:locationId/posts/bulk-delete`

### 6. REQUIRED PARAMETERS:

*   **Path Parameters:**
    *   locationId (string): The ID of the location (sub-account) to which the posts belong.
*   **Header Parameters:**
    *   Version (string): API Version. Possible values: `2021-07-28`.
*   **Body Parameters:**
    *   postIds (string[]): An array of post IDs to be deleted. (Maximum 50 posts per request).

### 7. OPTIONAL PARAMETERS:
None specified in documentation

### 8. AUTHENTICATION:
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** Bearer (JWT format)
*   **In:** Header (e.g., `Authorization: Bearer <TOKEN>`)

### 9. RESPONSE FORMAT:

*   **201 Success:**
    ```json
    {
      "success": true,
      "statusCode": 201,
      "message": "Posts Deleted Successfully",
      "results": {
        "message": "Posts deleted successfully",
        "deletedCount": 10
      }
    }
    ```
    *   `success` (boolean): Indicates success or failure.
    *   `statusCode` (number): HTTP status code (e.g., 201).
    *   `message` (string): A descriptive message (e.g., "Posts Deleted Successfully").
    *   `results` (object): Contains a message and the count of deleted posts.
        *   `message` (string): "Posts deleted successfully"
        *   `deletedCount` (number): The number of posts successfully deleted.

*   **400 Bad Request:**
    ```json
    {
      "statusCode": 400,
      "message": "Bad Request"
    }
    ```
    (e.g., "Cannot delete more than 50 posts at a time.")

*   **401 Unauthorized:**
    ```json
    {
      "statusCode": 401,
      "message": "Invalid token: access token is invalid",
      "error": "Unauthorized"
    }
    ```

*   **422 Unprocessable Entity:**
    ```json
    {
      "statusCode": 422,
      "message": ["Unprocessable Entity"],
      "error": "Unprocessable Entity"
    }
    ```
    (e.g., "No posts found with the given IDs.")

*   **500 Internal Server Error:** Not specified in detail, but implies a generic server error.

### 10. PURPOSE:
This endpoint allows users to delete multiple social media posts efficiently by providing a list of their unique identifiers.
