## STRUCTURED SUMMARY

### 1. ENDPOINT NAME:
Starts OAuth For Tiktok Account

### 2. CATEGORY:
Social Planner (Oauth | Tiktok)

### 3. HTTP METHOD:
GET

### 4. ENDPOINT URL:
`/social-media-posting/oauth/tiktok/start`

### 5. FULL URL:
`https://services.leadconnectorhq.com/social-media-posting/oauth/tiktok/start`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters:**
    *   `Version` (string): API Version. Possible values: [`2021-07-28`]
*   **Query Parameters:**
    *   `locationId` (string): Location Id. Example: `w37swmmLbA02zgqKPpxITe2`
    *   `userId` (string): User Id. Example: `u37swmmLbA02zgqKPpxITe2`

### 7. OPTIONAL PARAMETERS:
*   **Query Parameters:**
    *   `page` (string): Page. Example: `integration`
    *   `reconnect` (string): Reconnect. Example: `true`

### 8. AUTHENTICATION:
*   **Scope(s):** `socialplanner/oauth.readonly`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`

### 9. RESPONSE FORMAT:
The API call itself triggers a redirect to the Tiktok login OAuth screen. A direct JSON response (200 status code) is not returned to the initial API request. Instead, upon successful user login and authorization on Tiktok, an event message is sent to the initiating window object.

**Successful OAuth Event Data Response (via `window.addEventListener('message', ...)`)**:
*   **Status Code:** N/A (redirect followed by event message)
*   **Structure:**
    ```json
    {
      "actionType": "string", // Ex: "close"
      "page": "string",       // Ex: "social-media-posting"
      "platform": "string",   // Ex: "tiktok"
      "placement": "string",  // Ex: "placement"
      "accountId": "string",  // Ex: "658a9b6833b91e0ecb8f3958"
      "reconnectAccounts": ["string"] // Ex: ["658a9b6833b91e0ecb834acd", "efd2daa9b6833b91e0ecb8f3511"]
    }
    ```

**Error Responses:**
*   **400 Bad Request:**
    ```json
    {"statusCode":400,"message":"Bad Request"}
    ```
*   **401 Unauthorized:**
    ```json
    {"statusCode":401,"message":"Invalid token: access token is invalid","error":"Unauthorized"}
    ```
*   **422 Unprocessable Entity:**
    ```json
    {"statusCode":422,"message":["Unprocessable Entity"],"error":"Unprocessable Entity"}
    ```

### 10. PURPOSE:
This endpoint initiates the OAuth authorization flow for connecting a Tiktok account, redirecting the user to the Tiktok login page, and upon successful login, provides account-related event data via a window message listener.

Social Planner, TikTok, OAuth, Authorization, Account, Connect, Social Media, Redirect
