Here's a structured summary of the "Update Task" API documentation:

### 1. ENDPOINT NAME:
Update Task

### 2. CATEGORY:
Contacts (specifically, Tasks under Contacts)

### 3. HTTP METHOD:
PUT

### 4. ENDPOINT URL:
`/contacts/:contactId/tasks/:taskId`

### 5. FULL URL:
`https://services.leadconnectorhq.com/contacts/:contactId/tasks/:taskId`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters:**
    *   Version (string): API Version (Possible values: `2021-07-28`)
*   **Path Parameters:**
    *   contactId (string): Contact Id (Example: `sx6wyHhbFdRXh302LLNR`)
    *   taskId (string): Task Id (Example: `ocQHyuzHvysMo5N5VsXc`)

### 7. OPTIONAL PARAMETERS:
*   **Body Parameters:** (The request body is required, but individual fields within it are optional, allowing partial updates)
    *   title (string): The title of the task. Example: `First Task`
    *   body (string): The description or body of the task. Example: `loram ipsum`
    *   dueDate (string): The due date of the task in ISO 8601 format. Example: `2020-10-25T11:00:00Z`
    *   completed (boolean): Indicates whether the task is completed. Example: `true`
    *   assignedTo (string): The ID of the user to whom the task is assigned. Example: `hxHGVRb1YJUscrCB8eXK`

### 8. AUTHENTICATION:
*   **Scope(s):** `contacts.write`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Authorization Header:** `Bearer <TOKEN>` (Bearer format: JWT)

### 9. RESPONSE FORMAT:
*   **200 OK (Successful response)**
    *   **Content-Type:** `application/json`
    *   **Schema:**
        ```json
        {
            "task": {
                "id": "string",
                "title": "string",
                "body": "string",
                "assignedTo": "string",
                "dueDate": "string",
                "completed": "boolean",
                "contactId": "string"
            }
        }
        ```
    *   **Example:**
        ```json
        {
            "task": {
                "id": "lJpzYrWdpkC2hX6t2yue",
                "title": "test",
                "body": "testing",
                "assignedTo": "tesTUcmRxWrjqzJS8EjkxNKting",
                "dueDate": "2021-07-08T02:30:00.000Z",
                "completed": true,
                "contactId": "lJpzYrWdpkC2hX6t2yue"
            }
        }
        ```
*   **400 Bad Request**
    *   **Content-Type:** `application/json`
    *   **Schema:** `{"statusCode": number, "message": "string"}`
    *   **Example:** `{"statusCode":400,"message":"Bad Request"}`
*   **401 Unauthorized**
    *   **Content-Type:** `application/json`
    *   **Schema:** `{"statusCode": number, "message": "string", "error": "string"}`
    *   **Example:** `{"statusCode":401,"message":"Invalid token: access token is invalid","error":"Unauthorized"}`
*   **422 Unprocessable Entity**
    *   **Content-Type:** `application/json`
    *   **Schema:** `{"statusCode": number, "message": "string[]", "error": "string"}`
    *   **Example:** `{"statusCode":422,"message":["Unprocessable Entity"],"error":"Unprocessable Entity"}`

### 10. PURPOSE:
This endpoint allows an application to update the details of an existing task associated with a specific contact in HighLevel by providing the contact ID and task ID.
