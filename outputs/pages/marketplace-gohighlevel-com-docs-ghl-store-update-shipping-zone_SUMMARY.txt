Here's a structured summary of the "Update Shipping Zone" API documentation:

### 1. ENDPOINT NAME
Update Shipping Zone

### 2. CATEGORY
Store

### 3. HTTP METHOD
PUT

### 4. ENDPOINT URL
`/store/shipping-zone/:shippingZoneId`

### 5. FULL URL
`https://services.leadconnectorhq.com/store/shipping-zone/:shippingZoneId`

### 6. REQUIRED PARAMETERS

*   **Path Parameters:**
    *   `shippingZoneId` (string): ID of the item that needs to be returned.
*   **Body Parameters (application/json):**
    *   `altId` (string): Location Id or Agency Id.
    *   `altType` (string): Possible values: [`location`].
    *   `name` (string): Name of the shipping zone.
    *   `countries` (object[]): List of countries that are available.
        *   `countries[].code` (number): Country code. Possible values are an extensive list of country codes (e.g., `US`, `CA`, `AF`).

### 7. OPTIONAL PARAMETERS

*   **Body Parameters (application/json):**
    *   `countries[].states` (object[]): List of states that are available. If states is empty, then all states are available.
        *   `countries[].states[].code` (string): State code. Possible values are an extensive list of state codes (e.g., `AL`, `VA`, `AB`).

### 8. AUTHENTICATION
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Header:** `Authorization: Bearer <TOKEN>` (Bearer format: JWT)
