Here is a structured summary of the provided API documentation:

### 1. ENDPOINT NAME:
Remove Action from Agent

### 2. CATEGORY:
Conversation AI - Actions

### 3. HTTP METHOD:
DELETE

### 4. ENDPOINT URL:
`/conversation-ai/agents/:agentId/actions/:actionId`

### 5. FULL URL:
`https://services.leadconnectorhq.com/conversation-ai/agents/:agentId/actions/:actionId`

### 6. REQUIRED PARAMETERS:
*   `Version` (string): API Version (Possible values: `2021-04-15`) - **Header Parameter**
*   `actionId` (string): The unique identifier of the action ID Attached to the agent - **Path Parameter**
*   `agentId` (string): The unique identifier of the agent ID - **Path Parameter**

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:
*   **Scope(s):** `conversation-ai.write`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** `bearer` (JWT)
*   **In:** `header` (e.g., `Authorization: Bearer <TOKEN>`)
*   **Description:** Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account.

### 10. PURPOSE:
Permanently deletes an action, removing it from all associated agents, and this operation cannot be undone.
