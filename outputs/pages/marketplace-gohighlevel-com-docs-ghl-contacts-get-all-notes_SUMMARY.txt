Here is a structured summary of the provided API documentation:

### 1. ENDPOINT NAME:
Get All Notes

### 2. CATEGORY:
Contacts (specifically, Notes within Contacts)

### 3. HTTP METHOD:
GET

### 4. ENDPOINT URL:
`/contacts/:contactId/notes`

### 5. FULL URL:
`https://services.leadconnectorhq.com/contacts/:contactId/notes`

### 6. REQUIRED PARAMETERS:
*   `Version` (string): API Version. Possible values: [`2021-07-28`]
*   `contactId` (string): Contact Id. Example: `sx6wyHhbFdRXh302LLNR`

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:
*   **Scope(s):** `contacts.readonly`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** `bearer`
*   **Bearer Format:** `JWT`
*   **In:** `header`

### 9. RESPONSE FORMAT:

*   **200 OK (Successful response):**
    *   **Content-Type:** `application/json`
    *   **Schema:**
        ```json
        {
          "notes": [
            {
              "id": "string",  // Example: "HGPcayliwcdoUFzvbTok"
              "body": "string", // Example: "lorem ipsum"
              "userId": "string", // Example: "TUcmRxWrjqzJS8EjkxNK"
              "dateAdded": "string", // Example: "2021-07-08T12:02:11.285Z"
              "contactId": "string" // Example: "TUcmRxWrjqzJS8EjkxNK"
            }
          ]
        }
        ```
    *   **Example:**
        ```json
        {"notes":[{"id":"HGPcayliwcdoUFzvbTok","body":"lorem ipsum","userId":"TUcmRxWrjqzJS8EjkxNK","dateAdded":"2021-07-08T12:02:11.285Z","contactId":"TUcmRxWrjqzJS8EjkxNK"}]}
        ```
*   **400 Bad Request:**
    *   **Content-Type:** `application/json`
    *   **Schema:**
        ```json
        {
          "statusCode": "number", // Example: 400
          "message": "string"   // Example: "Bad Request"
        }
        ```
    *   **Example:**
        ```json
        {"statusCode":400,"message":"Bad Request"}
        ```
*   **401 Unauthorized:**
    *   **Content-Type:** `application/json`
    *   **Schema:**
        ```json
        {
          "statusCode": "number", // Example: 401
          "message": "string",   // Example: "Invalid token: access token is invalid"
          "error": "string"     // Example: "Unauthorized"
        }
        ```
    *   **Example:**
        ```json
        {"statusCode":401,"message":"Invalid token: access token is invalid","error":"Unauthorized"}
        ```

### 10. PURPOSE:
This endpoint retrieves all notes associated with a specific contact using its ID.
