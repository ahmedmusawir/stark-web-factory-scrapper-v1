Here is a structured summary of the API documentation for "Delete Estimate Template":

### 1. ENDPOINT NAME:
Delete Estimate Template

### 2. CATEGORY:
Invoice/Estimate Management

### 3. HTTP METHOD:
DELETE

### 4. ENDPOINT URL:
`/invoices/estimate/template/:templateId`

### 5. FULL URL:
`https://services.leadconnectorhq.com/invoices/estimate/template/:templateId`

### 6. REQUIRED PARAMETERS:

*   **Header Parameters:**
    *   `Version` (string): API Version. Possible values: `2021-07-28`
*   **Path Parameters:**
    *   `templateId` (string): Template Id. Example: `5f9d6d8b1b2d2c001f2d9e4b`
*   **Body Parameters:**
    *   `altId` (string): Location Id or Agency Id. Example: `6578278e879ad2646715ba9c`
    *   `altType` (string): Possible values: `location`

### 7. OPTIONAL PARAMETERS:
Not specified in documentation for the request body.

### 8. AUTHENTICATION:
*   **Scope(s):** `invoices/estimate.write`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`, `Agency Token`
*   **Scheme:** `bearer`
*   **Bearer Format:** `JWT`
*   **In:** `header` (Authorization)

### 9. RESPONSE FORMAT:

*   **200 OK - Successfully deleted**
    *   **Schema:** Returns the deleted estimate template object.
        *   `altId` (string): Location Id or Agency Id
        *   `altType` (string): Possible values: `location`
        *   `_id` (string): Unique identifier
        *   `liveMode` (boolean): Indicates if it is in live mode
        *   `deleted` (boolean): Indicates if deleted
        *   `name` (string): Name
        *   `currency` (string): Currency code
        *   `businessDetails` (object): Business details associated with the estimate
            *   `logoUrl` (string)
            *   `name` (string)
            *   `address` (object)
                *   `addressLine1` (string)
                *   `city` (string)
                *   `state` (string)
                *   `countryCode` (string)
                *   `postalCode` (string)
            *   `phoneNo` (string)
            *   `website` (string)
            *   `customValues` (array of objects)
                *   `name` (string)
                *   `fieldKey` (string)
                *   `id` (string)
                *   `value` (string)
        *   `items` (array of objects): An array of items
            *   `taxes` (array of objects, optional)
                *   `_id` (string)
                *   `name` (string)
                *   `rate` (number)
                *   `calculation` (string)
            *   `taxInclusive` (boolean)
            *   `_id` (string)
            *   `description` (string)
            *   `currency` (string)
            *   `productId` (string)
            *   `priceId` (string)
            *   `amount` (number)
            *   `qty` (number)
            *   `name` (string)
            *   `type` (string)
        *   `discount` (object, optional): Discount details for the estimate template
            *   `value` (number): Discount Value (Default: `0`)
            *   `type` (string): Discount type (Possible values: `percentage`, `fixed`; Default: `percentage`)
            *   `validOnProductIds` (array of strings): Product Ids on which discount is applicable
        *   `title` (string): Title
        *   `estimateNumberPrefix` (string): Estimate number prefix
        *   `attachments` (array of objects, optional): Attachments
            *   `id` (string)
            *   `name` (string)
            *   `url` (string)
            *   `type` (string)
            *   `size` (number)
        *   `updatedBy` (string): User Id of who last updated
        *   `total` (number): Total amount
        *   `createdAt` (date-time): Timestamp when created
        *   `updatedAt` (date-time): Timestamp when last updated
        *   `__v` (number): Version number
        *   `automaticTaxesEnabled` (boolean): Indicates if automatic taxes are enabled for this estimate
        *   `termsNotes` (string): Terms and conditions for the estimate, supports HTML markup
