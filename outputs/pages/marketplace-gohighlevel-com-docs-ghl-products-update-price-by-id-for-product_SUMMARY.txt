Here is a structured summary of the API documentation for "Update Price by ID for a Product":

### 1. ENDPOINT NAME:
Update Price by ID for a Product

### 2. CATEGORY:
Products (Prices)

### 3. HTTP METHOD:
PUT

### 4. ENDPOINT URL:
`/products/:productId/price/:priceId`

### 5. FULL URL:
`https://services.leadconnectorhq.com/products/:productId/price/:priceId`

### 6. REQUIRED PARAMETERS:

*   **Header Parameters:**
    *   `Version` (string): API Version (Possible values: `2021-07-28`)

*   **Path Parameters:**
    *   `productId` (string): ID of the product that needs to be used.
    *   `priceId` (string): ID of the price that needs to be returned.

*   **Body Parameters:**
    *   `name` (string): The name of the price.
    *   `type` (string): The type of the price. (Possible values: `one_time`, `recurring`)
    *   `currency` (string): The currency of the price.
    *   `amount` (number): The amount of the price. (min: 0)
    *   `locationId` (string): The unique identifier of the location associated with the price.
    *   `recurring.interval` (string): The interval at which the recurring event occurs. (Conditionally required: if `type` is `recurring` and the `recurring` object is provided in the request body). (Possible values: `day`, `month`, `week`, `year`)
    *   `recurring.intervalCount` (number): The number of intervals between each occurrence of the event. (Conditionally required: if `type` is `recurring` and the `recurring` object is provided in the request body).

### 7. OPTIONAL PARAMETERS:

*   **Body Parameters:**
    *   `recurring` (object): The recurring details of the price (if `type` is `recurring`). If this object is included, `interval` and `intervalCount` are required fields within it.
    *   `description` (string): A brief description of the price.
    *   `membershipOffers` (object[]): An array of membership offers associated with the price. If an object is included in this array, the following fields are required within it:
        *   `label` (string): Membership offer label.
        *   `value` (string): Membership offer value.
        *   `_id` (string): The unique identifier for the membership offer.
    *   `trialPeriod` (number): The trial period duration in days.
    *   `totalCycles` (number): The total number of billing cycles for the price. (min: 1)
    *   `setupFee` (number): The setup fee for the price.
    *   `variantOptionIds` (string[]): An array of variant option IDs associated with the price.
    *   `compareAtPrice` (number): The compare at price for the price.
    *   `userId` (string): The unique identifier of the user who created the price.
    *   `meta` (object): Additional metadata associated with the price. If this object is included, the following fields are required within it:
        *   `source` (string): The source of the price. (Possible values: `stripe`, `woocommerce`, `shopify`)
        *   `stripePriceId` (string): The Stripe price ID associated with the price.
        *   `internalSource` (string): The internal source of the price. (Possible values: `agency_plan`, `funnel`, `membership`, `communities`, `gokollab`, `calendar`)
        *   `sourceId` (string): The id of the source of the price from where it is imported.
    *   `trackInventory` (boolean): Need to track inventory stock quantity.
    *   `availableQuantity` (number): Available inventory stock quantity.
    *   `allowOutOfStockPurchases` (boolean): Continue selling when out of stock.
    *   `sku` (string): The unique identifier of the SKU associated with the price.
    *   `shippingOptions` (object): Shipping options of the Price.
        *   `weight` (object): Weight options of the product. If this object is included, the following fields are required within it:
            *   `value` (number): Actual weight of the product.
            *   `unit` (string): Weight unit of the product. (Possible values: `kg`, `lb`, `g`, `oz`)
        *   `dimensions` (object): Dimensions of the product. If this object is included, the following fields are required within it:
            *   `height` (number): Height of the price.
            *   `width` (number): Width of the price.
            *   `length` (number): Length of the price.
            *   `unit` (string): Unit of the price dimensions. (Possible values: `cm`, `in`, `m`)
    *   `isDigitalProduct` (boolean): Is the product a digital product.
    *   `digitalDelivery` (string[]): Digital delivery options.

### 8. AUTHENTICATION:
*   **Scope(s):** `products/prices.write`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`, `Agency Token`
*   **Scheme:** Bearer (JWT)

The "Update Price by ID for a Product" API allows modifying information for a specific price associated with a particular product using its unique identifier.
