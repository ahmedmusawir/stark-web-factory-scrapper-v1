```
1. ENDPOINT NAME: Get all knowledge bases for a location by location Id (paginated)

2. CATEGORY: Knowledge Base

3. HTTP METHOD: GET

4. ENDPOINT URL: /knowledge-bases/

5. FULL URL: https://services.leadconnectorhq.com/knowledge-bases/

6. REQUIRED PARAMETERS:
   - Authorization (string): Access Token (Example: Bearer 9c48df2694a849b6089f9d0d3513efe)
   - Version (string): API Version (Possible values: `2021-04-15`)
   - locationId (string): Not specified in documentation (ID of the location for which to retrieve knowledge bases)

7. OPTIONAL PARAMETERS:
   - query (string): search query for knowledge base name
   - limit (number): Maximum number of knowledge bases to return (Default value: `20`, Example: 20)
   - lastKnowledgeBaseId (string): ID of the last knowledge base from the previous page (for pagination) (Example: ZwTB8S0yo0FIBY6OPZTD)

8. AUTHENTICATION:
   - Auth Method(s): `OAuth Access Token`, `Private Integration Token`
   - Token Type(s): `Sub-Account Token`
   - Scheme: `bearer`
   - Format: `JWT`
   - In: `header`

9. RESPONSE FORMAT:
   - Status Code: `200` (Paginated knowledge bases retrieved successfully)
   - Content Type: `application/json`
   - Schema:
     ```json
     {
       "success": boolean,
       "data": {
         "knowledgeBases": [
           {
             "id": string,
             "name": string,
             "createdAt": string
           }
         ],
         "activeCount": number,
         "hasMore": boolean,
         "lastKnowledgeBaseId": string
       }
     }
     ```
   - Example:
     ```json
     {
       "success": true,
       "data": {
         "knowledgeBases": [
           {
             "id": "ZwTB8S0yo0FIBY6OPZTD",
             "name": "bot training kb",
             "createdAt": "2025-08-02T20:26:57.057Z"
           }
         ],
         "activeCount": 16,
         "hasMore": true,
         "lastKnowledgeBaseId": "ZwTB8S0yo0FIBY6OPZTD"
       }
     }
     ```
   - Other possible responses:
     - `400` (Bad Request): `{"statusCode":400,"message":"Bad Request"}`
     - `401` (Unauthorized): `{"statusCode":401,"message":"Invalid token: access token is invalid","error":"Unauthorized"}`

10. PURPOSE: This endpoint retrieves all knowledge bases associated with a given location ID, with support for pagination.
