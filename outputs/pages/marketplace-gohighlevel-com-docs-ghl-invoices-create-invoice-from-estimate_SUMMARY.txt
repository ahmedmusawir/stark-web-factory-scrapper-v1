Here's a structured summary of the API documentation:

### 1. ENDPOINT NAME:
Create Invoice from Estimate

### 2. CATEGORY:
Invoices / Estimates

### 3. HTTP METHOD:
POST

### 4. ENDPOINT URL:
`/invoices/estimate/:estimateId/invoice`

### 5. FULL URL:
`https://services.leadconnectorhq.com/invoices/estimate/:estimateId/invoice`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters:**
    *   `Version` (string): API Version. Possible values: [`2021-07-28`]
*   **Path Parameters:**
    *   `estimateId` (string): Estimate Id. Example: `5f9d6d8b1b2d2c001f2d9e4b`
*   **Body Parameters (application/json):**
    *   `altId` (string): Location Id or Agency Id. Example: `6578278e879ad2646715ba9c`
    *   `altType` (string): Possible values: [`location`]
    *   `markAsInvoiced` (boolean): Mark Estimate as Invoiced. Example: `true`

### 7. OPTIONAL PARAMETERS:
*   **Body Parameters (application/json):**
    *   `version` (string): Version of the update request. Possible values: [`v1`, `v2`]. Example: `v2`

### 8. AUTHENTICATION:
*   **Scope(s):** `invoices/estimate.write`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`, `Agency Token`
*   **Scheme:** Bearer (JWT) in header

### 9. RESPONSE FORMAT:
*   **Status Code:** `200` (Successfully Created)
*   **Content Type:** `application/json`
*   **Schema:** An object containing `estimate` and `invoice` details.
    *   `estimate` (object): Contains comprehensive details of the estimate, including `_id`, `altId`, `altType`, `name`, `currency`, `businessDetails`, `items`, `total`, `contactDetails`, `issueDate`, `expiryDate`, `createdAt`, `updatedAt`, `automaticTaxesEnabled`, `meta`, `frequencySettings`, `autoInvoice`, and more.
    *   `invoice` (object): Contains details of the newly created invoice, including `_id`, `status`, `liveMode`, `amountPaid`, `altId`, `altType`, `name`, `businessDetails`, `invoiceNumber`, `currency`, `contactDetails`, `issueDate`, `dueDate`, `discount`, `invoiceItems`, `total`, `amountDue`, `createdAt`, `updatedAt`, `automaticTaxesEnabled`, `automaticTaxesCalculated`, and `paymentSchedule`.

### 10. PURPOSE:
This endpoint creates a new invoice by converting an existing estimate.
