Here's a structured summary of the "Update Blog Post" API documentation:

### 1. ENDPOINT NAME:
Update Blog Post

### 2. CATEGORY:
Blogs

### 3. HTTP METHOD:
PUT

### 4. ENDPOINT URL:
`/blogs/posts/:postId`

### 5. FULL URL:
`https://services.leadconnectorhq.com/blogs/posts/:postId`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters:**
    *   `Version (string)`: API Version (Possible value: `2021-07-28`)
*   **Body Parameters:**
    *   `title (string)`: Your blog title
    *   `locationId (string)`: Location ID
    *   `blogId (string)`: You can find the blog id from blog site dashboard link
    *   `imageUrl (string)`: Image URL
    *   `description (string)`: A short description
    *   `rawHTML (string)`: Your blog content
    *   `status (string)`: Publication status of the blog post (Possible values: `DRAFT`, `PUBLISHED`, `SCHEDULED`, `ARCHIVED`)
    *   `imageAltText (string)`: Alt text for your blog image
    *   `categories (string[])`: Array of category IDs, which can be obtained from the category get API call.
    *   `author (string)`: Author ID, which can be obtained from the author get API call.
    *   `urlSlug (string)`: The URL slug for the blog post.
    *   `publishedAt (string)`: Provide ISO timestamp

### 7. OPTIONAL PARAMETERS:
*   **Body Parameters:**
    *   `tags (string[])`: Array of tags associated with the blog post.
    *   `canonicalLink (string)`: Canonical link of the blog post.

### 8. AUTHENTICATION:
*   **Scope(s):** `blogs/post-update.write`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** Bearer (JWT format)
*   **In:** Header (Authorization header)

### 9. RESPONSE FORMAT:
*   **Status Code:** `200` (Successful response)
*   **Content Type:** `application/json`
*   **Structure:** An object containing a key `updatedBlogPost`. The `updatedBlogPost` object includes:
    *   `categories (string[])`: Array of category IDs.
    *   `tags (string[])`: Array of tags.
    *   `archived (boolean)`: Indicates if the blog post is archived.
    *   `_id (string)`: Unique identifier of the blog post.
    *   `title (string)`: Title of the blog post.
    *   `description (string)`: Description of the blog post.
    *   `imageUrl (string)`: URL of the image.
    *   `status (string)`: Publication status.
    *   `imageAltText (string)`: Alternative text for the image.
    *   `urlSlug (string)`: URL slug.
    *   `canonicalLink (string)`: Canonical link.
    *   `author (string)`: Identifier of the author.
    *   `publishedAt (string)`: Timestamp when published.
    *   `updatedAt (string)`: Timestamp when last updated.

### 10. PURPOSE:
The "Update Blog Post" API allows you to update an existing blog post for any given blog site.
