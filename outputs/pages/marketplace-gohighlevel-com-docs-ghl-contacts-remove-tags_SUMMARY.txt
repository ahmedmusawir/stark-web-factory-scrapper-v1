## STRUCTURED API SUMMARY

### 1. ENDPOINT NAME:
Remove Tags

### 2. CATEGORY:
Contacts

### 3. HTTP METHOD:
DELETE

### 4. ENDPOINT URL:
/contacts/:contactId/tags

### 5. FULL URL:
https://services.leadconnectorhq.com/contacts/:contactId/tags

### 6. REQUIRED PARAMETERS:
*   **Header Parameters:**
    *   Version (string): API Version. Possible values: [`2021-07-28`]
*   **Path Parameters:**
    *   contactId (string): Contact Id. Example: `sx6wyHhbFdRXh302LLNR`
*   **Body Parameters (application/json):**
    *   tags (string[]): An array of tags to be removed from the contact. Example: `["minim","velit magna"]`

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:
*   **Scope(s):** `contacts.write`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** `bearer` (JWT format)
*   **In:** `header` (`Authorization: Bearer <TOKEN>`)
*   **Description:** Use the Access Token generated with user type as Sub-Account OR Private Integration Token of Sub-Account.

### 9. RESPONSE FORMAT:
*   **200 Successful Response (application/json):**
    *   **Status Code:** `200`
    *   **Schema:**
        ```json
        {
          "tags": ["string"]
        }
        ```
    *   **Example:**
        ```json
        {"tags":["minim","velit magna"]}
        ```
    (Note: This response seems to echo back the tags that were processed/removed, or the current state of tags after removal.)

*   **Error Responses:**
    *   **400 Bad Request (application/json):**
        *   `statusCode` (number): `400`
        *   `message` (string): `Bad Request`
    *   **401 Unauthorized (application/json):**
        *   `statusCode` (number): `401`
        *   `message` (string): `Invalid token: access token is invalid`
        *   `error` (string): `Unauthorized`
    *   **422 Unprocessable Entity (application/json):**
        *   `statusCode` (number): `422`
        *   `message` (string[]): `["Unprocessable Entity"]`
        *   `error` (string): `Unprocessable Entity`

### 10. PURPOSE:
This endpoint allows users to remove one or more specified tags from a contact within a Sub-Account.

### 11. TAGS:
Contacts, Tags, Remove, Delete, API, HighLevel, CRM, Sub-Account, `contacts.write`, REST.

Code examples are available for `curl`, `nodejs`, `python`, `php`, `java`, `go`, `ruby`, and `powershell`. A `curl` example is provided directly in the documentation.
