Here's a structured summary of the "Get Contact" API documentation:

### 1. ENDPOINT NAME:
Get Contact

### 2. CATEGORY:
Contacts

### 3. HTTP METHOD:
GET

### 4. ENDPOINT URL:
`/contacts/:contactId`

### 5. FULL URL:
`https://services.leadconnectorhq.com/contacts/:contactId`

### 6. REQUIRED PARAMETERS:

*   **Header Parameter:**
    *   Version (string): API Version. Possible values: [`2021-07-28`]
*   **Path Parameter:**
    *   contactId (string): Contact Id (Example: `ocQHyuzHvysMo5N5VsXc`)

### 7. OPTIONAL PARAMETERS:
Not specified in documentation for the request.

### 8. AUTHENTICATION:

*   **Scope(s):** `contacts.readonly`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Authorization Header:** `Bearer <TOKEN>` (Bearer format: JWT, in: header, description: Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account.)

### 10. PURPOSE:
This endpoint allows retrieving comprehensive details for a specific contact using their unique contact ID.
