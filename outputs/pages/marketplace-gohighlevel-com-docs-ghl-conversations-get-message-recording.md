# Get Recording by Message ID
```
GET 
## https://services.leadconnectorhq.com/conversations/messages/:messageId/locations/:locationId/recording

```

Get the recording for a message by passing the message id
### Requirements
#### Auth Method(s)
`OAuth Access Token``Private Integration Token`
#### Token Type(s)
`Sub-Account Token`
## Request[​](https://marketplace.gohighlevel.com/docs/ghl/conversations/get-message-recording/index.html#request "Direct link to Request")
### Header Parameters
**Version** stringrequired
**Possible values:** [`2021-04-15`]
API Version


### Path Parameters
**locationId** stringrequired
Location ID as string
Example: tDtDnQdgm2LXpyiqYvZ6
**messageId** stringrequired
Message ID as string
Example: tDtDnQdgm2LXpyiqYvZ6

  * 401
