Here is a structured summary of the API documentation for "Put Sub-Account (Formerly Location)":

### 1. ENDPOINT NAME:
Put Sub-Account (Formerly Location)

### 2. CATEGORY:
Sub-Account Management / Locations

### 3. HTTP METHOD:
PUT

### 4. ENDPOINT URL:
`/locations/:locationId`

### 5. FULL URL:
`https://services.leadconnectorhq.com/locations/:locationId`

### 6. REQUIRED PARAMETERS:
*   `Version` (string): API Version (Header Parameter)
*   `locationId` (string): Location Id (Path Parameter)
*   `companyId` (string): Company/Agency Id (Body Parameter)
*   `prospectInfo.firstName` (string): First name of the prospect (Required if `prospectInfo` object is included in the body)
*   `prospectInfo.lastName` (string): Last name of the prospect (Required if `prospectInfo` object is included in the body)
*   `prospectInfo.email` (string): Email of the prospect (Required if `prospectInfo` object is included in the body)
*   `twilio.sid` (string): SID provided by Twilio (Required if `twilio` object is included in the body)
*   `twilio.authToken` (string): Auth token provided by Twilio (Required if `twilio` object is included in the body)
*   `mailgun.apiKey` (string): API key provided by Mailgun (Required if `mailgun` object is included in the body)
*   `mailgun.domain` (string): Domain connected with Mailgun (Required if `mailgun` object is included in the body)
*   `snapshot.id` (string): Snaptshot ID (Required if `snapshot` object is included in the body)

### 7. OPTIONAL PARAMETERS:
*   `name` (string): The name for the sub-account/location
*   `phone` (string): The phone number of the business for which sub-account is created
*   `address` (string): The address of the business for which sub-account is created
*   `city` (string): The city where the business is located for which sub-account is created
*   `state` (string): The state in which the business operates for which sub-account is created
*   `country` (string): The country in which the business is present for which sub-account is created (Possible values list provided in docs)
*   `postalCode` (string): The postal code of the business for which sub-account is created
*   `website` (string): The website of the business for which sub-account is created
*   `timezone` (string): The timezone of the business for which sub-account is created
*   `prospectInfo` (object): Prospect information (The object itself is optional; if provided, its nested fields are required as listed above)
*   `settings` (object): The default settings for location
    *   `settings.allowDuplicateContact` (boolean)
    *   `settings.allowDuplicateOpportunity` (boolean)
    *   `settings.allowFacebookNameMerge` (boolean)
    *   `settings.disableContactTimezone` (boolean)
*   `social` (object): The social media links for location
    *   `social.facebookUrl` (string): Facebook URL
    *   `social.googlePlus` (string): Googleplus URL
    *   `social.linkedIn` (string): LinkedIn URL
    *   `social.foursquare` (string): Foursquare URL
    *   `social.twitter` (string): Twitter URL
    *   `social.yelp` (string): Yelp URL
    *   `social.instagram` (string): Instagram URL
    *   `social.youtube` (string): YouTube URL
    *   `social.pinterest` (string): Pinterest URL
    *   `social.blogRss` (string): Blog RSS URL
    *   `social.googlePlacesId` (string): Google Business Places ID
*   `twilio` (object): Twilio credentials for location (The object itself is optional; if provided, its nested fields are required as listed above)
*   `mailgun` (object): Mailgun credentials for location (The object itself is optional; if provided, its nested fields are required as listed above)
*   `snapshot` (object): The snapshot to be updated in the location (The object itself is optional; if provided, its nested field `id` is required as listed above)
    *   `snapshot.override` (boolean): If you want to override all conflicted assets then pass true. Default value is `false`.

### 8. AUTHENTICATION:
*   Required Scope(s): `locations.write`
*   Auth Method(s): `OAuth Access Token`, `Private Integration Token`
*   Token Type(s): `Agency Token`
