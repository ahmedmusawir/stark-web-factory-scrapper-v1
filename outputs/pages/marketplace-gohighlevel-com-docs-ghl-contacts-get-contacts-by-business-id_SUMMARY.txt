## STRUCTURED API DOCUMENTATION SUMMARY

### 1. ENDPOINT NAME:
Get Contacts By BusinessId

### 2. CATEGORY:
Contacts

### 3. HTTP METHOD:
GET

### 4. ENDPOINT URL:
/contacts/business/:businessId

### 5. FULL URL:
https://services.leadconnectorhq.com/contacts/business/:businessId

### 6. REQUIRED PARAMETERS:
*   **Version** (string): API Version. Possible values: `2021-07-28` (Header Parameter)
*   **businessId** (string): (Path Parameter)
*   **locationId** (string): (Query Parameter)

### 7. OPTIONAL PARAMETERS:
*   **limit** (string): (Query Parameter) Default value: `25`. Example: `10`
*   **skip** (string): (Query Parameter) Default value: `0`. Example: `10`
*   **query** (string): (Query Parameter) Example: `contact name`

### 8. AUTHENTICATION:
*   **Scope(s)**: `contacts.readonly`
*   **Auth Method(s)**: `OAuth Access Token`, `Private Integration Token`, `Bearer Token`
*   **Token Type(s)**: `Sub-Account Token`
*   **Scheme**: `bearer`
*   **Bearer Format**: `JWT`
*   **In**: `header`
*   **Description**: Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account.

### 9. RESPONSE FORMAT:

**200 OK - Successful Response (application/json)**
A JSON object containing:
*   **contacts** (array of objects): An array of contact objects. Each contact object includes:
    *   **id** (string)
    *   **locationId** (string)
    *   **email** (string)
    *   **timezone** (string)
    *   **country** (string)
    *   **source** (string)
    *   **dateAdded** (string)
    *   **customFields** (array of objects):
        *   **id** (string)
        *   **value** (string)
    *   **tags** (array of strings)
    *   **businessId** (string)
    *   **attributions** (array of objects):
        *   **url** (string, required)
        *   **campaign** (string, nullable)
        *   **utmSource** (string, nullable)
        *   **utmMedium** (string, nullable)
        *   **utmContent** (string, nullable)
        *   **referrer** (string, nullable)
        *   **campaignId** (string, nullable)
        *   **fbclid** (string, nullable)
        *   **gclid** (string, nullable)
        *   **msclikid** (string, nullable)
        *   **dclid** (string, nullable)
        *   **fbc** (string, nullable)
        *   **fbp** (string, nullable)
        *   **fbEventId** (string, nullable)
        *   **userAgent** (string, nullable)
        *   **ip** (string, nullable)
        *   **medium** (string, nullable)
        *   **mediumId** (string, nullable)
    *   **followers** (array of strings)
*   **count** (number)

**400 Bad Request (application/json)**
A JSON object with `statusCode`, `message`.

**401 Unauthorized (application/json)**
A JSON object with `statusCode`, `message`, `error`.

**422 Unprocessable Entity (application/json)**
A JSON object with `statusCode`, `message` (array of strings), `error`.

### 10. PURPOSE:
This endpoint retrieves a list of contacts associated with a specific business ID.
