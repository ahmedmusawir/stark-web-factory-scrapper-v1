**1. ENDPOINT NAME:**
Create New Estimate

**2. CATEGORY:**
Invoices

**3. HTTP METHOD:**
POST

**4. ENDPOINT URL:**
`/invoices/estimate`

**5. FULL URL:**
`https://services.leadconnectorhq.com/invoices/estimate`

**6. REQUIRED PARAMETERS:**

*   **Header Parameters:**
    *   `Version` (string): API Version (Possible values: `2021-07-28`)

*   **Body Parameters:**
    *   `altId` (string): Location Id or Agency Id
    *   `altType` (string): Possible values: [`location`]
    *   `name` (string): Estimate Name
    *   `businessDetails` (object): Business details (This object is required, but its sub-fields are mostly optional, see Optional Parameters for details. However, `currency` is a top-level required field.)
    *   `currency` (string): Currency code
    *   `items` (object[]): An array of items for the estimate. (This array is required, and its immediate children are listed below.)
        *   `name` (string): Invoice Item Name
        *   `currency` (string): Currency
        *   `amount` (number): Product amount
        *   `qty` (number): Product Quantity
    *   `discount` (object): Discount (This object is required, and its immediate child is listed below.)
        *   `type` (string): Discount type (Possible values: [`percentage`, `fixed`], Default value: `percentage`)

**7. OPTIONAL PARAMETERS:**

*   **Body Parameters:**
    *   `businessDetails` (object): Business details (Required, but its sub-fields are optional)
        *   `logoUrl` (string): Business Logo URL
        *   `name` (string): Business Name
        *   `phoneNo` (string): Business Phone Number
        *   `address` (object): Business Address
            *   `addressLine1` (string): Address Line 1
            *   `addressLine2` (string): Address Line 2
            *   `city` (string): City
            *   `state` (string): State
            *   `countryCode` (string): Country Code
            *   `postalCode` (string): Postal Code
        *   `website` (string): Business Website Link
        *   `customValues` (string[]): Custom Values
    *   `items` (object[]): An array of items for the estimate (Required, but its sub-fields are optional, except for `name`, `currency`, `amount`, `qty` which are required)
        *   `description` (string): Invoice descriptions
        *   `productId` (string): Product Id
        *   `priceId` (string): Price Id
        *   `taxes` (object[]): Tax (Optional. If provided, `_id`, `name`, `rate` are required)
            *   `_id` (string): Required if `taxes` object is provided
            *   `name` (string): Required if `taxes` object is provided
            *   `rate` (number): Required if `taxes` object is provided
            *   `calculation` (string): Possible values: [`exclusive`]
            *   `description` (string)
            *   `taxId` (string)
        *   `automaticTaxCategoryId` (string): Tax category id for calculating automatic tax
        *   `isSetupFeeItem` (boolean): Setupfee item, only created when 1st invoice of recurring schedule is generated
        *   `type` (string): Price type of the item (Possible values: [`one_time`, `recurring`])
        *   `taxInclusive` (boolean): true if item amount is tax inclusive (Default value: `false`)
        *   `attachments` (string[]): Attachments for the line item
    *   `liveMode` (boolean): livemode for estimate (Default value: `true`)
    *   `discount` (object): Discount (Required, but `value` and `validOnProductIds` are optional)
        *   `value` (number): Discount Value (Default value: `0`)
        *   `validOnProductIds` (string[]): Product Ids on which discount is applicable
    *   `termsNotes` (string): Terms notes, Also supports HTML markups
    *   `title` (string): Title for the estimate
    *   `contactDetails` (object): Contact information to send the estimate to (Optional. If provided, `id`, `name`, `phoneNo`, `email` are required)
        *   `id` (string): Contact ID (Required if `contactDetails` is provided)
        *   `name` (string): Contact Name (Required if `contactDetails` is provided)
        *   `phoneNo` (string): Contact Phone Number (Required if `contactDetails` is provided)
        *   `email` (string): Contact Email (Required if `contactDetails` is provided)
        *   `additionalEmails` (object[]): Secondary email addresses for the contact to be saved (Optional. If provided, `email` is required)
            *   `email` (string): Required if `additionalEmails` is provided
        *   `companyName` (string): Contact Company Name
        *   `address` (object)
            *   `addressLine1` (string): Address Line 1
            *   `addressLine2` (string): Address Line 2
            *   `city` (string): City
            *   `state` (string): State
            *   `countryCode` (string): Country Code
            *   `postalCode` (string): Postal Code
        *   `customFields` (string[]): Custom Values
    *   `estimateNumber` (number): Estimate Number, if not specified will take in the next valid estimate number
    *   `issueDate` (string): issue date estimate (YYYY-MM-DD)
    *   `expiryDate` (string): expiry date estimate (YYYY-MM-DD)
    *   `sentTo` (object): Email and sent to details for the estimate (Optional. If provided, `email` is required)
        *   `email` (string[]): Email Address (Required if `sentTo` is provided)
        *   `emailCc` (string[]): cc to be kept in any sent out emails
        *   `emailBcc` (string[]): bcc to be kept in any sent out emails
        *   `phoneNo` (string[]): Contact Phone Number
    *   `automaticTaxesEnabled` (boolean): Automatic taxes enabled for the Estimate (Default value: `false`)
    *   `meta` (object): Meta data for the estimate
    *   `sendEstimateDetails` (object): When sending estimate directly while saving (Optional. If provided, `altId`, `altType`, `action`, `liveMode`, `userId` are required)
        *   `altId` (string): Location Id or Agency Id (Required if `sendEstimateDetails` is provided)
        *   `altType` (string): Possible values: [`location`] (Required if `sendEstimateDetails` is provided)
        *   `action` (string): Possible values: [`sms_and_email`, `send_manually`, `email`, `sms`] (Required if `sendEstimateDetails` is provided)
        *   `liveMode` (boolean): livemode for estimate (Required if `sendEstimateDetails` is provided)
        *   `userId` (string): User ID (Required if `sendEstimateDetails` is provided)
        *   `sentFrom` (object): sender details for invoice, valid only if invoice is not sent manually
            *   `fromName` (string): Sender name
            *   `fromEmail` (string): Email id to be used
        *   `estimateName` (string): estimate name
    *   `frequencySettings` (object): frequency settings for the estimate (Optional. If provided, `enabled` and `schedule` are required)
        *   `enabled` (boolean): enabled for the frequency settings (Required if `frequencySettings` is provided)
        *   `schedule` (object): schedule setting for the estimate (Required if `frequencySettings` is provided. Its sub-fields are: `intervalType`, `interval`, `startDate` are required if `schedule` is provided, others are optional.)
            *   `executeAt` (string)
            *   `rrule` (object)
                *   `intervalType` (string): Required if `schedule.rrule` is provided (Possible values: [`yearly`, `monthly`, `weekly`, `daily`, `hourly`, `minutely`, `secondly`])
                *   `interval` (number): Required if `schedule.rrule` is provided
                *   `startDate` (string): Required if `schedule.rrule` is provided (YYYY-MM-DD)
                *   `startTime` (string): HH:mm:ss
                *   `endDate` (string): YYYY-MM-DD
                *   `endTime` (string): HH:mm:ss
                *   `dayOfMonth` (number)
                *   `dayOfWeek` (string): Possible values: [`mo`, `tu`, `we`, `th`, `fr`, `sa`, `su`]
                *   `numOfWeek` (number)
                *   `monthOfYear` (string): Possible values: [`jan`, `feb`, `mar`, `apr`, `may`, `jun`, `jul`, `aug`, `sep`, `oct`, `nov`, `dec`]
                *   `count` (number): Max number of task executions
                *   `daysBefore` (number): Execute task number of days before
                *   `useStartAsPrimaryUserAccepted` (boolean): Start as primary user accepted date
                *   `endType` (string): End type like after, by, count
    *   `estimateNumberPrefix` (string): Prefix for the estimate number (Default value: `EST-`)
    *   `userId` (string): User Id
    *   `attachments` (object[]): attachments for the invoice (Optional. If provided, `id`, `name`, `url`, `type`, `size` are required)
        *   `id` (string): Id of the file selected (Required if `attachments` array is provided)
        *   `name` (string): Name of the file (Required if `attachments` array is provided)
        *   `url` (string): URL of the file (Required if `attachments` array is provided)
        *   `type` (string): Type of the file (Required if `attachments` array is provided)
        *   `size` (number): Size of the file (Required if `attachments` array is provided)
    *   `autoInvoice` (object): Auto invoice for the estimate (Optional. If provided, `enabled` is required)
        *   `enabled` (boolean): Enable Auto Invoice (Required if `autoInvoice` is provided)
        *   `directPayments` (boolean): Direct Payments
    *   `miscellaneousCharges` (object): miscellaneous charges for the estimate (Optional. If provided, `charges` is required)
        *   `charges` (array[]): charges for the processing fee (Required if `miscellaneousCharges` is provided)
        *   `collectedMiscellaneousCharges` (number): collected miscellaneous charges
        *   `paidCharges` (object[]): paid miscellaneous charges (Optional. If provided, `name`, `charge`, `amount`, `_id` are required)
            *   `name` (string): name of the processing fee (Required if `paidCharges` is provided)
            *   `charge` (number): charge for the processing fee (Required if `paidCharges` is provided)
            *   `amount` (number): amount of the processing fee (Required if `paidCharges` is provided)
            *   `_id` (string): id of the processing fee (Required if `paidCharges` is provided)
    *   `paymentScheduleConfig` (object): Payment Schedule Config for the estimate (Optional. If provided, `type`, `dateConfig`, `schedules` are required)
        *   `type` (string): Payment Schedule Type (Required if `paymentScheduleConfig` is provided) (Possible values: [`fixed`, `percentage`])
        *   `dateConfig` (object): Due date type configuration (Required if `paymentScheduleConfig` is provided. Its sub-fields `depositDateType` and `scheduleDateType` are required.)
            *   `depositDateType` (string): Deposit date type (Required if `dateConfig` is provided) (Possible values: [`estimate_accepted`, `custom`])
            *   `scheduleDateType` (string): Payment Schedule Date Type (Required if `dateConfig` is provided) (Possible values: [`regular_interval`, `custom`])
        *   `schedules` (array[]): Payment Schedule Items (Required if `paymentScheduleConfig` is provided)

**8. AUTHENTICATION:**
*   **Scope(s):** `invoices/estimate.write`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`, `Agency Token`

**9. RESPONSE FORMAT:**

*   **Status Code:** `201 Created`
*   **Content Type:** `application/json`
*   **Schema:**
    *   `altId` (string): Location Id or Agency Id
    *   `altType` (string): Possible values: [`location`]
    *   `_id` (string): Unique identifier
    *   `liveMode` (boolean): Indicates if it is in live mode
    *   `deleted` (boolean): Indicates if deleted
    *   `name` (string): Name
    *   `currency` (string): Currency code
    *   `businessDetails` (object): Business details associated with the estimate
    *   `items` (array[]): An array of items
    *   `discount` (object): Discount details for the estimate template
        *   `value` (number): Discount Value (Default: `0`)
        *   `type` (string): Discount type (Possible values: [`percentage`, `fixed`], Default: `percentage`)
        *   `validOnProductIds` (string[]): Product Ids on which discount is applicable
    *   `title` (string): Title
    *   `estimateNumberPrefix` (string): Estimate number prefix
    *   `attachments` (object[]): Attachments (Each item: `id`, `name`, `url`, `type`, `size` strings/numbers)
    *   `updatedBy` (string): User Id of who last updated
    *   `total` (number): Total amount
    *   `createdAt` (date-time): Timestamp when created
    *   `updatedAt` (date-time): Timestamp when last updated
    *   `__v` (number): Version number
    *   `automaticTaxesEnabled` (boolean): Indicates if automatic taxes are enabled for this estimate
    *   `termsNotes` (string): Terms and conditions for the estimate, supports HTML markup
    *   `companyId` (string): Company identifier associated with the estimate
    *   `contactDetails` (object): Contact details for the estimate
    *   `issueDate` (date-time): Date when the estimate was issued
    *   `expiryDate` (date-time): Date when the estimate expires
    *   `sentBy` (string): User who sent the estimate
    *   `automaticTaxesCalculated` (boolean): Indicates if automatic taxes were calculated
    *   `meta` (object): Additional metadata associated with the estimate
    *   `estimateActionHistory` (string[]): History of actions taken on the estimate
    *   `sentTo` (object): Recipient details for the estimate
    *   `frequencySettings` (object): Frequency settings for recurring estimates
        *   `enabled` (boolean): enabled for the frequency settings
        *   `schedule` (object): schedule setting for the estimate (Contains `executeAt`, `rrule` object with detailed recurrence fields like `intervalType`, `interval`, `startDate`, etc.)
    *   `lastVisitedAt` (date-time): Timestamp when the estimate was last visited
    *   `totalamountInUSD` (number): Total amount in USD
    *   `autoInvoice` (object): Auto-invoice settings for the estimate
    *   `traceId` (string): Trace ID for logging and debugging

**10. PURPOSE:**
This endpoint allows you to create a new estimate with specified details for a given location or agency.
