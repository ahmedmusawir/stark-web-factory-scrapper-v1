Here is a structured summary of the provided API documentation:

### 1. ENDPOINT NAME:
Create Price for a Product

### 2. CATEGORY:
Products

### 3. HTTP METHOD:
POST

### 4. ENDPOINT URL:
`/products/:productId/price`

### 5. FULL URL:
`https://services.leadconnectorhq.com/products/:productId/price`

### 6. REQUIRED PARAMETERS:

*   **Header Parameters:**
    *   Version (string): API Version (Possible values: `2021-07-28`)

*   **Path Parameters:**
    *   productId (string): ID of the product that needs to be used (Example: `6578278e879ad2646715ba9c`)

*   **Body Parameters:**
    *   name (string): The name of the price. (Example: `Price Name`)
    *   type (string): The type of the price. (Possible values: [`one_time`, `recurring`]) (Example: `one_time`)
    *   currency (string): The currency of the price. (Example: `USD`)
    *   amount (number): The amount of the price. (min: 0) (Example: `99.99`)
    *   locationId (string): The unique identifier of the location associated with the price. (Example: `6578278e879ad2646715ba9c`)
    *   meta (object): Additional metadata associated with the price.
        *   source (string): The source of the price. (Possible values: [`stripe`, `woocommerce`, `shopify`]) (Example: `stripe`)
        *   stripePriceId (string): The Stripe price ID associated with the price. (Example: `price_123`)
        *   internalSource (string): The internal source of the price. (Possible values: [`agency_plan`, `funnel`, `membership`, `communities`, `gokollab`, `calendar`]) (Example: `agency_plan`)
    *   If `type` is `recurring`, then `recurring` object is expected with these required fields:
        *   recurring.interval (string): The interval at which the recurring event occurs. (Possible values: [`day`, `month`, `week`, `year`]) (Example: `day`)
        *   recurring.intervalCount (number): The number of intervals between each occurrence of the event. (Example: `1`)
    *   If `membershipOffers` array is present, each object requires:
        *   membershipOffers.label (string): Membership offer label (Example: `top_50`)
        *   membershipOffers.value (string): Membership offer label (Example: `50`)
        *   membershipOffers._id (string): The unique identifier for the membership offer. (Example: `655b33aa2209e60b6adb87a7`)
    *   If `shippingOptions.weight` is present, it requires:
        *   shippingOptions.weight.value (number): Actual weight of the product (Example: `10`)
        *   shippingOptions.weight.unit (string): Weight unit of the product (Possible values: [`kg`, `lb`, `g`, `oz`]) (Example: `kg`)
    *   If `shippingOptions.dimensions` is present, it requires:
        *   shippingOptions.dimensions.height (number): Height of the price (Example: `10`)
        *   shippingOptions.dimensions.width (number): Width of the price (Example: `10`)
        *   shippingOptions.dimensions.length (number): Length of the price (Example: `10`)
        *   shippingOptions.dimensions.unit (string): Unit of the price dimensions (Possible values: [`cm`, `in`, `m`]) (Example: `cm`)

### 7. OPTIONAL PARAMETERS:

*   **Body Parameters:**
    *   recurring (object): The recurring details of the price (if type is recurring). (Note: Its sub-fields `interval` and `intervalCount` become required if `type` is `recurring`).
    *   description (string): A brief description of the price.
    *   membershipOffers (object[]): An array of membership offers associated with the price.
    *   trialPeriod (number): The trial period duration in days (if applicable). (Example: `7`)
    *   totalCycles (number): The total number of billing cycles for the price. (min: 1) (Example: `12`)
    *   setupFee (number): The setup fee for the price. (Example: `10.99`)
    *   variantOptionIds (string[]): An array of variant option IDs associated with the price. (Example: `["option_id_1","option_id_2"]`)
    *   compareAtPrice (number): The compare at price for the price. (Example: `19.99`)
    *   userId (string): The unique identifier of the user who created the price. (Example: `6578278e879ad2646715ba9c`)
    *   meta.sourceId (string): The id of the source of the price from where it is imported (Example: `123`)
    *   trackInventory (boolean): Need to track inventory stock quantity (Example: `true`)
    *   availableQuantity (number): Available inventory stock quantity (Example: `5`)
    *   allowOutOfStockPurchases (boolean): Continue selling when out of stock (Example: `true`)
    *   sku (string): The unique identifier of the SKU associated with the price (Example: `sku_123`)
    *   shippingOptions (object): Shipping options of the Price
        *   weight (object): Weight options of the product
        *   dimensions (object): Dimensions of the product
    *   isDigitalProduct (boolean): Is the product a digital product (Example: `true`)
    *   digitalDelivery (string[]): Digital delivery options

### 8. AUTHENTICATION:

*   **Scope(s):** `products/prices.write`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`, `Agency Token`
*   **Scheme:** Bearer (JWT) in header.

### 10. PURPOSE:
The "Create Price for a Product" API allows adding a new price associated with a specific product to the system, enabling the creation of prices with specified details for a particular product.
