Here is a structured summary of the provided API documentation:

### 1. ENDPOINT NAME:
List Prices for a Product

### 2. CATEGORY:
Products / Prices

### 3. HTTP METHOD:
GET

### 4. ENDPOINT URL:
`/products/:productId/price`

### 5. FULL URL:
`https://services.leadconnectorhq.com/products/:productId/price`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters:**
    *   `Version` (string): API Version. Possible values: `2021-07-28`
*   **Path Parameters:**
    *   `productId` (string): ID of the product that needs to be used. Example: `6578278e879ad2646715ba9c`
*   **Query Parameters:**
    *   `locationId` (string): The unique identifier for the location. Example: `3SwdhCsvxI8Au3KsPJt6`

### 7. OPTIONAL PARAMETERS:
*   **Query Parameters:**
    *   `limit` (number): The maximum number of items to be included in a single page of results. Default value: `0`. Example: `20`
    *   `offset` (number): The starting index of the page, indicating the position from which the results should be retrieved. Default value: `0`. Example: `0`
    *   `ids` (string): To filter the response only with the given price ids, Please provide with comma separated. Example: `6241712be68f7a98102ba272,632027d51f7876cd3020213d`

### 8. AUTHENTICATION:
*   **Scope(s):** `products/prices.readonly`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`, `Agency Token`
*   **Scheme:** Bearer (JWT) in header
