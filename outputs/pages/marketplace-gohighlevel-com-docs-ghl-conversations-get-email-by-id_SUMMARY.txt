## STRUCTURED SUMMARY

### 1. ENDPOINT NAME:
Get email by Id

### 2. CATEGORY:
Conversations (Email sub-category)

### 3. HTTP METHOD:
GET

### 4. ENDPOINT URL:
/conversations/messages/email/:id

### 5. FULL URL:
https://services.leadconnectorhq.com/conversations/messages/email/:id

### 6. REQUIRED PARAMETERS:
- id (string): The unique identifier of the email message to retrieve. (Path parameter)

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:
Not specified in documentation

### 9. RESPONSE FORMAT:
- **Status Code**: 200
- **Content Type**: application/json
- **Schema (Email object)**:
    - id (string, required): Unique identifier of the email. Example: `ve9EPM428h8vShlRW1KT`
    - altId (string): External Id. Example: `ve9EPM428h8vShlRW1KT`
    - threadId (string, required): Message Id or thread Id. Example: `ve9EPM428h8vShlRW1KT`
    - locationId (string, required): Example: `ve9EPM428h8vShlRW1KT`
    - contactId (string, required): Example: `ve9EPM428h8vShlRW1KT`
    - conversationId (string, required): Example: `ve9EPM428h8vShlRW1KT`
    - dateAdded (string, required): Timestamp when the email was added. Example: `2024-03-27T18:13:49.000Z`
    - subject (string): Subject of the email. Example: `Order confirm`
    - body (string, required): Content of the email. Example: `Hi there`
    - direction (string, required): Direction of the email. Possible values: [`inbound`, `outbound`]
    - status (string): Current status of the email. Possible values: [`pending`, `scheduled`, `sent`, `delivered`, `read`, `undelivered`, `connected`, `failed`, `opened`]
    - contentType (string, required): Content type of the email body. Example: `text/plain`
    - attachments (string[]): An array of attachment URLs.
    - provider (string): The email provider.
    - from (string, required): Name and Email Id of the sender.
    - to (string[], required): List of email Ids of the receivers.
    - cc (string[]): List of email Ids of the people in the CC field.
    - bcc (string[]): List of email Ids of the people in the BCC field.
    - replyToMessageId (string): Email message Id of the email this message is a reply to.
    - source (string): Source of the email. Possible values: [`workflow`, `bulk_actions`, `campaign`, `api`, `app`]
    - conversationProviderId (string): Conversation provider ID. Example: `cI08i1Bls3iTB9bKgF01`
- **Example**:

```

This endpoint retrieves the details of a specific email message using its unique identifier.
