Here's a structured summary of the API documentation:

### 1. ENDPOINT NAME:
Fetch given provider config

### 2. CATEGORY:
Payments - Custom Provider

### 3. HTTP METHOD:
GET

### 4. ENDPOINT URL:
`/payments/custom-provider/connect`

### 5. FULL URL:
`https://services.leadconnectorhq.com/payments/custom-provider/connect`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters:**
    *   Version (string): API Version. Possible values: `2021-07-28`
*   **Query Parameters:**
    *   locationId (string): Location id. Example: `Lk3nlfk4lxlelVEwcW`

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:
*   **Scope(s):** `payments/custom-provider.readonly`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Authorization Header:** `Bearer <TOKEN>` (Bearer Format: JWT, In: Header)

### 9. RESPONSE FORMAT:
*   **Successful Response (200 OK):**
    *   **Content Type:** `application/json`
    *   **Schema:**
        *   `name` (string): The name of the custom provider. Example: `Company Paypal Integration`
        *   `description` (string): Description of payment gateway. Shown on the payments integrations page as subtext. Example: `This payment gateway supports payments in India via UPI, Net banking, cards and wallets.`
        *   `paymentsUrl` (string): This url will be loaded in iFrame to start a payment session. Example: `https://testpayment.paypal.com`
        *   `queryUrl` (string): The url used for querying payments related events. Ex. verify, refund, subscription etc. Example: `https://testsubscription.paypal.com`
        *   `imageUrl` (string): Public image url for logo of the payment gateway displayed on the payments integrations page. Example: `https://testsubscription.paypal.com`
        *   `_id` (string): The unique identifier for the custom provider. Example: `662a44ad19a2a44d3cd9d749`
        *   `locationId` (string): Location id. Example: `Lk3nlfk4lxlelVEwcW`
        *   `marketplaceAppId` (string): The application id of marketplace. Example: `65f0b217a05c774da7f1efa5`
        *   `paymentProvider` (object): Payment provider details. Example: `{ live: { liveMode: true }, test: { liveMode: false, apiKey: "y5ZQxryRFXZHvUJZdLXXXXXX", publishableKey: "rzp_test_zPRoVMLOa0A9wo" }}`
        *   `deleted` (boolean): Whether the config is deleted or not. true represents config is deleted. Example: `true`
        *   `createdAt` (date-time): The creation timestamp of the custom provider. Example: `2023-11-20T10:23:36.515Z`
        *   `updatedAt` (date-time): The last update timestamp of the custom provider. Example: `2024-01-23T09:57:04.846Z`
        *   `traceId` (string, optional): Trace id of the custom provider. Example: `302d2cf4-1ba0-4bf5-bc3b-f8fa76fda58a`
    *   **Example (JSON):**
        ```json
        {
          "name": "Company Paypal Integration",
          "description": "This payment gateway supports payments in India via UPI, Net banking, cards and wallets.",
          "paymentsUrl": "https://testpayment.paypal.com",
          "queryUrl": "https://testsubscription.paypal.com",
          "imageUrl": "https://testsubscription.paypal.com",
          "_id": "662a44ad19a2a44d3cd9d749",
          "locationId": "Lk3nlfk4lxlelVEwcW",
          "marketplaceAppId": "65f0b217a05c774da7f1efa5",
          "paymentProvider": "{ live: { liveMode: true }, test: { liveMode: false, apiKey: \"y5ZQxryRFXZHvUJZdLXXXXXX\", publishableKey: \"rzp_test_zPRoVMLOa0A9wo\" }}",
          "deleted": true,
          "createdAt": "2023-11-20T10:23:36.515Z",
          "updatedAt": "2024-01-23T09:57:04.846Z",
          "traceId": "302d2cf4-1ba0-4bf5-bc3b-f8fa76fda58a"
        }
        ```
*   **Error Responses:**
    *   **400 Bad Request:** `{"statusCode":400,"message":"Bad Request"}` (No such config exists for given locationId and marketplaceAppId)
    *   **401 Unauthorized:** `{"statusCode":401,"message":"Invalid token: access token is invalid","error":"Unauthorized"}`
    *   **422 Unprocessable Entity:** `{"statusCode":422,"message":["Unprocessable Entity"],"error":"Unprocessable Entity"}`

### 10. PURPOSE:
This API endpoint fetches an existing custom payment provider configuration for a given location.
