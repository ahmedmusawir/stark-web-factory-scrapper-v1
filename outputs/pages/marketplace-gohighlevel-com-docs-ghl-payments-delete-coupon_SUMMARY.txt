Here's a structured summary of the API documentation:

### 1. ENDPOINT NAME:
Delete Coupon

### 2. CATEGORY:
Payments

### 3. HTTP METHOD:
DELETE

### 4. ENDPOINT URL:
`/payments/coupon`

### 5. FULL URL:
`https://services.leadconnectorhq.com/payments/coupon`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters:**
    *   Version (string): API Version (Possible values: `2021-07-28`)
*   **Body Parameters:**
    *   altId (string): Location Id
    *   altType (string): Alt Type (Possible values: `location`)
    *   id (string): Coupon Id

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:
*   **Scope(s):** `payments/coupons.write`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** Bearer (JWT)

### 9. RESPONSE FORMAT:
*   **Status Code:** `200 OK`
*   **Structure (application/json):**
    ```json
    {
      "success": true,
      "traceId": "c667b18d-8f5e-44cf-a914"
    }
    ```
    *   `success` (boolean): Indicates whether the delete was successful.
    *   `traceId` (string): Unique identifier for tracing this API request.

*   **Error Response (422 Unprocessable Entity - application/json):**
    ```json
    {
      "statusCode": 422,
      "message": ["Unprocessable Entity"],
      "error": "Unprocessable Entity"
    }
    ```

### 10. PURPOSE:
The "Delete Coupon" API allows you to permanently remove a coupon from your system using its unique identifier, making it useful for discontinuing promotional offers or cleaning up unused coupons, an action that cannot be undone.
