Here is a structured summary of the API documentation:

### 1. ENDPOINT NAME:
Update a knowledge base

### 2. CATEGORY:
Knowledge Base

### 3. HTTP METHOD:
PUT

### 4. ENDPOINT URL:
`/knowledge-bases/:id`

### 5. FULL URL:
`https://services.leadconnectorhq.com/knowledge-bases/:id`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters:**
    *   Authorization (string): Access Token. Example: Bearer <TOKEN>
    *   Version (string): API Version. Possible values: [`2021-04-15`]
*   **Path Parameters:**
    *   id (string): The ID of the knowledge base to update.

### 7. OPTIONAL PARAMETERS:
*   **Body Parameters (Body itself is required, but fields within are optional for partial updates):**
    *   name (string): field to update the name of the knowledge base
    *   description (string): field to update the description of the knowledge base

### 8. AUTHENTICATION:
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Description:** Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account.

### 9. RESPONSE FORMAT:
*   **200 OK (Knowledge base updated successfully):**
    ```json
    {
      "success": true
    }
    ```
*   **400 Bad Request:**
    ```json
    {
      "statusCode": 400,
      "message": "Bad Request"
    }
    ```
*   **401 Unauthorized:**
    ```json
    {
      "statusCode": 401,
      "message": "Invalid token: access token is invalid",
      "error": "Unauthorized"
    }
    ```

### 10. PURPOSE:
This endpoint is used to update an existing knowledge base by its ID.
