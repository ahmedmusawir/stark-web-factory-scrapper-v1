## STRUCTURED SUMMARY

### 1. ENDPOINT NAME:
List Shipping Rates

### 2. CATEGORY:
Store (Shipping Zone Rates)

### 3. HTTP METHOD:
GET

### 4. ENDPOINT URL:
`/store/shipping-zone/:shippingZoneId/shipping-rate`

### 5. FULL URL:
`https://services.leadconnectorhq.com/store/shipping-zone/:shippingZoneId/shipping-rate`

### 6. REQUIRED PARAMETERS:
*   **Path Parameters:**
    *   `shippingZoneId` (string): ID of the item that needs to be returned
*   **Query Parameters:**
    *   `altId` (string): Location Id or Agency Id
    *   `altType` (string): Possible values: [`location`]

### 7. OPTIONAL PARAMETERS:
*   **Query Parameters:**
    *   `limit` (number): The maximum number of items to be included in a single page of results. Default value: `0`.
    *   `offset` (number): The starting index of the page, indicating the position from which the results should be retrieved. Default value: `0`.

### 8. AUTHENTICATION:
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** Bearer (JWT)
*   **In:** Header (`Authorization: Bearer <TOKEN>`)

### 9. RESPONSE FORMAT:
*   **Successful Response (200 OK):**
    *   **Content Type:** `application/json`
    *   **Schema:**
        *   `total` (number): Total number of items
        *   `data` (array of objects): An array of shipping rate items, each containing:
            *   `altId` (string): Location Id or Agency Id
            *   `altType` (string): Possible values: [`location`]
            *   `name` (string): Name of the shipping zone
            *   `description` (string, optional): Delivery description
            *   `currency` (string): The currency of the amount of the rate / handling fee
            *   `amount` (number): The amount of the shipping rate if it is a normal rate (0 means free). Fixed Handling fee if it is a carrier rate (it will add to the carrier rate).
            *   `conditionType` (string): Type of condition to provide the conditional pricing. Possible values: [`none`, `price`, `weight`]
            *   `minCondition` (number, optional): Minimum condition for applying this price. Set 0 or null if there is no minimum.
            *   `maxCondition` (number, optional): Maximum condition for applying this price. Set 0 or null if there is no maximum.
            *   `isCarrierRate` (boolean, optional): Indicates if this is a carrier rate
            *   `shippingCarrierId` (string): Shipping carrier ID
            *   `percentageOfRateFee` (number, optional): Percentage of rate fee if it is a carrier rate.
            *   `shippingCarrierServices` (array of objects, optional): An array of shipping carrier services. Each service includes:
                *   `name` (string): Name of the shipping carrier service
                *   `value` (string): Value of the shipping carrier service
            *   `_id` (string): The unique identifier for the shipping rate.
            *   `shippingZoneId` (string): The unique identifier for the shipping zone.
            *   `createdAt` (string): Timestamp when the shipping rate was created (ISO 8601).
            *   `updatedAt` (string): Timestamp when the shipping rate was last updated (ISO 8601).
*   **Error Responses:**
    *   `400 Bad Request`: `{"statusCode": 400, "message": "Bad Request"}`
    *   `401 Unauthorized`: `{"statusCode": 401, "message": "Invalid token: access token is invalid", "error": "Unauthorized"}`
    *   `422 Unprocessable Entity`: `{"statusCode": 422, "message": ["Unprocessable Entity"], "error": "Unprocessable Entity"}`

### 10. PURPOSE:
The "List Shipping Rate" API allows to retrieve a list of shipping rates.
