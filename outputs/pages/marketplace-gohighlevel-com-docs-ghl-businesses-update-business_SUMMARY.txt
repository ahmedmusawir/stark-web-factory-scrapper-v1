Here is a structured summary of the API documentation for "Update Business":

## STRUCTURED SUMMARY

### 1. ENDPOINT NAME:
Update Business

### 2. CATEGORY:
Businesses

### 3. HTTP METHOD:
PUT

### 4. ENDPOINT URL:
`/businesses/:businessId`

### 5. FULL URL:
`https://services.leadconnectorhq.com/businesses/:businessId`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters**:
    *   Version (string): API Version. Possible values: `2021-07-28`
*   **Path Parameters**:
    *   businessId (string): The unique identifier for the business. Example: `5DP4iH6HLkQsiKESj6rh`
*   **Body Parameters**:
    *   name (string): The name of the business. Example: `Microsoft` (While the request body section doesn't explicitly mark `name` as required, the successful response schema lists it as such, indicating it's a core required field for a business object.)

### 7. OPTIONAL PARAMETERS:
*   **Body Parameters**:
    *   phone (string): The phone number of the business. Example: `+18832327657`
    *   email (string): The email address of the business. Example: `john@deo.com`
    *   postalCode (string): The postal code of the business address. Example: `12312312`
    *   website (string): The website URL of the business. Example: `www.xyz.com`
    *   address (string): The street address of the business. Example: `street adress`
    *   state (string): The state of the business address. Example: `new york`
    *   city (string): The city of the business address. Example: `new york`
    *   country (string): The country of the business address (e.g., 'us'). Example: `us`
    *   description (string): A description of the business. Example: `business description`

### 8. AUTHENTICATION:
*   **Scope(s)**: `businesses.write`
*   **Auth Method(s)**: `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s)**: `Sub-Account Token`
*   **Scheme**: Bearer
*   **Bearer Format**: JWT
*   **Description**: Use an Access Token generated with user type as Sub-Account, or a Private Integration Token of a Sub-Account.

### 10. PURPOSE:
This endpoint allows an authenticated user to update specific details of an existing business identified by its unique ID.
