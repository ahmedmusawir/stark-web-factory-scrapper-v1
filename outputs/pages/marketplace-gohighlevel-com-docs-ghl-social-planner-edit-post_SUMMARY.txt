Here's a structured summary of the API documentation for "Edit post":

---

### 1. ENDPOINT NAME:
Edit post

### 2. CATEGORY:
Social Planner

### 3. HTTP METHOD:
PUT

### 4. ENDPOINT URL:
`/social-media-posting/:locationId/posts/:id`

### 5. FULL URL:
`https://services.leadconnectorhq.com/social-media-posting/:locationId/posts/:id`

### 6. REQUIRED PARAMETERS:

*   **Header Parameters:**
    *   `Version` (string): API Version (Possible values: `2021-07-28`)

*   **Path Parameters:**
    *   `locationId` (string): Location Id (Example: `ve9EPM428h8vShlRW1KT`)
    *   `id` (string): Post Id (Example: `65fac446d599990d1313c1dd`)

*   **Body Parameters:**
    *   `accountIds` (string[]): Account Ids (Example: `["aF3KhyL8JIuBwzK3m7Ly_iVrVJ2uoXNF0wzcBzgl5_12554616564525983496"]`)
    *   `type` (object): Post Type must be one of the following values: - post, story, reel (Example: `post`)
    *   `userId` (string): User ID (Example: `sdfdsfdsfEWEsdfsdsW32dd`)

    **Conditional Required Parameters (if parent object is included in the request body):**
    *   **If `media` (object[]) is provided:**
        *   `media.url` (string): (Example: `https://i0.wp.com/...stairs.jpg`)
    *   **If `gmbPostDetails` (object) is provided:**
        *   `gmbPostDetails.startDate.startDate.year` (number): (Example: `2022`)
        *   `gmbPostDetails.startDate.startDate.month` (number): (Example: `1`)
        *   `gmbPostDetails.startDate.startDate.day` (number): (Example: `1`)
        *   `gmbPostDetails.startDate.startTime.hours` (number): (Example: `23`)
        *   `gmbPostDetails.startDate.startTime.minutes` (number): (Example: `56`)
        *   `gmbPostDetails.startDate.startTime.seconds` (number): (Example: `34`)
        *   `gmbPostDetails.endDate.endDate.year` (number): (Example: `2022`)
        *   `gmbPostDetails.endDate.endDate.month` (number): (Example: `1`)
        *   `gmbPostDetails.endDate.endDate.day` (number): (Example: `1`)
        *   `gmbPostDetails.endDate.endTime.hours` (number): (Example: `23`)
        *   `gmbPostDetails.endDate.endTime.minutes` (number): (Example: `56`)
        *   `gmbPostDetails.endDate.endTime.seconds` (number): (Example: `34`)
    *   **If `linkedinPostDetails` (object) is provided:**
        *   `linkedinPostDetails.pdfTitle` (string): Title of the PDF (Example: `test.pdf`)
        *   `linkedinPostDetails.postAsPdf` (boolean): If the post is to be posted as PDF (Example: `true`)
    *   **If `pinterestPostDetails` (object) is provided:**
        *   `pinterestPostDetails.boardIds` (object): Mapping of oauth IDs of connected accounts to board IDs (Example: `{"6887d6de1d8175813d50dab8": "boardId"}`)
    *   **If `facebookPostDetails` (object) is provided:**
        *   `facebookPostDetails.type` (object): Post Type must be one of the following values: - post, story, reel (Example: `post`)
    *   **If `instagramPostDetails` (object) is provided:**
        *   `instagramPostDetails.type` (object): Post Type must be one of the following values: - post, story, reel (Example: `post`)

### 7. OPTIONAL PARAMETERS:

*   **Body Parameters:**
    *   `summary` (string): Post Content (Example: `Hello World`)
    *   `media` (object[]): Post Media Data (if included, `url` within each media object is required)
        *   `media.caption` (string): (Example: `Caption 1`)
        *   `media.type` (string): (Example: `video/mp4 or image/png`)
        *   `media.thumbnail` (string): (Example: `https://storage.googleapis.com/test/...test.jpeg`)
        *   `media.defaultThumb` (string): (Example: `https://storage.googleapis.com/test/...test.jpeg`)
        *   `media.id` (string): (Example: `Edf3323fsfsdsd`)
    *   `status` (object): Status (Possible values: `null`, `in_progress`, `draft`, `failed`, `published`, `scheduled`, `in_review`, `notification_sent`, `deleted`) (Example: `draft`)
    *   `scheduleDate` (string): Schedule Date (Example: `string`)
    *   `createdBy` (string): Created By (Example: `string`)
    *   `followUpComment` (string): Follow Up Comment on platform. Not allowed on Tiktok and GMB, 280 character limit for Twitter. (Example: `First comment`)
    *   `ogTagsDetails` (object): Og Tags Meta Data
        *   `ogTagsDetails.metaImage` (string): URL of the image that represents the content when shared. (Example: `https://wwww.lifeofanarchitect.com/...stairs.jpg`)
        *   `ogTagsDetails.metaLink` (string): The URL of the original webpage or article. (Example: `https://www.yahoo.com/`)
        *   `ogTagsDetails.ogTitle` (string): The title of the content as it should appear when shared. (Example: `Yahoo | Mail, Weather, Search...`)
    *   `postApprovalDetails` (object): Post Approval Details
        *   `postApprovalDetails.approver` (string): Approver (Example: `iVrVJ2uoXNF0wzcBzgl5`)
        *   `postApprovalDetails.requesterNote` (string): Requester Notes (Example: `Test suggestion`)
        *   `postApprovalDetails.approverNote` (string): Approver Notes (Example: `Test suggestion`)
        *   `postApprovalDetails.approvalStatus` (object): Approval Status (Possible values: `pending`, `approved`, `rejected`, `not_required`) (Example: `approved`)
    *   `scheduleTimeUpdated` (boolean): If schedule datetime is updated (Example: `true`)
    *   `tags` (string[]): Array of Tag Value (Example: `["65f151c99bc2bf3aaf970d72"]`)
    *   `categoryId` (string): Category Id (Example: `65f151c99bc2bf3aaf970d72`)
    *   `tiktokPostDetails` (object): Tiktok Post Details
        *   `tiktokPostDetails.privacyLevel` (object): Privacy level (Possible values: `PUBLIC_TO_EVERYONE`, `MUTUAL_FOLLOW_FRIENDS`, `SELF_ONLY`) (Example: `PUBLIC_TO_EVERYONE`)
        *   `tiktokPostDetails.promoteOtherBrand` (boolean): Promote other brand (Example: `true`)
        *   `tiktokPostDetails.enableComment` (boolean): Enable comment (Example: `true`)
        *   `tiktokPostDetails.enableDuet` (boolean): Enable duet (Example: `true`)
        *   `tiktokPostDetails.enableStitch` (boolean): Enable stitch (Example: `true`)
        *   `tiktokPostDetails.videoDisclosure` (boolean): Video disclosure (Example: `true`)
        *   `tiktokPostDetails.promoteYourBrand` (boolean): Promote your brand (Example: `true`)
    *   `gmbPostDetails` (object): GMB Post Details (if included, date/time sub-fields are required)
        *   `gmbPostDetails.gmbEventType` (string): (Possible values: `STANDARD`, `EVENT`, `OFFER`) (Example: `STANDARD`)
        *   `gmbPostDetails.title` (string): Title (Example: `Event Title`)
        *   `gmbPostDetails.offerTitle` (string): Offer Title (Example: `Hey`)
        *   `gmbPostDetails.startDate` (object): Start Date (outer object)
            *   `gmbPostDetails.startDate.startTime` (object): Start Time (outer object)
        *   `gmbPostDetails.endDate` (object): End Date (outer object)
            *   `gmbPostDetails.endDate.endTime` (object): End Time (outer object)
        *   `gmbPostDetails.termsConditions` (string): Terms Condition Url (Example: `https://google.com/privacy`)
        *   `gmbPostDetails.url` (string): Url (Example: `https://google.com`)
        *   `gmbPostDetails.couponCode` (string): Coupon Code (Example: `BOGO-50`)
        *   `gmbPostDetails.redeemOnlineUrl` (string): Redeem Online Url (Example: `https://google.com`)
        *   `gmbPostDetails.actionType` (object): Action Type (Possible values: `none`, `order`, `book`, `shop`, `learn_more`, `call`, `sign_up`) (Example: `book`)
    *   `linkedinPostDetails` (object): Linkedin Post Details (if included, `pdfTitle` and `postAsPdf` are required)
    *   `pinterestPostDetails` (object): Pinterest Post Details (if included, `boardIds` is required)
        *   `pinterestPostDetails.title` (string): Title of the Pinterest Post (Example: `My Pinterest Pin`)
        *   `pinterestPostDetails.link` (string): Link associated with the Pinterest Post (Example: `https://www.pinterest.com/`)
    *   `facebookPostDetails` (object): Facebook Post Details (if included, `type` is required)
    *   `instagramPostDetails` (object): Instagram Post Details (if included, `type` is required)
        *   `instagramPostDetails.collaborators` (object): Object mapping account IDs to arrays of associated usernames for collaboration. (Example: `{"accountId1":["username1","username2"]}`)
    *   `youtubePostDetails` (object): Youtube Post Details
        *   `youtubePostDetails.title` (string): Title (Example: `Untitled`)
        *   `youtubePostDetails.privacyLevel` (object): Youtube Privacy Level (Possible values: `private`, `public`, `unlisted`) (Example: `public`)
        *   `youtubePostDetails.type` (object): Youtube Post Type (Possible values: `video`, `short`) (Example: `video`)
    *   `mediaOptimization` (boolean): Pass this parameter to optimize the image media (Example: `true`)

### 8. AUTHENTICATION:

*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** `bearer`
*   **Bearer Format:** `JWT`
*   **In:** `header` (Parameter name: `Authorization`)

### 9. RESPONSE FORMAT:

*   **Status Code:** `200 OK`
*   **Structure:**
    ```json
    {
      "success": true,
      "statusCode": 200,
      "message": "Updated Post"
    }
    ```
*   **Example:** `{"success":true,"statusCode":200,"message":"Updated Post"}`

### 10. PURPOSE:
This endpoint allows editing existing social media posts for all supported platforms, enabling customization of content per channel.
