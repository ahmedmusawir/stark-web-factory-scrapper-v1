Here's a structured summary of the API documentation for "Create template":

---

### 1. ENDPOINT NAME
Create template

### 2. CATEGORY
Invoice Template

### 3. HTTP METHOD
POST

### 4. ENDPOINT URL
`/invoices/template`

### 5. FULL URL
`https://services.leadconnectorhq.com/invoices/template`

### 6. REQUIRED PARAMETERS

**Header Parameters:**
*   `Version` (string): API Version.
    *   **Possible values:** `2021-07-28`

**Body Parameters:**
*   `altId` (string): location Id / company Id based on altType
*   `altType` (string): Alt Type.
    *   **Possible values:** `location`
*   `name` (string): Name of the template
*   `businessDetails` (object): Business Details.
    *   **Note:** This object is required, but its sub-fields are not explicitly marked required in the provided schema.
*   `currency` (string): Currency
*   `items` (object[]): Array of invoice items.
    *   **For each item object within `items` array:**
        *   `name` (string): Invoice Item Name
        *   `currency` (string): Currency
        *   `amount` (number): Product amount
        *   `qty` (number): Product Quantity
*   `tipsConfiguration` (object): Configuration for tips on invoices.
    *   **Within `tipsConfiguration` object:**
        *   `tipsPercentage` (string[]): Percentage of tips allowed
        *   `tipsEnabled` (boolean): Tips enabled status
*   `lateFeesConfiguration` (object): Late fees configuration for the invoices.
    *   **Within `lateFeesConfiguration` object:**
        *   `enable` (boolean): Enable late fees
        *   `value` (number): Late Fees Value
        *   `type` (string): Late Fees Type.
            *   **Possible values:** `fixed`, `percentage`
        *   `frequency` (object): Late Fees Frequency.
            *   **Within `frequency` object:**
                *   `intervalCount` (number): Late fees interval count
                *   `interval` (string): Late fees interval.
                    *   **Possible values:** `minute`, `hour`, `day`, `week`, `month`, `one_time`
*   `paymentMethods` (object): Payment Methods for Invoices.
    *   **Within `paymentMethods` object:**
        *   `stripe` (object): Payment Method (Stripe).
            *   **Within `stripe` object:**
                *   `enableBankDebitOnly` (boolean): Enable Bank Debit Only

### 7. OPTIONAL PARAMETERS

**Body Parameters:**
*   `internal` (boolean)
*   `businessDetails.logoUrl` (string): Business Logo URL
*   `businessDetails.name` (string): Business Name
*   `businessDetails.phoneNo` (string): Business Phone Number
*   `businessDetails.address` (object): Business Address
    *   `addressLine1` (string): Address Line 1
    *   `addressLine2` (string): Address Line 2
    *   `city` (string): City
    *   `state` (string): State
    *   `countryCode` (string): Country Code
    *   `postalCode` (string): Postal Code
*   `businessDetails.website` (string): Business Website Link
*   `businessDetails.customValues` (string[]): Custom Values
*   `items[].description` (string): Invoice descriptions
*   `items[].productId` (string): Product Id
*   `items[].priceId` (string): Price Id
*   `items[].taxes` (object[]): Tax.
    *   **If `taxes` array is present, for each tax object:**
        *   `_id` (string)
        *   `name` (string)
        *   `rate` (number)
        *   `calculation` (string):
            *   **Possible values:** `exclusive`
        *   `description` (string)
        *   `taxId` (string)
*   `items[].automaticTaxCategoryId` (string): Tax category id for calculating automatic tax
*   `items[].isSetupFeeItem` (boolean): Setupfee item, only created when 1st invoice of recurring schedule is generated
*   `items[].type` (string): Price type of the item.
    *   **Possible values:** `one_time`, `recurring`
*   `items[].taxInclusive` (boolean): true if item amount is tax inclusive.
    *   **Default value:** `false`
*   `automaticTaxesEnabled` (boolean): Automatic taxes enabled for the Invoice
*   `discount` (object): Discount.
    *   **If `discount` object is present:**
        *   `value` (number): Discount Value.
            *   **Default value:** `0`
        *   `type` (string): Discount type.
            *   **Required if `discount` is present.**
            *   **Possible values:** `percentage`, `fixed`
            *   **Default value:** `percentage`
        *   `validOnProductIds` (string[]): Product Ids on which discount is applicable
*   `termsNotes` (string)
*   `title` (string): Template title
*   `lateFeesConfiguration.grace` (object): Late Fees Grace.
    *   **If `grace` object is present:**
        *   `intervalCount` (number): Late fees grace interval count.
            *   **Required if `grace` is present.**
        *   `interval` (string): Late fees grace interval.
            *   **Required if `grace` is present.**
            *   **Possible values:** `day`
*   `lateFeesConfiguration.maxLateFees` (object): Max late fees payable.
    *   **If `maxLateFees` object is present:**
        *   `type` (string):
            *   **Required if `maxLateFees` is present.**
            *   **Possible values:** `fixed`
        *   `value` (number): Max late fees to pay.
            *   **Required if `maxLateFees` is present.**
*   `invoiceNumberPrefix` (string): prefix for invoice number
*   `attachments` (string[]): attachments for the invoice
*   `miscellaneousCharges` (object): miscellaneous charges for the invoice.
    *   `charges` (array[]): charges for the processing fee. (Example shows `[[null]]`, indicating a potentially complex or specific structure).
    *   `collectedMiscellaneousCharges` (number): collected miscellaneous charges
    *   `paidCharges` (object[]): paid miscellaneous charges.
        *   **If `paidCharges` array is present, for each charge object:**
            *   `name` (string): name of the processing fee
            *   `charge` (number): charge for the processing fee
            *   `amount` (number): amount of the processing fee
            *   `_id` (string): id of the processing fee

### 8. AUTHENTICATION
*   **Scopes:** `invoices/template.write`
*   **Auth Methods:** `OAuth Access Token`, `Private Integration Token`
*   **Token Types:** `Sub-Account Token`, `Agency Token`
*   **Scheme:** Bearer (JWT)

### 9. RESPONSE FORMAT

**Successful Response (200 OK):**
*   **Content Type:** `application/json`
*   **Schema:** An object representing the created invoice template.
    *   `_id` (string): Template Id
    *   `altId` (string): Location Id or Agency Id
    *   `altType` (string): Possible values: `location`
    *   `name` (string): Name of the Template
    *   `businessDetails` (object): Business Details (includes `logoUrl`, `name`, `phoneNo`, `address` object, `website`, `customValues`)
    *   `currency` (string): Currency
    *   `discount` (object): Discount details (`value`, `type`, `validOnProductIds`)
    *   `items` (string[]): Invoice Items (array of objects)
    *   `invoiceNumberPrefix` (string): prefix for invoice number
    *   `total` (number): Total Amount
    *   `createdAt` (string): created at (ISO 8601 datetime)
    *   `updatedAt` (string): updated at (ISO 8601 datetime)

**Error Responses:**
*   **400 Bad Request:** `{"statusCode":400,"message":"Bad Request"}`
*   **401 Unauthorized:** `{"statusCode":401,"message":"Invalid token: access token is invalid","error":"Unauthorized"}`
*   **422 Unprocessable Entity:** `{"statusCode":422,"message":["Unprocessable Entity"],"error":"Unprocessable Entity"}`

### 10. PURPOSE
This API endpoint allows you to create a new invoice template with customizable business details, items, discounts, tips configuration, late fees, payment methods, and other miscellaneous charges.
