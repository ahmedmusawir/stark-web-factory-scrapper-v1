Here is a structured summary of the provided API documentation:

### 1. ENDPOINT NAME:
Get Blogs by Location ID

### 2. CATEGORY:
Blogs

### 3. HTTP METHOD:
GET

### 4. ENDPOINT URL:
`/blogs/site/all`

### 5. FULL URL:
`GET https://services.leadconnectorhq.com/blogs/site/all`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters:**
    *   `Version` (string): API Version. Possible values: `2021-07-28`.
*   **Query Parameters:**
    *   `locationId` (string): Example: `ve9EPM428h8vShlRW1KT`
    *   `skip` (number): Example: `0`
    *   `limit` (number): Example: `4`

### 7. OPTIONAL PARAMETERS:
*   **Query Parameters:**
    *   `searchTerm` (string): search for any post by name. Example: `ai news`

### 8. AUTHENTICATION:
*   **Scope(s):** `blogs/list.readonly`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** `bearer`
*   **Bearer Format:** `JWT`
*   **In:** `header`
*   **Description:** Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account.

### 9. RESPONSE FORMAT:
*   **200 Successful Response (application/json):**
    ```json
    {
      "data": [
        {
          "_id": "lMOzIQZne5m6zQ528sT6",
          "name": "My blog"
        }
      ]
    }
    ```
    *   **Schema:**
        *   `data` (array of objects, required): Object containing response data of blog
            *   `_id` (string, required): Unique identifier of the blog. Example: `lMOzIQZne5m6zQ528sT6`
            *   `name` (string, required): Name of the blog. Example: `My blog`

*   **400 Bad Request (application/json):**
    ```json
    {"statusCode":400,"message":"Bad Request"}
    ```
*   **401 Unauthorized (application/json):**
    ```json
    {"statusCode":401,"message":"Invalid token: access token is invalid","error":"Unauthorized"}
    ```
*   **422 Unprocessable Entity (application/json):**
    ```json
    {"statusCode":422,"message":["Unprocessable Entity"],"error":"Unprocessable Entity"}
    ```

### 10. PURPOSE:
The "Get Blogs by Location ID" API allows you to retrieve blogs associated with a specific Location ID.
