Here's a structured summary of the API documentation for "Send invoice":

### 1. ENDPOINT NAME:
Send invoice

### 2. CATEGORY:
Invoice

### 3. HTTP METHOD:
POST

### 4. ENDPOINT URL:
`/invoices/:invoiceId/send`

### 5. FULL URL:
`https://services.leadconnectorhq.com/invoices/:invoiceId/send`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters:**
    *   `Version` (string): API Version. Possible values: [`2021-07-28`]
*   **Path Parameters:**
    *   `invoiceId` (string): Invoice Id. Example: `6578278e879ad2646715ba9c`
*   **Body Parameters:**
    *   `altId` (string): location Id / company Id based on altType. Example: `6578278e879ad2646715ba9c`
    *   `altType` (string): Alt Type. Possible values: [`location`]. Example: `location`
    *   `userId` (string): Please ensure that the UserId corresponds to an authorized personnel, either by an employee ID or agency ID, to access this location. This account will serve as the primary channel for all future communications and updates. Example: `6578278e879ad2646715ba9c`
    *   `action` (string): Possible values: [`sms_and_email`, `send_manually`, `email`, `sms`]
    *   `liveMode` (boolean): Live Mode

### 7. OPTIONAL PARAMETERS:
*   **Body Parameters:**
    *   `sentFrom` (object): sender details for invoice, valid only if invoice is not sent manually
        *   `fromName` (string): Sender name to be used while sending email notification. Example: `Alex`
        *   `fromEmail` (string): Email id to be used while sending email notification. Example: `alex@example.com`
    *   `autoPayment` (object): auto-payment configuration
        *   `enable` (boolean): **(Required if `autoPayment` object is present)**
        *   `type` (string):
        *   `paymentMethodId` (string):
        *   `customerId` (string):
        *   `card` (object):
            *   `brand` (string): **(Required if `card` object is present)**
            *   `last4` (string): **(Required if `card` object is present)**
        *   `usBankAccount` (object):
            *   `bank_name` (string): **(Required if `usBankAccount` object is present)**
            *   `last4` (string): **(Required if `usBankAccount` object is present)**
        *   `sepaDirectDebit` (object):
            *   `bank_code` (string): **(Required if `sepaDirectDebit` object is present)**
            *   `last4` (string): **(Required if `sepaDirectDebit` object is present)**
            *   `branch_code` (string): **(Required if `sepaDirectDebit` object is present)**
        *   `bacsDirectDebit` (object):
            *   `sort_code` (string): **(Required if `bacsDirectDebit` object is present)**
            *   `last4` (string): **(Required if `bacsDirectDebit` object is present)**
        *   `becsDirectDebit` (object):
            *   `bsb_number` (string): **(Required if `becsDirectDebit` object is present)**
            *   `last4` (string): **(Required if `becsDirectDebit` object is present)**
        *   `cardId` (string):
        *   `provider` (object):

### 8. AUTHENTICATION:
*   **Scope(s):** `invoices.write`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`, `Agency Token`
*   **Scheme:** Bearer (JWT)

### 10. PURPOSE:
This API endpoint allows sending an invoice by its ID, with options for sending method (SMS, email, both, or manually) and auto-payment configuration.
