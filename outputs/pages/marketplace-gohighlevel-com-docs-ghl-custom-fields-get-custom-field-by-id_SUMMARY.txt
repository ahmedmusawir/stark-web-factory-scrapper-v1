Here is a structured summary of the API documentation for "Get Custom Field / Folder By Id":

---

### 1. ENDPOINT NAME:
Get Custom Field / Folder By Id

### 2. CATEGORY:
Custom Fields V2

### 3. HTTP METHOD:
GET

### 4. ENDPOINT URL:
`/custom-fields/:id`

### 5. FULL URL:
`https://services.leadconnectorhq.com/custom-fields/:id`

### 6. REQUIRED PARAMETERS:

*   **Header Parameters:**
    *   `Version` (string): API Version. Possible values: [`2021-07-28`]
*   **Path Parameters:**
    *   `id` (string): Unique identifier of the custom field or folder.

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:

*   **Scope(s)**: `locations/customFields.readonly`
*   **Auth Method(s)**: `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s)**: `Sub-Account Token`
*   **Scheme**: `bearer`
*   **Bearer Format**: `JWT`
*   **Location**: `header`
*   **Description**: Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account.

### 9. RESPONSE FORMAT:

*   **Successful Response (200 OK):**
    *   **Content Type**: `application/json`
    *   **Schema**:
        ```json
        {
          "field": {
            "locationId": "string",          // required: Location Id
            "name": "string",                // Field name
            "description": "string",         // Description of the field
            "placeholder": "string",         // Placeholder text for the field
            "showInForms": boolean,          // required: Whether the field should be shown in forms
            "options": [                     // Options for the field (Optional, valid only for SINGLE_OPTIONS, MULTIPLE_OPTIONS, RADIO, CHECKBOX, TEXTBOX_LIST type)
              {
                "key": "string",             // required: Key of the option
                "label": "string",           // required: Value of the option
                "url": "string"              // URL associated with the option (Optional, valid only for RADIO type)
              }
            ],
            "acceptedFormats": "string",     // Allowed file formats for uploads. Possible values: [`.pdf`, `.docx`, `.doc`, `.jpg`, `.jpeg`, `.png`, `.gif`, `.csv`, `.xlsx`, `.xls`, `all`]
            "id": "string",                  // required: Unique identifier of the object
            "objectKey": "string",           // required: The key for your custom / standard object. Example: "custom_object.pet"
            "dataType": "string",            // required: Type of field. Possible values: [`TEXT`, `LARGE_TEXT`, `NUMERICAL`, `PHONE`, `MONETORY`, `CHECKBOX`, `SINGLE_OPTIONS`, `MULTIPLE_OPTIONS`, `DATE`, `TEXTBOX_LIST`, `FILE_UPLOAD`, `RADIO`]
            "parentId": "string",            // required: ID of the parent folder
            "fieldKey": "string",            // required: Field key. Example: "custom_object.pet.name"
            "allowCustomOption": boolean,    // Determines if users can add a custom option value
            "maxFileLimit": number,          // Maximum file limit for uploads
            "dateAdded": "date-time",        // required: Date and time when the object was added
            "dateUpdated": "date-time"       // required: Date and time when the object was last updated
          }
        }
        ```
*   **Error Responses:**
    *   **400 Bad Request**:
        ```json
        {"statusCode":400,"message":"Bad Request"}
        ```
    *   **401 Unauthorized**:
        ```json
        {"statusCode":401,"message":"Invalid token: access token is invalid","error":"Unauthorized"}
        ```

### 10. PURPOSE:
This endpoint retrieves a custom field or a custom field folder by its unique identifier. It currently supports Custom Objects and Company (Business) objects.
