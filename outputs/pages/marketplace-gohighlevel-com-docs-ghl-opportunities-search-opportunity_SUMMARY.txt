Here's a structured summary of the API documentation:

### 1. ENDPOINT NAME
Search Opportunity

### 2. CATEGORY
Opportunities

### 3. HTTP METHOD
GET

### 4. ENDPOINT URL
`/opportunities/search`

### 5. FULL URL
`https://services.leadconnectorhq.com/opportunities/search`

### 6. REQUIRED PARAMETERS
*   **Version** (string): API Version (Possible value: `2021-07-28`)
*   **location_id** (string): Location Id (Example: `i2SpAtBVHSVea1sL6oah`)

### 7. OPTIONAL PARAMETERS
*   **q** (string): Search query (Example: `john@deo.com`)
*   **pipeline_id** (string): Pipeline Id (Example: `bCkKGpDsyPP4peuKowkG`)
*   **pipeline_stage_id** (string): Stage Id (Example: `7915dedc-8f18-44d5-8bc3-77c04e994a10`)
*   **contact_id** (string): Contact Id (Example: `WFwVrSSjZ2CNHbZThQX2`)
*   **status** (string): Opportunity status (Possible values: [`open`, `won`, `lost`, `abandoned`, `all`])
*   **assigned_to** (string): User Id assigned to (Example: `082goXVW3lIExEQPOnd3`)
*   **campaignId** (string): Campaign Id (Example: `Y2I9XM7aO1hncuSOlc9L`)
*   **id** (string): Opportunity Id (Example: `123akv4LFn6C9frZoy3e`)
*   **order** (string): Sort order (Example: `added_asc`)
*   **endDate** (string): End date (Example: `mm-dd-yyyy`)
*   **startAfter** (string): Start After timestamp (Example: `1628008053263`)
*   **startAfterId** (string): Start After Id (Example: `UIaE1WjAwWKdlyD7osQI`)
*   **date** (string): Start date (Example: `mm-dd-yyyy`)
*   **country** (string): Country (Example: `US`)
*   **page** (number): Page number (Default value: `1`)
*   **limit** (number): Limit Per Page records count. (Maximum `100`, Default `20`)
*   **getTasks** (boolean): Get Tasks in contact (`true`/`false`)
*   **getNotes** (boolean): Get Notes in contact (`true`/`false`)
*   **getCalendarEvents** (boolean): Get Calendar events in contact (`true`/`false`)

### 8. AUTHENTICATION
*   **Scope(s):** `opportunities.readonly`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** Bearer (JWT)

This endpoint allows searching for opportunities based on various criteria such as location, pipeline, contact, status, and other filters.
