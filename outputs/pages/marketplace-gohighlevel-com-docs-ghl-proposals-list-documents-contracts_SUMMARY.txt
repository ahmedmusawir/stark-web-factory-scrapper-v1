Here's a structured summary of the API documentation:

---

### 1. ENDPOINT NAME:
List documents

### 2. CATEGORY:
Proposals (sub-category: Documents)

### 3. HTTP METHOD:
GET

### 4. ENDPOINT URL:
`/proposals/document`

### 5. FULL URL:
`https://services.leadconnectorhq.com/proposals/document`

### 6. REQUIRED PARAMETERS:
*   **Version** (string): API Version.
    *   Possible values: `2021-07-28`
*   **locationId** (string): Location Id.

### 7. OPTIONAL PARAMETERS:
*   **status** (string): Document status, pass as comma separated values.
    *   Possible values: `draft`, `sent`, `viewed`, `completed`, `accepted`
*   **paymentStatus** (string): Payment status, pass as comma separated values.
    *   Possible values: `waiting_for_payment`, `paid`, `no_payment`
*   **limit** (number): Limit to fetch number of records.
*   **skip** (number): Skip number of records.
*   **query** (string): Search string.
*   **dateFrom** (string): Date start from (ISO 8601), dateFrom & DateTo must be provided together.
*   **dateTo** (string): Date to (ISO 8601), dateFrom & DateTo must be provided together.

### 8. AUTHENTICATION:
*   **Auth Method(s)**: `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s)**: `Sub-Account Token`, `Agency Token`
*   **Security Scheme**: HTTP Bearer (JWT) in the `Authorization` header.

### 10. PURPOSE:
This endpoint retrieves a list of documents for a specified location, with options to filter by status, payment status, date range, and search query.
