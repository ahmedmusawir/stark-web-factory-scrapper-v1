Here is a structured summary of the API documentation:

### 1. ENDPOINT NAME:
Fetch List of Redirects

### 2. CATEGORY:
Funnels (specifically, Redirects within Funnels)

### 3. HTTP METHOD:
GET

### 4. ENDPOINT URL:
`/funnels/lookup/redirect/list`

### 5. FULL URL:
`https://services.leadconnectorhq.com/funnels/lookup/redirect/list`

### 6. REQUIRED PARAMETERS:
*   **Version** (string): API Version. Possible values: `2021-07-28` (Header Parameter)
*   **locationId** (string): Example: `6p2RxpgtMKQwO3E6IUaT` (Query Parameter)
*   **limit** (number): Example: `20` (Query Parameter)
*   **offset** (number): Example: `10` (Query Parameter)

### 7. OPTIONAL PARAMETERS:
*   **search** (string): Example: `example.com/test` (Query Parameter)

### 8. AUTHENTICATION:
*   **Scope(s)**: `funnels/redirect.readonly`
*   **Auth Method(s)**: `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s)**: `Sub-Account Token`
*   **Scheme**: `bearer`
*   **Bearer Format**: `JWT`
*   **In**: `header`

### 9. RESPONSE FORMAT:
*   **Status Code**: `200` (Successful response - List of URL redirects returned)
*   **Content Type**: `application/json`
*   **Schema**:
    ```json
    {
      "data": {
        "count": 42,
        "data": []
      }
    }
    ```
    *   **data** (object): Object containing the count of redirects and an array of redirect data.
        *   **count** (number): Total count of redirects.
        *   **data** (array): Array of redirect objects (structure not detailed but indicated as an empty array in the example).
*   **Status Code**: `422` (Unprocessable Entity - The provided data is invalid or incomplete)

### 10. PURPOSE:
Retrieves a list of all URL redirects based on the given query parameters.
