Here is a structured summary of the provided API documentation:

### 1. ENDPOINT NAME:
Disable SaaS for locations

### 2. CATEGORY:
Saas

### 3. HTTP METHOD:
POST

### 4. ENDPOINT URL:
`/saas-api/public-api/bulk-disable-saas/:companyId`

### 5. FULL URL:
`https://services.leadconnectorhq.com/saas-api/public-api/bulk-disable-saas/:companyId`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters:**
    *   Version (string): API Version. Possible values: `[2021-04-15]`
*   **Path Parameters:**
    *   companyId (string): Company ID to disable SaaS for. Example: `5DP4iH6HLkQsiKESj6rh`
*   **Body Parameters (application/json):**
    *   locationIds (string[]): Location IDs. Example: `["locationId1","locationId2"]`

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Agency Token`
*   **Authorization Header:** `Authorization: Bearer <TOKEN>` (Use the Access Token generated with user type as Company)

### 10. PURPOSE:
This endpoint is used to disable SaaS for a list of specified locations belonging to a given company. Note that this endpoint is deprecated.
