Here is a structured summary of the "Get Calendars" API documentation:

---

### 1. ENDPOINT NAME
Get Calendars

### 2. CATEGORY
Calendars

### 3. HTTP METHOD
GET

### 4. ENDPOINT URL
/calendars/

### 5. FULL URL
https://services.leadconnectorhq.com/calendars/

### 6. REQUIRED PARAMETERS
*   **Version** (string): API Version (Possible values: `2021-04-15`)
*   **locationId** (string): Location Id (Example: `ve9EPM428h8vShlRW1KT`)

### 7. OPTIONAL PARAMETERS
*   **groupId** (string): Group Id (Example: `BqTwX8QFwXzpegMve9EQ`)
*   **showDrafted** (boolean): Show drafted (Default value: `true`)

### 8. AUTHENTICATION
*   **Scope(s)**: `calendars.readonly`
*   **Auth Method(s)**: `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s)**: `Sub-Account Token`

### 10. PURPOSE
This endpoint retrieves all calendars associated with a specific location.
