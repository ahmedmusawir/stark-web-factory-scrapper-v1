Here is a structured summary of the "Update invoice" API documentation:

### 1. ENDPOINT NAME:
Update invoice

### 2. CATEGORY:
Invoice

### 3. HTTP METHOD:
PUT

### 4. ENDPOINT URL:
`/invoices/:invoiceId`

### 5. FULL URL:
`https://services.leadconnectorhq.com/invoices/:invoiceId`

### 6. REQUIRED PARAMETERS:

*   **Header Parameters:**
    *   `Version` (string): API Version. Possible values: [`2021-07-28`]

*   **Path Parameters:**
    *   `invoiceId` (string): Invoice Id. Example: `6578278e879ad2646715ba9c`

*   **Body Parameters:**
    *   `altId` (string): location Id / company Id based on altType. Example: `6578278e879ad2646715ba9c`
    *   `altType` (string): Alt Type. Possible values: [`location`]. Example: `location`
    *   `name` (string): Name to be updated. Example: `New Invoice`
    *   `currency` (string): Currency. Example: `USD`
    *   `contactDetails` (object):
        *   `id` (string): Contact ID. Example: `6578278e879ad2646715ba9c`
        *   `name` (string): Contact Name. Example: `Alex`
        *   `phoneNo` (string): Contact Phone Number. Example: `+1234567890`
        *   `email` (string): Contact Email. Example: `alex@example.com`
    *   `invoiceItems` (array of objects):
        *   `name` (string): Invoice Item Name. Example: `ABC Product`
        *   `currency` (string): Currency. Example: `USD`
        *   `amount` (number): Product amount. Example: `999`
        *   `qty` (number): Product Quantity. Example: `1`
        *   `taxes` (array of objects, if present):
            *   `_id` (string)
            *   `name` (string)
            *   `rate` (number)
    *   `issueDate` (string): Issue date in YYYY-MM-DD format. Example: `2023-01-01`
    *   `dueDate` (string): Due date in YYYY-MM-DD format. Example: `2023-01-14`
    *   `discount.type` (string, if `discount` object is present): Discount type. Possible values: [`percentage`, `fixed`]. Default value: `percentage`. Example: `percentage`
    *   `paymentSchedule.type` (string, if `paymentSchedule` object is present): Payment schedule type. Possible values: [`fixed`, `percentage`]. Example: `percentage`
    *   `paymentSchedule.schedules` (array of strings, if `paymentSchedule` object is present): payment schedule item.
    *   `tipsConfiguration.tipsPercentage` (array of strings, if `tipsConfiguration` object is present): Percentage of tips allowed. Example: `[5,10,15]`
    *   `tipsConfiguration.tipsEnabled` (boolean, if `tipsConfiguration` object is present): Tips enabled status. Example: `true`
    *   `paymentMethods.stripe.enableBankDebitOnly` (boolean, if `paymentMethods.stripe` object is present): Enable Bank Debit Only. Example: `false`
    *   `attachments` (array of objects, if present):
        *   `id` (string): Id of the file selected. Example: `6241712be68f7a98102ba272`
        *   `name` (string): Name of the file. Example: `Electronics.pdf`
        *   `url` (string): URL of the file. Example: `https://example.com/digital-delivery`
        *   `type` (string): Type of the file.
        *   `size` (number): Size of the file. Example: `10000`
    *   `miscellaneousCharges.charges` (array of arrays, if `miscellaneousCharges` object is present): charges for the processing fee.
    *   `miscellaneousCharges.paidCharges` (array of objects, if `miscellaneousCharges` object is present):
        *   `name` (string): name of the processing fee. Example: `Processing Fee`
        *   `charge` (number): charge for the processing fee. Example: `10`
        *   `amount` (number): amount of the processing fee. Example: `10`
        *   `_id` (string): id of the processing fee. Example: `673d01d7d547648a8dab6211`

### 7. OPTIONAL PARAMETERS:

*   **Body Parameters:**
    *   `title` (string): Title for the invoice. Example: `INVOICE`
    *   `description` (string): Description. Example: `ABC Corp payments`
    *   `businessDetails` (object): Business details which need to be updated
        *   `logoUrl` (string): Business Logo URL. Example: `https://example.com/logo.png`
        *   `name` (string): Business Name. Example: `ABC Corp.`
        *   `phoneNo` (string): Business Phone Number. Example: `+1-214-559-6993`
        *   `address` (object): Business Address
            *   `addressLine1` (string): Address Line 1. Example: `9931 Beechwood`
            *   `addressLine2` (string): Address Line 2. Example: `Beechwood`
            *   `city` (string): City. Example: `St. Houston`
            *   `state` (string): State. Example: `TX`
            *   `countryCode` (string): Country Code. Example: `US`
            *   `postalCode` (string): Postal Code. Example: `559-6993`
        *   `website` (string): Business Website Link. Example: `wwww.example.com`
    *   `customValues` (array of strings): Custom Values
    *   `invoiceNumber` (string): Invoice Number. Example: `1001`
    *   `contactId` (string): Id of the contact which you need to send the invoice. Example: `6578278e879ad2646715ba9c`
    *   `contactDetails.additionalEmails` (array of objects, if `contactDetails` is present):
        *   `email` (string): Example: `alex@example.com`
    *   `contactDetails.companyName` (string, if `contactDetails` is present): Contact Company Name. Example: `ABC Corp.`
    *   `contactDetails.address` (object, if `contactDetails` is present):
        *   `addressLine1` (string): Address Line 1. Example: `9931 Beechwood`
        *   `addressLine2` (string): Address Line 2. Example: `Beechwood`
        *   `city` (string): City. Example: `St. Houston`
        *   `state` (string): State. Example: `TX`
        *   `countryCode` (string): Country Code. Example: `US`
        *   `postalCode` (string): Postal Code. Example: `559-6993`
    *   `contactDetails.customFields` (array of strings, if `contactDetails` is present): Custom Values
    *   `termsNotes` (string): Terms notes, Also supports HTML markups. Example: `<p>This is a default terms.</p>`
    *   `discount.value` (number, if `discount` object is present): Discount Value. Default value: `0`. Example: `10`
    *   `discount.validOnProductIds` (array of strings, if `discount` object is present): Product Ids on which discount is applicable. Example: `[ '6579751d56f60276e5bd4154' ]`
    *   `invoiceItems.description` (string, if `invoiceItems` is present): Invoice descriptions. Example: `ABC Corp.`
    *   `invoiceItems.productId` (string, if `invoiceItems` is present): Product Id. Example: `6578278e879ad2646715ba9c`
    *   `invoiceItems.priceId` (string, if `invoiceItems` is present): Price Id. Example: `6578278e879ad2646715ba9c`
    *   `invoiceItems.taxes` (array of objects, if present):
        *   `calculation` (string): Possible values: [`exclusive`]
        *   `description` (string)
        *   `taxId` (string)
    *   `invoiceItems.automaticTaxCategoryId` (string, if `invoiceItems` is present): Tax category id for calculating automatic tax. Example: `6578278e879ad2646715ba9c`
    *   `invoiceItems.isSetupFeeItem` (boolean, if `invoiceItems` is present): Setupfee item, only created when 1st invoice of recurring schedule is generated
    *   `invoiceItems.type` (string, if `invoiceItems` is present): Price type of the item. Possible values: [`one_time`, `recurring`]. Example: `one_time`
    *   `invoiceItems.taxInclusive` (boolean, if `invoiceItems` is present): true if item amount is tax inclusive. Default value: `false`. Example: `true`
    *   `automaticTaxesEnabled` (boolean): Automatic taxes enabled for the Invoice. Example: `true`
    *   `liveMode` (boolean): Payment mode
    *   `xeroDetails` (object):
        *   `invoiceNumberPrefix` (string): prefix for invoice number. Example: `INV-`
    *   `paymentMethods` (object): Payment Methods for Invoices
        *   `stripe` (object): Payment Method
    *   `miscellaneousCharges.collectedMiscellaneousCharges` (number, if `miscellaneousCharges` object is present): collected miscellaneous charges. Example: `10`

### 8. AUTHENTICATION:
*   **Scopes:** `invoices.write`
*   **Auth Methods:** `OAuth Access Token`, `Private Integration Token`
*   **Token Types:** `Sub-Account Token`, `Agency Token`

### 9. RESPONSE FORMAT:

*   **Successful Response (200 OK):**
    *   **Content Type:** `application/json`
    *   **Schema (object):**
        *   `_id` (string, required): Invoice Id. Example: `6578278e879ad2646715ba9c`
        *   `status` (string, required): Invoice Status. Possible values: [`draft`, `sent`, `payment_processing`, `paid`, `void`, `partially_paid`]. Example: `draft`
        *   `liveMode` (boolean, required): Live Mode. Example: `false`
        *   `amountPaid` (number, required): Amount Paid. Example: `0`
        *   `altId` (string, required): Location Id or Agency Id. Example: `6578278e879ad2646715ba9c`
        *   `altType` (string, required): Possible values: [`location`]
        *   `name` (string, required): Name of the invoice. Example: `New Invoice`
        *   `businessDetails` (object, required): Business Details. Example: `{"name":"Alex","address":{"addressLine1":"9931 Beechwood","city":"St. Houston","state":"TX","countryCode":"USA","postalCode":"559-6993"},"phoneNo":"+1-214-559-6993","website":"www.example.com"}`
        *   `invoiceNumber` (number, required): Invoice Number. Example: `19`
        *   `currency` (string, required): Currency. Example: `USD`
        *   `contactDetails` (object, required): Contact Details. Example: `{"id":"c6tZZU0rJBf30ZXx9Gli","phoneNo":"+1-214-559-6993","email":"alex@example.com","customFields":[],"name":"Alex","address":{"countryCode":"US"}}`
        *   `issueDate` (string, required): Issue date in YYYY-MM-DD format. Example: `2023-01-01`
        *   `dueDate` (string, required): Due date in YYYY-MM-DD format. Example: `2023-01-01`
        *   `discount` (object): Discount. Example: `{"type":"percentage","value":0}`
        *   `invoiceItems` (array of strings, required): Invoice Items. Example: `[{"taxes":[],"_id":"c6tZZU0rJBf30ZXx9Gli","productId":"c6tZZU0rJBf30ZXx9Gli","priceId":"c6tZZU0rJBf30ZXx9Gli","currency":"USD","name":"Macbook Pro","qty":1,"amount":999}]`
        *   `total` (number, required): Total Amount. Example: `999`
        *   `title` (string, required): Title. Example: `INVOICE`
        *   `amountDue` (number, required): Total Amount Due. Example: `999`
        *   `createdAt` (string, required): created at. Example: `2023-12-12T09:27:42.355Z`
        *   `updatedAt` (string, required): updated at. Example: `2023-12-12T09:27:42.355Z`
        *   `automaticTaxesEnabled` (boolean): Automatic taxes enabled for the Invoice. Example: `true`
        *   `automaticTaxesCalculated` (boolean): Is Automatic taxes calculated for the Invoice items. Example: `true`
        *   `paymentSchedule` (object): split invoice into payment schedule summing up to full invoice amount.
    *   **Example (auto):** Provided in documentation.

*   **Error Responses:**
    *   **400 Bad Request:** `{"statusCode":400,"message":"Bad Request"}`
    *   **401 Unauthorized:** `{"statusCode":401,"message":"Invalid token: access token is invalid","error":"Unauthorized"}`
    *   **422 Unprocessable Entity:** `{"statusCode":422,"message":["Unprocessable Entity"],"error":"Unprocessable Entity"}`

API to update an existing invoice by its invoice ID.
