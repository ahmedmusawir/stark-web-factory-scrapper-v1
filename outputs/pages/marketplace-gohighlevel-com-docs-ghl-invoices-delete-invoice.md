# Delete invoice
```
DELETE 
## https://services.leadconnectorhq.com/invoices/:invoiceId

```

API to delete invoice by invoice id
### Requirements
#### Scope(s)
`invoices.write`
#### Auth Method(s)
`OAuth Access Token``Private Integration Token`
#### Token Type(s)
`Sub-Account Token``Agency Token`
## Request[​](https://marketplace.gohighlevel.com/docs/ghl/invoices/delete-invoice/index.html#request "Direct link to Request")
### Header Parameters
**Version** stringrequired
**Possible values:** [`2021-07-28`]
API Version


### Path Parameters
**invoiceId** stringrequired
Invoice Id
Example: 6578278e879ad2646715ba9c


### Query Parameters
**altId** stringrequired
location Id / company Id based on altType
Example: 6578278e879ad2646715ba9c
**altType** stringrequired
**Possible values:** [`location`]
Alt Type
Example: location
