Here is a structured summary of the API documentation:

### 1. ENDPOINT NAME:
List Estimate Templates

### 2. CATEGORY:
Invoice (specifically Estimate Templates)

### 3. HTTP METHOD:
GET

### 4. ENDPOINT URL:
`/invoices/estimate/template`

### 5. FULL URL:
`https://services.leadconnectorhq.com/invoices/estimate/template`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters:**
    *   Version (string): API Version (Possible values: `2021-07-28`)
*   **Query Parameters:**
    *   altId (string): Location Id or Agency Id (Example: `6578278e879ad2646715ba9c`)
    *   altType (string): Possible values: [`location`]
    *   limit (string): Limit the number of items to return (Example: `10`)
    *   offset (string): Number of items to skip (Example: `10`)

### 7. OPTIONAL PARAMETERS:
*   **Query Parameters:**
    *   search (string): To search for an estimate template by id / name (Example: `Alex`)

### 8. AUTHENTICATION:
*   **Scope(s):** `invoices/estimate.readonly`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`, `Agency Token`
*   **Scheme:** Bearer (JWT)
*   **In:** Header (Authorization)
*   **Description:** Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account.

### 9. RESPONSE FORMAT:
*   **Status Code:** 200 (Successful response)
*   **Content Type:** `application/json`
*   **Schema:**
    *   `data` (string[]): List of estimate templates (required)
    *   `totalCount` (number): Total number of estimate templates available (required)
    *   `traceId` (string): Unique identifier for tracing the request (required)
*   **Example:**
    ```json
    {"data":["string"],"totalCount":0,"traceId":"string"}
    ```
*   **Error Responses:**
    *   400 Bad Request
    *   401 Unauthorized
    *   422 Unprocessable Entity

### 10. PURPOSE:
Get a list of estimate templates or a specific template by ID.
