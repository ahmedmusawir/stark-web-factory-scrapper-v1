**1. ENDPOINT NAME:** Get posts

**2. CATEGORY:** Social Planner / Post

**3. HTTP METHOD:** POST

**4. ENDPOINT URL:** /social-media-posting/:locationId/posts/list

**5. FULL URL:** https://services.leadconnectorhq.com/social-media-posting/:locationId/posts/list

**6. REQUIRED PARAMETERS:**
*   **Header Parameters:**
    *   Version (string): API Version. Possible values: `2021-07-28`
*   **Path Parameters:**
    *   locationId (string): Location Id. Example: `ve9EPM428h8vShlRW1KT`
*   **Body Parameters:**
    *   type (string): Type of posts to filter. Must be one of the following values: `recent`, `all`, `scheduled`, `draft`, `failed`, `in_review`, `published`, `in_progress`, and `deleted`. Default value: `all`. Example: `Filter type`
    *   skip (string): Number of records to skip for pagination. Default value: `0`. Example: `1`
    *   limit (string): Maximum number of records to return. Default value: `10`. Example: `10`
    *   fromDate (string): Start date for filtering posts. Example: `2024-01-22T05:32:49.463Z`
    *   toDate (string): End date for filtering posts. Example: `2024-03-20T05:32:49.463Z`
    *   includeUsers (string): Include User Data. Example: `true`

**7. OPTIONAL PARAMETERS:**
*   **Body Parameters:**
    *   accounts (string): List of account Ids separated by comma as a string. Example: `660a83fc29deacac50033e2b_omaDY3RbWtTP511e808O_17841465964543589, 38bF83fc29deacac50033e2b_omaDY3RbWtr3P11e808O_17841465964543998`
    *   postType (object): Post Type must be one of the following values: `post`, `story`, `reel`. Example: `post`

**8. AUTHENTICATION:**
*   **Scope(s):** `socialplanner/post.readonly`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** Bearer (JWT)
*   **In:** header
