Here's a structured summary of the "Get Calendar" API documentation:

1.  **ENDPOINT NAME:** Get Calendar

2.  **CATEGORY:** Calendars

3.  **HTTP METHOD:** GET

4.  **ENDPOINT URL:** /calendars/:calendarId

5.  **FULL URL:** https://services.leadconnectorhq.com/calendars/:calendarId

6.  **REQUIRED PARAMETERS:**
    *   Version (string, Header Parameter): API Version. Possible values: `2021-04-15`
    *   calendarId (string, Path Parameter): Calendar Id. Example: `ocQHyuzHvysMo5N5VsXc`

7.  **OPTIONAL PARAMETERS:**
    *   Not specified in documentation

8.  **AUTHENTICATION:**
    *   **Scope(s):** `calendars.readonly`
    *   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
    *   **Token Type(s):** `Sub-Account Token`
