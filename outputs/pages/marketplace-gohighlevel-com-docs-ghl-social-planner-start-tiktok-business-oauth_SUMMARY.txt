Here is a structured summary of the provided API documentation:

### 1. ENDPOINT NAME:
Starts OAuth For Tiktok Business Account

### 2. CATEGORY:
Social Planner (specifically Oauth | Tiktok Business)

### 3. HTTP METHOD:
GET

### 4. ENDPOINT URL:
`/social-media-posting/oauth/tiktok-business/start`

### 5. FULL URL:
`https://services.leadconnectorhq.com/social-media-posting/oauth/tiktok-business/start`

### 6. REQUIRED PARAMETERS:
*   **Version** (string): API Version. Possible values: `2021-07-28`
*   **locationId** (string): Location Id. Example: `w37swmmLbA02zgqKPpxITe2`
*   **userId** (string): User Id. Example: `u37swmmLbA02zgqKPpxITe2`

### 7. OPTIONAL PARAMETERS:
*   **page** (string): Page. Example: `integration`
*   **reconnect** (string): Reconnect. Example: `true`

### 8. AUTHENTICATION:
*   **Scope(s)**: `socialplanner/oauth.readonly`
*   **Auth Method(s)**: `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s)**: `Sub-Account Token`
*   **Header**: `Authorization: Bearer <TOKEN>` (JWT bearer format)

### 9. RESPONSE FORMAT:
The API itself returns no direct successful HTTP response body (e.g., 200 OK with JSON). Instead, it navigates the user to the TikTok Business login OAuth screen. Upon successful login, the result is communicated back to the originating window via a JavaScript `window.postMessage` event.

**Event Data Response (from `window.addEventListener('message', ...)`):**
```json
{
  "actionType": "close",
  "page": "social-media-posting",
  "platform": "tiktok-business",
  "placement": "placement",
  "accountId": "658a9b6833b91e0ecb8f3958",
  "reconnectAccounts": ["658a9b6833b91e0ecb834acd", "efd2daa9b6833b91e0ecb8f3511"]
}
```

**Error Responses:**
*   **400 Bad Request:**
    ```json
    {"statusCode":400,"message":"Bad Request"}
    ```
*   **401 Unauthorized:**
    ```json
    {"statusCode":401,"message":"Invalid token: access token is invalid","error":"Unauthorized"}
    ```
*   **422 Unprocessable Entity:**
    ```json
    {"statusCode":422,"message":["Unprocessable Entity"],"error":"Unprocessable Entity"}
    ```

### 10. PURPOSE:
This endpoint initiates the OAuth flow for a user to log in and authorize their TikTok Business account, redirecting the user to TikTok's login screen and communicating the success or failure via a JavaScript event listener.
