Here's a structured summary of the API documentation for "Create Note":

### 1. ENDPOINT NAME:
Create Note

### 2. CATEGORY:
Calendars

### 3. HTTP METHOD:
POST

### 4. ENDPOINT URL:
`/calendars/appointments/:appointmentId/notes`

### 5. FULL URL:
`https://services.leadconnectorhq.com/calendars/appointments/:appointmentId/notes`

### 6. REQUIRED PARAMETERS:
*   **Header Parameter:**
    *   `Version` (string): API Version. Possible values: [`2021-04-15`]
*   **Path Parameter:**
    *   `appointmentId` (string): Appointment ID
*   **Body Parameter:**
    *   `body` (string): Note body. Possible values: `<= 5000 characters`

### 7. OPTIONAL PARAMETERS:
*   **Body Parameter:**
    *   `userId` (string): User ID

### 8. AUTHENTICATION:
*   **Scope(s):** `calendars/events.write`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** `bearer` (bearerFormat: `JWT`)
*   **In:** `header` (Header name: `Authorization`)
*   **Description:** Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account.

### 9. RESPONSE FORMAT:
*   **Status Code:** `201` (Successful response)
*   **Structure (application/json):**
    ```json
    {
      "note": {
        "id": "HGPcayliwcdoUFzvbTok",
        "body": "lorem ipsum",
        "userId": "TUcmRxWrjqzJS8EjkxNK",
        "dateAdded": "2021-07-08T12:02:11.285Z",
        "contactId": "TUcmRxWrjqzJS8EjkxNK",
        "createdBy": {
          "id": "TUcmRxWr",
          "name": "John Doe"
        }
      }
    }
    ```
*   **Error Responses:**
    *   `400 Bad Request`: `{"statusCode":400,"message":"Bad Request"}`
    *   `401 Unauthorized`: `{"statusCode":401,"message":"Invalid token: access token is invalid","error":"Unauthorized"}`

### 10. PURPOSE:
This endpoint allows creating a new note for a specific appointment within a calendar.
