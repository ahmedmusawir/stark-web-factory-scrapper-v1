Here is a structured summary of the API documentation:

### STRUCTURED SUMMARY

1.  **ENDPOINT NAME**: Bulk Delete / Trash Files or Folders

2.  **CATEGORY**: Media Storage (specifically Medias)

3.  **HTTP METHOD**: PUT

4.  **ENDPOINT URL**: `/medias/delete-files`

5.  **FULL URL**: `https://services.leadconnectorhq.com/medias/delete-files`

6.  **REQUIRED PARAMETERS**:
    *   **Header Parameters:**
        *   Version (string): API Version. Possible values: `2021-07-28`
    *   **Body Parameters:**
        *   filesToBeDeleted (object[]): Array of file objects to be deleted or trashed.
            *   _id (string): Unique identifier of the file or folder to be deleted. Example: `686f630df0d3166d68fbcec2`
        *   altType (string): Type of entity that owns the files. Possible values: `location`. Example: `location`
        *   altId (string): Location identifier. Example: `sx6wyHhbFdRXh302LLNR`
        *   status (string): Status to set for the files (deleted or trashed). Possible values: `deleted`, `trashed`. Example: `deleted`

7.  **OPTIONAL PARAMETERS**: Not specified in documentation

8.  **AUTHENTICATION**:
    *   Auth Method(s): `OAuth Access Token`, `Private Integration Token`
    *   Token Type(s): `Sub-Account Token`
    *   Scheme: Bearer (JWT)
    *   Header: `Authorization: Bearer <TOKEN>`

9.  **RESPONSE FORMAT**:
    *   Status Code: `200`
    *   Content Type: `application/json`
    *   Schema/Example:
        ```json
        [
          {
            "deleted": true,
            "id": "686f630df0d3166d68fbcec2"
          }
        ]
        ```
    *   Description: Successful response

10. **PURPOSE**: Soft-deletes or trashes multiple files and folders in a single request.
