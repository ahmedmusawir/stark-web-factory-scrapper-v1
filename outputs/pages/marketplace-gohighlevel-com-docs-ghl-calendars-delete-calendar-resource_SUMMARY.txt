Here is a structured summary of the API documentation:

### 1. ENDPOINT NAME:
Delete Calendar Resource

### 2. CATEGORY:
Calendars (specifically Calendar Resources: Rooms & Equipments)

### 3. HTTP METHOD:
DELETE

### 4. ENDPOINT URL:
`/calendars/resources/:resourceType/:id`

### 5. FULL URL:
`https://services.leadconnectorhq.com/calendars/resources/:resourceType/:id`

### 6. REQUIRED PARAMETERS:
*   **Version** (string, header): API Version. Possible values: `2021-04-15`
*   **resourceType** (string, path): Calendar Resource Type. Possible values: `equipments`, `rooms`
*   **id** (string, path): Calendar Resource ID

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:
*   **Scope(s)**: `calendars/resources.write`
*   **Auth Method(s)**: `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s)**: `Sub-Account Token`
*   **Scheme**: bearer (JWT)
*   **Header**: `Authorization: Bearer <TOKEN>`

### 9. RESPONSE FORMAT:
**200 OK (Success)**
*   **Content Type**: `application/json`
*   **Schema**:
    ```json
    {
      "success": boolean
    }
    ```
*   **Example**:
    ```json
    {
      "success": true
    }
    ```

**400 Bad Request**
*   **Content Type**: `application/json`
*   **Schema**:
    ```json
    {
      "statusCode": number,
      "message": string
    }
    ```
*   **Example**:
    ```json
    {
      "statusCode": 400,
      "message": "Bad Request"
    }
    ```

**401 Unauthorized**
*   **Content Type**: `application/json`
*   **Schema**:
    ```json
    {
      "statusCode": number,
      "message": string,
      "error": string
    }
    ```
*   **Example**:
    ```json
    {
      "statusCode": 401,
      "message": "Invalid token: access token is invalid",
      "error": "Unauthorized"
    }
    ```

### 10. PURPOSE:
This endpoint allows you to delete a specific calendar resource (either an equipment or a room) by its ID.
