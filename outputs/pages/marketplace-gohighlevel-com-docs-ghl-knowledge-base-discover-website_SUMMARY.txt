Here is a structured summary of the API documentation:

### 1. ENDPOINT NAME
Start crawling and discover pages for training

### 2. CATEGORY
Knowledge Base / Web Crawler

### 3. HTTP METHOD
POST

### 4. ENDPOINT URL
`/knowledge-bases/crawler`

### 5. FULL URL
`https://services.leadconnectorhq.com/knowledge-bases/crawler`

### 6. REQUIRED PARAMETERS
*   **Header Parameters:**
    *   `Authorization` (string): Access Token. Example: `Bearer 9c48df2694a849b6089f9d0d3513efe`
    *   `Version` (string): API Version. Possible values: `2021-04-15`
*   **Body Parameters (application/json):**
    *   `locationId` (string): Location ID as string. Example: `tDtDnQdgm2LXpyiqYvZ6`
    *   `url` (string): Website URL as string. Example: `https://kubernetes.io/tDtDnQdgm2LXpyiqYvZ6`
    *   `option` (string): Mode as string. Possible values: `Exact`, `Path`, `Domain`. Example: `Exact`
    *   `knowledgeBaseId` (string): Knowledge base ID as string. Example: `tDtDnQdgm2LXpyiqYvZ6`

### 7. OPTIONAL PARAMETERS
Not specified in documentation

### 8. AUTHENTICATION
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Authorization Header:** `Bearer <TOKEN>` (JWT format)

### 9. RESPONSE FORMAT
**201 Created - Crawling and discovery started successfully (application/json)**
```json
{
  "success": true,
  "data": {
    "operationId": "688e410c8a18870ecf4d13bb",
    "status": "Processing",
    "url": "https://developer.mozilla.org/en-US/blog/"
  }
}
```
*   `success` (boolean): Indicates if the operation was successful (Example: `true`)
*   `data` (object): Data containing operation details
    *   `operationId` (string): Operation ID for tracking the discovery process (Example: `688e410c8a18870ecf4d13bb`)
    *   `status` (string): Current status of the website discovery operation. Possible values: `Pending`, `Processing`, `Successful`, `Failed`, `Existing`, `Restricted`, `Cancelled`, `Aborted`, `Training` (Example: `Processing`)
    *   `url` (string): The URL being discovered/crawled (Example: `https://developer.mozilla.org/en-US/blog/`)

### 10. PURPOSE
This endpoint initiates the crawling process to discover website pages for training and ingesting into a specified knowledge base.
