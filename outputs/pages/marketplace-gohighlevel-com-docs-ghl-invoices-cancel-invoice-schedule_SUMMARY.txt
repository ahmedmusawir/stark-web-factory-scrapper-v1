Here is a structured summary of the API documentation:

### 1. ENDPOINT NAME
Cancel an scheduled invoice

### 2. CATEGORY
Invoice (Schedule)

### 3. HTTP METHOD
POST

### 4. ENDPOINT URL
`/invoices/schedule/:scheduleId/cancel`

### 5. FULL URL
`https://services.leadconnectorhq.com/invoices/schedule/:scheduleId/cancel`

### 6. REQUIRED PARAMETERS
*   **Header Parameters:**
    *   `Version` (string): API Version. Possible values: `2021-07-28`
*   **Path Parameters:**
    *   `scheduleId` (string): Schedule Id. Example: `6578278e879ad2646715ba9c`
*   **Body Parameters (application/json):**
    *   `altId` (string): location Id / company Id based on altType. Example: `6578278e879ad2646715ba9c`
    *   `altType` (string): Alt Type. Possible values: [`location`]. Example: `location`

### 7. OPTIONAL PARAMETERS
Not specified in documentation

### 8. AUTHENTICATION
*   **Scope(s):** `invoices/schedule.write`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`, `Agency Token`
*   **Scheme:** `bearer`
*   **Bearer Format:** `JWT`
*   **In:** `header`
*   **Description:** Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account.

### 9. RESPONSE FORMAT
**Successful Response (200 OK):**
*   **Content Type:** `application/json`
*   **Schema:** A JSON object representing the cancelled schedule.
    *   `_id` (string): Schedule Id. Example: `6578278e879ad2646715ba9c`
    *   `status` (object): Schedule Status. Example: `draft`
    *   `liveMode` (boolean): Live Mode. Example: `false`
    *   `altId` (string): Location Id or Agency Id. Example: `6578278e879ad2646715ba9c`
    *   `altType` (string): Possible values: [`location`]
    *   `name` (string): Name of the invoice. Example: `New Invoice`
    *   `schedule` (object): Contains schedule details including `executeAt` (string) and `rrule` (object with fields like `intervalType`, `interval`, `startDate`, `startTime`, `endDate`, `endTime`, `dayOfMonth`, `dayOfWeek`, `numOfWeek`, `monthOfYear`, `count`, `daysBefore`, `useStartAsPrimaryUserAccepted`, `endType`).
    *   `invoices` (object[]): An array of invoice objects. Each invoice includes fields such as `_id`, `status`, `liveMode`, `amountPaid`, `altId`, `altType`, `name`, `businessDetails` (object), `invoiceNumber`, `currency`, `contactDetails` (object), `issueDate`, `dueDate`, `discount` (object), `invoiceItems` (string[]), `total`, `title`, `amountDue`, `createdAt`, `updatedAt`, `automaticTaxesEnabled`, `automaticTaxesCalculated`, `paymentSchedule` (object).
    *   `businessDetails` (object): Business Details including `logoUrl`, `name`, `phoneNo`, `address` (object with `addressLine1`, `addressLine2`, `city`, `state`, `countryCode`, `postalCode`), `website`, `customValues`.
    *   `currency` (string): Currency. Example: `USD`
    *   `contactDetails` (object): Contact Details including `id`, `name`, `phoneNo`, `email`, `additionalEmails` (object[]), `companyName`, `address` (object with `addressLine1`, `addressLine2`, `city`, `state`, `countryCode`, `postalCode`), `customFields`.
    *   `discount` (object): Discount details including `value`, `type` (`percentage`, `fixed`), `validOnProductIds` (string[]).
    *   `items` (string[]): Invoice Items.
    *   `total` (number): Total Amount.
    *   `title` (string): Title.
    *   `termsNotes` (string): Terms notes.
    *   `compiledTermsNotes` (string): Compiled terms notes.
    *   `createdAt` (string): created at.
    *   `updatedAt` (string): updated at.

**Error Responses:**
*   **400 Bad Request:** `{"statusCode":400,"message":"Bad Request"}`
*   **401 Unauthorized:** `{"statusCode":401,"message":"Invalid token: access token is invalid","error":"Unauthorized"}`
*   **422 Unprocessable Entity:** `{"statusCode":422,"message":["Unprocessable Entity"],"error":"Unprocessable Entity"}`

### 10. PURPOSE
This API allows cancellation of a previously scheduled invoice using its schedule ID.

Invoice, Schedule, Cancel, Recurring, Billing, Payments, Delete
