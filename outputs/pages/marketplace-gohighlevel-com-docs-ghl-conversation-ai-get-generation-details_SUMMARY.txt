Here is a structured summary of the provided API documentation:

### 1. ENDPOINT NAME:
Get the generation details

### 2. CATEGORY:
Conversation AI

### 3. HTTP METHOD:
GET

### 4. ENDPOINT URL:
`/conversation-ai/generations`

### 5. FULL URL:
`https://services.leadconnectorhq.com/conversation-ai/generations`

### 6. REQUIRED PARAMETERS:

*   **Header Parameters**:
    *   Version (string): API Version. Possible values: `[2021-04-15]`
*   **Query Parameters**:
    *   messageId (string): Message Id. Example: `messageId123`
    *   source (string): Possible values: `[conversation, workflow]`. Example: `conversation`

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:

*   **Scope(s)**: `conversation-ai.readonly`
*   **Auth Method(s)**: `OAuth Access Token`, `Private Integration Token`, `Bearer Token`
*   **Token Type(s)**: `Sub-Account Token`
*   **Description**: Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account.

### 9. RESPONSE FORMAT:

*   **200 OK (application/json)**:
    *   `prompt` (string, required): The complete prompt used for the AI response.
    *   `intent` (string): The intent/goal extracted from location prompt.
    *   `responseMessage` (string, required): The response message generated by the AI.
    *   `faqs` (array): FAQ chunks used in generating the response from fine-tuned data.
        *   `id` (string)
        *   `content` (string)
        *   `title` (string)
    *   `website` (array): Website content chunks used in generating the response.
        *   `id` (string)
        *   `content` (string)
        *   `url` (string)
    *   `agentId` (string): ID of the employee/agent that generated the response.
    *   `input` (string): The original input message that triggered this response.
    *   `actionLogs` (array, required): List of actions taken during this interaction.
        *   `contactUpdateAction` (array): Contains objects with `fieldId` (string) and `value` (string).
    *   `history` (array, required): Conversation history leading up to this response.
        *   `role` (string)
        *   `content` (string)
    *   `mode` (string): Mode of operation during this interaction.

### 10. PURPOSE:
Retrieves detailed information about AI responses including the System Prompt, Conversation history, Knowledge base, website, FAQ chunks, and Rich Text chunks.
