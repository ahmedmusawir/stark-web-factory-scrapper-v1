Here's a structured summary of the API documentation for "Get Forms Submissions":

---

### 1. ENDPOINT NAME
Get Forms Submissions

### 2. CATEGORY
Forms

### 3. HTTP METHOD
GET

### 4. ENDPOINT URL
`/forms/submissions`

### 5. FULL URL
`https://services.leadconnectorhq.com/forms/submissions`

### 6. REQUIRED PARAMETERS
*   **Version** (string): API Version. Possible values: [`2021-07-28`]. (Header Parameter)
*   **locationId** (string): Example: `ve9EPM428h8vShlRW1KT`. (Query Parameter)

### 7. OPTIONAL PARAMETERS
*   **page** (number): Page No. By default it will be 1. Default value: `1`. (Query Parameter)
*   **limit** (number): Limit Per Page records count. Will allow a maximum of 100 and default will be 20. Default value: `20`. (Query Parameter)
*   **formId** (string): Filter submission by form id. Example: `jjusM6EOngDExnbo2DbU`. (Query Parameter)
*   **q** (string): Filter by contactId, name, email or phone no. Example: `john@deo.com`. (Query Parameter)
*   **startAt** (string): Get submission by starting of this date. By default it will be the same date of last month (YYYY-MM-DD). Example: `2020-11-14`. (Query Parameter)
*   **endAt** (string): Get submission by ending of this date. By default it will be the current date (YYYY-MM-DD). Example: `2020-12-14`. (Query Parameter)

### 8. AUTHENTICATION
*   **Scope(s)**: `forms.readonly`
*   **Auth Method(s)**: `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s)**: `Sub-Account Token`
*   **Scheme**: `bearer`
*   **Bearer Format**: `JWT`
*   **In**: `header` (Authorization)

### 10. PURPOSE
This endpoint retrieves a paginated list of form submissions for a specific sub-account location, with optional filtering by form ID, contact details (name, email, phone), and submission date range.
