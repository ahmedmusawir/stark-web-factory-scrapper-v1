Here's a structured summary of the API documentation:

### 1. ENDPOINT NAME:
Delete shipping zone

### 2. CATEGORY:
Store, Shipping Zone

### 3. HTTP METHOD:
DELETE

### 4. ENDPOINT URL:
`/store/shipping-zone/:shippingZoneId`

### 5. FULL URL:
`https://services.leadconnectorhq.com/store/shipping-zone/:shippingZoneId`

### 6. REQUIRED PARAMETERS:
*   **Path Parameters:**
    *   `shippingZoneId` (string): ID of the item that needs to be returned.
*   **Query Parameters:**
    *   `altId` (string): Location Id or Agency Id.
    *   `altType` (string): Possible values: [`location`]

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** Bearer (JWT)
*   **In:** Header
*   **Description:** Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account.

### 9. RESPONSE FORMAT:

*   **200 OK (Successful response):**
    *   **Content Type:** `application/json`
    *   **Schema:**
        *   `status` (boolean, required): Status of API action. Example: `true`
        *   `message` (string): Success message. Example: `Successfully created`
    *   **Example:**
        ```json
        {"status":true,"message":"Successfully created"}
        ```
*   **400 Bad Request:**
    *   **Content Type:** `application/json`
    *   **Schema:**
        *   `statusCode` (number)
        *   `message` (string)
    *   **Example:**
        ```json
        {"statusCode":400,"message":"Bad Request"}
        ```
*   **401 Unauthorized:**
    *   **Content Type:** `application/json`
    *   **Schema:**
        *   `statusCode` (number)
        *   `message` (string)
        *   `error` (string)
    *   **Example:**
        ```json
        {"statusCode":401,"message":"Invalid token: access token is invalid","error":"Unauthorized"}
        ```
*   **422 Unprocessable Entity:**
    *   **Content Type:** `application/json`
    *   **Schema:**
        *   `statusCode` (number)
        *   `message` (string[])
        *   `error` (string)
    *   **Example:**
        ```json
        {"statusCode":422,"message":["Unprocessable Entity"],"error":"Unprocessable Entity"}
        ```

### 10. PURPOSE:
This endpoint is used to delete a specific shipping zone by its unique ID.
