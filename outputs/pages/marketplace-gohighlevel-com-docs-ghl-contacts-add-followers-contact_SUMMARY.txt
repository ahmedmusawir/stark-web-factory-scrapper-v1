Here's a structured summary of the provided API documentation for "Add Followers":

### 1. ENDPOINT NAME:
Add Followers

### 2. CATEGORY:
Contacts

### 3. HTTP METHOD:
POST

### 4. ENDPOINT URL:
`/contacts/:contactId/followers`

### 5. FULL URL:
`https://services.leadconnectorhq.com/contacts/:contactId/followers`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters:**
    *   `Version` (string): API Version. Possible values: [`2021-07-28`]
*   **Path Parameters:**
    *   `contactId` (string): Contact Id. Example: `sx6wyHhbFdRXh302Lunr`
*   **Body Parameters (application/json):**
    *   `followers` (string[]): An array of user IDs to add as followers to the contact.
        Example: `["sx6wyHhbFdRXh302Lunr","sx6wyHhbFdRXh302Lunr"]`

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:
*   **Scope(s):** `contacts.write`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** `bearer`
*   **Bearer Format:** `JWT`
*   **In:** `header`
*   **Description:** Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account.

### 9. RESPONSE FORMAT:
*   **201 Successful response** (`application/json`)
    *   `followers` (string[]): An array of all current followers on the contact, including those just added.
        Example: `["sx6wyHhbFdRXh302Lunr","sx6wyHhbFdRXh302LLss"]`
    *   `followersAdded` (string[]): An array of user IDs that were successfully added as new followers.
        Example: `["Mx6wyHhbFdRXh302Luer","Ka6wyHhbFdRXh302LLsAm"]`
*   **Error Responses:**
    *   `400 Bad Request` (`application/json`)
        *   `statusCode` (number): `400`
        *   `message` (string): `Bad Request`
    *   `401 Unauthorized` (`application/json`)
        *   `statusCode` (number): `401`
        *   `message` (string): `Invalid token: access token is invalid`
        *   `error` (string): `Unauthorized`
    *   `422 Unprocessable Entity` (`application/json`)
        *   `statusCode` (number): `422`
        *   `message` (string[]): `["Unprocessable Entity"]`
        *   `error` (string): `Unprocessable Entity`

### 10. PURPOSE:
This endpoint allows you to add one or more users as followers to a specific contact within the HighLevel platform.
