Here's a structured summary of the "Update Product by ID" API documentation:

### 1. ENDPOINT NAME:
Update Product by ID

### 2. CATEGORY:
Products

### 3. HTTP METHOD:
PUT

### 4. ENDPOINT URL:
`/products/:productId`

### 5. FULL URL:
`https://services.leadconnectorhq.com/products/:productId`

### 6. REQUIRED PARAMETERS:

*   **Header Parameters:**
    *   `Version` (string): API Version. Possible values: [`2021-07-28`]
*   **Path Parameters:**
    *   `productId` (string): ID or the slug of the product that needs to be returned.
*   **Body Parameters:**
    *   `name` (string): The name of the product.
    *   `locationId` (string): The unique identifier for the location.
    *   `productType` (string): The type of the product. Possible values: [`DIGITAL`, `PHYSICAL`, `SERVICE`, `PHYSICAL/DIGITAL`]
    *   **Conditional Requirements within Body:**
        *   If `medias` array is provided:
            *   `medias[].id` (string): The unique identifier for the media.
            *   `medias[].url` (string): The URL where the media file is stored.
            *   `medias[].type` (string): The type of the media file (e.g., image, video will be supporting soon). Possible values: [`image`, `video`]
        *   If `variants` array is provided:
            *   `variants[].id` (string): A unique identifier for the variant.
            *   `variants[].name` (string): The name of the variant.
            *   `variants[].options` (object[]): An array of options for the variant.
                *   `variants[].options[].id` (string): The unique identifier for the option.
                *   `variants[].options[].name` (string): The name of the option.
        *   If `isLabelEnabled` is `true`:
            *   `label` (object): The label object cannot be empty.
            *   `label.title` (string): The content for the product label.
        *   If `isTaxesEnabled` is `true`:
            *   `taxes` (string[]): The taxes array cannot be empty.

### 7. OPTIONAL PARAMETERS:

*   **Body Parameters:**
    *   `description` (string): A brief description of the product.
    *   `image` (string): The URL for the product image.
    *   `statementDescriptor` (string): The statement descriptor for the product.
    *   `availableInStore` (boolean): Indicates whether the product is available in-store.
    *   `medias` (object[]): An array of medias for the product. (See conditional requirements above for nested fields if provided).
        *   `medias[].title` (string): The title of the media file.
        *   `medias[].isFeatured` (boolean): Indicates whether the media is featured.
        *   `medias[].priceIds` (array[]): Mongo ObjectIds of the prices for which the media is assigned.
    *   `variants` (object[]): An array of variants for the product. (See conditional requirements above for nested fields if provided).
    *   `collectionIds` (string[]): An array of category Ids for the product.
    *   `isTaxesEnabled` (boolean): Are there any taxes attached to the product. (Default value: `false`).
    *   `taxes` (string[]): List of ids of Taxes attached to the Product. (See conditional requirements above if `isTaxesEnabled` is `true`).
    *   `automaticTaxCategoryId` (string): Tax category ID for Automatic taxes calculation.
    *   `isLabelEnabled` (boolean): Is the product label enabled. (Default value: `false`).
    *   `label` (object): Details for Product Label. (See conditional requirements above for nested fields if `isLabelEnabled` is `true`).
        *   `label.startDate` (string): Start date in YYYY-MM-DDTHH:mm:ssZ format.
        *   `label.endDate` (string): Start date in YYYY-MM-DDTHH:mm:ssZ format.
    *   `slug` (string): The slug using which the product navigation will be handled.
    *   `seo` (object): SEO data for the product that will be displayed in the preview.
        *   `seo.title` (string): SEO title.
        *   `seo.description` (string): SEO description.
    *   `taxInclusive` (boolean): Whether the taxes should be included in the purchase price. (Default value: `false`).
    *   `prices` (string[]): The prices of the product.

### 8. AUTHENTICATION:

*   **Required Scope(s):** `products.write`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`, `Agency Token`

### 9. RESPONSE FORMAT:

*   **Status Code:** `200` (Successful response)
*   **Structure:** A JSON object representing the updated product, including:
    *   `_id` (string): The unique identifier for the product.
    *   `description` (string): Product description.
    *   `variants` (object[]): An array of variants with `id`, `name`, and `options` (each with `id`, `name`).
    *   `locationId` (string): The unique identifier for the location.
    *   `name` (string): The name of the product.
    *   `productType` (string): The type of the product.
    *   `availableInStore` (boolean): Indicates whether the product is available in-store.
    *   `createdAt` (date-time): The creation timestamp.
    *   `updatedAt` (date-time): The last update timestamp.
    *   `statementDescriptor` (string): The statement descriptor.
    *   `image` (string): The URL for the product image.
    *   `collectionIds` (string[]): An array of category Ids.
    *   `isTaxesEnabled` (boolean): Indicates if taxes are enabled.
    *   `taxes` (string[]): An array of IDs of taxes attached to the product.
    *   `automaticTaxCategoryId` (string): Tax category ID for automatic taxes.
    *   `label` (object): Product label details with `title`, `startDate`, `endDate`.
    *   `slug` (string): The slug of the product.

### 10. PURPOSE:
The "Update Product by ID" API allows modifying information for a specific product using its unique identifier, enabling updates to details for a single product based on the provided product ID.
