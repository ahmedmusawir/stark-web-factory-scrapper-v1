Here is a structured summary of the provided API documentation:

### 1. ENDPOINT NAME:
Delete Account

### 2. CATEGORY:
Social Planner > Account

### 3. HTTP METHOD:
DELETE

### 4. ENDPOINT URL:
`/social-media-posting/:locationId/accounts/:id`

### 5. FULL URL:
`https://services.leadconnectorhq.com/social-media-posting/:locationId/accounts/:id`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters:**
    *   Version (string): API Version. Possible values: [`2021-07-28`]
*   **Path Parameters:**
    *   locationId (string): Location Id (Example: `ve9EPM428h8vShlRW1KT`)
    *   id (string): Id (Example: `65fac446d599990d1313c1dd`)

### 7. OPTIONAL PARAMETERS:
*   **Query Parameters:**
    *   companyId (string): Company ID (Example: `sdfdsfdsfEWEsdfsdsW32dd`)
    *   userId (string): User ID (Example: `sdfdsfdsfEWEsdfsdsW32dd`)

### 8. AUTHENTICATION:
*   **Auth Method(s):** OAuth Access Token, Private Integration Token
*   **Token Type(s):** Sub-Account Token
*   **Authorization Header:** `Authorization: Bearer <TOKEN>`
*   **Description:** Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account. The scheme is `bearer` with `JWT` format.

### 9. RESPONSE FORMAT:
**Successful Response (200 OK):**
*   **Status Code:** `200`
*   **Content Type:** `application/json`
*   **Schema:**
    ```json
    {
      "success": true,        // boolean (required) - Success or Failure
      "statusCode": 200,      // number (required) - Status Code
      "message": "Deleted Account", // string (required) - Message
      "results": {            // object (optional) - Requested Results
        "locationId": "ve9EPM428h8vShlRW1KT", // string (optional) - Location Id
        "id": "65fac446d599990d1313c1dd"      // string (optional) - Id
      }
    }
    ```
*   **Example:**
    ```json
    {"success":true,"statusCode":200,"message":"Deleted Account","results":{"locationId":"ve9EPM428h8vShlRW1KT","id":"65fac446d599990d1313c1dd"}}
    ```

**Error Responses:**
*   **400 Bad Request:**
    ```json
    {"statusCode":400,"message":"Bad Request"}
    ```
*   **401 Unauthorized:**
    ```json
    {"statusCode":401,"message":"Invalid token: access token is invalid","error":"Unauthorized"}
    ```
*   **422 Unprocessable Entity:**
    ```json
    {"statusCode":422,"message":["Unprocessable Entity"],"error":"Unprocessable Entity"}
    ```

### 10. PURPOSE:
This endpoint allows you to delete a social media account and its associated group from a specified location.
