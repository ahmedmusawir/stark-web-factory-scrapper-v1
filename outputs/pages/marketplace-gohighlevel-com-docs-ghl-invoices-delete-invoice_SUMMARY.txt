Here is a structured summary of the API documentation for "Delete invoice":

### 1. ENDPOINT NAME:
Delete invoice

### 2. CATEGORY:
Invoice

### 3. HTTP METHOD:
DELETE

### 4. ENDPOINT URL:
`/invoices/:invoiceId`

### 5. FULL URL:
`https://services.leadconnectorhq.com/invoices/:invoiceId`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters**:
    *   Version (string): API Version (Possible values: [`2021-07-28`])
*   **Path Parameters**:
    *   invoiceId (string): Invoice Id (Example: `6578278e879ad2646715ba9c`)
*   **Query Parameters**:
    *   altId (string): location Id / company Id based on altType (Example: `6578278e879ad2646715ba9c`)
    *   altType (string): Alt Type (Possible values: [`location`]) (Example: `location`)

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:
*   **Scope(s)**: `invoices.write`
*   **Auth Method(s)**: `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s)**: `Sub-Account Token`, `Agency Token`
*   **Scheme**: bearer
*   **Format**: JWT
*   **In**: header

### 9. RESPONSE FORMAT:

**200 OK (Successful response)**
*   **Content Type**: `application/json`
*   **Schema (main fields)**:
    *   _id (string): Invoice Id (Example: `6578278e879ad2646715ba9c`)
    *   status (string): Invoice Status (Possible values: [`draft`, `sent`, `payment_processing`, `paid`, `void`, `partially_paid`]) (Example: `draft`)
    *   liveMode (boolean): Live Mode (Example: `false`)
    *   amountPaid (number): Amount Paid (Example: `0`)
    *   altId (string): Location Id or Agency Id (Example: `6578278e879ad2646715ba9c`)
    *   altType (string): (Possible values: [`location`])
    *   name (string): Name of the invoice (Example: `New Invoice`)
    *   businessDetails (object): Business Details (Example: `{"name":"Alex", ...}`)
    *   invoiceNumber (number): Invoice Number (Example: `19`)
    *   currency (string): Currency (Example: `USD`)
    *   contactDetails (object): Contact Details (Example: `{"id":"c6tZZU0rJBf30ZXx9Gli", ...}`)
    *   issueDate (string): Issue date in YYYY-MM-DD format (Example: `2023-01-01`)
    *   dueDate (string): Due date in YYYY-MM-DD format (Example: `2023-01-01`)
    *   discount (object, optional): Discount (Example: `{"type":"percentage","value":0}`)
    *   invoiceItems (string[]): Invoice Items (Example: `[{"taxes":[],"_id":"c6tZZU0rJBf30ZXx9Gli", ...}]`)
    *   total (number): Total Amount (Example: `999`)
    *   title (string): Title (Example: `INVOICE`)
    *   amountDue (number): Total Amount Due (Example: `999`)
    *   createdAt (string): created at (Example: `2023-12-12T09:27:42.355Z`)
    *   updatedAt (string): updated at (Example: `2023-12-12T09:27:42.355Z`)
    *   automaticTaxesEnabled (boolean, optional): Automatic taxes enabled for the Invoice (Example: `true`)
    *   automaticTaxesCalculated (boolean, optional): Is Automatic taxes calculated for the Invoice items (Example: `true`)
    *   paymentSchedule (object, optional): split invoice into payment schedule summing up to full invoice amount

**Error Responses**:
*   **400 Bad Request**:
    *   `{"statusCode":400,"message":"Unable to find an invoice with the given invoice id"}`
    *   `{"statusCode":400,"message":"Invoice status need to be draft to delete an invoice"}`
*   **401 Unauthorized**:
    *   `{"statusCode":401,"message":"Invalid token: access token is invalid","error":"Unauthorized"}`
*   **422 Unprocessable Entity**:
    *   `{"statusCode":422,"message":["Unprocessable Entity"],"error":"Unprocessable Entity"}`

### 10. PURPOSE:
This API endpoint allows you to delete an invoice by its ID, provided the invoice status is 'draft'.
