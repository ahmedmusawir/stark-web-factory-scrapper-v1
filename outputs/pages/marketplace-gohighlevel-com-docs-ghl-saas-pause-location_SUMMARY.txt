Here is a structured summary of the API documentation:

### 1. ENDPOINT NAME:
Pause location

### 2. CATEGORY:
Saas

### 3. HTTP METHOD:
POST

### 4. ENDPOINT URL:
`/saas/pause/:locationId`

### 5. FULL URL:
`https://services.leadconnectorhq.com/saas/pause/:locationId`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters:**
    *   Version (string): API Version. Possible values: `2021-04-15`
*   **Path Parameters:**
    *   locationId (string)
*   **Body Parameters:**
    *   paused (boolean): Paused. Example: `true`
    *   companyId (string): Company ID. Example: `companyId1`

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Agency Token`
*   **Authorization Header:** `Bearer <TOKEN>` (JWT format). Use the Access Token generated with user type as Company.

### 9. RESPONSE FORMAT:
*   **Status Code:** `201`
*   **Structure:** Not explicitly detailed beyond the status code.

### 10. PURPOSE:
This endpoint is used to pause a Sub-Account (formerly location) for a given `locationId`.

### 11. TAGS:
Saas, Sub-Account, Location, Pause, Billing, Agency, Company, Suspend

### 12. CODE EXAMPLES:
Code examples are available for: `curl`, `nodejs`, `python`, `php`, `java`, `go`, `ruby`, `powershell`. A cURL example is provided in the documentation.
