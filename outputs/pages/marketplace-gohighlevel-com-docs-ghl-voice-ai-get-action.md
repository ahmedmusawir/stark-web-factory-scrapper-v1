# Get Agent Action
```
GET 
## https://services.leadconnectorhq.com/voice-ai/actions/:actionId

```

Retrieve details of a specific action by its ID. Returns the action configuration including actionParameters.
### Requirements
#### Scope(s)
`voice-ai-agent-goals.readonly`
#### Auth Method(s)
`OAuth Access Token``Private Integration Token`
#### Token Type(s)
`Sub-Account Token`
## Request[​](https://marketplace.gohighlevel.com/docs/ghl/voice-ai/get-action/index.html#request "Direct link to Request")
### Header Parameters
**Version** stringrequired
**Possible values:** [`2021-04-15`]
API Version


### Path Parameters
**actionId** stringrequired
Unique identifier for the action


### Query Parameters
**locationId** stringrequired
Location ID
Example: LOC123456789ABCDEF
