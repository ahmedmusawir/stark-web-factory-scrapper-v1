Here's a structured summary of the provided API documentation:

### 1. ENDPOINT NAME:
Attach facebook pages

### 2. CATEGORY:
Social Planner

### 3. HTTP METHOD:
POST

### 4. ENDPOINT URL:
`/social-media-posting/oauth/:locationId/facebook/accounts/:accountId`

### 5. FULL URL:
`https://services.leadconnectorhq.com/social-media-posting/oauth/:locationId/facebook/accounts/:accountId`

### 6. REQUIRED PARAMETERS:

*   **Header Parameters:**
    *   `Version` (string): API Version. Possible values: [`2021-07-28`]
*   **Path Parameters:**
    *   `locationId` (string): Account Location Id. Example: `w37swmmLbA02zgqKPpxITe2`
    *   `accountId` (string): Account Id. Example: `w37swmmLbA02zgqKPpxITe`
*   **Body Parameters (application/json):**
    *   `type` (string): Possible values: [`page`]. Example: `page`
    *   `originId` (string): Example: `244405****11687`
    *   `name` (string): Example: `JOHN_DEO`
    *   `avatar` (string): Example: `https://storage.googleapis.com/2ad21ebc23/test`

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** Bearer (JWT) in header.
*   **Description:** Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account.
