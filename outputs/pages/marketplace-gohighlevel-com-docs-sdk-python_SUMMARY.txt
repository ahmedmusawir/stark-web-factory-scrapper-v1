### 6. REQUIRED PARAMETERS:
These parameters are required for initializing the `HighLevel` client.
*   `client_id` (string): Your HighLevel application client ID.
*   `client_secret` (string): Your HighLevel application client secret.

### 7. OPTIONAL PARAMETERS:
These parameters are optional for initializing the `HighLevel` client.
*   `session_storage` (object): An instance of a session storage class (e.g., `MongoDBSessionStorage`) to manage JWT tokens for production resiliency.

### 8. AUTHENTICATION:
The SDK handles token automation automatically using the provided `client_id` and `client_secret` during client initialization. It also integrates with webhooks to manage `INSTALL`/`UNINSTALL` events and synchronize session storage.

### 9. RESPONSE FORMAT:
Not specified in detail for the SDK itself. When making an API call using the SDK (as shown in the example), the SDK returns the API response object. The example `print(response)` suggests a standard structured response from the called API endpoint.

### 10. PURPOSE:
The official `gohighlevel-api-client` package provides an async Python client to interact with all HighLevel API endpoints, offering token automation, webhook helpers, and adaptable storage solutions.
