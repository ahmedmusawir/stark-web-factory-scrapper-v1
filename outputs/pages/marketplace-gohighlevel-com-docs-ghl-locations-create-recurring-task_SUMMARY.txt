Here is a structured summary of the API documentation for the "Create Recurring Task" endpoint:

### 1. ENDPOINT NAME:
Create Recurring Task

### 2. CATEGORY:
Sub-Account (formerly Location) / Recurring Tasks

### 3. HTTP METHOD:
POST

### 4. ENDPOINT URL:
`/locations/:locationId/recurring-tasks`

### 5. FULL URL:
`https://services.leadconnectorhq.com/locations/:locationId/recurring-tasks`

### 6. REQUIRED PARAMETERS:

*   **Header Parameters:**
    *   `Version` (string): API Version. Possible values: `2021-07-28`

*   **Path Parameters:**
    *   `locationId` (string): Not explicitly described but implied to be the ID of the location/sub-account.

*   **Body Parameters (application/json):**
    *   `title` (string): Name of the task
    *   `rruleOptions` (object): Recurring rules
        *   `intervalType` (string): Possible values: [`yearly`, `monthly`, `weekly`, `daily`, `hourly`]
        *   `interval` (number): Interval for the recurrence
        *   `startDate` (string): Start Date (e.g., `2021-09-30T00:00:00.000Z`)
        *   `dueAfterSeconds` (number): Due after seconds

### 7. OPTIONAL PARAMETERS:

*   **Body Parameters (application/json):**
    *   `description` (string): Description of the task
    *   `contactIds` (string[]): Contact Id
    *   `owners` (string[]): Assigned To
    *   `rruleOptions` (object): Recurring rules
        *   `endDate` (string): End Date (e.g., `2021-09-30T00:00:00.000Z`)
        *   `dayOfMonth` (number): Day of the month (1-31)
        *   `dayOfWeek` (string): Possible values: [`MO`, `TU`, `WE`, `TH`, `FR`, `SA`, `SU`]
        *   `monthOfYear` (number): Month of the year (1-12)
        *   `count` (number): Max number of task executions
        *   `createTaskIfOverDue` (boolean): Create Task If Over Due
        *   `ignoreTaskCreation` (boolean): Create initial task or not

### 8. AUTHENTICATION:

*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** Bearer (JWT)
*   **Location:** `Authorization` header

### 9. RESPONSE FORMAT:

*   **201 Successful response (application/json):**
    *   **Schema:**
        *   `recurringTask` (object)
            *   `id` (string): Recurring Task Id
            *   `title` (string): Name of the task
            *   `description` (string): Description of the task
            *   `locationId` (string): Location Id
            *   `updatedAt` (string): Updated At (e.g., `2021-04-15T10:00:00.000Z`)
            *   `createdAt` (string): Created At (e.g., `2021-04-15T10:00:00.000Z`)
            *   `rruleOptions` (object): Recurring rules
                *   `createTaskIfOverDue` (boolean)
                *   `interval` (number)
                *   `intervalType` (string): Possible values: [`yearly`, `monthly`, `weekly`, `daily`, `hourly`]
                *   `startDate` (string)
                *   `dueAfterSeconds` (number)
                *   `count` (number)
            *   `totalOccurrence` (number): Total Occurrence
            *   `deleted` (boolean): Deleted
            *   `assignedTo` (string): Assigned To
            *   `contactId` (string): Contact Id
    *   **Example:**
        ```json
        {
          "recurringTask": {
            "id": "sx6wyHhbFdRXh302Lunr",
            "title": "Task Name",
            "description": "Task Description",
            "locationId": "sx6wyHhbFdRXh302Lunr",
            "updatedAt": "2021-04-15T10:00:00.000Z",
            "createdAt": "2021-04-15T10:00:00.000Z",
            "rruleOptions": {
              "createTaskIfOverDue": false,
              "interval": 1,
              "intervalType": "hourly",
              "startDate": "2024-10-29T12:34:03.000Z",
              "dueAfterSeconds": 600,
              "count": 550
            },
            "totalOccurrence": 10,
            "deleted": false,
            "assignedTo": "sx6wyHhbFdRXh302Lunr",
            "contactId": "v5cEPM428h8vShlRW1KT"
          }
        }
        ```

*   **400 Bad Request (application/json):**
    *   **Schema:** `statusCode` (number), `message` (string)
    *   **Example:** `{"statusCode":400,"message":"Bad Request"}`

*   **401 Unauthorized (application/json):**
    *   **Schema:** `statusCode` (number), `message` (string), `error` (string)
    *   **Example:** `{"statusCode":401,"message":"Invalid token: access token is invalid","error":"Unauthorized"}`

### 10. PURPOSE:
This endpoint allows users to create a new recurring task for a specific sub-account (location) with defined recurrence rules, assignees, and due dates.
