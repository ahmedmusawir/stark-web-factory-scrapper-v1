Here's a structured summary of the "Create Business" API documentation:

### 1. ENDPOINT NAME:
Create Business

### 2. CATEGORY:
Business

### 3. HTTP METHOD:
POST

### 4. ENDPOINT URL:
`/businesses/`

### 5. FULL URL:
`https://services.leadconnectorhq.com/businesses/`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters:**
    *   `Version` (string): API Version. Possible values: `2021-07-28`
*   **Body Parameters:**
    *   `name` (string): The name of the business. Example: `Microsoft`
    *   `locationId` (string): The ID of the location to associate the business with. Example: `5DP4iH6HLkQsiKESj6rh`

### 7. OPTIONAL PARAMETERS:
*   **Body Parameters:**
    *   `phone` (string): The phone number of the business. Example: `+18832327657`
    *   `email` (string): The email address of the business. Example: `john@deo.com`
    *   `website` (string): The website URL of the business. Example: `www.xyz.com`
    *   `address` (string): The street address of the business. Example: `street adress`
    *   `city` (string): The city where the business is located. Example: `new york`
    *   `postalCode` (string): The postal code of the business address. Example: `12312312`
    *   `state` (string): The state where the business is located. Example: `new york`
    *   `country` (string): The country where the business is located. Example: `us`
    *   `description` (string): A description of the business. Example: `business description`

### 8. AUTHENTICATION:
*   **Scope(s):** `businesses.write`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** Bearer (JWT format)
*   **In:** Header (`Authorization: Bearer <TOKEN>`)
*   **Description:** Use an Access Token generated with user type as Sub-Account OR a Private Integration Token of Sub-Account.

### 9. RESPONSE FORMAT:
**Status Code:** `201 Created`
**Content Type:** `application/json`
**Schema (Successful response - Example):**
```json
{
  "success": true,
  "buiseness": {
    "id": "63771dcac1116f0e21de8e12",
    "name": "Microsoft",
    "phone": "string",
    "email": "abc@microsoft.com",
    "website": "microsoft.com",
    "address": "string",
    "city": "string",
    "description": "string",
    "state": "string",
    "postalCode": "string",
    "country": "united states",
    "updatedBy": {},
    "locationId": "string",
    "createdBy": {},
    "createdAt": "2024-07-29T15:51:28.071Z",
    "updatedAt": "2024-07-29T15:51:28.071Z"
  }
}
```
*   `success` (boolean): Indicates if the operation was successful.
*   `buiseness` (object): Contains the details of the newly created business.
    *   `id` (string): The unique identifier of the business.
    *   `name` (string): The name of the business.
    *   `phone` (string): The phone number of the business.
    *   `email` (string): The email address of the business.
    *   `website` (string): The website of the business.
    *   `address` (string): The address of the business.
    *   `city` (string): The city of the business.
    *   `description` (string): The description of the business.
    *   `state` (string): The state of the business.
    *   `postalCode` (string): The postal code of the business.
    *   `country` (string): The country of the business.
    *   `updatedBy` (object): Information about the user who last updated the business.
    *   `locationId` (string): The ID of the location the business belongs to.
    *   `createdBy` (object): Information about the user who created the business.
    *   `createdAt` (date-time): Timestamp of creation.
    *   `updatedAt` (date-time): Timestamp of last update.

### 10. PURPOSE:
This endpoint allows users to create a new business entry within a specified location in the system.
