Here is a structured summary of the API documentation:

1.  **ENDPOINT NAME:** Delete Group

2.  **CATEGORY:** Calendars

3.  **HTTP METHOD:** DELETE

4.  **ENDPOINT URL:** /calendars/groups/:groupId

5.  **FULL URL:** https://services.leadconnectorhq.com/calendars/groups/:groupId

6.  **REQUIRED PARAMETERS:**
    *   Version (string): API Version. Possible values: `2021-04-15`
    *   groupId (string): Group Id. Example: `ocQHyuzHvysMo5N5VsXc`

7.  **OPTIONAL PARAMETERS:** None specified in documentation

8.  **AUTHENTICATION:**
    *   Scope(s): `calendars/groups.write`
    *   Auth Method(s): `OAuth Access Token`, `Private Integration Token`
    *   Token Type(s): `Sub-Account Token`
    *   Scheme: `bearer`
    *   Bearer Format: `JWT`

9.  **RESPONSE FORMAT:**
    *   **200 OK**
        *   Content-Type: `application/json`
        *   Schema:
            ```json
            {
              "success": boolean // Success
            }
            ```
        *   Example: `{"success":"true"}`
    *   **400 Bad Request**
        *   Schema:
            ```json
            {
              "statusCode": number, // Example: 400
              "message": string // Example: "Bad Request"
            }
            ```
    *   **401 Unauthorized**
        *   Schema:
            ```json
            {
              "statusCode": number, // Example: 401
              "message": string, // Example: "Invalid token: access token is invalid"
              "error": string // Example: "Unauthorized"
            }
            ```

10. **PURPOSE:** This endpoint allows for the deletion of a specific calendar group by its ID.
