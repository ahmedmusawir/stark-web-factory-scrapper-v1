Here's a structured summary of the "Update Opportunity" API documentation:

### 1. ENDPOINT NAME:
Update Opportunity

### 2. CATEGORY:
Opportunities

### 3. HTTP METHOD:
PUT

### 4. ENDPOINT URL:
`/opportunities/:id`

### 5. FULL URL:
`https://services.leadconnectorhq.com/opportunities/:id`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters:**
    *   Version (string): API Version (Possible values: `2021-07-28`)
*   **Path Parameters:**
    *   id (string): Opportunity Id (Example: `yWQobCRIhRguQtD2llvk`)
*   **Body Parameters:**
    *   Body (object): The request body itself is required, containing fields for the opportunity update. While the top-level body fields (`pipelineId`, `name`, etc.) are not explicitly marked as `required` in the "Request" section, updating an opportunity typically requires at least one of these to be present. For `customFields`, the `id` field within each custom field object is explicitly marked as required.
        *   customFields (object[]): Array of custom field objects.
            *   id (string): Pass either `id` or `key` of custom field (required within the custom field object). (Example: `6dvNaf7VhkQ9snc5vnjJ`)

### 7. OPTIONAL PARAMETERS:
*   **Body Parameters:**
    *   pipelineId (string): pipeline Id (Example: `bCkKGpDsyPP4peuKowkG`)
    *   name (string): (Example: `First Opps`)
    *   pipelineStageId (string): (Example: `7915dedc-8f18-44d5-8bc3-77c04e994a10`)
    *   status (string): (Possible values: `open`, `won`, `lost`, `abandoned`, `all`)
    *   monetaryValue (number): (Example: `220`)
    *   assignedTo (string): (Example: `082goXVW3lIExEQPOnd3`)
    *   customFields (object[]): Update custom fields to opportunities.
        *   key (string): Pass either `id` or `key` of custom field. (Example: `my_custom_field`)
        *   field_value (string): The value for a string-type custom field. (Example: `9039160788`)
        *   field_value (string[]): The value for an array-type custom field. (Example: `["test","test2"]`)
        *   field_value (object): The value for an object-type custom field. (Example: `{}`)

### 8. AUTHENTICATION:
*   **Scope(s):** `opportunities.write`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`

### 10. PURPOSE:
This endpoint allows for updating the details of an existing opportunity, including its pipeline, stage, status, monetary value, assigned user, and custom fields.
