Here is a structured summary of the provided API documentation:

### 1. ENDPOINT NAME
Manage Auto payment for an schedule invoice

### 2. CATEGORY
Invoice Schedule Management

### 3. HTTP METHOD
POST

### 4. ENDPOINT URL
`/invoices/schedule/:scheduleId/auto-payment`

### 5. FULL URL
`https://services.leadconnectorhq.com/invoices/schedule/:scheduleId/auto-payment`

### 6. REQUIRED PARAMETERS

*   **Header Parameters:**
    *   `Version` (string): API Version. Possible values: [`2021-07-28`]
*   **Path Parameters:**
    *   `scheduleId` (string): Schedule Id. Example: `6578278e879ad2646715ba9c`
*   **Body Parameters:**
    *   `altId` (string): location Id / company Id based on altType. Example: `6578278e879ad2646715ba9c`
    *   `altType` (string): Alt Type. Possible values: [`location`]. Example: `location`
    *   `id` (string): Not described.
    *   `autoPayment` (object): auto-payment configuration
        *   `enable` (boolean): Not described.
    *   `autoPayment.card.brand` (string): Required if `card` object is provided. Not described.
    *   `autoPayment.card.last4` (string): Required if `card` object is provided. Not described.
    *   `autoPayment.usBankAccount.bank_name` (string): Required if `usBankAccount` object is provided. Not described.
    *   `autoPayment.usBankAccount.last4` (string): Required if `usBankAccount` object is provided. Not described.
    *   `autoPayment.sepaDirectDebit.bank_code` (string): Required if `sepaDirectDebit` object is provided. Not described.
    *   `autoPayment.sepaDirectDebit.last4` (string): Required if `sepaDirectDebit` object is provided. Not described.
    *   `autoPayment.sepaDirectDebit.branch_code` (string): Required if `sepaDirectDebit` object is provided. Not described.
    *   `autoPayment.bacsDirectDebit.sort_code` (string): Required if `bacsDirectDebit` object is provided. Not described.
    *   `autoPayment.bacsDirectDebit.last4` (string): Required if `bacsDirectDebit` object is provided. Not described.
    *   `autoPayment.becsDirectDebit.bsb_number` (string): Required if `becsDirectDebit` object is provided. Not described.
    *   `autoPayment.becsDirectDebit.last4` (string): Required if `becsDirectDebit` object is provided. Not described.

### 7. OPTIONAL PARAMETERS

*   **Body Parameters:**
    *   `autoPayment.type` (string): Not described.
    *   `autoPayment.paymentMethodId` (string): Not described.
    *   `autoPayment.customerId` (string): Not described.
    *   `autoPayment.card` (object): Contains details for card payment.
    *   `autoPayment.usBankAccount` (object): Contains details for US bank account payment.
    *   `autoPayment.sepaDirectDebit` (object): Contains details for SEPA Direct Debit payment.
    *   `autoPayment.bacsDirectDebit` (object): Contains details for BACS Direct Debit payment.
    *   `autoPayment.becsDirectDebit` (object): Contains details for BECS Direct Debit payment.
    *   `autoPayment.cardId` (string): Not described.
    *   `autoPayment.provider` (object): Not described.

### 8. AUTHENTICATION

*   **Scope(s):** `invoices/schedule.write`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`, `Agency Token`
*   **Scheme:** `bearer`
*   **Bearer Format:** `JWT`
*   **In:** `header`
*   **Description:** Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account.

### 9. RESPONSE FORMAT

*   **Status Code:** `200 OK`
*   **Content Type:** `application/json`
*   **Schema:** A Schedule object is returned, containing the updated schedule details. Key fields include:
    *   `_id` (string): Schedule Id.
    *   `status` (object): Schedule Status (e.g., `draft`).
    *   `liveMode` (boolean): Indicates if it's in live mode.
    *   `altId` (string): Location Id or Agency Id.
    *   `altType` (string): Type of alternate ID (e.g., `location`).
    *   `name` (string): Name of the invoice schedule.
    *   `schedule` (object): Contains recurrence rules (`rrule`) and scheduling parameters.
    *   `invoices` (array of objects): A list of invoices associated with the schedule, each with its own `_id`, `status`, `amountPaid`, `businessDetails`, `contactDetails`, `total`, `amountDue`, `createdAt`, `updatedAt`, etc.
    *   `businessDetails` (object): Details of the business.
    *   `currency` (string): Currency used (e.g., `USD`).
    *   `contactDetails` (object): Details of the contact.
    *   `discount` (object): Discount applied.
    *   `items` (array of strings/objects): List of invoice items.
    *   `total` (number): Total amount.
    *   `title` (string): Invoice title.
    *   `termsNotes` (string): Terms and notes.
    *   `compiledTermsNotes` (string): Compiled terms and notes.
    *   `createdAt` (string): Timestamp of creation.
    *   `updatedAt` (string): Timestamp of last update.

### 10. PURPOSE
This API endpoint allows you to manage the auto-payment configuration for an existing invoice schedule.
