Here's a structured summary of the API documentation:

### 1. ENDPOINT NAME:
Get User by Location

### 2. CATEGORY:
Users

### 3. HTTP METHOD:
GET

### 4. ENDPOINT URL:
`/users/`

### 5. FULL URL:
`https://services.leadconnectorhq.com/users/`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters**:
    *   Version (string): API Version. Possible values: [`2021-07-28`]
*   **Query Parameters**:
    *   locationId (string): Example: `s4BtzHFWmT28mbb85uPa`

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:
*   **Scope(s)**: `users.readonly`
*   **Auth Method(s)**: `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s)**: `Sub-Account Token`

### 9. RESPONSE FORMAT:

*   **200 Successful response (application/json)**:
    An array of user objects, each containing:
    *   `id` (string): Example: `0IHuJvc2ofPAAA8GzTRi`
    *   `name` (string): Example: `John Deo`
    *   `firstName` (string): Example: `John`
    *   `lastName` (string): Example: `Deo`
    *   `email` (string): Example: `john@deo.com`
    *   `phone` (string): Example: `+1 808-868-8888`
    *   `extension` (string)
    *   `permissions` (object): Contains various boolean flags for user permissions (e.g., `campaignsEnabled`, `contactsEnabled`, `workflowsEnabled`, `socialPlanner`, `paymentsEnabled`, etc.).
    *   `scopes` (string): List of possible scope values.
    *   `roles` (object): Contains `type` (string, e.g., `account`), `role` (string, e.g., `admin`), `locationIds` (string array), `restrictSubAccount` (boolean).
    *   `deleted` (boolean): Example: `false`
    *   `lcPhone` (object): LC Phone Inbound Phone Numbers. Example: `{"locationId":"+1234556677"}`

    *   `statusCode` (number): `400`
    *   `message` (string): `Bad Request`
*   **401 Unauthorized (application/json)**:
    *   `statusCode` (number): `401`
    *   `message` (string): `Invalid token: access token is invalid`

### 10. PURPOSE:
This endpoint retrieves a list of users associated with a specific location (Sub-Account) within HighLevel.
