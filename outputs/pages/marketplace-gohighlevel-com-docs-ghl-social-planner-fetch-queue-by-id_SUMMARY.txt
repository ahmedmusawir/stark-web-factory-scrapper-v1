## STRUCTURED SUMMARY

### 1. ENDPOINT NAME:
Fetch a category queue by ID

### 2. CATEGORY:
Social Planner - Category Queue

### 3. HTTP METHOD:
GET

### 4. ENDPOINT URL:
`/social-media-posting/category/queues/:queueId`

### 5. FULL URL:
`https://services.leadconnectorhq.com/social-media-posting/category/queues/:queueId`

### 6. REQUIRED PARAMETERS:
*   **Version** (string): API Version (Possible values: [`2021-07-28`])
*   **queueId** (string): Unique ID of the category queue.
*   **locationId** (string): Location ID (Example: `609e126a1c4ae1001291e1b5`)

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:
Token-based (e.g., Access Token) implied by 401 response ("Invalid token: access token is invalid"). Specific scopes or detailed authentication methods are not provided for this endpoint, but general API authorization is covered in other documentation sections like "Authorization" and "OAuth 2.0".

### 9. RESPONSE FORMAT:
**200 OK - application/json**
A successful response returns a JSON object containing the details of the fetched category queue and a count of posts with errors.

*   `success` (boolean): `true`
*   `statusCode` (number): `200`
*   `results` (object):
    *   `message` (string): "Queue fetched successfully"
    *   `queue` (object):
        *   `_id` (string): Queue ID (Example: `60af88475f1b2c001f5d5f4b`)
        *   `locationId` (string): Location ID (Example: `location-123`)
        *   `categoryId` (string): Category ID (Example: `60af88475f1b2c001f5d5f4b`)
        *   `timeSlots` (array of objects): Time slots for scheduling posts
            *   `dayOfWeek` (number): Day of the week (0-6) (Example: `0`)
            *   `time` (string): Time in HH:mm format (Example: `09:00`)
        *   `enableFuturePosts` (boolean): Enable posting future content (Example: `false`)
        *   `prioritizeNewContent` (boolean): Prioritize new content over older content (Example: `false`)
        *   `currentOrder` (number): Current order number in the queue (Example: `1000`)
        *   `status` (string): Status of the queue. Possible values: [`active`, `paused`, `draft`] (Example: `active`)
        *   `startDate` (date-time): Start date of the queue (Example: `2023-01-01T12:00:00Z`)
        *   `skipDateTime` (array of date-time): Dates/times to skip posting (Example: `["2023-01-02T12:00:00Z"]`)
        *   `currentPostId` (string, nullable): ID of the currently scheduled post (Example: `60af88475f1b2c001f5d5f4b`)
        *   `totalPosts` (number): Total number of posts in the queue (Example: `10`)
        *   `lastScheduledTime` (date-time, nullable): Timestamp of the last scheduled post (Example: `2023-01-01T12:00:00Z`)
        *   `createdBy` (string): ID of the user who created the queue (Example: `user-123`)
        *   `createdAt` (date-time): Creation timestamp (Example: `2023-01-01T00:00:00Z`)
        *   `updatedAt` (date-time): Last update timestamp (Example: `2023-01-01T00:00:00Z`)
    *   `errorPostCount` (number): Number of posts with errors in the queue (Example: `0`)
*   `traceId` (string)

**Error Responses:**
*   **400 Bad Request:** `{"statusCode":400,"message":"Bad Request"}`
*   **401 Unauthorized:** `{"statusCode":401,"message":"Invalid token: access token is invalid","error":"Unauthorized"}`
*   **422 Unprocessable Entity:** `{"statusCode":422,"message":["Unprocessable Entity"],"error":"Unprocessable Entity"}`

### 10. PURPOSE:
This endpoint retrieves the comprehensive details of a specific category queue using its unique ID, including configuration, post counts, and any errors within the queue.
