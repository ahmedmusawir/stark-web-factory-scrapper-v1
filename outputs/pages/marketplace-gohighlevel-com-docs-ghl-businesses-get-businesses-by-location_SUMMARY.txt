Here's a structured summary of the API documentation for "Get Businesses by Location":

### 1. ENDPOINT NAME:
Get Businesses by Location

### 2. CATEGORY:
Business / Businesses

### 3. HTTP METHOD:
GET

### 4. ENDPOINT URL:
`/businesses/`

### 5. FULL URL:
`https://services.leadconnectorhq.com/businesses/`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters:**
    *   `Version` (string): API Version. Possible values: [`2021-07-28`]
*   **Query Parameters:**
    *   `locationId` (string): The ID of the location for which to retrieve businesses. Example: `5DP4iH6HLkQsiKESj6rh`

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:
*   **Scope(s)**: `businesses.readonly`
*   **Auth Method(s)**: `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s)**: `Sub-Account Token`
*   **Scheme**: `bearer`
*   **Bearer Format**: `JWT`
*   **In**: `header` (for Authorization)
*   **Description**: Use an Access Token generated with user type as Sub-Account (OR) a Private Integration Token of a Sub-Account.
