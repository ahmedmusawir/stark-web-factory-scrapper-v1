Here is a structured summary of the API documentation:

### 1. ENDPOINT NAME:
List Order Notes

### 2. CATEGORY:
Payments

### 3. HTTP METHOD:
GET

### 4. ENDPOINT URL:
`/payments/orders/:orderId/notes`

### 5. FULL URL:
`https://services.leadconnectorhq.com/payments/orders/:orderId/notes`

### 6. REQUIRED PARAMETERS:
*   `Version` (string): API Version. Possible values: `2021-07-28` (Header Parameter)
*   `orderId` (string): ID of the order that needs to be returned. Example: `653f5e0cde5a1314e62a837c` (Path Parameter)
*   `altId` (string): Location Id or Agency Id. Example: `6578278e879ad2646715ba9c` (Query Parameter)
*   `altType` (string): Possible values: [`location`] (Query Parameter)

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** Bearer
*   **Bearer Format:** JWT
*   **Description:** Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account.

### 9. RESPONSE FORMAT:
*   **200 Successful response:**
    *   Status Code: `200`
    *   Schema: Not explicitly detailed for a successful payload in the provided documentation.
*   **400 Bad Request:**
    *   Status Code: `400`
    *   Schema:
        *   `statusCode` (number): Example: `400`
        *   `message` (string): Example: `Bad Request`
*   **401 Unauthorized:**
    *   Status Code: `401`
    *   Schema:
        *   `statusCode` (number): Example: `401`
        *   `message` (string): Example: `Invalid token: access token is invalid`
        *   `error` (string): Example: `Unauthorized`

    *   Status Code: `422`

        *   `statusCode` (number): Example: `422`

### 10. PURPOSE:
This endpoint is used to retrieve a list of all notes associated with a specific order.
