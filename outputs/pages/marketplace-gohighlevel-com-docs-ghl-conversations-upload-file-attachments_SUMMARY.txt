Here is a structured summary of the provided API documentation:

### 1. ENDPOINT NAME:
Upload file attachments

### 2. CATEGORY:
Conversations (Messages)

### 3. HTTP METHOD:
POST

### 4. ENDPOINT URL:
`/conversations/messages/upload`

### 5. FULL URL:
`https://services.leadconnectorhq.com/conversations/messages/upload`

### 6. REQUIRED PARAMETERS:

*   **Header Parameters:**
    *   `Version` (string): API Version. Possible values: [`2021-04-15`]

*   **Body Parameters (multipart/form-data):**
    *   `fileAttachment` (buffer): The actual file content to be uploaded. The files need to be a buffer with the key "fileAttachment".
        *   **Allowed file types:** JPG, JPEG, PNG, MP4, MPEG, ZIP, RAR, PDF, DOC, DOCX, TXT, MP3, WAV
    *   `conversationId` (string): Conversation Id. Example: `ve9EPM428h8vShlRW1KT`
    *   `locationId` (string): Location Id.
    *   `attachmentUrls` (string[]): (Description not explicitly provided in the documentation, but listed as a required array in the request body section.)

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:

*   **Scope(s):** `conversations/message.write`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** `bearer`
*   **Bearer Format:** `JWT`
*   **In:** `header`
*   **Description:** Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account.

### 9. RESPONSE FORMAT:

*   **Status Code:** `200 OK`
*   **Description:** Uploaded the file successfully
*   **Content Type:** `application/json`
*   **Schema:**
    ```json
    {
      "uploadedFiles": {}
    }
    ```
    (The `uploadedFiles` object is expected to contain the URLs of the uploaded files, although the example shows an empty object.)

### 10. PURPOSE:
This endpoint allows users to upload file attachments to conversations by posting a file buffer and relevant conversation details, returning the URLs of the successfully uploaded files.

Conversations, Messages, Upload, File, Attachments, Media, Post, Communication
