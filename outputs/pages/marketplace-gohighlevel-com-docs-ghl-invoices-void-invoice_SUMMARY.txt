Here is a structured summary of the provided API documentation:

### 1. ENDPOINT NAME:
Void invoice

### 2. CATEGORY:
Invoice

### 3. HTTP METHOD:
POST

### 4. ENDPOINT URL:
`/invoices/:invoiceId/void`

### 5. FULL URL:
`https://services.leadconnectorhq.com/invoices/:invoiceId/void`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters:**
    *   Version (string): API Version. Possible values: `[2021-07-28]`
*   **Path Parameters:**
    *   invoiceId (string): Invoice Id. Example: `6578278e879ad2646715ba9c`
*   **Body Parameters:**
    *   altId (string): location Id / company Id based on altType. Example: `6578278e879ad2646715ba9c`
    *   altType (string): Alt Type. Possible values: `[location]`. Example: `location`

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:
*   **Scope(s):** `invoices.write`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`, `Agency Token`
*   **Scheme:** Bearer (JWT)
*   **In:** Header (Authorization)
*   **Description:** Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account.

### 9. RESPONSE FORMAT:
**Successful Response (200 OK):**
A JSON object representing the voided invoice, with its `status` updated to `void` (if applicable) or other relevant status.
Key fields include:
*   `_id` (string): Invoice Id
*   `status` (string): Invoice Status (e.g., `draft`, `sent`, `payment_processing`, `paid`, `void`, `partially_paid`)
*   `liveMode` (boolean): Live Mode
*   `amountPaid` (number): Amount Paid
*   `altId` (string): Location Id or Agency Id
*   `altType` (string): Possible values: `[location]`
*   `name` (string): Name of the invoice
*   `businessDetails` (object): Details of the business
*   `invoiceNumber` (string): Invoice Number
*   `currency` (string): Currency
*   `contactDetails` (object): Contact Details
*   `issueDate` (string): Issue date in YYYY-MM-DD format
*   `dueDate` (string): Due date in YYYY-MM-DD format
*   `discount` (object): Discount details
*   `invoiceItems` (array of objects): List of invoice items
*   `total` (number): Total Amount
*   `title` (string): Title
*   `amountDue` (number): Total Amount Due
*   `createdAt` (string): created at (ISO 8601 format)
*   `updatedAt` (string): updated at (ISO 8601 format)
*   `automaticTaxesEnabled` (boolean, optional): Automatic taxes enabled for the Invoice
*   `automaticTaxesCalculated` (boolean, optional): Is Automatic taxes calculated for the Invoice items
*   `paymentSchedule` (object, optional): split invoice into payment schedule

**Error Responses:**
*   **400 Bad Request:**
    *   `Unable to find an invoice with the given invoice id`
    *   `Can not void draft invoice. You can delete draft invoice!`
    *   `To void an invoice which has received payment through the payment provider, the corresponding transaction needs to be refunded first`
*   **401 Unauthorized:** Invalid token or unauthorized access.
*   **422 Unprocessable Entity:** Request cannot be processed.

### 10. PURPOSE:
This endpoint voids an existing invoice identified by its ID, changing its status and indicating it's no longer valid.
