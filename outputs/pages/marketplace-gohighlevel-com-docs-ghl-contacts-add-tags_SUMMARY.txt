Here's a structured summary of the "Add Tags" API documentation:

### 1. ENDPOINT NAME:
Add Tags

### 2. CATEGORY:
Contacts

### 3. HTTP METHOD:
POST

### 4. ENDPOINT URL:
`/contacts/:contactId/tags`

### 5. FULL URL:
`https://services.leadconnectorhq.com/contacts/:contactId/tags`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters:**
    *   `Version` (string): API Version. Possible values: `2021-07-28`.
*   **Path Parameters:**
    *   `contactId` (string): Contact Id.
*   **Body Parameters:**
    *   `tags` (string[]): An array of strings representing the tags to be added.

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:
*   **Scope(s)**: `contacts.write`
*   **Auth Method(s)**: `OAuth Access Token`, `Private Integration Token` (Bearer scheme with JWT format)
*   **Token Type(s)**: `Sub-Account Token`

### 9. RESPONSE FORMAT:
*   **Status Code**: `201 Created`
*   **Content Type**: `application/json`
*   **Schema**:
    ```json
    {
      "tags": ["string"]
    }
    ```
*   **Example**:
    ```json
    {"tags":["minim","velit magna"]}
    ```

### 10. PURPOSE:
This endpoint allows a user to add one or more specified tags to an existing contact.
