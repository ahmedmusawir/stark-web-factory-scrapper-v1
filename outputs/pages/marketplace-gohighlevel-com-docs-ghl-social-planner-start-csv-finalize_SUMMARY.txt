Here's a structured summary of the API documentation for "Start CSV Finalize":

### 1. ENDPOINT NAME:
Start CSV Finalize

### 2. CATEGORY:
Social Planner (CSV)

### 3. HTTP METHOD:
PATCH

### 4. ENDPOINT URL:
`/social-media-posting/:locationId/csv/:id`

### 5. FULL URL:
`https://services.leadconnectorhq.com/social-media-posting/:locationId/csv/:id`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters:**
    *   `Version` (string): API Version (Possible values: `2021-07-28`)
*   **Path Parameters:**
    *   `locationId` (string): Location ID
    *   `id` (string): CSV Id
*   **Body Parameters:**
    *   `userId` (string): User ID

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** `bearer`
*   **Bearer Format:** `JWT`
*   **In:** `header`
*   **Description:** Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account.
