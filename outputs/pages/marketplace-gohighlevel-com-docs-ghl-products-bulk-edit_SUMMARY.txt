Here is a structured summary of the provided API documentation:

### 1. ENDPOINT NAME:
Bulk Edit Products and Prices

### 2. CATEGORY:
Products

### 3. HTTP METHOD:
POST

### 4. ENDPOINT URL:
`/products/bulk-update/edit`

### 5. FULL URL:
`https://services.leadconnectorhq.com/products/bulk-update/edit`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters:**
    *   `Version` (string): API Version. Possible values: [`2021-07-28`]
*   **Body Parameters:**
    *   `altId` (string): Location Id or Agency Id
    *   `altType` (string): Possible values: [`location`]
    *   `products` (object[]): Array of products to update.
        *   `_id` (string): Product ID
        *   `prices` (object[]): Array of price variants for the product.
            *   `_id` (string): Price ID
            *   `shippingOptions` (object): Shipping options
                *   `weight` (object): Weight options of the product
                    *   `value` (number): Actual weight of the product
                    *   `unit` (string): Weight unit of the product. Possible values: [`kg`, `lb`, `g`, `oz`]
                *   `dimensions` (object): Dimensions of the product
                    *   `height` (number): Height of the price
                    *   `width` (number): Width of the price
                    *   `length` (number): Length of the price
                    *   `unit` (string): Unit of the price dimensions. Possible values: [`cm`, `in`, `m`]
            *   `recurring` (object): Recurring details
                *   `interval` (string): The interval at which the recurring event occurs. Possible values: [`day`, `month`, `week`, `year`]
                *   `intervalCount` (number): The number of intervals between each occurrence of the event.

### 7. OPTIONAL PARAMETERS:
*   **Body Parameters:**
    *   `products` (object[]):
        *   `name` (string): Product name
        *   `description` (string): Product description
        *   `image` (string): Product image
        *   `availableInStore` (boolean): Product availability in store
        *   `collectionIds` (string[]): Collection IDs
        *   `isLabelEnabled` (boolean): Enable product label
        *   `isTaxesEnabled` (boolean): Enable taxes
        *   `seo` (object): SEO metadata for the product
            *   `title` (string): SEO title
            *   `description` (string): SEO description
            *   `slug` (string): Product URL slug
        *   `automaticTaxCategoryId` (string): Automatic tax category ID
        *   `taxInclusive` (boolean): Tax inclusive pricing
        *   `taxes` (object[]): Product taxes (Inner fields not specified)
        *   `medias` (object[]): Product media (Inner fields not specified)
        *   `label` (object): Product label (Inner fields not specified)
    *   `products.prices` (object[]):
        *   `name` (string): Price name
        *   `amount` (number): Price amount
        *   `currency` (string): Price currency
        *   `compareAtPrice` (number): Compare at price
        *   `availableQuantity` (number): Available quantity
        *   `trackInventory` (boolean): Track inventory
        *   `allowOutOfStockPurchases` (boolean): Allow out of stock purchases
        *   `sku` (string): SKU
        *   `trialPeriod` (number): Trial period in days
        *   `totalCycles` (number): Total billing cycles
        *   `setupFee` (number): Setup fee

### 8. AUTHENTICATION:
Authentication via an OAuth 2.0 access token is implied by the `Highlevel API 2.0` context and the `401 Unauthorized` response example message (`Invalid token: access token is invalid`). Specific scopes are not explicitly mentioned for this endpoint, but general authorization details might be found in linked `Authorization` and `OAuth 2.0` documentation.

### 9. RESPONSE FORMAT:
*   **Success (201 Created):**
    *   Status Code: `201`
    *   Content Type: `application/json`
    *   Body Structure:
        ```json
        {
          "message": "Products updated successfully",
          "status": true,
          "updatedCount": 5
        }
        ```
*   **Error Responses:**
    *   `400 Bad Request`: `{"statusCode":400,"message":"Bad Request"}`
    *   `401 Unauthorized`: `{"statusCode":401,"message":"Invalid token: access token is invalid","error":"Unauthorized"}`
    *   `422 Unprocessable Entity`: `{"statusCode":422,"message":["Unprocessable Entity"],"error":"Unprocessable Entity"}`

### 10. PURPOSE:
This API endpoint allows for bulk editing of up to 30 products and their associated prices simultaneously within a specified location or agency.
