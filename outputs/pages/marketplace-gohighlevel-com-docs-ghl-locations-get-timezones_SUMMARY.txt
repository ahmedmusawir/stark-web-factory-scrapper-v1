Here's a structured summary of the API documentation for "Fetch Timezones":

### 1. ENDPOINT NAME:
Fetch Timezones

### 2. CATEGORY:
Sub-Account (Formerly location) / Timezone

### 3. HTTP METHOD:
GET

### 4. ENDPOINT URL:
`/locations/:locationId/timezones`

### 5. FULL URL:
`https://services.leadconnectorhq.com/locations/:locationId/timezones`

### 6. REQUIRED PARAMETERS:
*   **locationId** (string): The unique identifier for the sub-account (formerly location). This is a path parameter.
*   **Version** (string): API Version.
    *   Possible values: [`2021-07-28`] (This is a header parameter).

### 7. OPTIONAL PARAMETERS:
Not specified in documentation
