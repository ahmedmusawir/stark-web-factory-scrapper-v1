Here's a structured summary of the API documentation for "Get SaaS Plan":

### 1. ENDPOINT NAME
Get SaaS Plan

### 2. CATEGORY
Saas

### 3. HTTP METHOD
GET

### 4. ENDPOINT URL
`/saas-api/public-api/saas-plan/:planId`

### 5. FULL URL
`https://services.leadconnectorhq.com/saas-api/public-api/saas-plan/:planId`

### 6. REQUIRED PARAMETERS
*   **Header Parameters:**
    *   `Version` (string): API Version. Possible values: [`2021-04-15`]
*   **Path Parameters:**
    *   `planId` (string): Plan ID to get SaaS plan details for. Example: `66c4d36534f21f900dc2a265`
*   **Query Parameters:**
    *   `companyId` (string): Company ID to filter SaaS plan. Example: `5DP4iH6HLkQsiKESj6rh`

### 7. OPTIONAL PARAMETERS
Not specified in documentation

### 8. AUTHENTICATION
*   **Auth Method(s)**: `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s)**: `Agency Token`
*   **Bearer Format**: `JWT`
*   **In**: `header`
*   **Description**: Use the Access Token generated with user type as Company.

### 9. RESPONSE FORMAT
**Status Code: 200 - SaaS plan retrieved successfully**
*   **Content Type**: `application/json`
*   **Schema**:
    *   `planId` (string): Unique identifier for the SaaS plan
    *   `companyId` (string): Company ID associated with the SaaS plan
    *   `title` (string): Title of the SaaS plan
    *   `description` (string): Description of the SaaS plan
    *   `saasProducts` (string[]): Array of SaaS products included in the plan
    *   `addOns` (string[]): Array of add-ons included in the plan
    *   `planLevel` (number): Level of the plan (0-4)
    *   `trialPeriod` (number): Trial period in days
    *   `setupFee` (number): Setup fee for the plan
    *   `userLimit` (number): User limit for the plan
    *   `contactLimit` (number): Contact limit for the plan
    *   `prices` (object[]): Prices for the plan (array of objects)
        *   `id` (string)
        *   `billingInterval` (string): Possible values: [`month`, `year`]
        *   `active` (boolean)
        *   `amount` (number)
        *   `currency` (string)
        *   `symbol` (string)
    *   `categoryId` (string): Category ID for the plan
    *   `snapshotId` (string): Snapshot ID for the plan
    *   `providerLocationId` (string): Provider location ID
    *   `productId` (string): Product ID for the plan
    *   `isSaaSV2` (boolean): Indicates if this is a SaaS V2 plan
    *   `createdAt` (date-time): Creation timestamp
    *   `updatedAt` (date-time): Last update timestamp

**Error Responses:**
*   **400 Bad Request**: JSON object with `statusCode` (number) and `message` (string).
*   **401 Unauthorized**: JSON object with `statusCode` (number), `message` (string), and `error` (string).
*   **404 Resource not found**: JSON object with `statusCode` (number) and `message` (string or string array).
*   **500 Internal server error**: JSON object with `statusCode` (number) and `message` (string).

### 10. PURPOSE
This endpoint is used to fetch the details of a specific SaaS plan by its plan ID. (Note: This endpoint is deprecated and may be replaced or removed in future API versions).
