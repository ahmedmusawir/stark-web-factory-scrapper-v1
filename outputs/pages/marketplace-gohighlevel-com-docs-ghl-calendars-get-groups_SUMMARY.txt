Here's a structured summary of the API documentation for "Get Groups":

### 1. ENDPOINT NAME
Get Groups

### 2. CATEGORY
Calendars, Calendar Groups

### 3. HTTP METHOD
GET

### 4. ENDPOINT URL
`/calendars/groups`

### 5. FULL URL
`https://services.leadconnectorhq.com/calendars/groups`

### 6. REQUIRED PARAMETERS
*   **Version** (string): API Version. Possible values: `2021-04-15`. (Header Parameter)
*   **locationId** (string): Location Id. Example: `ve9EPM428h8vShlRW1KT`. (Query Parameter)

### 7. OPTIONAL PARAMETERS
Not specified in documentation

### 8. AUTHENTICATION
*   **Scope(s)**: `calendars/groups.readonly`
*   **Auth Method(s)**: `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s)**: `Sub-Account Token`
*   **Details**: The `Authorization` header should contain a Bearer token (JWT format). This token must be an Access Token generated with user type as Sub-Account OR a Private Integration Token of a Sub-Account.

### 9. RESPONSE FORMAT
*   **Status Code**: `200` (Successful response)
*   **Content Type**: `application/json`
*   **Schema**:
    ```json
    {
      "groups": [
        {
          "locationId": "string",  // Example: "ocQHyuzHvysMo5N5VsXc"
          "name": "string",        // Example: "group a"
          "description": "string", // Example: "group description"
          "slug": "string",        // Example: "15-mins"
          "isActive": "boolean",   // Example: true
          "id": "string"           // Example: "ocQHyuzHvysMo5N5VsXc"
        }
      ]
    }
    ```
*   **Example (200)**:
    ```json
    {
      "groups": [
        {
          "locationId": "ocQHyuzHvysMo5N5VsXc",
          "name": "group a",
          "description": "group description",
          "slug": "15-mins",
          "isActive": true,
          "id": "ocQHyuzHvysMo5N5VsXc"
        }
      ]
    }
    ```
*   **Error Responses**:
    *   `400 Bad Request`: `{"statusCode":400,"message":"Bad Request"}`
    *   `401 Unauthorized`: `{"statusCode":401,"message":"Invalid token: access token is invalid","error":"Unauthorized"}`

### 10. PURPOSE
Get all calendar groups in a specific location.
