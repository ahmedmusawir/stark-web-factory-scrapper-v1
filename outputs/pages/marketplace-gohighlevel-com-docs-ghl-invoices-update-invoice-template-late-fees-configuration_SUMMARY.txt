Here's a structured summary of the provided API documentation:

---

### 1. ENDPOINT NAME:
Update template late fees configuration

### 2. CATEGORY:
Invoice (specifically, Template management within Invoices)

### 3. HTTP METHOD:
PATCH

### 4. ENDPOINT URL:
`/invoices/template/:templateId/late-fees-configuration`

### 5. FULL URL:
`https://services.leadconnectorhq.com/invoices/template/:templateId/late-fees-configuration`

### 6. REQUIRED PARAMETERS:

*   **Header Parameters**:
    *   `Version` (string): API Version. Possible values: `2021-07-28`
*   **Path Parameters**:
    *   `templateId` (string): Template Id. Example: `6578278e879ad2646715ba9c`
*   **Body Parameters (application/json)**:
    *   `altId` (string): location Id / company Id based on altType. Example: `6578278e879ad2646715ba9c`
    *   `altType` (string): Alt Type. Possible values: `location`. Example: `location`
    *   `lateFeesConfiguration` (object): late fees configuration
        *   `enable` (boolean): Enable late fees. Example: `true`
        *   `value` (number): Late Fees Value. Example: `10`
        *   `type` (string): Late Fees Type. Possible values: `fixed`, `percentage`. Example: `fixed`
        *   `frequency` (object): Late Fees Frequency
            *   `intervalCount` (number): Late fees interval count. Example: `10`
            *   `interval` (string): Late fees interval. Possible values: `minute`, `hour`, `day`, `week`, `month`, `one_time`. Example: `day`

### 7. OPTIONAL PARAMETERS:

*   **Body Parameters (application/json)**:
    *   `lateFeesConfiguration.grace` (object): Late Fees Grace
        *   `intervalCount` (number): Late fees grace interval count (Required if `grace` object is provided). Example: `10`
        *   `interval` (string): Late fees grace interval (Required if `grace` object is provided). Possible values: `day`. Example: `day`
    *   `lateFeesConfiguration.maxLateFees` (object): Max late fees payable
        *   `type` (string): (Required if `maxLateFees` object is provided). Possible values: `fixed`. Example: `fixed`
        *   `value` (number): Max late fees to pay (Required if `maxLateFees` object is provided). Example: `10`

### 8. AUTHENTICATION:
*   **Auth Method(s)**: `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s)**: `Sub-Account Token`, `Agency Token`
*   **Scheme**: Bearer (JWT)
*   **Header**: `Authorization: Bearer <TOKEN>`
