**1. ENDPOINT NAME:** List Transactions

**2. CATEGORY:** Payments

**3. HTTP METHOD:** GET

**4. ENDPOINT URL:** /payments/transactions

**5. FULL URL:** https://services.leadconnectorhq.com/payments/transactions

**6. REQUIRED PARAMETERS:**
*   **Header Parameters:**
    *   Version (string): API Version. Possible values: [`2021-07-28`]
*   **Query Parameters:**
    *   altId (string): AltId is the unique identifier e.g: location id.
    *   altType (string): AltType is the type of identifier.

**7. OPTIONAL PARAMETERS:**
*   **Query Parameters:**
    *   locationId (string): LocationId is the id of the sub-account.
    *   paymentMode (string): Mode of payment.
    *   startAt (string): Starting interval of transactions.
    *   endAt (string): Closing interval of transactions.
    *   entitySourceType (string): Source of the transactions.
    *   entitySourceSubType (string): Source sub-type of the transactions.
    *   search (string): The name of the transaction for searching.
    *   subscriptionId (string): Subscription id for filtering of transactions.
    *   entityId (string): Entity id for filtering of transactions.
    *   contactId (string): Contact id for filtering of transactions.
    *   limit (number): The maximum number of items to be included in a single page of results. (Default value: `10`)
    *   offset (number): The starting index of the page, indicating the position from which the results should be retrieved. (Default value: `0`)

**8. AUTHENTICATION:**
*   **Scope(s):** `payments/transactions.readonly`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** `bearer`
*   **Bearer Format:** `JWT`
*   **In:** `header`

**9. RESPONSE FORMAT:**
*   **Successful Response (200 OK):**
    *   **Content-Type:** `application/json`
    *   **Schema:** A JSON object containing:
        *   `data` (array of objects): An array of transaction objects, each with fields like `_id`, `altId`, `altType`, `contactId`, `contactName`, `currency`, `amount`, `status`, `liveMode`, `entityType`, `entityId`, `entitySourceType`, `createdAt`, `updatedAt`, etc.
        *   `totalCount` (number): The total count of transactions.
*   **Error Responses:**
    *   **400 Bad Request:** `{"statusCode":400,"message":"Bad Request"}`
    *   **401 Unauthorized:** `{"statusCode":401,"message":"Invalid token: access token is invalid","error":"Unauthorized"}`
    *   **422 Unprocessable Entity:** `{"statusCode":422,"message":["Unprocessable Entity"],"error":"Unprocessable Entity"}`

**10. PURPOSE:**
This endpoint allows retrieving a paginated list of transactions, which can be customized and filtered based on various parameters such as name, type, status, payment mode, date range, source, contact, subscription ID, or entity ID.
