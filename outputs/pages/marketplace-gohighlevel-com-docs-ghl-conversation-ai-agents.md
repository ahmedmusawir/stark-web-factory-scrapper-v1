# Agents
Documentation for AI Employees API
## [📄️ Create an AgentCreates a new AI agent for the location. The agent will be created with the specified configuration including name, role, actions, and behavior settings.](https://marketplace.gohighlevel.com/docs/ghl/conversation-ai/create-agent)## [📄️ Search AgentsSearches for AI agents based on various criteria including name, status, and configuration. Supports advanced filtering and full-text search capabilities.](https://marketplace.gohighlevel.com/docs/ghl/conversation-ai/search-agent)## [📄️ Update AgentUpdates an existing AI agent's configuration. All fields in the agent configuration can be updated including name, status, actions, and behavior settings.](https://marketplace.gohighlevel.com/docs/ghl/conversation-ai/update-agent)## [📄️ Get AgentRetrieves a specific AI agent by its ID. Returns the complete agent configuration including name, status, actions, and settings.](https://marketplace.gohighlevel.com/docs/ghl/conversation-ai/get-agent)## [📄️ Delete AgentDeletes an AI agent permanently. This action cannot be undone. All associated configurations and conversation history will be removed.](https://marketplace.gohighlevel.com/docs/ghl/conversation-ai/delete-agent)
