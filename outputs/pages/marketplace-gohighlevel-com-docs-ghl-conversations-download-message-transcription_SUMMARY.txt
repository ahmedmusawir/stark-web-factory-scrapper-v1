Here's a structured summary of the API documentation:

### 1. ENDPOINT NAME:
Download transcription by Message ID

### 2. CATEGORY:
Conversations, Messages

### 3. HTTP METHOD:
GET

### 4. ENDPOINT URL:
`/conversations/locations/:locationId/messages/:messageId/transcription/download`

### 5. FULL URL:
`https://services.leadconnectorhq.com/conversations/locations/:locationId/messages/:messageId/transcription/download`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters:**
    *   `Version` (string): API Version. Possible values: [`2021-04-15`]
*   **Path Parameters:**
    *   `locationId` (string): Location ID as string. Example: `tDtDnQdgm2LXpyiqYvZ6`
    *   `messageId` (string): Message ID as string. Example: `tDtDnQdgm2LXpyiqYvZ6`

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** Bearer (JWT)
*   **Description:** Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account.

### 9. RESPONSE FORMAT:
*   **200 OK (Success - Download):**
    *   **Description:** Downloads the attached transcription of the message.
    *   **Response Headers:**
        *   `Content-Type`: `text/plain`
        *   `Content-Disposition`: `Attachment; filename="transcription.txt"`
    *   **Response Body:** The plain text content of the transcription.
*   **400 Bad Request:**
    *   **Content-Type:** `application/json`
    *   **Schema:**
        *   `statusCode` (number): Example: `400`
        *   `message` (string): Example: `Bad Request`
    *   **Example:** `{"statusCode":400,"message":"Bad Request"}`
*   **401 Unauthorized:**
    *   **Content-Type:** `application/json`
    *   **Schema:**
        *   `statusCode` (number): Example: `401`
        *   `message` (string): Example: `Invalid token: access token is invalid`
        *   `error` (string): Example: `Unauthorized`
    *   **Example:** `{"statusCode":401,"message":"Invalid token: access token is invalid","error":"Unauthorized"}`

### 10. PURPOSE:
This endpoint allows users to download the recording transcription for a specific message by providing its message ID.
