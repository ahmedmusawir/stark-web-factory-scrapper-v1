Here's a structured summary of the API documentation:

### 1. ENDPOINT NAME
Get Workflow

### 2. CATEGORY
Workflows

### 3. HTTP METHOD
GET

### 4. ENDPOINT URL
`/workflows/`

### 5. FULL URL
`https://services.leadconnectorhq.com/workflows/`

### 6. REQUIRED PARAMETERS
*   **Header Parameters**:
    *   Version (string): API Version. Possible values: `2021-07-28`
*   **Query Parameters**:
    *   locationId (string): Example: `ve9EPM428h8vShlRW1KT`

### 7. OPTIONAL PARAMETERS
Not specified in documentation

### 8. AUTHENTICATION
*   **Scope(s)**: `workflows.readonly`
*   **Auth Method(s)**: `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s)**: `Sub-Account Token`
*   **Scheme**: `bearer`
*   **Bearer Format**: `JWT`
*   **In**: `header`

### 9. RESPONSE FORMAT
**Successful Response (200 OK):**
*   **Content Type**: `application/json`
*   **Schema**: An object containing a `workflows` array.
    *   `workflows`: Array of workflow objects, each with:
        *   `id` (string): Unique identifier for the workflow. Example: `78559bb3-b920-461e-b010-7b2a2816d2a9`
        *   `name` (string): Name of the workflow. Example: `First Workflow`
        *   `status` (string): Current status of the workflow. Example: `draft`
        *   `version` (number): Version number of the workflow. Example: `2`
        *   `createdAt` (string): ISO 8601 timestamp of when the workflow was created. Example: `2021-05-26T11:33:49.000Z`
        *   `updatedAt` (string): ISO 8601 timestamp of when the workflow was last updated. Example: `2021-05-26T11:33:49.000Z`
        *   `locationId` (string): ID of the sub-account (location) the workflow belongs to. Example: `eBG6WapS3v4ZqwA45MTxtYJ`
*   **Example**:
    ```json
    {"workflows":[{"id":"78559bb3-b920-461e-b010-7b2a2816d2a9","name":"First Workflow","status":"draft","version":2,"createdAt":"2021-05-26T11:33:49.000Z","updatedAt":"2021-05-26T11:33:49.000Z","locationId":"eBG6WapS3v4ZqwA45MTxtYJ"}]}
    ```

**Error Responses**:
*   **400 Bad Request**:
    ```json
    {"statusCode":400,"message":"Bad Request"}
    ```
*   **401 Unauthorized**:
    ```json
    {"statusCode":401,"message":"Invalid token: access token is invalid","error":"Unauthorized"}
    ```
*   **422 Unprocessable Entity**:
    ```json
    {"statusCode":422,"message":["Unprocessable Entity"],"error":"Unprocessable Entity"}
    ```

### 10. PURPOSE
This endpoint retrieves a list of workflows associated with a specific sub-account (location).
