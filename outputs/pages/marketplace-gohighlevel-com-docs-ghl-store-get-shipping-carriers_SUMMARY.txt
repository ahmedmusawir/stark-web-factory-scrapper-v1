Here's a structured summary of the provided API documentation:

### 1. ENDPOINT NAME:
Get Shipping Carrier

### 2. CATEGORY:
Store - Shipping Carrier

### 3. HTTP METHOD:
GET

### 4. ENDPOINT URL:
`/store/shipping-carrier/:shippingCarrierId`

### 5. FULL URL:
`https://services.leadconnectorhq.com/store/shipping-carrier/:shippingCarrierId`

### 6. REQUIRED PARAMETERS:
*   **shippingCarrierId** (string): ID of the shipping carrier that needs to be returned.
*   **altId** (string): Location Id or Agency Id.
*   **altType** (string): Possible values: [`location`]

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:
*   **Auth Methods**: OAuth Access Token, Private Integration Token
*   **Token Types**: Sub-Account Token
*   **Scheme**: Bearer (JWT)
*   **Location**: `Authorization` header

### 9. RESPONSE FORMAT:

#### Successful Response (HTTP 200 OK)
*   **Content-Type**: `application/json`
*   **Schema**:
    *   `status` (boolean): Status of api action (e.g., `true`)
    *   `message` (string): Success message (e.g., `Successfully created`)
    *   `data` (object): Shipping carrier data
        *   `altId` (string): Location Id or Agency Id (e.g., `6578278e879ad2646715ba9c`)
        *   `altType` (string): Possible values: [`location`]
        *   `name` (string): Name of the shipping carrier (e.g., `FedEx`)
        *   `callbackUrl` (string): The URL endpoint that GHL needs to retrieve shipping rates. This must be a public URL. (e.g., `https://example.com/get-shipping-rates`)
        *   `services` (array of objects): An array of available shipping carrier services
            *   `name` (string): Name of the shipping carrier service (e.g., `Priority Mail Express International`)
            *   `value` (string): Value of the shipping carrier service (e.g., `PriorityMailExpressInternational`)
        *   `allowsMultipleServiceSelection` (boolean): The seller can choose multiple services while creating shipping rates if this is true. (e.g., `true`)
        *   `_id` (string): The unique identifier for the product. (e.g., `655b33a82209e60b6adb87a5`)
        *   `marketplaceAppId` (string): The unique identifier for the marketplace app. (e.g., `655b33a82209e60b6adb87a5`)
        *   `createdAt` (string): created at (e.g., `2023-12-12T09:27:42.355Z`)
        *   `updatedAt` (string): updated at (e.g., `2023-12-12T09:27:42.355Z`)

*   **Example**:
    ```json
    {
      "status": true,
      "message": "Successfully created",
      "data": {
        "altId": "6578278e879ad2646715ba9c",
        "altType": "location",
        "name": "FedEx",
        "callbackUrl": "https://example.com/get-shipping-rates",
        "services": [
          {
            "name": "Priority Mail Express International",
            "value": "PriorityMailExpressInternational"
          }
        ],
        "allowsMultipleServiceSelection": true,
        "_id": "655b33a82209e60b6adb87a5",
        "marketplaceAppId": "655b33a82209e60b6adb87a5",
        "createdAt": "2023-12-12T09:27:42.355Z",
        "updatedAt": "2023-12-12T09:27:42.355Z"
      }
    }
    ```

#### Error Responses:
*   **400 Bad Request**: `{ "statusCode": 400, "message": "Bad Request" }`
*   **401 Unauthorized**: `{ "statusCode": 401, "message": "Invalid token: access token is invalid", "error": "Unauthorized" }`
*   **422 Unprocessable Entity**: `{ "statusCode": 422, "message": ["Unprocessable Entity"], "error": "Unprocessable Entity" }`

This endpoint allows the retrieval of a specific shipping carrier's details using its unique ID.
