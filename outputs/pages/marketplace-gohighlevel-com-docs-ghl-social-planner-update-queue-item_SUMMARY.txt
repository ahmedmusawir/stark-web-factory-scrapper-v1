Here's a structured summary of the provided API documentation:

### 1. ENDPOINT NAME
Update an item in a queue

### 2. CATEGORY
Social Planner - Category Queue

### 3. HTTP METHOD
PUT

### 4. ENDPOINT URL
`/social-media-posting/category/queues/:queueId/items/:itemId`

### 5. FULL URL
`https://services.leadconnectorhq.com/social-media-posting/category/queues/:queueId/items/:itemId`

### 6. REQUIRED PARAMETERS
*   **Header Parameters:**
    *   `Version` (string): API Version. Possible values: [`2021-07-28`]
*   **Path Parameters:**
    *   `queueId` (string)
    *   `itemId` (string)
*   **Body Parameters (application/json):**
    *   `locationId` (string): Location ID
    *   `modifiedPostPayload` (object): Modifications to the original post
        *   `media` (object[]): Post Media. Each object in the array requires:
            *   `url` (string)
        *   If `gmbPostDetails` (object) is included:
            *   `startDate` (object): Start Date. Requires:
                *   `startDate` (object): Start Date (nested). Requires:
                    *   `year` (number)
                    *   `month` (number)
                    *   `day` (number)
                *   `startTime` (object): Start Time. Requires:
                    *   `hours` (number)
                    *   `minutes` (number)
                    *   `seconds` (number)
            *   `endDate` (object): End Date. Requires:
                *   `endDate` (object): End Date (nested). Requires:
                    *   `year` (number)
                    *   `month` (number)
                    *   `day` (number)
                *   `endTime` (object): End Time. Requires:
                    *   `hours` (number)
                    *   `minutes` (number)
                    *   `seconds` (number)
        *   If `linkedinPostDetails` (object) is included:
            *   `pdfTitle` (string): Title of the PDF
            *   `postAsPdf` (boolean): If the post is to be posted as PDF
        *   If `pinterestPostDetails` (object) is included:
            *   `boardIds` (object): Mapping of oauth IDs of connected accounts to board IDs
        *   If `facebookPostDetails` (object) is included:
            *   `type` (object): Post Type must be one of the following values: - post, story, reel
        *   If `instagramPostDetails` (object) is included:
            *   `type` (object): Post Type must be one of the following values: - post, story, reel

### 7. OPTIONAL PARAMETERS
*   **Body Parameters (application/json):**
    *   `modifiedPostPayload` (object): Modifications to the original post
        *   `accountIds` (string[]): Account Ids (OAuth only)
        *   `summary` (string): Post Content
        *   `media` (object[]): Post Media. Each object in the array can optionally include:
            *   `caption` (string)
            *   `type` (string)
            *   `thumbnail` (string)
            *   `defaultThumb` (string)
            *   `id` (string)
        *   `status` (object): Status must be one of the following values: null, in_progress, draft, failed, published, scheduled, in_review, notification_sent, deleted
        *   `scheduleDate` (string): Schedule Date
        *   `createdBy` (string): Created By
        *   `followUpComment` (string): Follow Up Comment on platform. It is not allowed on Tiktok and GMB accounts.
        *   `ogTagsDetails` (object): Og Tags Meta Data
            *   `metaImage` (string): URL of the image that represents the content when shared on social media platforms.
            *   `metaLink` (string): The URL of the original webpage or article that is being referenced or shared in the post.
            *   `ogTitle` (string): The title of the content as it should appear when shared on social media platforms.
        *   `type` (object): Post Type must be one of the following values: - post, story, reel
        *   `postApprovalDetails` (object): Post Approval Details
            *   `approver` (string): Approver
            *   `requesterNote` (string): Requester Notes
            *   `approverNote` (string): Approver Notes
            *   `approvalStatus` (object): Approval Status must be one of the following values: pending, approved, rejected, not_required
        *   `scheduleTimeUpdated` (boolean): if schedule datetime is updated
        *   `tags` (string[]): Array of Tag Value
        *   `categoryId` (string): Category Id
        *   `tiktokPostDetails` (object): Tiktok Post Details
            *   `privacyLevel` (object): privacy level is an enum and must be one of the following values: PUBLIC_TO_EVERYONE, MUTUAL_FOLLOW_FRIENDS, SELF_ONLY
            *   `promoteOtherBrand` (boolean): promote other brand
            *   `enableComment` (boolean): enable comment
            *   `enableDuet` (boolean): enable duet
            *   `enableStitch` (boolean): enable stitch
            *   `videoDisclosure` (boolean): video disclosure
            *   `promoteYourBrand` (boolean): promote your brand
        *   `gmbPostDetails` (object): GMB Post Details
            *   `gmbEventType` (string): gmbEventType must be one of the following values: STANDARD, EVENT, OFFER
            *   `title` (string): Title
            *   `offerTitle` (string): Offer Title
            *   `termsConditions` (string): Terms Condition Url
            *   `url` (string): Url
            *   `couponCode` (string): Coupon Code
            *   `redeemOnlineUrl` (string): Redeem Online Url
            *   `actionType` (object): Action Type must be one of the following values: none, order, book, shop, learn_more, call, sign_up
        *   `userId` (string): User ID
        *   `pinterestPostDetails` (object): Pinterest Post Details
            *   `title` (string): Title of the Pinterest Post
            *   `link` (string): Link associated with the Pinterest Post
        *   `instagramPostDetails` (object): Instagram Post Details
            *   `collaborators` (object): Object mapping account IDs to arrays of associated usernames for collaboration. Only allowed for type 'post' and 'reels'
        *   `youtubePostDetails` (object): Youtube Post Details
            *   `title` (string): Title
            *   `privacyLevel` (object): Youtube Privacy Level is an enum and must be one of the following values: private, public, unlisted
            *   `type` (object): Youtube Post Type is an enum and must be one of the following values: video, short
        *   `locationId` (string): Location Id (nested inside `modifiedPostPayload`, distinct from the root-level required `locationId`)
    *   `newOrder` (number): New Order
    *   `variations` (object[]): Variations. Each object in the array can optionally include:
        *   `content` (string)
        *   `mentions` (object[])
        *   `ogTags` (object)
            *   `metaLink` (object)
            *   `metaImage` (object)
            *   `ogTitle` (object)
    *   `primaryImage` (string): Primary media URL (image)

### 8. AUTHENTICATION
Not specified in documentation for this specific endpoint. General API authorization is mentioned in the main navigation.
