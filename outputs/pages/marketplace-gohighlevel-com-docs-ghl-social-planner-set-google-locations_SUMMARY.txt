Here is a structured summary of the provided API documentation:

### 1. ENDPOINT NAME:
Set google business locations

### 2. CATEGORY:
Social Planner (under OAuth | Google)

### 3. HTTP METHOD:
POST

### 4. ENDPOINT URL:
`/social-media-posting/oauth/:locationId/google/locations/:accountId`

### 5. FULL URL:
`https://services.leadconnectorhq.com/social-media-posting/oauth/:locationId/google/locations/:accountId`

### 6. REQUIRED PARAMETERS:

*   **Header Parameters:**
    *   `Version` (string): API Version (Possible values: `2021-07-28`)
*   **Path Parameters:**
    *   `locationId` (string): Account Location Id (Example: `w37swmmLbA02zgqKPpxITe2`)
    *   `accountId` (string): Account Id (Example: `w37swmmLbA02zgqKPpxITe`)
*   **Body Parameters (within `location` object):**
    *   `location.name` (string): Location name
    *   `location.title` (string): Location title
*   **Body Parameters (within `account` object):**
    *   `account.name` (string): Account name identifier
    *   `account.accountName` (string): Display name of the account
    *   `account.type` (string): Type of the account
    *   `account.verificationState` (string): State of account verification
    *   `account.vettedState` (string): Vetting state of the account

### 7. OPTIONAL PARAMETERS:

*   **Body Parameters (within `location` object):**
    *   `location.storeCode` (string): Store code
    *   `location.storefrontAddress` (object): Storefront address details (empty object shown in example)
    *   `location.metadata` (object): Additional metadata (empty object shown in example)
    *   `location.maxLocation` (boolean): Whether this is a max location
    *   `location.isVerified` (boolean): Whether the location is verified
    *   `location.isConnected` (boolean): Whether the location is connected

### 8. AUTHENTICATION:
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** Bearer (JWT)
*   **In:** Header (`Authorization: Bearer <TOKEN>`)
