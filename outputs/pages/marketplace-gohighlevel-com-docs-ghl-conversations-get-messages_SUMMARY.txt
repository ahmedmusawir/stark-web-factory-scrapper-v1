```
1. ENDPOINT NAME: Get messages by conversation id

2. CATEGORY: Conversations / Messages

3. HTTP METHOD: GET

4. ENDPOINT URL: /conversations/:conversationId/messages

5. FULL URL: https://services.leadconnectorhq.com/conversations/:conversationId/messages

6. REQUIRED PARAMETERS:
   - Version (string): API Version. Possible values: [`2021-04-15`]
   - conversationId (string): Conversation ID as string. Example: tDtDnQdgm2LXpyiqYvZ6

7. OPTIONAL PARAMETERS:
   - lastMessageId (string): Message ID of the last message in the list as a string. Example: tDtDnQdgm2LXpyiqYvZ6
   - limit (number): Number of messages to be fetched from the conversation. Default limit is 20. Example: 20
   - type (string): Types of message to be fetched separated with comma. Possible values: [`TYPE_CALL`, `TYPE_SMS`, `TYPE_EMAIL`, `TYPE_FACEBOOK`, `TYPE_GMB`, `TYPE_INSTAGRAM`, `TYPE_WHATSAPP`, `TYPE_ACTIVITY_APPOINTMENT`, `TYPE_ACTIVITY_CONTACT`, `TYPE_ACTIVITY_INVOICE`, `TYPE_ACTIVITY_PAYMENT`, `TYPE_ACTIVITY_OPPORTUNITY`, `TYPE_LIVE_CHAT`, `TYPE_INTERNAL_COMMENTS`, `TYPE_ACTIVITY_EMPLOYEE_ACTION_LOG`]. Example: TYPE_SMS,TYPE_CALL

8. AUTHENTICATION:
   - Scope(s): `conversations/message.readonly`
   - Auth Method(s): `OAuth Access Token`, `Private Integration Token`
   - Token Type(s): `Sub-Account Token`
   - Scheme: `bearer`
   - Bearer Format: `JWT`
   - In: `header`

9. RESPONSE FORMAT:
   - **200 OK (application/json):**
     ```json
     {
       "messages": {
         "lastMessageId": "string",
         "nextPage": boolean,
         "messages": [
           {
             "id": "string",
             "altId": "string",
             "type": number,
             "messageType": "string",
             "locationId": "string",
             "contactId": "string",
             "conversationId": "string",
             "dateAdded": "string",
             "body": "string",
             "direction": "string",
             "status": "string",
             "contentType": "string",
             "attachments": [
               "string"
             ],
             "meta": {
               "callDuration": "string",
               "callStatus": "string",
               "email": {
                 "email": {
                   "messageIds": [
                     "string"
                   ]
                 }
               },
               "ig": {
                 "ig": {
                   "page_id": "string",
                   "page_name": "string"
                 }
               },
               "fb": {
                 "fb": {
                   "page_id": "string",
                   "page_name": "string"
                 }
               }
             },
             "source": "string",
             "userId": "string",
             "conversationProviderId": "string",
             "chatWidgetId": "string"
           }
         ]
       }
     }
     ```
     - `messages.lastMessageId` (string): ID of the last message in the messages array.
     - `messages.nextPage` (boolean): `true` if there are more messages to fetch using `lastMessageId`.
     - `messages.messages` (array of objects): Array of message objects, each containing:
       - `id` (string), `altId` (string), `type` (number), `messageType` (string, e.g., `SMS`), `locationId` (string), `contactId` (string), `conversationId` (string), `dateAdded` (string), `body` (string), `direction` (string, `inbound` or `outbound`), `status` (string, e.g., `connected`, `delivered`), `contentType` (string, e.g., `text/plain`).
       - `attachments` (string[]): Array of attachment URLs. Empty for Call and Voicemails.
       - `meta` (object): Contains `callDuration` (string), `callStatus` (string), `email` (object with `messageIds`), `ig` (object with `page_id`, `page_name`), `fb` (object with `page_id`, `page_name`).
       - `source` (string, e.g., `workflow`, `api`), `userId` (string), `conversationProviderId` (string), `chatWidgetId` (string).
   - **400 Bad Request (application/json):**
     ```json
     {
       "statusCode": 400,
       "message": "Bad Request"
     }
     ```
   - **401 Unauthorized (application/json):**
     ```json
     {
       "statusCode": 401,
       "message": "Invalid token: access token is invalid",
       "error": "Unauthorized"
     }
     ```
