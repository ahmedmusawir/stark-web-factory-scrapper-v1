Here is a structured summary of the "Get Subscription by ID" API documentation:

### 1. ENDPOINT NAME
Get Subscription by ID

### 2. CATEGORY
Payments, Subscriptions

### 3. HTTP METHOD
GET

### 4. ENDPOINT URL
`/payments/subscriptions/:subscriptionId`

### 5. FULL URL
`https://services.leadconnectorhq.com/payments/subscriptions/:subscriptionId`

### 6. REQUIRED PARAMETERS
*   **Header Parameters:**
    *   `Version` (string): API Version. Possible values: [`2021-07-28`]
*   **Path Parameters:**
    *   `subscriptionId` (string): ID of the subscription that needs to be returned. Example: `6322e9c9e39fc14ab3ed7042`
*   **Query Parameters:**
    *   `altId` (string): AltId is the unique identifier e.g: location id. Example: `3SwdhCu3svxI8AKsPJt6`
    *   `altType` (string): AltType is the type of identifier. Possible values: [`location`]. Example: `location`

### 7. OPTIONAL PARAMETERS
Not specified in documentation

### 8. AUTHENTICATION
*   **Scope(s):** `payments/subscriptions.readonly`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** `bearer` (Bearer JWT)
*   **In:** `header` (`Authorization`)

### 9. RESPONSE FORMAT

**200 OK (Successful response)**
*   **Content-Type:** `application/json`
*   **Schema (Top-level fields):**
    *   `_id` (string): The unique identifier for the subscription.
    *   `altType` (object): AltType is the type of identifier.
    *   `altId` (string): AltId is the unique identifier eg: location id.
    *   `contactId` (string): Contact id corresponding to the subscription.
    *   `contactSnapshot` (object): Contact details of the subscriber.
    *   `coupon` (object): Coupon details of the subscription.
    *   `currency` (string): Currency in which subscription was made.
    *   `amount` (number): Subscription value.
    *   `status` (object): Subscription status.
    *   `liveMode` (boolean): Subscription is in live / test mode.
    *   `entityType` (string): Entity type of subscription (eg: order).
    *   `entityId` (string): Entity id for the subscription. e.g: order id
    *   `entitySource` (object): Entity source details for the subscription.
        *   `type` (string, required): Possible values: [`funnel`, `website`, `invoice`, `calendar`, `text2Pay`, `document_contracts`, `membership`, `mobile_app`, `communities`, `point_of_sale`, `manual`, `form`, `survey`, `payment_link`, `external`]
        *   `subType` (string): Possible values: [`one_step_order_form`, `two_step_order_form`, `upsell`, `tap_to_pay`, `card_payment`, `store`, `contact_view`, `email_campaign`, `payments_dashboard`, `shopify`, `subscription_view`, `store_upsell`, `woocommerce`, `service`, `meeting`, `imported_csv`, `qr_code`, `saas_one_time`, `saas_subscription`]
        *   `id` (string, required)
        *   `name` (string)
        *   `meta` (object)
    *   `subscriptionId` (string): Subscription id for subscription.
    *   `subscriptionSnapshot` (object): Snapshot of subscription.
    *   `paymentProvider` (object): Payment provider details for the subscription.
    *   `ipAddress` (string): Ip address from where subscription was initiated.
    *   `createdAt` (date-time): The creation timestamp of the subscription.
    *   `updatedAt` (date-time): The last update timestamp of the subscription.
    *   `meta` (object): Meta details of the subscription.
    *   `markAsTest` (boolean): Is test subscription.
    *   `schedule` (object): Schedule details for the subscription.
        *   `executeAt` (string)
        *   `rrule` (object)
        *   `intervalType` (string, required): Possible values: [`yearly`, `monthly`, `weekly`, `daily`, `hourly`, `minutely`, `secondly`]
        *   `interval` (number, required)
        *   `startDate` (string, required): Start date in YYYY-MM-DD format
        *   `startTime` (string): Start time in HH:mm:ss format
        *   `endDate` (string): End date in YYYY-MM-DD format
        *   `endTime` (string): End time in HH:mm:ss format
        *   `dayOfMonth` (number): -1, 1, 2, 3, ..., 27, 28
        *   `dayOfWeek` (string): Possible values: [`mo`, `tu`, `we`, `th`, `fr`, `sa`, `su`]
        *   `numOfWeek` (number): -1, 1, 2, 3, 4
        *   `monthOfYear` (string): Possible values: [`jan`, `feb`, `mar`, `apr`, `may`, `jun`, `jul`, `aug`, `sep`, `oct`, `nov`, `dec`]
        *   `count` (number): Max number of task executions
        *   `daysBefore` (number): Execute task number of days before
    *   `autoPayment` (object): Auto payment details of the subscription.
    *   `recurringProduct` (object): Recurring product details of the subscription.
    *   `canceledAt` (date-time): Cancellation timestamp of the subscription.
    *   `canceledBy` (string): User id who cancelled the subscription.
    *   `traceId` (string): Trace id of the subscription.
    *   `createdBy` (string): User ID who created the subscription.

**400 Bad Request**
*   **Content-Type:** `application/json`
*   **Schema:** `statusCode` (number), `message` (string)
*   **Example:** `{"statusCode":400,"message":"Bad Request"}`

**401 Unauthorized**
*   **Content-Type:** `application/json`
*   **Schema:** `statusCode` (number), `message` (string), `error` (string)
*   **Example:** `{"statusCode":401,"message":"Invalid token: access token is invalid","error":"Unauthorized"}`

**422 Unprocessable Entity**
*   **Content-Type:** `application/json`
*   **Schema:** `statusCode` (number), `message` (string[]), `error` (string)
*   **Example:** `{"statusCode":422,"message":["Unprocessable Entity"],"error":"Unprocessable Entity"}`

### 10. PURPOSE
This endpoint allows retrieval of detailed information for a specific subscription using its unique identifier (subscription ID).
