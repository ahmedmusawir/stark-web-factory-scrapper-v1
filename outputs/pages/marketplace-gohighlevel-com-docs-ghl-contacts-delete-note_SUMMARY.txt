Here is a structured summary of the API documentation for "Delete Note":

### 1. ENDPOINT NAME
Delete Note

### 2. CATEGORY
Contacts

### 3. HTTP METHOD
DELETE

### 4. ENDPOINT URL
`/contacts/:contactId/notes/:id`

### 5. FULL URL
`https://services.leadconnectorhq.com/contacts/:contactId/notes/:id`

### 6. REQUIRED PARAMETERS
*   **Header Parameters:**
    *   Version (string): API Version. Possible values: `2021-07-28`
*   **Path Parameters:**
    *   contactId (string): Contact Id (Example: `sx6wyHhbFdRXh302LLNR`)
    *   id (string): Note Id (Example: `ocQHyuzHvysMo5N5VsXc`)

### 7. OPTIONAL PARAMETERS
Not specified in documentation

### 8. AUTHENTICATION
*   **Scope(s):** `contacts.write`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`

### 9. RESPONSE FORMAT
*   **200 OK (Successful response):**
    *   Content-Type: `application/json`
    *   Schema: `{"succeded": boolean}`
    *   Example: `{"succeded":true}`

*   **400 Bad Request:**
    *   Content-Type: `application/json`
    *   Schema: `{"statusCode": number, "message": string}`
    *   Example: `{"statusCode":400,"message":"Bad Request"}`

*   **401 Unauthorized:**
    *   Content-Type: `application/json`
    *   Schema: `{"statusCode": number, "message": string, "error": string}`
    *   Example: `{"statusCode":401,"message":"Invalid token: access token is invalid","error":"Unauthorized"}`

*   **422 Unprocessable Entity:**
    *   Content-Type: `application/json`
    *   Schema: `{"statusCode": number, "message": string[], "error": string}`
    *   Example: `{"statusCode":422,"message":["Unprocessable Entity"],"error":"Unprocessable Entity"}`

### 10. PURPOSE
This endpoint allows you to delete a specific note associated with a given contact in the HighLevel system.
