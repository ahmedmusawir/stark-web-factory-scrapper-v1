Here is the structured summary of the API documentation:

### 1. ENDPOINT NAME:
Update Product Collection

### 2. CATEGORY:
Products (Collections)

### 3. HTTP METHOD:
PUT

### 4. ENDPOINT URL:
`/products/collections/:collectionId`

### 5. FULL URL:
`https://services.leadconnectorhq.com/products/collections/:collectionId`

### 6. REQUIRED PARAMETERS:

*   **Header Parameters:**
    *   Version (string): API Version. Possible values: [`2021-07-28`]
*   **Path Parameters:**
    *   collectionId (string): MongoId of the collection. Example: `65d71377c326ea78e1c47df5`
*   **Body Parameters:**
    *   altId (string): Location Id. Example: `6578278e879ad2646715ba9c`
    *   altType (string): The type of alt. For now it is only LOCATION. Possible values: [`location`]. Example: `LOCATION`

### 7. OPTIONAL PARAMETERS:

*   **Body Parameters:**
    *   name (string): Name of the Product Collection. Example: `Best Sellers`
    *   slug (string): Slug of the Product Collection which helps in navigation. Example: `best-sellers`
    *   image (string): The URL of the image that is going to be displayed as the collection Thumbnail. Example: `http://example.com/watermark.png`
    *   seo (object): The metadata information which will be displayed in SEO previews
        *   title (string): The title which will be displayed as an SEO format. Example: `Best Sellers`
        *   description (string): The description which would be displayed in preview purposes. Example: `Collections where all the best products are available`

### 8. AUTHENTICATION:

*   **Scope(s):** `products/collection.write`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** `bearer` (JWT format)
*   **In:** `header` (Authorization header)

### 9. RESPONSE FORMAT:

*   **200 OK (Successful response):**
    *   **Content Type:** `application/json`
    *   **Schema:**
        *   status (boolean, required): Status of api action. Example: `true`
        *   message (string): Success message. Example: `Successfully created`
    *   **Example:**
        ```json
        {"status": true, "message": "Successfully created"}
        ```
*   **400 Bad Request:**
    *   **Content Type:** `application/json`
    *   **Schema:** `statusCode` (number), `message` (string)
    *   **Example:** `{"statusCode":400,"message":"Bad Request"}`
*   **401 Unauthorized:**
    *   **Content Type:** `application/json`
    *   **Schema:** `statusCode` (number), `message` (string), `error` (string)
    *   **Example:** `{"statusCode":401,"message":"Invalid token: access token is invalid","error":"Unauthorized"}`
*   **422 Unprocessable Entity:**
    *   **Content Type:** `application/json`
    *   **Schema:** `statusCode` (number), `message` (string[]), `error` (string)
    *   **Example:** `{"statusCode":422,"message":["Unprocessable Entity"],"error":"Unprocessable Entity"}`

### 10. PURPOSE:
This endpoint updates a specific product collection identified by its `collectionId`.
