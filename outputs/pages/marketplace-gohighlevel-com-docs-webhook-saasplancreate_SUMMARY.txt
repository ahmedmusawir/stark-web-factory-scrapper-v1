    *   **billingInterval** (string): Billing frequency ("month", "year", etc.).
    *   **active** (boolean): Whether this price is currently active.
    *   **amount** (number): Price amount in cents (e.g., 29700 = $297.00).
    *   **currency** (string): Currency code (e.g., "usd").
    *   **symbol** (string): Currency symbol (e.g., "$").
*   **categoryId** (string): Identifier linking the plan to a specific category or grouping.
*   **snapshotId** (string): Identifier for the plan snapshot, used for versioning or backup purposes.
*   **productId** (string): Identifier for the associated product in the billing system (usually Stripe product ID).
*   **isSaaSV2** (boolean): Flag indicating whether this plan uses the newer SaaS V2 architecture.
*   **createdAt** (string, ISO 8601 date-time): Timestamp when the plan was initially created.
*   **updatedAt** (string, ISO 8601 date-time): Timestamp when the plan was last modified.
