Here is a structured summary of the API documentation:

### 1. ENDPOINT NAME:
Remove Contact From Every Campaign

### 2. CATEGORY:
Contacts (Sub-category: Campaigns)

### 3. HTTP METHOD:
DELETE

### 4. ENDPOINT URL:
`/contacts/:contactId/campaigns/removeAll`

### 5. FULL URL:
`https://services.leadconnectorhq.com/contacts/:contactId/campaigns/removeAll`

### 6. REQUIRED PARAMETERS:
*   `Version` (string): API Version. Possible values: [`2021-07-28`]
*   `contactId` (string): Contact Id. Example: `3bZD1nQzbul0MCancbQD`

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:
*   **Scope(s)**: `contacts.write`
*   **Auth Method(s)**: `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s)**: `Sub-Account Token`
*   **Scheme**: `bearer`
*   **Bearer Format**: `JWT`
*   **In**: `header` (for the `Authorization` header)

### 9. RESPONSE FORMAT:
**Status Code**: `200` (Successful response)
**Content Type**: `application/json`
**Schema**:
```json
{
  "succeded": true
}
```
**Description**: A boolean indicating if the operation was successful.

### 10. PURPOSE:
This endpoint is used to remove a specific contact from all campaigns they are currently associated with.
