Here's a structured summary of the API documentation:

### 1. ENDPOINT NAME:
Fetch email templates

### 2. CATEGORY:
Email Templates

### 3. HTTP METHOD:
GET

### 4. ENDPOINT URL:
`/emails/builder`

### 5. FULL URL:
`https://services.leadconnectorhq.com/emails/builder`

### 6. REQUIRED PARAMETERS:
*   `Version` (string): API Version. Possible values: `2021-07-28` (Header Parameter)
*   `locationId` (string): Example: `ve9EPM428h8vShlRW1KT` (Query Parameter)

### 7. OPTIONAL PARAMETERS:
*   `limit` (string): Default value: `10` (Query Parameter)
*   `offset` (string): Default value: `0` (Query Parameter)
*   `search` (string): Default value: ` ` (empty string) (Query Parameter)
*   `sortByDate` (string): Default value: `desc` (Query Parameter)
*   `archived` (string): Default value: `false` (Query Parameter)
*   `builderVersion` (string): Possible values: `1`, `2`. Default value: `2` (Query Parameter)
*   `name` (string): Default value: ` ` (empty string) (Query Parameter)
*   `parentId` (string): Default value: ` ` (empty string) (Query Parameter)
*   `originId` (string): Example: `ve9EPM428h8vShlRW1KT` (Query Parameter)
*   `templatesOnly` (string): Default value: `false` (Query Parameter)

### 8. AUTHENTICATION:
*   **Scope(s):** `emails/builder.readonly`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** `bearer`
*   **Bearer Format:** `JWT`
*   **In:** `header`
*   **Description:** Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account.

### 9. RESPONSE FORMAT:

**200 Success**
*   **Content Type:** `application/json`
*   **Schema:**
    *   `name` (string): template name. Example: `New Template`
    *   `updatedBy` (string): updated by. Example: `John Doe`
    *   `isPlainText` (boolean): plain text based template. Example: `false`
    *   `lastUpdated` (string): last updated. Example: `2024-11-12T12:34:36.070Z`
    *   `dateAdded` (string): date added. Example: `2024-11-12T12:34:36.070Z`
    *   `previewUrl` (string): preview url. Example: `https://example.com`
    *   `id` (string): id. Example: `67334b231f2fad724062f52b5`
    *   `version` (string): version. Example: `1`
    *   `templateType` (string): type. Example: `builder`
*   **Example (JSON):**
    ```json
    {
      "name": "New Template",
      "updatedBy": "John Doe",
      "isPlainText": "false",
      "lastUpdated": "2024-11-12T12:34:36.070Z",
      "dateAdded": "2024-11-12T12:34:36.070Z",
      "previewUrl": "https://example.com",
      "id": "67334b231f2fad724062f52b5",
      "version": "1",
      "templateType": "builder"
    }
    ```

**400 Bad Request**
*   **Content Type:** `application/json`
*   **Schema:** `statusCode` (number), `message` (string)
*   **Example:** `{"statusCode":400,"message":"Bad Request"}`

**401 Unauthorized**
*   **Content Type:** `application/json`
*   **Schema:** `statusCode` (number), `message` (string), `error` (string)
*   **Example:** `{"statusCode":401,"message":"Invalid token: access token is invalid","error":"Unauthorized"}`

**404 Not Found**
*   Not specified in documentation

**422 Unprocessable Entity**
*   **Content Type:** `application/json`
*   **Schema:** `statusCode` (number), `message` (string[]), `error` (string)
*   **Example:** `{"statusCode":422,"message":["Unprocessable Entity"],"error":"Unprocessable Entity"}`

### 10. PURPOSE:
This endpoint allows fetching a list of email templates associated with a specific location ID.
