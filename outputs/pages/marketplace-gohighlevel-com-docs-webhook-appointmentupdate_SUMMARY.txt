Not specified in documentation. This is a user-defined URL where the webhook payload will be sent.

### 6. REQUIRED PARAMETERS
The webhook payload is a JSON object with the following properties:

*   **type** (string): The type of webhook event. For this webhook, it should typically be "AppointmentUpdate" (though the example shows "AppointmentCreate").
*   **locationId** (string): The unique identifier of the location (sub-account) where the appointment was updated.
*   **appointment** (object): An object containing details of the updated appointment.
    *   **id** (string): The unique identifier of the appointment.
    *   **address** (string): The physical address or virtual meeting link associated with the appointment.
    *   **title** (string): The title or subject of the appointment.
    *   **calendarId** (string): The unique identifier of the calendar to which the appointment belongs.
    *   **contactId** (string): The unique identifier of the contact associated with the appointment.
    *   **groupId** (string): The group identifier for the appointment, often the same as `contactId`.
    *   **appointmentStatus** (string): The current status of the appointment (e.g., "confirmed", "pending", "cancelled").
    *   **assignedUserId** (string): The unique identifier of the user to whom the appointment is assigned.
    *   **users** (array): An array of unique identifiers for all users involved in the appointment.
    *   **notes** (string): Any additional notes or descriptions for the appointment.
    *   **source** (string): The source from which the appointment was created or updated (e.g., "booking_widget", "manual").
    *   **startTime** (string): The start date and time of the appointment in ISO 8601 format (e.g., `YYYY-MM-DDTHH:mm:ss+offset`).
    *   **endTime** (string): The end date and time of the appointment in ISO 8601 format (e.g., `YYYY-MM-DDTHH:mm:ss+offset`).
    *   **dateAdded** (string): The date and time when the appointment was originally created, in ISO 8601 format.
    *   **dateUpdated** (string): The date and time when the appointment was last updated, in ISO 8601 format.

### 7. OPTIONAL PARAMETERS
Not specified in documentation. All properties listed in the schema appear to be part of the standard payload.

### 8. AUTHENTICATION
Not specified for receiving the webhook payload. Typically, webhook integrations involve a shared secret for signature verification, but this documentation does not detail such a mechanism for this specific webhook.

### 9. RESPONSE FORMAT
The HighLevel platform sends a JSON payload (as described in the Schema and Example sections). Upon successful receipt and processing of the webhook by the listening server, an HTTP `200 OK` status code is typically expected as an acknowledgment.

### 10. PURPOSE
This webhook is called by the HighLevel platform whenever an existing appointment record is updated.
