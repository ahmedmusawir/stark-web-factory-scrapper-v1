Here's a structured summary of the provided API documentation:

### 1. ENDPOINT NAME
List Actions for an Agent

### 2. CATEGORY
Conversation AI

### 3. HTTP METHOD
GET

### 4. ENDPOINT URL
`/conversation-ai/agents/:agentId/actions/list`

### 5. FULL URL
`https://services.leadconnectorhq.com/conversation-ai/agents/:agentId/actions/list`

### 6. REQUIRED PARAMETERS
*   **Header Parameters:**
    *   `Version` (string): API Version (Possible values: `2021-04-15`)
*   **Path Parameters:**
    *   `agentId` (string): The unique identifier for the agent.

### 7. OPTIONAL PARAMETERS
Not specified in documentation

### 8. AUTHENTICATION
*   **Required Scope(s):** `conversation-ai.readonly`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** `bearer`
*   **Bearer Format:** `JWT`
*   **Location:** `header` (`Authorization`)

### 9. RESPONSE FORMAT
*   **Status Code:** `200` (Success)
*   **Content Type:** `application/json`
*   **Structure:** An object containing a `data` array and a `success` boolean.
    *   `data` (array of objects): Grouped actions by type. Each object represents an action with the following fields:
        *   `id` (string): Unique identifier for the action.
        *   `name` (string): Name of the action.
        *   `type` (string): Type of the action (Possible values: `triggerWorkflow`, `updateContactField`, `appointmentBooking`, `stopBot`, `humanHandOver`, `advancedFollowup`, `transferBot`).
        *   `agentId` (string): Agent ID where the action belongs.
        *   `details` (object): Action-specific details. The structure depends on the `type` of the action and is one of `triggerWorkflowDto`, `updateContactFieldDto`, `appointmentBookingDto`, `stopBotDto`, `humanHandOverDto`, `advancedFollowupDto`, or `transferBotDto`.
    *   `success` (boolean): Success status of the request.

### 10. PURPOSE
This endpoint retrieves a list of all actions configured for a specific Conversation AI agent.
