Here is a structured summary of the API documentation:

### 1. ENDPOINT NAME:
Update product display priorities in store

### 2. CATEGORY:
Products (Store)

### 3. HTTP METHOD:
POST

### 4. ENDPOINT URL:
`/products/store/:storeId/priority`

### 5. FULL URL:
`https://services.leadconnectorhq.com/products/store/:storeId/priority`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters:**
    *   Version (string): API Version. Possible values: `2021-07-28`
*   **Path Parameters:**
    *   storeId (string): Products related to the store. Example: `3SwdhCu3svxI8AKsPJt6`
*   **Body Parameters (application/json):**
    *   altId (string): Location Id or Agency Id. Example: `6578278e879ad2646715ba9c`
    *   altType (string): Possible values: `location`
    *   products (array[]): Array of products with their display priorities. Example: `[ [ null ] ]`

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** Bearer (JWT) in the `Authorization` header.

### 9. RESPONSE FORMAT:
*   **200 OK (Success):**
    *   Message: "Successfully updated display priorities"
    *   No explicit JSON schema provided for a 200 success response.
*   **400 Bad Request:**
    ```json
    {
      "statusCode": 400,
      "message": "Bad Request"
    }
    ```
*   **401 Unauthorized:**
    ```json
    {
      "statusCode": 401,
      "message": "Invalid token: access token is invalid",
      "error": "Unauthorized"
    }
    ```

### 10. PURPOSE:
API to set the display priority of products in a store.
