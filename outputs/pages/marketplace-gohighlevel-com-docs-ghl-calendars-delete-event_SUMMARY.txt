Here is a structured summary of the API documentation for the "Delete Event" endpoint:

### 1. ENDPOINT NAME:
Delete Event

### 2. CATEGORY:
Calendars / Calendar Events

### 3. HTTP METHOD:
DELETE

### 4. ENDPOINT URL:
`/calendars/events/:eventId`

### 5. FULL URL:
`https://services.leadconnectorhq.com/calendars/events/:eventId`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters:**
    *   `Version` (string): API Version. Possible values: `2021-04-15`.
*   **Path Parameters:**
    *   `eventId` (string): Event Id or Instance id. For recurring appointments, send `masterEventId` to modify the original series.
        *   Examples: `ocQHyuzHvysMo5N5VsXc` (Event ID), `ocQHyuzHvysMo5N5VsXc_1729821600000_1800` (Recurring Instance ID).
*   **Body Parameters:**
    *   `Body` (object): An empty JSON object `{}` is required.

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:
*   **Scope(s):** `calendars/events.write`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`, `Bearer` scheme with `JWT` format.
*   **Token Type(s):** `Sub-Account Token`

### 9. RESPONSE FORMAT:
*   **Successful Response (Status Code: 201):**
    *   **Schema:**
        ```json
        {
          "succeeded": boolean
        }
        ```
    *   **Example:**
        ```json
        {"succeeded":true}
        ```
*   **Error Responses:**
    *   **Bad Request (Status Code: 400):**
        ```json
        {
          "statusCode": 400,
          "message": "Bad Request"
        }
        ```
    *   **Unauthorized (Status Code: 401):**
        ```json
        {
          "statusCode": 401,
          "message": "Invalid token: access token is invalid",
          "error": "Unauthorized"
        }
        ```

### 10. PURPOSE:
This endpoint allows you to delete an event by its ID, including individual instances of recurring appointments or the entire series using the masterEventId.
