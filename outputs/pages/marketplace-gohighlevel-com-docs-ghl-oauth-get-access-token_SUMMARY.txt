Here's a structured summary of the "Get Access Token" API documentation:

### 1. ENDPOINT NAME:
Get Access Token

### 2. CATEGORY:
OAuth 2.0

### 3. HTTP METHOD:
POST

### 4. ENDPOINT URL:
`/oauth/token`

### 5. FULL URL:
`https://services.leadconnectorhq.com/oauth/token`

### 6. REQUIRED PARAMETERS:
-   **client_id** (string): The ID provided by GHL for your integration.
-   **client_secret** (string): The secret provided by GHL for your integration.
-   **grant_type** (string): Specifies the type of grant. Possible values: `authorization_code`, `refresh_token`, `client_credentials`.

### 7. OPTIONAL PARAMETERS:
-   **code** (string): The authorization code received from the authorization server. *Required when `grant_type` is `authorization_code`.*
-   **refresh_token** (string): The refresh token received in a previous access token response. *Required when `grant_type` is `refresh_token`.*
-   **user_type** (string): The type of token to be requested. Possible values: `Company`, `Location`.
-   **redirect_uri** (string): The redirect URI for your application.

### 8. AUTHENTICATION:
This endpoint facilitates obtaining access tokens. Authentication is performed by providing the `client_id` and `client_secret` in the request body, along with other grant-specific parameters (like `code` for authorization code flow or `refresh_token` for refreshing tokens). No bearer token is required to call *this* endpoint itself.

### 9. RESPONSE FORMAT:

**Successful Response (200 OK):**
Content Type: `application/json`
Schema:
-   **access_token** (string): The access token to be used for API requests.
-   **token_type** (string): Type of the token, e.g., `Bearer`.
-   **expires_in** (number): Lifetime in seconds of the access token.
-   **refresh_token** (string): Token used to obtain a new access token without re-authentication.
-   **scope** (string): Scopes associated with the access token.
-   **userType** (string): Type of user context the token is for (e.g., `Location`).
-   **locationId** (string): Location ID (present only for Sub-Account Access Token).
-   **companyId** (string): Company ID.
-   **approvedLocations** (string[]): List of approved locations to generate location access tokens.
-   **userId** (string): User ID of the person who performed the installation.
-   **planId** (string): Plan Id of the subscribed plan in paid apps.
-   **isBulkInstallation** (boolean): Indicates if it's a bulk installation.

Example:
```json
{
  "access_token": "ab12dc0ae1234a7898f9ff06d4f69gh",
  "token_type": "Bearer",
  "expires_in": 86399,
  "refresh_token": "xy34dc0ae1234a4858f9ff06d4f66ba",
  "scope": "conversations/message.readonly conversations/message.write",
  "userType": "Location",
  "locationId": "l1C08ntBrFjLS0elLIYU",
  "companyId": "l1C08ntBrFjLS0elLIYU",
  "approvedLocations": [
    "l1C08ntBrFjLS0elLIYU"
  ],
  "userId": "l1C08ntBrFjLS0elLIYU",
  "planId": "l1C08ntBrFjLS0elLIYU",
  "isBulkInstallation": "Bearer"
}
```

**Error Responses:**
-   **400 Bad Request**:
    ```json
    {"statusCode":400,"message":"Bad Request"}
    ```
-   **401 Unauthorized**:
    ```json
    {"statusCode":401,"message":"Invalid token: access token is invalid","error":"Unauthorized"}
    ```
-   **422 Unprocessable Entity**:
    ```json
    {"statusCode":422,"message":["Unprocessable Entity"],"error":"Unprocessable Entity"}
    ```

### 10. PURPOSE:
This endpoint is used to obtain access tokens, which are necessary to access GoHighLevel resources on behalf of an authenticated location or company, by exchanging an authorization code, refresh token, or client credentials.
