## STRUCTURED API SUMMARY

### 1. ENDPOINT NAME:
Update Recurring Task

### 2. CATEGORY:
Recurring Tasks (Sub-Account/Location)

### 3. HTTP METHOD:
PUT

### 4. ENDPOINT URL:
`/locations/:locationId/recurring-tasks/:id`

### 5. FULL URL:
`https://services.leadconnectorhq.com/locations/:locationId/recurring-tasks/:id`

### 6. REQUIRED PARAMETERS:

*   **Header Parameters:**
    *   `Version` (string): API Version. Possible values: [`2021-07-28`]
*   **Path Parameters:**
    *   `id` (string): Recurring Task Id. Example: `sx6wyHhbFdRXh302Lunr`
    *   `locationId` (string): Location Id. Example: `sx6wyHhbFdRXh302Lunr`
*   **Body Parameters (within `rruleOptions` object, if `rruleOptions` is provided):**
    *   `rruleOptions.intervalType` (string): Possible values: [`yearly`, `monthly`, `weekly`, `daily`, `hourly`]. Example: `monthly`
    *   `rruleOptions.interval` (number): Example: `2`
    *   `rruleOptions.startDate` (string): Start Date. Example: `2021-09-30T00:00:00.000Z`
    *   `rruleOptions.dueAfterSeconds` (number): Due after seconds. Example: `23404000`

### 7. OPTIONAL PARAMETERS:

*   **Body Parameters:**
    *   `title` (string): Name of the task. Example: `Task Name`
    *   `description` (string): Description of the task. Example: `Task Description`
    *   `contactIds` (string[]): Contact Id. Example: `["sx6wyHhbFdRXh302Lunr"]`
    *   `owners` (string[]): Assigned To. Example: `["sx6wyHhbFdRXh302Lunr"]`
    *   `rruleOptions` (object): Recurring rules (If this object is included, its required fields must be present).
        *   `rruleOptions.endDate` (string): End Date. Example: `2021-09-30T00:00:00.000Z`
        *   `rruleOptions.dayOfMonth` (number): 1, 2, 3, ..., 27, 31. Example: `15`
        *   `rruleOptions.dayOfWeek` (string): Possible values: [`MO`, `TU`, `WE`, `TH`, `FR`, `SA`, `SU`]. Example: `MO`
        *   `rruleOptions.monthOfYear` (number): 1, 2, ....., 11, 12. Example: `1`
        *   `rruleOptions.count` (number): Max number of task executions. Example: `10`
        *   `rruleOptions.createTaskIfOverDue` (boolean): Create Task If Over Due. Example: `true`
    *   `ignoreTaskCreation` (boolean): Create initial task or not. Example: `true`

### 8. AUTHENTICATION:

*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** `bearer`
*   **Bearer Format:** `JWT`
*   **In:** `header`
*   **Description:** Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account.
