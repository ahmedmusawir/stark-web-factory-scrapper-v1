Here's a structured summary of the "Get Agent Action" API documentation:

### 1. ENDPOINT NAME
Get Agent Action

### 2. CATEGORY
Voice AI Actions

### 3. HTTP METHOD
GET

### 4. ENDPOINT URL
`/voice-ai/actions/:actionId`

### 5. FULL URL
`https://services.leadconnectorhq.com/voice-ai/actions/:actionId`

### 6. REQUIRED PARAMETERS (Request)
*   **Header Parameters:**
    *   `Version` (string): API Version (Possible values: `2021-04-15`)
*   **Path Parameters:**
    *   `actionId` (string): Unique identifier for the action
*   **Query Parameters:**
    *   `locationId` (string): Location ID

### 7. OPTIONAL PARAMETERS (Request)
None specified in documentation.

### 8. AUTHENTICATION
*   **Scope(s):** `voice-ai-agent-goals.readonly`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** `bearer`
*   **Bearer Format:** `JWT`
*   **In:** `header`
*   **Description:** Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account.

### 9. RESPONSE FORMAT
*   **Successful Response (200 OK):**
    *   **Status Code:** `200`
    *   **Content Type:** `application/json`
    *   **Schema (Top-level fields):**
        *   `id` (string): Unique identifier for the action (e.g., `507f1f77bcf86cd799439011`)
        *   `actionType` (string): Type of action (Possible values: `CALL_TRANSFER`, `DATA_EXTRACTION`, `IN_CALL_DATA_EXTRACTION`, `WORKFLOW_TRIGGER`, `SMS`, `APPOINTMENT_BOOKING`, `CUSTOM_ACTION`, `KNOWLEDGE_BASE`)
        *   `name` (string): Human-readable name for this action (e.g., `Transfer to Manager`)
        *   `actionParameters` (object): Action-specific parameters. The structure varies based on the `actionType` (e.g., for `CALL_TRANSFER`, it includes `triggerPrompt`, `transferToType`, `transferToValue`, `triggerMessage`, `hearWhisperMessage`).
*   **Error Responses:**
    *   **400 Bad Request:** `{"statusCode": 400, "message": "Bad Request"}`
    *   **401 Unauthorized:** `{"statusCode": 401, "message": "Invalid token: access token is invalid", "error": "Unauthorized"}`
    *   **422 Unprocessable Entity:** `{"statusCode": 422, "message": ["Unprocessable Entity"], "error": "Unprocessable Entity"}`

### 10. PURPOSE
This endpoint retrieves the details of a specific Voice AI agent action, including its configuration and action parameters, identified by its unique ID.
