### STRUCTURED SUMMARY FOR API ENDPOINT

1.  **ENDPOINT NAME**: Get facebook pages

2.  **CATEGORY**: Social Planner (Sub-category: Oauth | Facebook)

3.  **HTTP METHOD**: GET

4.  **ENDPOINT URL**: `/social-media-posting/oauth/:locationId/facebook/accounts/:accountId`

5.  **FULL URL**: `https://services.leadconnectorhq.com/social-media-posting/oauth/:locationId/facebook/accounts/:accountId`

6.  **REQUIRED PARAMETERS**:
    *   **Header Parameters**:
        *   Version (string): API Version (Possible values: `2021-07-28`)
    *   **Path Parameters**:
        *   locationId (string): Account Location Id
        *   accountId (string): Account Id

7.  **OPTIONAL PARAMETERS**:
    *   **Query Parameters**:
        *   search (string): Search term for filtering accounts/pages

8.  **AUTHENTICATION**:
    *   **Auth Method(s)**: OAuth Access Token, Private Integration Token
    *   **Token Type(s)**: Sub-Account Token
    *   **Scheme**: Bearer (JWT)
    *   **In**: Header (Authorization: Bearer <TOKEN>)

9.  **RESPONSE FORMAT**:
    *   **Successful Response (200 OK)**:
        *   Content-Type: `application/json`
        *   Structure:
            ```json
            {
              "success": boolean,
              "statusCode": number,
              "message": string,
              "results": {
                "pages": [
                  {
                    "id": string,
                    "name": string,
                    "avatar": string,
                    "isOwned": boolean,
                    "isConnected": boolean
                  }
                ]
              }
            }
            ```
        *   Example:
            ```json
            {"success":true,"statusCode":200,"message":"Fetched Facebook Account","results":{"pages":[{"id":"u37swmmLbA02zgqKPpxITe2","name":"FB Page","avatar":"u37swmmLbA02zgqKPpxITe2","isOwned":true,"isConnected":true}]}}
            ```
    *   **Error Responses**:
        *   400 Bad Request
        *   401 Unauthorized
        *   422 Unprocessable Entity

10. **PURPOSE**: This endpoint retrieves a list of Facebook pages associated with a specific Facebook account under a given location ID.

11. **TAGS**: Social Planner, Facebook, Pages, Accounts, OAuth, Social Media Posting, GET, API, HighLevel
