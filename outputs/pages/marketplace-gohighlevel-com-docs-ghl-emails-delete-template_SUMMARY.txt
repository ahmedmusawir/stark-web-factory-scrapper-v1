Here's a structured summary of the API documentation for "Delete a template":

### 1. ENDPOINT NAME:
Delete a template

### 2. CATEGORY:
Email

### 3. HTTP METHOD:
DELETE

### 4. ENDPOINT URL:
`/emails/builder/:locationId/:templateId`

### 5. FULL URL:
`https://services.leadconnectorhq.com/emails/builder/:locationId/:templateId`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters:**
    *   `Version` (string): API Version. Possible values: `2021-07-28`
*   **Path Parameters:**
    *   `locationId` (string): The ID of the location/sub-account. Example: `ve9EPM428h8vShlRW1KT`
    *   `templateId` (string): The ID of the email template to delete. Example: `zYy3YOUuHxgomU1uYJty`

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Authorization Header:** `Authorization: Bearer <TOKEN>` (Bearer format: JWT)
*   **Description:** Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account.

### 9. RESPONSE FORMAT:
**200 Success**
*   **Content Type:** `application/json`
*   **Schema:**
    *   `ok` (string): Indicates success. Example: `true`
    *   `traceId` (string): A unique trace ID for the request. Example: `0c52e980-41f6-4be7-8c4b-32332ss`
*   **Example:**
    ```json
    {"ok":"true","traceId":"0c52e980-41f6-4be7-8c4b-32332ss"}
    ```

### 10. PURPOSE:
This endpoint allows users to delete an existing email template identified by its `templateId` within a specific `locationId`.
