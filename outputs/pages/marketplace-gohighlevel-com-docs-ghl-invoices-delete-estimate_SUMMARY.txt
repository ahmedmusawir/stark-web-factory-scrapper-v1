Here is the structured summary of the API documentation:

### 1. ENDPOINT NAME:
Delete Estimate

### 2. CATEGORY:
Invoice / Estimate

### 3. HTTP METHOD:
DELETE

### 4. ENDPOINT URL:
`/invoices/estimate/:estimateId`

### 5. FULL URL:
`https://services.leadconnectorhq.com/invoices/estimate/:estimateId`

### 6. REQUIRED PARAMETERS:

*   **Header Parameters:**
    *   Version (string): API Version (Possible values: `2021-07-28`)
*   **Path Parameters:**
    *   estimateId (string): Estimate Id (Example: `5f9d6d8b1b2d2c001f2d9e4b`)
*   **Body Parameters (application/json):**
    *   altId (string): Location Id or Agency Id (Example: `6578278e879ad2646715ba9c`)
    *   altType (string): Possible values: [`location`]

### 7. OPTIONAL PARAMETERS:
Not specified in documentation. All listed parameters are marked as required.

### 8. AUTHENTICATION:
*   **Scope(s):** `invoices/estimate.write`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`, `Agency Token`
*   **Scheme:** Bearer (JWT)
