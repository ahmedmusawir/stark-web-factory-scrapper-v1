Here's a structured summary of the API documentation:

### 1. ENDPOINT NAME:
Action to include/exclude the product in store

### 2. CATEGORY:
Products

### 3. HTTP METHOD:
POST

### 4. ENDPOINT URL:
`/products/store/:storeId`

### 5. FULL URL:
`https://services.leadconnectorhq.com/products/store/:storeId`

### 6. REQUIRED PARAMETERS:

*   **Header Parameters:**
    *   `Version` (string): API Version. Possible values: `2021-07-28`

*   **Path Parameters:**
    *   `storeId` (string): Products related to the store. Example: `3SwdhCu3svxI8AKsPJt6`

*   **Body Parameters (application/json):**
    *   `altId` (string): Location Id or Agency Id. Example: `6578278e879ad2646715ba9c`
    *   `altType` (string): Possible values: [`location`]
    *   `action` (string): Action to include or exclude the product from the store. Possible values: [`include`, `exclude`]. Example: `include`
    *   `productIds` (string[]): Array of product IDs. Example: `["productId1","productId2"]`

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:

*   **Scope(s):** `products.write`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** `bearer`
*   **Bearer Format:** `JWT`
*   **In:** `header`
*   **Description:** Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account.

### 9. RESPONSE FORMAT:

*   **201 Successful response (application/json):**
    *   `status` (boolean): Status of api action. Example: `true`
    *   `message` (string): Success message. Example: `Successfully created`
    *   **Example JSON:**
        ```json
        {"status":true,"message":"Successfully created"}
        ```

### 10. PURPOSE:
This API endpoint allows you to update the status of products within a specific store by either including them in the store or excluding them from it.
