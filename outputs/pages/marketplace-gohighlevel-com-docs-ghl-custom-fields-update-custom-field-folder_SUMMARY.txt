Here's a structured summary of the API documentation:

### 1. ENDPOINT NAME:
Update Custom Field Folder Name

### 2. CATEGORY:
Custom Fields V2

### 3. HTTP METHOD:
PUT

### 4. ENDPOINT URL:
`/custom-fields/folder/:id`

### 5. FULL URL:
`https://services.leadconnectorhq.com/custom-fields/folder/:id`

### 6. REQUIRED PARAMETERS:

*   **Header Parameters:**
    *   `Version` (string): API Version. Possible values: `2021-07-28`

*   **Path Parameters:**
    *   `id` (string): Unique identifier of the custom field folder.

*   **Body Parameters (application/json):**
    *   `name` (string): Field name. Example: `Name`
    *   `locationId` (string): Location Id. Example: `ve9EPM428h8vShlRW1KT`

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:

*   **Scope(s):** `locations/customFields.write`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** `bearer` (JWT format)
*   **In:** `header` (Authorization: Bearer <TOKEN>)
*   **Description:** Use the Access Token generated with user type as Sub-Account OR Private Integration Token of Sub-Account.

### 9. RESPONSE FORMAT:

*   **200 OK (Successful response - application/json):**
    ```json
    {
      "id": "string",
      "objectKey": "custom_object.pet",
      "locationId": "ve9EPM428h8vShlRW1KT",
      "name": "Name"
    }
    ```
    *   `id` (string): Unique identifier of the object
    *   `objectKey` (string): The key for your custom object. Example: "custom_object.pet"
    *   `locationId` (string): Location Id. Example: `ve9EPM428h8vShlRW1KT`
    *   `name` (string): Field name. Example: `Name`

*   **400 Bad Request (application/json):**
    ```json
    {
      "statusCode": 400,
      "message": "Bad Request"
    }
    ```

*   **401 Unauthorized (application/json):**
    ```json
    {
      "statusCode": 401,
      "message": "Invalid token: access token is invalid",
      "error": "Unauthorized"
    }
    ```

### 10. PURPOSE:
This endpoint updates the name of an existing custom field folder. It currently only supports Custom Objects and Company (Business) and will be extended to other Standard Objects in the future.
