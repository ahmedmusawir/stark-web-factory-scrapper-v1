## STRUCTURED SUMMARY OF API DOCUMENTATION

### 1. ENDPOINT NAME:
Create Custom Field Folder

### 2. CATEGORY:
Custom Fields V2

### 3. HTTP METHOD:
POST

### 4. ENDPOINT URL:
`/custom-fields/folder`

### 5. FULL URL:
`https://services.leadconnectorhq.com/custom-fields/folder`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters:**
    *   Version (string): API Version. Possible values: `2021-07-28`
*   **Body Parameters (application/json):**
    *   objectKey (string): The key for your custom object. This key uniquely identifies the custom object. Example: "custom_object.pet" for a custom object related to pets.
    *   name (string): Field name. Example: `Name`
    *   locationId (string): Location Id. Example: `ve9EPM428h8vShlRW1KT`

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:
*   **Scope(s):** `locations/customFields.write`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** `bearer`
*   **Bearer Format:** `JWT`
*   **In:** `header`
*   **Description:** Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account.

### 9. RESPONSE FORMAT:

**201 Successful response (application/json):**
```json
{
  "id": "string",
  "objectKey": "custom_object.pet",
  "locationId": "ve9EPM428h8vShlRW1KT",
  "name": "Name"
}
```

**400 Bad Request (application/json):**
```json
{
  "statusCode": 400,
  "message": "Bad Request"
}
```

**401 Unauthorized (application/json):**
```json
{
  "statusCode": 401,
  "message": "Invalid token: access token is invalid",
  "error": "Unauthorized"
}
```

### 10. PURPOSE:
This endpoint allows you to create a new custom field folder, currently supporting Custom Objects and Company (Business) objects.
