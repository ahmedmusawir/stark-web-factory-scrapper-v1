## STRUCTURED API SUMMARY

### 1. ENDPOINT NAME:
Get Price by ID for a Product

### 2. CATEGORY:
Products / Prices

### 3. HTTP METHOD:
GET

### 4. ENDPOINT URL:
`/products/:productId/price/:priceId`

### 5. FULL URL:
`https://services.leadconnectorhq.com/products/:productId/price/:priceId`

### 6. REQUIRED PARAMETERS:
*   **Version** (string): API Version (Possible values: `2021-07-28`)
*   **productId** (string): ID of the product that needs to be used. Example: `6578278e879ad2646715ba9c`
*   **priceId** (string): ID of the price that needs to be returned. Example: `6578278e879ad2646715ba9c`
*   **locationId** (string): location Id. Example: `6578278e879ad2646715ba9c`

### 7. OPTIONAL PARAMETERS:
None specified in documentation

### 8. AUTHENTICATION:
*   **Scope(s):** `products/prices.readonly`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`, `Agency Token`
*   **Scheme:** Bearer (JWT)
*   **In:** Header (Authorization)

### 9. RESPONSE FORMAT:

**200 OK (application/json)**
A successful response returns a JSON object containing the details of the requested price.

*   `_id` (string): The unique identifier for the price.
*   `membershipOffers` (array of objects): An array of membership offers associated with the price.
    *   `label` (string): Membership offer label.
    *   `value` (string): Membership offer label.
    *   `_id` (string): The unique identifier for the membership offer.
*   `variantOptionIds` (array of strings): An array of variant option IDs associated with the price.
*   `locationId` (string): The unique identifier for the location.
*   `product` (string): The unique identifier for the associated product.
*   `userId` (string): The unique identifier for the user.
*   `name` (string): The name of the price.
*   `type` (string): The type of the price. (Possible values: `one_time`, `recurring`)
*   `currency` (string): The currency code for the price.
*   `amount` (number): The amount of the price.
*   `recurring` (object, optional): The recurring details of the price (if type is `recurring`).
    *   `interval` (string): The interval at which the recurring event occurs. (Possible values: `day`, `month`, `week`, `year`)
    *   `intervalCount` (number): The number of intervals between each occurrence of the event.
*   `createdAt` (date-time): The creation timestamp of the price.
*   `updatedAt` (date-time): The last update timestamp of the price.
*   `compareAtPrice` (number, optional): The compare-at price for comparison purposes.
*   `trackInventory` (boolean, optional): Indicates whether inventory tracking is enabled.
*   `availableQuantity` (number, optional): Available inventory stock quantity.
*   `allowOutOfStockPurchases` (boolean, optional): Continue selling when out of stock.

**Error Responses:**
*   **400 Bad Request (application/json):** `{"statusCode":400,"message":"Bad Request"}`
*   **401 Unauthorized (application/json):** `{"statusCode":401,"message":"Invalid token: access token is invalid","error":"Unauthorized"}`
*   **422 Unprocessable Entity (application/json):** `{"statusCode":422,"message":["Unprocessable Entity"],"error":"Unprocessable Entity"}`

### 10. PURPOSE:
This endpoint allows retrieving detailed information for a specific price associated with a particular product using its unique product ID and price ID.
