Here is a structured summary of the "Upsert Opportunity" API documentation:

### 1. ENDPOINT NAME:
Upsert Opportunity

### 2. CATEGORY:
Opportunities

### 3. HTTP METHOD:
POST

### 4. ENDPOINT URL:
`/opportunities/upsert`

### 5. FULL URL:
`https://services.leadconnectorhq.com/opportunities/upsert`

### 6. REQUIRED PARAMETERS:

*   **Header Parameters:**
    *   Version (string): API Version. Possible values: `2021-07-28`
*   **Body Parameters:**
    *   pipelineId (string): pipeline Id
    *   locationId (string): locationId
    *   contactId (string): contactId

### 7. OPTIONAL PARAMETERS:

*   **Body Parameters:**
    *   name (string): name
    *   status (string): Possible values: [`open`, `won`, `lost`, `abandoned`, `all`]
    *   pipelineStageId (string)
    *   monetaryValue (number)
    *   assignedTo (string)

### 8. AUTHENTICATION:

*   **Scope(s):** `opportunities.write`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** `bearer` (JWT format in header)

### 9. RESPONSE FORMAT:

*   **Status Code:** 200 (Successful response)
*   **Content Type:** `application/json`
*   **Schema:**
    ```json
    {
      "opportunity": {},
      "new": true
    }
    ```
    *   **opportunity** (object): Updated / New Opportunity
    *   **new** (boolean): Indicates if a new opportunity was created (`true`) or an existing one was updated (`false` is implied, though the example only shows `true`).

### 10. PURPOSE:
This endpoint allows you to either create a new opportunity or update an existing one based on the provided details.
