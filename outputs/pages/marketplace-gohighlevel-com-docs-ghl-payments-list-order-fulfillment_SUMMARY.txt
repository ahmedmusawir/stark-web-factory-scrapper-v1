Here's a structured summary of the API documentation for "List fulfillment":

### 1. ENDPOINT NAME:
List fulfillment

### 2. CATEGORY:
Payments (specifically Order Fulfillments)

### 3. HTTP METHOD:
GET

### 4. ENDPOINT URL:
`/payments/orders/:orderId/fulfillments`

### 5. FULL URL:
`https://services.leadconnectorhq.com/payments/orders/:orderId/fulfillments`

### 6. REQUIRED PARAMETERS:
*   **Version** (string, Header Parameter): API Version. Possible values: `2021-07-28`
*   **orderId** (string, Path Parameter): ID of the order that needs to be returned. Example: `653f5e0cde5a1314e62a837c`
*   **altId** (string, Query Parameter): Location Id or Agency Id. Example: `6578278e879ad2646715ba9c`
*   **altType** (string, Query Parameter): Possible values: `location`

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:
*   **Scope(s)**: `payments/orders.readonly`
*   **Auth Method(s)**: `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s)**: `Sub-Account Token`

### 9. RESPONSE FORMAT:
*   **Status Code**: `200 OK`
*   **Content Type**: `application/json`
*   **Schema**:
    *   `status` (boolean): Status of API action. Example: `true`
    *   `data` (array of objects): An array of fulfilled items. Each object contains:
        *   `altId` (string): Location Id or Agency Id. Example: `6578278e879ad2646715ba9c`
        *   `altType` (string): Possible values: `location`
        *   `trackings` (array of objects): Fulfillment tracking information. Each object contains:
            *   `trackingNumber` (string): Tracking number provided by the shipping carrier. Example: `40012345678`
            *   `shippingCarrier` (string): Shipping carrier name. Example: `FedEx`
            *   `trackingUrl` (string): Tracking URL. Example: `https://www.fedex.com/wtrk/track/?trknbr=40012345678`
        *   `_id` (string): The unique identifier for the fulfillment item. Example: `655b33a82209e60b6adb87a5`
        *   `items` (array of objects): Fulfilled items. Each object contains:
            *   `_id` (string): The id of product price. Example: `6578278e879ad2646715ba9c`
            *   `name` (string): Name. Example: `Iphone 15 pro`
            *   `product` (object): Product details (includes `_id`, `description`, `variants`, `locationId`, `name`, `productType`, `availableInStore`, `createdAt`, `updatedAt`, `statementDescriptor`, `image`, `collectionIds`, `isTaxesEnabled`, `taxes`, `automaticTaxCategoryId`, `label`, `slug`).
            *   `price` (object): Price details (includes `_id`, `membershipOffers`, `variantOptionIds`, `locationId`, `product`, `userId`, `name`, `type`, `currency`, `amount`, `recurring`, `createdAt`, `updatedAt`, `compareAtPrice`, `trackInventory`, `availableQuantity`, `allowOutOfStockPurchases`).
            *   `qty` (number): The no of quantity of the current fulfilled item. Example: `1`
        *   `createdAt` (string): Created at timestamp. Example: `2023-12-12T09:27:42.355Z`
        *   `updatedAt` (string): Updated at timestamp. Example: `2023-12-12T09:27:42.355Z`

### 10. PURPOSE:
This endpoint retrieves all fulfillment history for a specific order.

Payments, Orders, Fulfillment, List, Get, History, Order Fulfillment, Readonly
