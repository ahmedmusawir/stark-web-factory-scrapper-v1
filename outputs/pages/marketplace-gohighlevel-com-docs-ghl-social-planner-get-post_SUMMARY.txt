Here is a structured summary of the API documentation:

### 1. ENDPOINT NAME:
Get post

### 2. CATEGORY:
Social Planner

### 3. HTTP METHOD:
GET

### 4. ENDPOINT URL:
`/social-media-posting/:locationId/posts/:id`

### 5. FULL URL:
`https://services.leadconnectorhq.com/social-media-posting/:locationId/posts/:id`

### 6. REQUIRED PARAMETERS:
*   `Version` (string, Header Parameter): API Version. Possible values: `2021-07-28`
*   `locationId` (string, Path Parameter): Location Id. Example: `ve9EPM428h8vShlRW1KT`
*   `id` (string, Path Parameter): Post Id. Example: `65fac446d599990d1313c1dd`

### 7. OPTIONAL PARAMETERS:
Not specified in documentation (all request parameters listed are required).

### 8. AUTHENTICATION:
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** Bearer (JWT)
*   **In:** Header (Authorization header)

### 10. PURPOSE:
This endpoint retrieves the details of a specific social media post by its unique ID within a given location.
