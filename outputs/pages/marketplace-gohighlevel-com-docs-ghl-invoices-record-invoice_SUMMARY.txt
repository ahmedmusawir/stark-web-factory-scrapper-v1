Here's a structured summary of the API documentation:

### 1. ENDPOINT NAME
Record a manual payment for an invoice

### 2. CATEGORY
Invoice

### 3. HTTP METHOD
POST

### 4. ENDPOINT URL
`/invoices/:invoiceId/record-payment`

### 5. FULL URL
`https://services.leadconnectorhq.com/invoices/:invoiceId/record-payment`

### 6. REQUIRED PARAMETERS

*   **Header Parameters:**
    *   `Version` (string): API Version (Possible values: `2021-07-28`)
*   **Path Parameters:**
    *   `invoiceId` (string): Invoice Id
*   **Body Parameters:**
    *   `altId` (string): location Id / company Id based on altType
    *   `altType` (string): Alt Type (Possible values: `location`)
    *   `mode` (string): manual payment method (Possible values: `cash`, `card`, `cheque`, `bank_transfer`, `other`)
    *   `card` (object): Required if `mode` is `card`.
        *   `brand` (string): Card brand
        *   `last4` (string): Last 4 digits of the card
    *   `cheque` (object): Required if `mode` is `cheque`.
        *   `number` (string): Check number

### 7. OPTIONAL PARAMETERS

*   **Body Parameters:**
    *   `notes` (string): Any note to be recorded with the transaction
    *   `amount` (number): Amount to be paid against the invoice.
    *   `meta` (object): Additional metadata (structure not further described)
    *   `paymentScheduleIds` (string[]): Payment Schedule Ids to be recorded against the invoice.
    *   `fulfilledAt` (string): Updated At to be recorded against the invoice. (Example: `2025-03-19T05:03:00.000Z`)

### 8. AUTHENTICATION

*   **Scope(s)**: `invoices.write`
*   **Auth Method(s)**: `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s)**: `Sub-Account Token`, `Agency Token`

### 9. RESPONSE FORMAT

*   **Status Code**: `200 OK`
*   **Structure**: A JSON object containing:
    *   `success` (boolean): Status of the request (e.g., `true`)
    *   `invoice` (object): The updated invoice object, including fields such as:
        *   `_id` (string): Invoice Id
        *   `status` (string): Invoice Status (e.g., `draft`, `sent`, `payment_processing`, `paid`, `void`, `partially_paid`)
        *   `liveMode` (boolean): Live Mode
        *   `amountPaid` (number): Amount Paid
        *   `altId` (string): Location Id or Agency Id
        *   `altType` (string): Type of altId (e.g., `location`)
        *   `name` (string): Name of the invoice
        *   `businessDetails` (object): Details of the business
        *   `invoiceNumber` (number): Invoice Number
        *   `currency` (string): Currency
        *   `contactDetails` (object): Details of the contact
        *   `issueDate` (string): Issue date in YYYY-MM-DD format
        *   `dueDate` (string): Due date in YYYY-MM-DD format
        *   `discount` (object): Discount details
        *   `invoiceItems` (string[]): Array of invoice items
        *   `total` (number): Total Amount
        *   `title` (string): Title
        *   `amountDue` (number): Total Amount Due
        *   `createdAt` (string): Timestamp of creation
        *   `updatedAt` (string): Timestamp of last update
        *   `automaticTaxesEnabled` (boolean): Automatic taxes enabled for the Invoice
        *   `automaticTaxesCalculated` (boolean): Is Automatic taxes calculated for the Invoice items
        *   `paymentSchedule` (object): split invoice into payment schedule summing up to full invoice amount
*   **Error Responses**:
    *   `400 Bad Request`: JSON object with `statusCode` and `message`.
    *   `401 Unauthorized`: JSON object with `statusCode`, `message`, and `error`.
    *   `422 Unprocessable Entity`: JSON object with `statusCode`, `message` (array of strings), and `error`.

### 10. PURPOSE
This API allows recording a manual payment for an existing invoice identified by its ID.
