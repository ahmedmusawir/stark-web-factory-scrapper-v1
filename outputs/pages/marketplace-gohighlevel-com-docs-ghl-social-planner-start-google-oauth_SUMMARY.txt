Here's a structured summary of the API documentation:

### 1. ENDPOINT NAME:
Starts OAuth For Google Account

### 2. CATEGORY:
Social Planner

### 3. HTTP METHOD:
GET

### 4. ENDPOINT URL:
`/social-media-posting/oauth/google/start`

### 5. FULL URL:
`https://services.leadconnectorhq.com/social-media-posting/oauth/google/start`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters:**
    *   Version (string): API Version. Possible values: [`2021-07-28`]
*   **Query Parameters:**
    *   locationId (string): Location Id
    *   userId (string): User Id

### 7. OPTIONAL PARAMETERS:
*   **Query Parameters:**
    *   page (string): Page
    *   reconnect (string): Reconnect

### 8. AUTHENTICATION:
*   **Scope(s):** `socialplanner/oauth.readonly`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** `bearer`
*   **Bearer Format:** `JWT`
*   **In:** `header`
*   **Description:** Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account.

### 9. RESPONSE FORMAT:

*   **200 Successful Response:** The API initiates a redirect to Google's OAuth screen. Upon successful login and authorization, a client-side `window` event listener will receive the following data:
    *   `actionType` (string): Ex: "close"
    *   `page` (string): Ex: "social-media-posting"
    *   `platform` (string): Ex: "google"
    *   `placement` (string): Ex: "placement"
    *   `accountId` (string): Ex: "658a9b6833b91e0ecb8f3958"
    *   `reconnectAccounts` (string[]): Ex: ["658a9b6833b91e0ecb834acd", "efd2daa9b6833b91e0ecb8f3511"]

*   **400 Bad Request:**
    *   Schema: `statusCode` (number), `message` (string)
    *   Example: `{"statusCode":400,"message":"Bad Request"}`

*   **401 Unauthorized:**
    *   Schema: `statusCode` (number), `message` (string), `error` (string)
    *   Example: `{"statusCode":401,"message":"Invalid token: access token is invalid","error":"Unauthorized"}`

*   **422 Unprocessable Entity:**
    *   Schema: `statusCode` (number), `message` (string[]), `error` (string)
    *   Example: `{"statusCode":422,"message":["Unprocessable Entity"],"error":"Unprocessable Entity"}`

### 10. PURPOSE:
This endpoint initiates the OAuth 2.0 flow for connecting a Google account to the Social Planner, redirecting the user to Google's login and authorization screen.
