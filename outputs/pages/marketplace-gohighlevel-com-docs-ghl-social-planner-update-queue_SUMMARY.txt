Here's a structured summary of the API documentation for "Update a category queue":

### 1. ENDPOINT NAME
Update a category queue

### 2. CATEGORY
Social Planner > Category Queue

### 3. HTTP METHOD
PUT

### 4. ENDPOINT URL
`/social-media-posting/category/queues/:queueId`

### 5. FULL URL
`https://services.leadconnectorhq.com/social-media-posting/category/queues/:queueId`

### 6. REQUIRED PARAMETERS
*   **Header Parameters:**
    *   `Version` (string): API Version. Possible values: `2021-07-28`.
*   **Path Parameters:**
    *   `queueId` (string): The unique identifier of the category queue to be updated.
*   **Body Parameters:**
    *   `locationId` (string): Location ID.

### 7. OPTIONAL PARAMETERS
*   **Body Parameters:**
    *   `status` (string): Status of the Queue. Possible values: `active`, `paused`, `draft`.
    *   `skipDateTime` (string): Skip Date Time in ISO format. Example: `2023-10-05T14:48:00.000Z`.

### 8. AUTHENTICATION
Token-based authentication is required, as indicated by the `401 Unauthorized` response example ("Invalid token: access token is invalid"). Specific OAuth 2.0 scopes or token types are not explicitly detailed in this document.

**Error Responses:**
*   **400 Bad Request:** `{"statusCode": 400, "message": "Bad Request"}`
*   **401 Unauthorized:** `{"statusCode": 401, "message": "Invalid token: access token is invalid", "error": "Unauthorized"}`
*   **422 Unprocessable Entity:** `{"statusCode": 422, "message": ["Unprocessable Entity"], "error": "Unprocessable Entity"}`

### 10. PURPOSE
This endpoint updates the parameters of a specific category queue, allowing changes to its status (e.g., active, paused) or the `skipDateTime` to prevent posting on a particular date.
