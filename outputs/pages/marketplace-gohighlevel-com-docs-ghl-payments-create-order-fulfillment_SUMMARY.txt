Here's a structured summary of the "Create order fulfillment" API documentation:

### 1. ENDPOINT NAME:
Create order fulfillment

### 2. CATEGORY:
Payments

### 3. HTTP METHOD:
POST

### 4. ENDPOINT URL:
`/payments/orders/:orderId/fulfillments`

### 5. FULL URL:
`https://services.leadconnectorhq.com/payments/orders/:orderId/fulfillments`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters:**
    *   Version (string): API Version. Possible values: [`2021-07-28`]
*   **Path Parameters:**
    *   orderId (string): ID of the order that needs to be returned.
*   **Body Parameters (application/json):**
    *   altId (string): Location Id or Agency Id.
    *   altType (string): Possible values: [`location`]
    *   trackings (object[]): Fulfillment tracking information.
        *   trackingNumber (string): Tracking number provided by the shipping carrier.
        *   shippingCarrier (string): Shipping carrier name.
        *   trackingUrl (string): Tracking URL.
    *   items (object[]): Fulfilled items.
        *   priceId (string): The id of product price.
        *   qty (number): The number of quantity of the item.
    *   notifyCustomer (boolean): Need to send a notification to customer.

### 7. OPTIONAL PARAMETERS:
Not specified in documentation. All request parameters are marked as required.

### 8. AUTHENTICATION:
*   **Scope(s):** `payments/orders.write`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** `bearer`
*   **Bearer Format:** `JWT`
*   **In:** `header`
*   **Description:** Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account.
