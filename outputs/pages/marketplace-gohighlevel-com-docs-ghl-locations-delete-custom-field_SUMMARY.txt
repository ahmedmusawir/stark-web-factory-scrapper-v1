Here is a structured summary of the API documentation:

### 1. ENDPOINT NAME:
Delete Custom Field

### 2. CATEGORY:
Sub-Account (Formerly Location) - Custom Field

### 3. HTTP METHOD:
DELETE

### 4. ENDPOINT URL:
`/locations/:locationId/customFields/:id`

### 5. FULL URL:
`https://services.leadconnectorhq.com/locations/:locationId/customFields/:id`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters:**
    *   Version (string): API Version. Possible values: `2021-07-28`
*   **Path Parameters:**
    *   locationId (string): Location Id. Example: `ve9EPM428h8vShlRW1KT`
    *   id (string): Custom Field Id. Example: `00NhGCcN1tlO8ZHcu7Wb`

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** Bearer (JWT)
*   **Description:** Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account.

### 9. RESPONSE FORMAT:

*   **200 OK (Successful response)**
    *   **Content Type:** `application/json`
    *   **Schema:**
        *   `succeded` (boolean)
    *   **Example:**
        ```json
        {"succeded": true}
        ```
*   **400 Bad Request**
    *   **Content Type:** `application/json`
    *   **Schema:**
        *   `statusCode` (number)
        *   `message` (string)
    *   **Example:**
        ```json
        {"statusCode": 400, "message": "Bad Request"}
        ```
*   **401 Unauthorized**
    *   **Content Type:** `application/json`
    *   **Schema:**
        *   `statusCode` (number)
        *   `message` (string)
        *   `error` (string)
    *   **Example:**
        ```json
        {"statusCode": 401, "message": "Invalid token: access token is invalid", "error": "Unauthorized"}
        ```
*   **422 Unprocessable Entity**
    *   **Content Type:** `application/json`
    *   **Schema:**
        *   `statusCode` (number)
        *   `message` (string[])
        *   `error` (string)
    *   **Example:**
        ```json
        {"statusCode": 422, "message": ["Unprocessable Entity"], "error": "Unprocessable Entity"}
        ```

### 10. PURPOSE:
This endpoint allows users to delete a specific custom field associated with a given sub-account (formerly location).
