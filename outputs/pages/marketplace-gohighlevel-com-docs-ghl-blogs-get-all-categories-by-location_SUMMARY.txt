Here is a structured summary of the API documentation:

### 1. ENDPOINT NAME:
Get all categories

### 2. CATEGORY:
Blogs

### 3. HTTP METHOD:
GET

### 4. ENDPOINT URL:
`/blogs/categories`

### 5. FULL URL:
`https://services.leadconnectorhq.com/blogs/categories`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters:**
    *   `Version` (string): API Version (Possible values: `2021-07-28`)
*   **Query Parameters:**
    *   `locationId` (string): The ID of the location for which to retrieve categories. Example: `ve9EPM428h8vShlRW1KT`
    *   `limit` (number): Number of categories to show in the listing.
    *   `offset` (number): Number of categories to skip in listing.

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:
*   **Required Scope(s):** `blogs/category.readonly`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** `bearer`
*   **Bearer Format:** `JWT`
*   **In:** `header`
*   **Description:** Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account.

### 9. RESPONSE FORMAT:

*   **Successful Response (200 OK):**
    *   **Content Type:** `application/json`
    *   **Schema:**
        *   `categories` (object[]): Array of blog categories.
            *   `_id` (string): Unique identifier for the category. Example: `lMOzIQZne5m6zQ528sT6`
            *   `label` (string): The display name of the category. Example: `HighLevel`
            *   `locationId` (string): The ID of the location the category belongs to. Example: `lMOzIQZne5m6zQ528sT6`
            *   `updatedAt` (string): Timestamp of when the category was last updated. Example: `2025-01-03T11:06:35.822Z`
            *   `canonicalLink` (string): The canonical URL for the category. Example: `https://tryghl.blog/doc/category/agency-growth`
            *   `urlSlug` (string): The URL slug for the category. Example: `agency-growth`
    *   **Example:**
        ```json
        {"categories":[{"_id":"lMOzIQZne5m6zQ528sT6","label":"HighLevel","locationId":"lMOzIQZne5m6zQ528sT6","updatedAt":"2025-01-03T11:06:35.822Z","canonicalLink":"https://tryghl.blog/doc/category/agency-growth","urlSlug":"agency-growth"}]}
        ```
*   **Error Responses:**
    *   `400 Bad Request`: `{"statusCode":400,"message":"Bad Request"}`
    *   `401 Unauthorized`: `{"statusCode":401,"message":"Invalid token: access token is invalid","error":"Unauthorized"}`
    *   `422 Unprocessable Entity`: `{"statusCode":422,"message":["Unprocessable Entity"],"error":"Unprocessable Entity"}`

### 10. PURPOSE:
This API endpoint returns a list of blog categories for a specified location ID.
