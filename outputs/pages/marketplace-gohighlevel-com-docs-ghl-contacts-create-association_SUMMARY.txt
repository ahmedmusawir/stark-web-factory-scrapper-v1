Here is a structured summary of the provided API documentation:

### 1. ENDPOINT NAME:
Update Contacts Tags

### 2. CATEGORY:
Contacts

### 3. HTTP METHOD:
POST

### 4. ENDPOINT URL:
`/contacts/bulk/tags/update/:type`

### 5. FULL URL:
`https://services.leadconnectorhq.com/contacts/bulk/tags/update/:type`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters:**
    *   Version (string): API Version (Possible values: `2021-07-28`)
*   **Body Parameters:**
    *   contacts (string[]): list of contact ids to be processed
    *   tags (string[]): list of tags to be added or removed
    *   locationId (string): location id from where the bulk request is executed

### 7. OPTIONAL PARAMETERS:
*   **Body Parameters:**
    *   removeAllTags (boolean): Option to implement remove all tags. if true, all tags will be removed from the contacts. Can only be used with remove type.

### 8. AUTHENTICATION:
Not specified in documentation for this specific endpoint. (The general API might require OAuth 2.0 or API keys as indicated by the sidebar navigation, but specific requirements for this endpoint are not detailed).

### 10. PURPOSE:
This endpoint allows you to update tags for multiple contacts at once, enabling the addition or removal of tags from a list of specified contacts.
