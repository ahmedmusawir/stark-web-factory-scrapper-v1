Here's a structured summary of the API documentation:

### 1. ENDPOINT NAME:
Create new integration

### 2. CATEGORY:
Payments / Custom Provider

### 3. HTTP METHOD:
`POST`

### 4. ENDPOINT URL:
`/payments/custom-provider/provider`

### 5. FULL URL:
`https://services.leadconnectorhq.com/payments/custom-provider/provider`

### 6. REQUIRED PARAMETERS:
*   `Version` (string, Header): API Version. Possible values: [`2021-07-28`]
*   `locationId` (string, Query): Location id. Example: `Lk3nlfk4lxlelVEwcW`
*   `name` (string, Body): The name of the custom provider. Example:`Company Paypal Integration`
*   `description` (string, Body): Description of payment gateway. Shown on the payments integrations page as subtext. Example:`This payment gateway supports payments in India via UPI, Net banking, cards and wallets.`
*   `paymentsUrl` (string, Body): This url will be loaded in iFrame to start a payment session. Example:`https://testpayment.paypal.com`
*   `queryUrl` (string, Body): The url used for querying payments related events. Ex. verify, refund, subscription etc. Example:`https://testsubscription.paypal.com`
*   `imageUrl` (string, Body): Public image url for logo of the payment gateway displayed on the payments integrations page. Example:`https://testsubscription.paypal.com`
*   `supportsSubscriptionSchedule` (boolean, Body): Whether the config supports subscription schedule or not. true represents config supports subscription schedule. Example:`true`

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:
*   **Scope(s):** `payments/custom-provider.write`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`

### 9. RESPONSE FORMAT:
*   **Status Code:** `200 OK`
*   **Structure (JSON):**
    *   `name` (string): The name of the custom provider.
    *   `description` (string): Description of payment gateway.
    *   `paymentsUrl` (string): This url will be loaded in iFrame to start a payment session.
    *   `queryUrl` (string): The url used for querying payments related events.
    *   `imageUrl` (string): Public image url for logo of the payment gateway.
    *   `_id` (string): The unique identifier for the custom provider.
    *   `locationId` (string): Location id.
    *   `marketplaceAppId` (string): The application id of marketplace.
    *   `paymentProvider` (object): Payment provider details, e.g., `{ live: { liveMode: true }, test: { liveMode: false, apiKey: "y5ZQxryRFXZHvUJZdLXXXXXX", publishableKey: "rzp_test_zPRoVMLOa0A9wo" }}`.
    *   `deleted` (boolean): Whether the config is deleted or not.
    *   `createdAt` (date-time): The creation timestamp of the custom provider.
    *   `updatedAt` (date-time): The last update timestamp of the custom provider.
    *   `traceId` (string): Trace id of the custom provider.

### 10. PURPOSE:
This API endpoint creates a new association for a marketplace app and a specific location with a custom payment provider.
