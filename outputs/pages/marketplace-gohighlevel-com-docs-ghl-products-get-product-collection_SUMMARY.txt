Here is a structured summary of the API documentation for "Fetch Product Collections":

### 1. ENDPOINT NAME:
Fetch Product Collections

### 2. CATEGORY:
Products / Collections

### 3. HTTP METHOD:
GET

### 4. ENDPOINT URL:
`/products/collections`

### 5. FULL URL:
`https://services.leadconnectorhq.com/products/collections`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters:**
    *   `Version` (string): API Version. Possible values: [`2021-07-28`]
*   **Query Parameters:**
    *   `altId` (string): Location Id
    *   `altType` (string): The type of alt. For now it is only LOCATION. Possible values: [`location`]

### 7. OPTIONAL PARAMETERS:
*   **Query Parameters:**
    *   `limit` (number): The maximum number of items to be included in a single page of results. Default value: `10`
    *   `offset` (number): The starting index of the page, indicating the position from which the results should be retrieved. Default value: `0`
    *   `collectionIds` (string): Ids of the collections separated by comma(,) for search purposes
    *   `name` (string): Query to search collection based on names

### 8. AUTHENTICATION:
*   **Scope(s):** `products/collection.readonly`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** `bearer`
*   **Bearer Format:** `JWT`
*   **In:** `header`
*   **Description:** Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account.

### 9. RESPONSE FORMAT:
*   **Status Code:** 200 OK
*   **Content Type:** `application/json`
*   **Schema:**
    *   `data` (array[]): Array of Collections.
    *   `total` (number): The total count of the collections present, which is useful to calculate the pagination.
*   **Example (200 OK):**
    ```json
    {"data":[[null]],"total":0}
    ```
*   **Error Responses:**
    *   **400 Bad Request:** `{"statusCode":400,"message":"Bad Request"}`
    *   **401 Unauthorized:** `{"statusCode":401,"message":"Invalid token: access token is invalid","error":"Unauthorized"}`
    *   **422 Unprocessable Entity:** `{"statusCode":422,"message":["Unprocessable Entity"],"error":"Unprocessable Entity"}`

### 10. PURPOSE:
This endpoint is an internal API used to fetch a collection of products.
