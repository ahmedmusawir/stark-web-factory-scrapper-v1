Here is a structured summary of the "Delete Custom Field Folder" API documentation:

### 1. ENDPOINT NAME:
Delete Custom Field Folder

### 2. CATEGORY:
Custom Fields V2

### 3. HTTP METHOD:
DELETE

### 4. ENDPOINT URL:
`/custom-fields/folder/:id`

### 5. FULL URL:
`https://services.leadconnectorhq.com/custom-fields/folder/:id`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters:**
    *   Version (string): API Version. Possible values: [`2021-07-28`]
*   **Path Parameters:**
    *   id (string): The unique identifier of the custom field folder to be deleted.
*   **Query Parameters:**
    *   locationId (string): The unique identifier of the location (sub-account) where the custom field folder exists.

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:
*   **Scope(s):** `locations/customFields.write`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Details:** The `Authorization` header should contain a Bearer token (JWT format). This token can be either an Access Token generated with a Sub-Account user type or a Private Integration Token belonging to a Sub-Account.

### 9. RESPONSE FORMAT:
**Status Code: 200 (Successful response)**
*   **Content Type:** `application/json`
*   **Schema:**
    *   `succeded` (boolean): Indicates whether the operation was successful. Example: `true`
    *   `id` (string): The ID of the deleted custom field folder. Example: `3v34PM428h8vShlRW1KT`
    *   `key` (string): The key associated with the deleted custom field folder. Example: `custom_object.pet.name`
*   **Example:**
    ```json
    {"succeded":true,"id":"3v34PM428h8vShlRW1KT","key":"custom_object.pet.name"}
    ```

**Error Responses:**
*   **400 Bad Request:**
    *   Schema: `statusCode` (number), `message` (string)
    *   Example: `{"statusCode":400,"message":"Bad Request"}`
*   **401 Unauthorized:**
    *   Schema: `statusCode` (number), `message` (string), `error` (string)
    *   Example: `{"statusCode":401,"message":"Invalid token: access token is invalid","error":"Unauthorized"}`

### 10. PURPOSE:
This endpoint allows developers to delete a specific custom field folder, identified by its unique ID, from a given location (sub-account).
