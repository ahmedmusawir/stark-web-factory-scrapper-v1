Here's a structured summary of the API documentation for "Delete template":

---

### 1. ENDPOINT NAME:
Delete template

### 2. CATEGORY:
Invoice Template Management

### 3. HTTP METHOD:
DELETE

### 4. ENDPOINT URL:
`/invoices/template/:templateId`

### 5. FULL URL:
`https://services.leadconnectorhq.com/invoices/template/:templateId`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters:**
    *   `Version` (string): API Version. Possible values: `2021-07-28`.
*   **Path Parameters:**
    *   `templateId` (string): Template Id. Example: `6578278e879ad2646715ba9c`
*   **Query Parameters:**
    *   `altId` (string): Location Id / Company Id based on altType. Example: `6578278e879ad2646715ba9c`
    *   `altType` (string): Alt Type. Possible values: `location`. Example: `location`

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:
*   **Scope(s):** `invoices/template.write`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`, `Agency Token`

### 9. RESPONSE FORMAT:
*   **200 OK (Successful response):**
    *   `application/json`
    *   **Schema:**
        ```json
        {
          "success": boolean
        }
        ```
    *   **Example:**
        ```json
        {"success":true}
        ```
*   **Other Responses (Error Handling):**
    *   **400 Bad Request:** `{"statusCode":400,"message":"Bad Request"}`
    *   **401 Unauthorized:** `{"statusCode":401,"message":"Invalid token: access token is invalid","error":"Unauthorized"}`
    *   **422 Unprocessable Entity:** `{"statusCode":422,"message":["Unprocessable Entity"],"error":"Unprocessable Entity"}`

### 10. PURPOSE:
This endpoint is used to delete an invoice template by its ID. (Note: The documentation mistakenly states "API to update an template by template id" under the "Delete template" heading, but the HTTP method and context clearly indicate deletion).
