Here is a structured summary of the API documentation:

### API Documentation Summary

1.  **ENDPOINT NAME**: Get categories by location id

2.  **CATEGORY**: Social Planner > Category

3.  **HTTP METHOD**: GET

4.  **ENDPOINT URL**: `/social-media-posting/:locationId/categories`

5.  **FULL URL**: `https://services.leadconnectorhq.com/social-media-posting/:locationId/categories`

6.  **REQUIRED PARAMETERS**:
    *   **Header Parameters**:
        *   Version (string): API Version. Possible values: `2021-07-28`
    *   **Path Parameters**:
        *   locationId (string): Location Id. Example: `ve9EPM428h8vShlRW1KT`

7.  **OPTIONAL PARAMETERS**:
    *   **Query Parameters**:
        *   searchText (string): Search text string. Example: `test`
        *   limit (string): Limit. Example: `10`
        *   skip (string): Skip. Example: `0`

8.  **AUTHENTICATION**:
    *   **Scope(s)**: `socialplanner/category.readonly`
    *   **Auth Method(s)**: `OAuth Access Token`, `Private Integration Token`
    *   **Token Type(s)**: `Sub-Account Token`
    *   **Authorization Header**: `Bearer <TOKEN>` (JWT format)
        *   Description: Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account.

9.  **RESPONSE FORMAT**:
    *   **200 OK (Successful response - application/json)**:
        ```json
        {
          "success": true,
          "statusCode": 200,
          "message": "Fetched Categories by Location ID",
          "results": {
            "count": 3,
            "categories": [
              {
                "name": "Primary",
                "primaryColor": "#FFFFFF",
                "secondaryColor": "#FFFFFF",
                "locationId": "Lx1EI6YIgQYMQi0ytFXv",
                "_id": "Lx1EI6YIgQYMQi0ytFXv",
                "createdBy": "Lx1EI6YIgQYMQi0ytFXv",
                "deleted": false,
                "createdAt": "2023-08-02T00:00:00.000Z",
                "updatedAt": "2023-08-02T00:00:00.000Z"
              }
            ]
          }
        }
        ```
        *   `success` (boolean): Success or Failure
        *   `statusCode` (number): Status Code
        *   `message` (string): Message
        *   `results` (object): Requested Results
            *   `count` (number): Count
            *   `categories` (array of objects): Meta Data
                *   `name` (string): Category Name
                *   `primaryColor` (string): Color For Category
                *   `secondaryColor` (string): Secondary Color
                *   `locationId` (string): Location ID
                *   `_id` (string): ID
                *   `createdBy` (string): Created By User
                *   `deleted` (boolean): Deleted Value
                *   `createdAt` (date-time)
                *   `updatedAt` (date-time)
    *   **400 Bad Request (application/json)**:
        ```json
        {"statusCode":400,"message":"Bad Request"}
        ```
    *   **401 Unauthorized (application/json)**:
        ```json
        {"statusCode":401,"message":"Invalid token: access token is invalid","error":"Unauthorized"}
        ```
    *   **422 Unprocessable Entity (application/json)**:
        ```json
        {"statusCode":422,"message":["Unprocessable Entity"],"error":"Unprocessable Entity"}
        ```

10. **PURPOSE**: This endpoint retrieves a list of social media posting categories associated with a specific location ID.
