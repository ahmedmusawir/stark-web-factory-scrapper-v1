Here's a structured summary of the API documentation:

### 1. ENDPOINT NAME:
Get Agency Plans

### 2. CATEGORY:
Saas

### 3. HTTP METHOD:
GET

### 4. ENDPOINT URL:
`/saas-api/public-api/agency-plans/:companyId`

### 5. FULL URL:
`https://services.leadconnectorhq.com/saas-api/public-api/agency-plans/:companyId`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters:**
    *   `Version` (string): API Version. Possible values: `2021-04-15`.
*   **Path Parameters:**
    *   `companyId` (string): Company ID to get agency plans for. Example: `5DP4iH6HLkQsiKESj6rh`

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Agency Token`
*   **Scheme:** Bearer (JWT) in `Authorization` header.

### 9. RESPONSE FORMAT:

*   **200 OK - Agency plans retrieved successfully**
    *   **Content-Type:** `application/json`
    *   **Schema:** An array of objects, each representing an agency plan.
        *   `planId` (string, required): Unique identifier for the plan. Example: `66c4d36534f21f900dc2a265`
        *   `title` (string, required): Title of the plan. Example: `AED 1.5 changed`
        *   `description` (string, required): Description of the plan. Example: `AED 1.5`
        *   `saasProducts` (string[], required): Array of SaaS products included in the plan. Example: `["2-way-text-messaging","gmb-messaging","web-chat","reputation-management"]`
        *   `addOns` (string[]): Array of add-ons included in the plan. Example: `["CONVERSATIONS_AI","CP_BRANDED_APP_49","WORDPRESS_V1"]`
        *   `planLevel` (number, required): Level of the plan (0-4). Example: `0`
        *   `trialPeriod` (number, required): Trial period in days. Example: `16`
        *   `userLimit` (number): User limit for the plan. Example: `50`
        *   `contactLimit` (number): Contact limit for the plan. Example: `50`
        *   `prices` (object[], required): Pricing information for the plan.
            *   `id` (string): ID of the price. Example: `66a9edbfcc6c505a22db7976`
            *   `billingInterval` (string): Billing interval for the plan. Possible values: [`month`, `year`]. Example: `month`
            *   `active` (boolean): Indicates if the price is active. Example: `true`
            *   `amount` (number): Amount of the price. Example: `150`
            *   `currency` (string): Currency of the price. Example: `AED`
            *   `symbol` (string): Symbol of the price. Example: `$`
        *   `categoryId` (string): Category ID for the plan. Example: `66911cdc98508ec2731979b9`
        *   `snapshotId` (string): Snapshot ID for the plan. Example: `G8KmpIeLnZc7ZMoJoxDx`
        *   `productId` (string): Product ID for the plan. Example: `66a9edbfcc6c5090bedb7974`
        *   `isSaaSV2` (boolean, required): Indicates if this is a SaaS V2 plan. Example: `true`
        *   `providerLocationId` (string): Provider location ID. Example: `r06mdj4OrrERzYDvsOdh`
        *   `createdAt` (string, required): Creation timestamp. Example: `2024-07-31T07:54:41.885Z`
        *   `updatedAt` (string, required): Last update timestamp. Example: `2025-04-01T12:27:29.167Z`
*   **400 Bad Request**
    *   **Schema:** `{"statusCode": 400, "message": "Bad Request"}`
*   **401 Unauthorized**
    *   **Schema:** `{"statusCode": 401, "message": "Invalid token: access token is invalid", "error": "Unauthorized"}`
*   **404 Resource not found**
    *   **Schema:** `{"statusCode": 404, "message": ["Contact not found", ...]}`
*   **500 Internal server error**
    *   **Schema:** `{"statusCode": 500, "message": "Internal Server Error"}`

### 10. PURPOSE:
This endpoint fetches all agency subscription plans for a given company ID. (Note: This endpoint is deprecated and may be replaced or removed in future versions of the API.)
