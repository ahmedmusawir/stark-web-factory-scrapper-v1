Here is a structured summary of the API documentation for "Get all Tasks":

### 1. ENDPOINT NAME:
Get all Tasks

### 2. CATEGORY:
Contacts (specifically, Tasks under Contacts)

### 3. HTTP METHOD:
GET

### 4. ENDPOINT URL:
`/contacts/:contactId/tasks`

### 5. FULL URL:
`https://services.leadconnectorhq.com/contacts/:contactId/tasks`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters:**
    *   `Version` (string): API Version. Possible values: `2021-07-28`
*   **Path Parameters:**
    *   `contactId` (string): Contact Id. Example: `sx6wyHhbFdRXh302LLNR`

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:
*   **Scope(s):** `contacts.readonly`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** `bearer`
*   **Bearer Format:** `JWT`
*   **In:** `header` (Parameter name: `Authorization`)

### 9. RESPONSE FORMAT:

*   **200 Successful Response (application/json):**
    *   **Schema:** An array of `tasks` objects.
        *   `tasks` (array of objects)
            *   `id` (string): Unique identifier for the task. Example: `lJpzYrWdpkC2hX6t2yue`
            *   `title` (string): Title of the task. Example: `test`
            *   `body` (string): Description or body of the task. Example: `testing`
            *   `assignedTo` (string): Identifier of the user or entity the task is assigned to. Example: `tesTUcmRxWrjqzJS8EjkxNKting`
            *   `dueDate` (string): Due date of the task (ISO 8601 format). Example: `2021-07-08T02:30:00.000Z`
            *   `completed` (boolean): Indicates if the task is completed. Example: `true`
            *   `contactId` (string): The ID of the contact associated with the task. Example: `lJpzYrWdpkC2hX6t2yue`
    *   **Example:**
        ```json
        {
          "tasks": [
            {
              "id": "lJpzYrWdpkC2hX6t2yue",
              "title": "test",
              "body": "testing",
              "assignedTo": "tesTUcmRxWrjqzJS8EjkxNKting",
              "dueDate": "2021-07-08T02:30:00.000Z",
              "completed": true,
              "contactId": "lJpzYrWdpkC2hX6t2yue"
            }
          ]
        }
        ```
*   **400 Bad Request Response (application/json):**
    *   **Schema:**
        *   `statusCode` (number): `400`
        *   `message` (string): `Bad Request`
*   **401 Unauthorized Response (application/json):**
    *   **Schema:**
        *   `statusCode` (number): `401`
        *   `message` (string): `Invalid token: access token is invalid`
        *   `error` (string): `Unauthorized`

### 10. PURPOSE:
This endpoint retrieves all tasks associated with a specific contact ID.
