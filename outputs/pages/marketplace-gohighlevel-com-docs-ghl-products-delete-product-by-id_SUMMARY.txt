Here's a structured summary of the API documentation for "Delete Product by ID":

### 1. ENDPOINT NAME:
Delete Product by ID

### 2. CATEGORY:
Products

### 3. HTTP METHOD:
DELETE

### 4. ENDPOINT URL:
`/products/:productId`

### 5. FULL URL:
`https://services.leadconnectorhq.com/products/:productId`

### 6. REQUIRED PARAMETERS:
*   `Version` (string): API Version. Possible values: [`2021-07-28`] (Header Parameter)
*   `productId` (string): ID or the slug of the product that needs to be returned. Example: `6578278e879ad2646715ba9c` (Path Parameter)
*   `locationId` (string): location Id. Example: `6578278e879ad2646715ba9c` (Query Parameter)

### 7. OPTIONAL PARAMETERS:
*   `sendWishlistStatus` (boolean): Parameter which will decide whether to show the wishlisting status of products. (Query Parameter)

### 8. AUTHENTICATION:
*   **Scope(s)**: `products.write`
*   **Auth Method(s)**: `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s)**: `Sub-Account Token`, `Agency Token`
*   **Scheme**: `bearer`
*   **Bearer Format**: `JWT`
*   **In**: `header`
*   **Description**: Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account.

### 9. RESPONSE FORMAT:
*   **Status Code**: `200` (Successful response)
*   **Content Type**: `application/json`
*   **Schema**:
    *   `status` (boolean, required): returns true if the product is successfully deleted.
*   **Example**:
    ```json
    {"status": true}
    ```

### 10. PURPOSE:
This API allows deleting a specific product from the system using its unique identifier.
