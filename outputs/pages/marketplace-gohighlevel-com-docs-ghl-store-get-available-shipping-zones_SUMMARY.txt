## STRUCTURED API SUMMARY

### 1. ENDPOINT NAME
Get available shipping rates

### 2. CATEGORY
Store (Shipping Zone)

### 3. HTTP METHOD
POST

### 4. ENDPOINT URL
/store/shipping-zone/shipping-rates

### 5. FULL URL
https://services.leadconnectorhq.com/store/shipping-zone/shipping-rates

### 6. REQUIRED PARAMETERS
- **altId** (string): Location Id or Agency Id. Example: `6578278e879ad2646715ba9c`
- **altType** (string): Possible values: [`location`]
- **country** (string): Country code of the customer. Possible values: [`US`, `CA`, `AF`, ..., `ZW`]
- **address.country** (string): Country code of the customer (required if `address` object is provided). Possible values: [`US`, `CA`, `AF`, ..., `ZW`]
- **totalOrderAmount** (number): The amount of the price. (min: 0.01). Example: `99.99`
- **totalOrderWeight** (number): Estimated weight of the order calculated from the order creation side in kg(s). Example: `10`
- **source.type** (string): Source of order. Possible values: [`funnel`, `website`, `invoice`, `calendar`, `text2Pay`, `document_contracts`, `membership`, `mobile_app`, `communities`, `point_of_sale`, `manual`, `form`, `survey`, `payment_link`, `external`]
- **products** (object[]): An array of price IDs and quantity.
    - **products.id** (string): id of product
    - **products.qty** (number): No of quantities

### 7. OPTIONAL PARAMETERS
- **address** (object): Address of the customer
    - **address.name** (string): Name of the customer. Example: `John Doe`
    - **address.companyName** (string): Name of the Company. Example: `ABC Company`
    - **address.addressLine1** (string): Address line 1 of the customer. Example: `123 Main St.`
    - **address.state** (string): State code of the customer. Possible values: [`AL`, `AK`, `AS`, ..., `TT`]
    - **address.city** (string): City of the customer. Example: `New York`
    - **address.zip** (string): Zip code of the customer. Example: `12345`
    - **address.phone** (string): Phone number of the customer. Example: `1234567890`
    - **address.email** (string): Email of the customer. Example: `abu@example.com`
- **amountAvailable** (string): It will not calculate the order amount from backend if it is true. Possible values: [`AF`, `AX`, `AL`, ..., `ZW`] (Note: The description implies a boolean, but possible values are country codes and example is a country code, which is conflicting). Example: `US`
- **weightAvailable** (boolean): Flag to pass when the weight is already calculated and should not calculate again. Example: `true`
- **source.subType** (string): Source subtype of order. Possible values: [`one_step_order_form`, `two_step_order_form`, `upsell`, ..., `qr_code`]
- **couponCode** (string): Coupon code. Example: `TEST`

### 8. AUTHENTICATION
Not explicitly specified, but error responses indicate token-based authorization (e.g., `Invalid token: access token is invalid`). No specific scopes mentioned.

### 9. RESPONSE FORMAT
**Successful Response (201 Created)**
- **Content-Type**: `application/json`
- **Schema**:
    - `status` (boolean): Status of api action. Example: `true`
    - `message` (string): Success message. Example: `Successfully created`
    - `data` (object[]): Shipping rate data
        - `name` (string): Name of the shipping zone. Example: `North zone`
        - `description` (string): Delivery description. Example: `Ships next day`
        - `currency` (string): The currency of the amount of the rate / handling fee. Example: `USD`
        - `amount` (number): The amount of the shipping rate if it is normal rate (0 means free). Fixed Handling fee if it is a carrier rate (it will add to the carrier rate). Example: `99.99`
        - `isCarrierRate` (boolean): is this a carrier rate. Example: `true`
        - `shippingCarrierId` (string): Shipping carrier id. Example: `655b33a82209e60b6adb87a5`
        - `percentageOfRateFee` (number): Percentage of rate fee if it is a carrier rate. Example: `10.99`
        - `shippingCarrierServices` (object[]): An array of items
            - `name` (string): Name of the shipping carrier service. Example: `Priority Mail Express International`
            - `value` (string): Value of the shipping carrier service. Example: `PriorityMailExpressInternational`
        - `_id` (string): The unique identifier for the product. Example: `655b33a82209e60b6adb87a5`
        - `shippingZoneId` (string): The unique identifier for the shipping zone. Example: `655b33a82209e60b6adb87a5`

### 10. PURPOSE
This endpoint returns available shipping rates for a specified country based on the order amount and other provided customer and order details.
