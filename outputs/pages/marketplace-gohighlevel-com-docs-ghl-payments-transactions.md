# Transactions
Documentation for payments API
## [📄️ List TransactionsThe 'List Transactions' API allows to retrieve a paginated list of transactions. Customize your results by filtering transactions based on name, alt type, transaction status, payment mode, date range, type of source, contact, subscription id, entity id or paginate through the list using the provided query parameters. This endpoint provides a straightforward way to explore and retrieve transaction information.](https://marketplace.gohighlevel.com/docs/ghl/payments/list-transactions)## [📄️ Get Transaction by IDThe 'Get Transaction by ID' API allows to retrieve information for a specific transaction using its unique identifier. Use this endpoint to fetch details for a single transaction based on the provided transaction ID.](https://marketplace.gohighlevel.com/docs/ghl/payments/get-transaction-by-id)
