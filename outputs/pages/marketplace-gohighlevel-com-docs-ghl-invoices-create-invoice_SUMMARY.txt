Here's a structured summary of the "Create Invoice" API documentation:

---

### 1. ENDPOINT NAME:
Create Invoice

### 2. CATEGORY:
Invoice

### 3. HTTP METHOD:
POST

### 4. ENDPOINT URL:
`/invoices/`

### 5. FULL URL:
`https://services.leadconnectorhq.com/invoices/`

### 6. REQUIRED PARAMETERS:

*   **Header Parameters:**
    *   `Version` (string): API Version
        *   Possible values: [`2021-07-28`]

*   **Body Parameters:**
    *   `altId` (string): location Id / company Id based on altType
    *   `altType` (string): Alt Type
        *   Possible values: [`location`]
    *   `name` (string): Invoice Name
    *   `businessDetails` (object): Business Details (if this object is provided, `name` is required)
        *   `name` (string): Business Name
    *   `currency` (string): Currency code (for the overall invoice)
    *   `items` (object[]): An array of items for the invoice. (At least one item is required, and each item object requires the following fields)
        *   `name` (string): Invoice Item Name
        *   `currency` (string): Currency (for the item)
        *   `amount` (number): Product amount
        *   `qty` (number): Product Quantity
        *   `taxes` (object[]): Tax (if this array is provided for an item, each tax object requires the following fields)
            *   `_id` (string)
            *   `name` (string)
            *   `rate` (number)
    *   `discount` (object): Discount (this object is required)
        *   `type` (string): Discount type
            *   Possible values: [`percentage`, `fixed`]
    *   `contactDetails` (object): Contact information to send the invoice to (if this object is provided, the following fields are required)
        *   `id` (string): Contact ID
        *   `name` (string): Contact Name
        *   `phoneNo` (string): Contact Phone Number
        *   `email` (string): Contact Email
    *   `issueDate` (string): Issue date in YYYY-MM-DD format
    *   `sentTo` (object): (this object is required)
        *   `email` (string[]): Email Address
    *   `liveMode` (boolean)
    *   `lateFeesConfiguration` (object): late fees configuration (if this object is provided, the following fields are required)
        *   `enable` (boolean): Enable late fees
        *   `value` (number): Late Fees Value
        *   `type` (string): Late Fees Type
            *   Possible values: [`fixed`, `percentage`]
        *   `frequency` (object): Late Fees Frequency (if `lateFeesConfiguration` is provided, `frequency` is required)
            *   `intervalCount` (number): Late fees interval count
            *   `interval` (string): Late fees interval
                *   Possible values: [`minute`, `hour`, `day`, `week`, `month`, `one_time`]
    *   `tipsConfiguration` (object): tips configuration for the invoice (if this object is provided, the following fields are required)
        *   `tipsPercentage` (number[]): Percentage of tips allowed
        *   `tipsEnabled` (boolean): Tips enabled status
    *   `paymentMethods` (object): Payment Methods for Invoices (if this object is provided, `stripe` is required)
        *   `stripe` (object): Payment Method (if `paymentMethods` is provided, `stripe` is required)
            *   `enableBankDebitOnly` (boolean): Enable Bank Debit Only
    *   `miscellaneousCharges` (object): miscellaneous charges for the invoice (if this object is provided, the following fields are required)
        *   `charges` (array[]): charges for the processing fee (The array itself is required, item schema not detailed)
        *   `paidCharges` (object[]): paid miscellaneous charges (if `miscellaneousCharges` is provided, `paidCharges` is required. Each object in this array requires:)
            *   `name` (string): name of the processing fee
            *   `charge` (number): charge for the processing fee
            *   `amount` (number): amount of the processing fee
            *   `_id` (string): id of the processing fee

### 7. OPTIONAL PARAMETERS:

*   **Body Parameters:**
    *   `businessDetails` (object): Business Details
        *   `logoUrl` (string): Business Logo URL
        *   `phoneNo` (string): Business Phone Number
        *   `address` (object): Business Address
            *   `addressLine1` (string): Address Line 1
            *   `addressLine2` (string): Address Line 2
            *   `city` (string): City
            *   `state` (string): State
            *   `countryCode` (string): Country Code
            *   `postalCode` (string): Postal Code
        *   `website` (string): Business Website Link
        *   `customValues` (string[]): Custom Values
    *   `items` (object[]): An array of items for the invoice. (Optional fields for each item object)
        *   `description` (string): Invoice descriptions
        *   `productId` (string): Product Id
        *   `priceId` (string): Price Id
        *   `taxes` (object[]): Tax (Optional fields for each tax object if the `taxes` array is provided)
            *   `calculation` (string):
                *   Possible values: [`exclusive`]
            *   `description` (string)
            *   `taxId` (string)
        *   `automaticTaxCategoryId` (string): Tax category id for calculating automatic tax
        *   `isSetupFeeItem` (boolean): Setupfee item, only created when 1st invoice of recurring schedule is generated
        *   `type` (string): Price type of the item
            *   Possible values: [`one_time`, `recurring`]
        *   `taxInclusive` (boolean): true if item amount is tax inclusive (Default: `false`)
    *   `discount` (object): Discount
        *   `value` (number): Discount Value (Default: `0`)
        *   `validOnProductIds` (string[]): Product Ids on which discount is applicable
    *   `termsNotes` (string): Terms notes, Also supports HTML markups
    *   `title` (string): Title for the invoice
    *   `contactDetails` (object): Contact information to send the invoice to (optional object)
        *   `additionalEmails` (object[]): Secondary email addresses for the contact to be saved (if provided, each object requires `email`)
            *   `email` (string)
        *   `companyName` (string): Contact Company Name
        *   `address` (object):
            *   `addressLine1` (string): Address Line 1
            *   `addressLine2` (string): Address Line 2
            *   `city` (string): City
            *   `state` (string): State
            *   `countryCode` (string): Country Code
            *   `postalCode` (string): Postal Code
        *   `customFields` (string[]): Custom Values
    *   `invoiceNumber` (string): Invoice Number
    *   `dueDate` (string): Due date in YYYY-MM-DD format
    *   `sentTo` (object):
        *   `emailCc` (string[]): cc to be kept in any sent out emails
        *   `emailBcc` (string[]): bcc to be kept in any sent out emails
        *   `phoneNo` (string[]): Contact Phone Number
    *   `automaticTaxesEnabled` (boolean): Automatic taxes enabled for the Invoice
    *   `paymentSchedule` (object): split invoice into payment schedule summing up to full invoice amount (if this object is provided, `type` and `schedules` are required)
        *   `type` (string): Payment schedule type
            *   Possible values: [`fixed`, `percentage`]
        *   `schedules` (string[]): payment schedule item
    *   `lateFeesConfiguration` (object): late fees configuration
        *   `grace` (object): Late Fees Grace
            *   `intervalCount` (number): Late fees grace interval count
            *   `interval` (string): Late fees grace interval
                *   Possible values: [`day`]
        *   `maxLateFees` (object): Max late fees payable
            *   `type` (string):
                *   Possible values: [`fixed`]
            *   `value` (number): Max late fees to pay
    *   `invoiceNumberPrefix` (string): prefix for invoice number
    *   `attachments` (object[]): attachments for the invoice (if this array is provided, each object requires the following fields)
        *   `id` (string): Id of the file selected
        *   `name` (string): Name of the file
        *   `url` (string): URL of the file
        *   `type` (string): Type of the file
        *   `size` (number): Size of the file
    *   `miscellaneousCharges` (object): miscellaneous charges for the invoice
        *   `collectedMiscellaneousCharges` (number): collected miscellaneous charges

### 8. AUTHENTICATION:

*   **Scope(s)**: `invoices.write`
*   **Auth Method(s)**: `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s)**: `Sub-Account Token`, `Agency Token`
*   **Scheme**: `bearer`
*   **Bearer Format**: `JWT`
*   **In**: `header`

### 9. RESPONSE FORMAT (200 OK):

*   **Status Code**: `200`
*   **Content Type**: `application/json`
*   **Schema**:
    *   `_id` (string): Invoice Id
    *   `status` (string): Invoice Status
        *   Possible values: [`draft`, `sent`, `payment_processing`, `paid`, `void`, `partially_paid`]
    *   `liveMode` (boolean): Live Mode
    *   `amountPaid` (number): Amount Paid
    *   `altId` (string): Location Id or Agency Id
    *   `altType` (string):
        *   Possible values: [`location`]
    *   `name` (string): Name of the invoice
    *   `businessDetails` (object): Business Details
    *   `invoiceNumber` (number): Invoice Number
    *   `currency` (string): Currency
    *   `contactDetails` (object): Contact Details
    *   `issueDate` (string): Issue date in YYYY-MM-DD format
    *   `dueDate` (string): Due date in YYYY-MM-DD format
    *   `discount` (object): Discount
    *   `invoiceItems` (object[]): Invoice Items
    *   `total` (number): Total Amount
    *   `title` (string): Title
    *   `amountDue` (number): Total Amount Due
    *   `createdAt` (string): created at
    *   `updatedAt` (string): updated at
    *   `automaticTaxesEnabled` (boolean): Automatic taxes enabled for the Invoice
    *   `automaticTaxesCalculated` (boolean): Is Automatic taxes calculated for the Invoice items
    *   `paymentSchedule` (object): split invoice into payment schedule summing up to full invoice amount
