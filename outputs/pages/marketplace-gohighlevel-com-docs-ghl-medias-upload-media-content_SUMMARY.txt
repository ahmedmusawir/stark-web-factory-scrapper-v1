Here is a structured summary of the API documentation:

### 1. ENDPOINT NAME:
Upload File into Media Storage

### 2. CATEGORY:
Media Storage

### 3. HTTP METHOD:
POST

### 4. ENDPOINT URL:
`/medias/upload-file`

### 5. FULL URL:
`https://services.leadconnectorhq.com/medias/upload-file`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters:**
    *   Version (string): API Version. Possible values: [`2021-07-28`]
*   **Body Parameters (multipart/form-data):**
    *   hosted (boolean): Required. Determines whether `fileUrl` or `file` is required.
    *   file (binary): Conditionally required. If `hosted` is `false`, this parameter is required. Maximum allowed size is 25 MB.
    *   fileUrl (string): Conditionally required. If `hosted` is `true`, this parameter is required.

### 7. OPTIONAL PARAMETERS:
*   **Body Parameters (multipart/form-data):**
    *   name (string): Name of the file.
    *   parentId (string): ID of the parent folder where the file should be uploaded.

### 8. AUTHENTICATION:
*   **Scope(s)**: `medias.write`
*   **Auth Method(s)**: `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s)**: `Sub-Account Token`
*   **Scheme**: `bearer` (JWT)
*   **In**: `header` (Authorization)

### 9. RESPONSE FORMAT:
*   **Status Code**: `200` (Successful response)
*   **Content Type**: `application/json`
*   **Schema**:
    *   fileId (string, required): ID of the uploaded file.
    *   url (string, required): Google Cloud Storage URL of the uploaded file.
*   **Example**:
    ```json
    {"fileId":"file.pdf","url":"https://storage.googleapis.com/bucket-name/path/to/file.pdf"}
    ```

### 10. PURPOSE:
This endpoint allows users to upload a file into the HighLevel Media Storage by providing either the file directly or a URL if it's hosted externally.
