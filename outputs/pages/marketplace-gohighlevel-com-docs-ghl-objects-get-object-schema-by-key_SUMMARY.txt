## STRUCTURED API DOCUMENTATION SUMMARY

1.  **ENDPOINT NAME**: Get Object Schema by key / id

2.  **CATEGORY**: Objects / Object Schema

3.  **HTTP METHOD**: GET

4.  **ENDPOINT URL**: `/objects/:key`

5.  **FULL URL**: `https://services.leadconnectorhq.com/objects/:key`

6.  **REQUIRED PARAMETERS**:
    *   **key** (string): key of the custom or standard object. For custom objects, the key must include the prefix “custom_objects.”. This key can be found on the Object Details page under Settings in the UI.
    *   **Version** (string): API Version (Possible values: `2021-07-28`)
    *   **locationId** (string): location id of the sub account

7.  **OPTIONAL PARAMETERS**:
    *   **fetchProperties** (string): Fetch Properties, Fetches all the standard / custom fields of the object when set to true

8.  **AUTHENTICATION**:
    *   **Scope(s)**: `objects/schema.readonly`
    *   **Auth Method(s)**: `OAuth Access Token`, `Private Integration Token`
    *   **Token Type(s)**: `Sub-Account Token`
    *   **Scheme**: Bearer (JWT)
    *   **In**: header
    *   **Description**: Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account.
