Here's a structured summary of the API documentation for "Update Shipping Rate":

### 1. ENDPOINT NAME:
Update Shipping Rate

### 2. CATEGORY:
Store (specifically Shipping Zone Rates)

### 3. HTTP METHOD:
PUT

### 4. ENDPOINT URL:
`/store/shipping-zone/:shippingZoneId/shipping-rate/:shippingRateId`

### 5. FULL URL:
`https://services.leadconnectorhq.com/store/shipping-zone/:shippingZoneId/shipping-rate/:shippingRateId`

### 6. REQUIRED PARAMETERS:

*   **Path Parameters:**
    *   shippingZoneId (string): ID of the shipping zone
    *   shippingRateId (string): ID of the shipping rate that needs to be returned
*   **Body Parameters:**
    *   altId (string): Location Id or Agency Id
    *   altType (string): Possible values: [`location`]
    *   name (string): Name of the shipping zone
    *   currency (string): The currency of the amount of the rate / handling fee
    *   amount (number): The amount of the shipping rate if it is normal rate (0 means free). Fixed Handling fee if it is a carrier rate (it will add to the carrier rate).
    *   conditionType (string): Type of condition to provide the conditional pricing. Possible values: [`none`, `price`, `weight`]
    *   minCondition (number): Minimum condition for applying this price. set 0 or null if there is no minimum
    *   maxCondition (number): Maximum condition for applying this price. set 0 or null if there is no maximum
    *   shippingCarrierId (string): Shipping carrier id
    *   shippingCarrierServices (object[]): An array of items
        *   name (string): Name of the shipping carrier service
        *   value (string): Value of the shipping carrier service

### 7. OPTIONAL PARAMETERS:

*   **Body Parameters:**
    *   description (string): Delivery description
    *   isCarrierRate (boolean): is this a carrier rate
    *   percentageOfRateFee (number): Percentage of rate fee if it is a carrier rate.

### 8. AUTHENTICATION:

*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** `bearer`
*   **Bearer Format:** `JWT`
*   **In:** `header`
*   **Description:** `Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account.`
