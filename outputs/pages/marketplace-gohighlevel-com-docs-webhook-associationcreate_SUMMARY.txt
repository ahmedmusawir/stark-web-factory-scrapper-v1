### 6. REQUIRED PARAMETERS (Webhook Payload Fields):
The webhook payload is a JSON object with the following fields, all of which are expected to be present in the received webhook:
*   `id` (string): Unique identifier for the association.
*   `associationType` (string): Specifies the type of association (e.g., `USER_DEFINED` or `SYSTEM_DEFINED`).
*   `firstObjectKey` (string): Key representing the first object in the association.
*   `firstObjectLabel` (string): Readable label for the first object.
*   `secondObjectKey` (string): Key representing the second object in the association.
*   `secondObjectLabel` (string): Readable label for the second object.
*   `key` (string): Unique key assigned to the association.
*   `locationId` (string): Identifies the location associated with the created association.
