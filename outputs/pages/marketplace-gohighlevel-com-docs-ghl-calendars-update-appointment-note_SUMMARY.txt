## STRUCTURED SUMMARY

### 1. ENDPOINT NAME:
Update Note

### 2. CATEGORY:
Calendars

### 3. HTTP METHOD:
PUT

### 4. ENDPOINT URL:
`/calendars/appointments/:appointmentId/notes/:noteId`

### 5. FULL URL:
`https://services.leadconnectorhq.com/calendars/appointments/:appointmentId/notes/:noteId`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters:**
    *   Version (string): API Version. Possible values: [`2021-04-15`]
*   **Path Parameters:**
    *   appointmentId (string): Appointment ID
    *   noteId (string): Note ID (Inferred from URL path)
*   **Body Parameters:**
    *   body (string): Note body. Possible values: `<= 5000 characters`

### 7. OPTIONAL PARAMETERS:
*   **Body Parameters:**
    *   userId (string): ID of the user associated with the note. Example: `GCs5KuzPqTls7vWclkEV`

### 8. AUTHENTICATION:
*   Scope(s): `calendars/events.write`
*   Auth Method(s): `OAuth Access Token`, `Private Integration Token`
*   Token Type(s): `Sub-Account Token`
*   Scheme: `bearer`
*   Bearer Format: `JWT`
*   In: `header`
*   Description: Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account.

    *   Content Type: `application/json`
