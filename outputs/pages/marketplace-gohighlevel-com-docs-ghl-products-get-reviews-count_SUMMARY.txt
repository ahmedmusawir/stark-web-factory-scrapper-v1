Here's a structured summary of the API documentation:

---

### 1. ENDPOINT NAME:
Fetch Review Count as per status

### 2. CATEGORY:
Reviews (Products)

### 3. HTTP METHOD:
GET

### 4. ENDPOINT URL:
`/products/reviews/count`

### 5. FULL URL:
`https://services.leadconnectorhq.com/products/reviews/count`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters:**
    *   Version (string): API Version. Possible values: `2021-07-28`
*   **Query Parameters:**
    *   altId (string): Location Id or Agency Id. Example: `6578278e879ad2646715ba9c`
    *   altType (string): Possible values: `location`

### 7. OPTIONAL PARAMETERS:
*   **Query Parameters:**
    *   rating (number): Key to filter the ratings. Example: `4`
    *   startDate (string): The start date for filtering reviews. Example: `2023-01-01T00:00:00Z`
    *   endDate (string): The end date for filtering reviews. Example: `2023-12-31T23:59:59Z`
    *   productId (string): Comma-separated list of product IDs. Example: `60d21b4667d0d8992e610c88,60d21b4667d0d8992e610c89,60d21b4667d0d8992e610c8a`
    *   storeId (string): Comma-separated list of store IDs. Example: `60d21b4667d0d8992e610c85,60d21b4667d0d8992e610c86,60d21b4667d0d8992e610c87`

### 8. AUTHENTICATION:
*   **Required Scopes:** `products.readonly`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`, `Bearer`
*   **Token Type(s):** `Sub-Account Token`, `JWT` (for Bearer)

### 9. RESPONSE FORMAT:
*   **Successful Response (200 OK):**
    *   **Content Type:** `application/json`
    *   **Schema:**
        ```json
        {
          "data": [
            [null] // Array of review status counts (as per 'data' description)
          ]
        }
        ```
    *   **Description:** JSON object containing a `data` array, which is an array of review status counts.

*   **Error Responses:**
    *   **400 Bad Request:** `{"statusCode":400,"message":"Bad Request"}`
    *   **401 Unauthorized:** `{"statusCode":401,"message":"Invalid token: access token is invalid","error":"Unauthorized"}`
    *   **422 Unprocessable Entity:** `{"statusCode":422,"message":["Unprocessable Entity"],"error":"Unprocessable Entity"}`

### 10. PURPOSE:
API to fetch the Review Count as per status.
