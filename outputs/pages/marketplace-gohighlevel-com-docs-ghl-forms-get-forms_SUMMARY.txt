Here is a structured summary of the provided API documentation for "Get Forms":

### 1. ENDPOINT NAME:
Get Forms

### 2. CATEGORY:
Forms

### 3. HTTP METHOD:
GET

### 4. ENDPOINT URL:
`/forms/`

### 5. FULL URL:
`https://services.leadconnectorhq.com/forms/`

### 6. REQUIRED PARAMETERS:
*   `Version` (string): API Version. Possible values: `[2021-07-28]` (Header Parameter)
*   `locationId` (string): Example: `ve9EPM428h8vShlRW1KT` (Query Parameter)

### 7. OPTIONAL PARAMETERS:
*   `skip` (number): Example: `0` (Query Parameter)
*   `limit` (number): Limit Per Page records count. Will allow maximum up to 50 and default will be 10. Default value: `10`. Example: `20` (Query Parameter)
*   `type` (string): Example: `folder` (Query Parameter)

### 8. AUTHENTICATION:
*   **Scope(s):** `forms.readonly`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** `bearer` (JWT)
*   **In:** `header`

### 9. RESPONSE FORMAT:
*   **Successful Response (200 OK):**
    *   **Content Type:** `application/json`
    *   **Schema:**
        *   `forms` (array of objects):
            *   `id` (string): Unique identifier for the form. Example: `YSWdvS4Is98wtIDGnpmI`
            *   `name` (string): Name of the form. Example: `Form 1`
            *   `locationId` (string): The ID of the location (sub-account) the form belongs to. Example: `ve9EPM428h8vShlRW1KT`
        *   `total` (number): Total number of forms. Example: `20`
    *   **Example:**
        ```json
        {"forms":[{"id":"YSWdvS4Is98wtIDGnpmI","name":"Form 1","locationId":"ve9EPM428h8vShlRW1KT"}],"total":"20"}
        ```
*   **Error Responses:**
    *   **400 Bad Request:**
        *   **Schema:** `statusCode` (number), `message` (string)
        *   **Example:** `{"statusCode":400,"message":"Bad Request"}`
    *   **401 Unauthorized:**
        *   **Schema:** `statusCode` (number), `message` (string), `error` (string)
        *   **Example:** `{"statusCode":401,"message":"Invalid token: access token is invalid","error":"Unauthorized"}`

### 10. PURPOSE:
This endpoint allows users to retrieve a paginated list of forms associated with a specific location (sub-account).
