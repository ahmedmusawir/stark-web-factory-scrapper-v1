Here's a structured summary of the API documentation for "Preview Estimate Template":

### 1. ENDPOINT NAME:
Preview Estimate Template

### 2. CATEGORY:
Invoice / Estimate

### 3. HTTP METHOD:
GET

### 4. ENDPOINT URL:
`/invoices/estimate/template/preview`

### 5. FULL URL:
`https://services.leadconnectorhq.com/invoices/estimate/template/preview`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters:**
    *   `Version` (string): API Version. Possible values: `2021-07-28`.
*   **Query Parameters:**
    *   `altId` (string): Location Id or Agency Id. Example: `6578278e879ad2646715ba9c`.
    *   `altType` (string): Possible values: `location`.
    *   `templateId` (string): Template Id. Example: `5f9d6d8b1b2d2c001f2d9e4b`.

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:
*   **Scope(s)**: `invoices/estimate.readonly`
*   **Auth Method(s)**: `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s)**: `Sub-Account Token`, `Agency Token`
*   **Scheme**: `bearer`
*   **Bearer Format**: `JWT`
*   **In**: `header`

### 9. RESPONSE FORMAT:
*   **Status Code**: `200`
*   **Content Type**: `application/json`
*   **Schema**:
    *   `altId` (string): Location Id or Agency Id.
    *   `altType` (string): Possible values: [`location`].
    *   `_id` (string): Unique identifier.
    *   `liveMode` (boolean): Indicates if it is in live mode.
    *   `deleted` (boolean): Indicates if deleted.
    *   `name` (string): Name.
    *   `currency` (string): Currency code.
    *   `businessDetails` (object): Business details associated with the estimate.
        *   `logoUrl` (string)
        *   `name` (string)
        *   `address` (object): `addressLine1`, `city`, `state`, `countryCode`, `postalCode`
        *   `phoneNo` (string)
        *   `website` (string)
        *   `customValues` (array of objects): `name`, `fieldKey`, `id`, `value`
    *   `items` (array of objects): An array of items.
        *   `taxes` (array)
        *   `taxInclusive` (boolean)
        *   `_id` (string)
        *   `description` (string)
        *   `currency` (string)
        *   `productId` (string)
        *   `priceId` (string)
        *   `amount` (number)
        *   `qty` (number)
        *   `name` (string)
        *   `type` (string): `one_time` or `recurring`
    *   `discount` (object, optional): Discount details for the estimate template.
        *   `value` (number): Discount Value. Default: `0`.
        *   `type` (string): Discount type. Possible values: [`percentage`, `fixed`]. Default: `percentage`.
        *   `validOnProductIds` (array of string): Product Ids on which discount is applicable.
    *   `title` (string): Title.
    *   `estimateNumberPrefix` (string): Estimate number prefix.
    *   `attachments` (array of objects): Attachments.
        *   `id` (string): Id of the file selected.
        *   `name` (string): Name of the file.
        *   `url` (string): URL of the file.
        *   `type` (string): Type of the file.
        *   `size` (number): Size of the file.
    *   `updatedBy` (string): User Id of who last updated.
    *   `total` (number): Total amount.
    *   `createdAt` (date-time): Timestamp when created.
    *   `updatedAt` (date-time): Timestamp when last updated.
    *   `__v` (number): Version number.
    *   `automaticTaxesEnabled` (boolean): Indicates if automatic taxes are enabled for this estimate.
    *   `termsNotes` (string): Terms and conditions for the estimate, supports HTML markup.

### 10. PURPOSE:
Get a preview of an estimate template.

Estimate, Template, Preview, Invoice, Get, Read, GHL, HighLevel
