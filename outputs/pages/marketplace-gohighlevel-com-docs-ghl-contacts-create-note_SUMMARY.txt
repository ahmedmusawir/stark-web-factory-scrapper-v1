Here is the structured summary of the API documentation for "Create Note":

### 1. ENDPOINT NAME
Create Note

### 2. CATEGORY
Contacts

### 3. HTTP METHOD
POST

### 4. ENDPOINT URL
`/contacts/:contactId/notes`

### 5. FULL URL
`https://services.leadconnectorhq.com/contacts/:contactId/notes`

### 6. REQUIRED PARAMETERS

*   **Header Parameters:**
    *   `Version` (string): API Version. Possible values: `2021-07-28`
*   **Path Parameters:**
    *   `contactId` (string): Contact Id. Example: `sx6wyHhbFdRXh302LLNR`
*   **Body Parameters (application/json):**
    *   `body` (string): The content of the note. Example: `lorem ipsum`

### 7. OPTIONAL PARAMETERS

*   **Body Parameters (application/json):**
    *   `userId` (string): The ID of the user creating the note. Example: `GCs5KuzPqTls7vWclkEV`

### 8. AUTHENTICATION

*   **Scope(s):** `contacts.write`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Bearer Format:** `JWT`
*   **In:** `header` (specifically the `Authorization` header)
*   **Description:** Use the Access Token generated with user type as Sub-Account OR Private Integration Token of Sub-Account.

### 9. RESPONSE FORMAT

*   **Status Code:** `201 Created`
*   **Content Type:** `application/json`
*   **Schema:** An object containing a `note` object.
    *   `note` (object):
        *   `id` (string): The unique identifier of the created note. Example: `HGPcayliwcdoUFzvbTok`
        *   `body` (string): The content of the note. Example: `lorem ipsum`
        *   `userId` (string): The ID of the user who created the note. Example: `TUcmRxWrjqzJS8EjkxNK`
        *   `dateAdded` (string): The timestamp when the note was added (ISO 8601 format). Example: `2021-07-08T12:02:11.285Z`
        *   `contactId` (string): The ID of the contact to which the note belongs. Example: `TUcmRxWrjqzJS8EjkxNK`
*   **Example (201):**
    ```json
    {
      "note": {
        "id": "HGPcayliwcdoUFzvbTok",
        "body": "lorem ipsum",
        "userId": "TUcmRxWrjqzJS8EjkxNK",
        "dateAdded": "2021-07-08T12:02:11.285Z",
        "contactId": "TUcmRxWrjqzJS8EjkxNK"
      }
    }
    ```
*   **Error Responses (examples provided):**
    *   `400 Bad Request`
    *   `401 Unauthorized`
    *   `422 Unprocessable Entity`

### 10. PURPOSE
This endpoint allows you to create a new note and associate it with a specific contact in the system.
