### 6. REQUIRED PARAMETERS:
This section describes the fields present in the **webhook payload**. All fields listed in the schema are part of the payload sent by HighLevel when a task is deleted. The documentation does not explicitly mark any fields as optional within the webhook payload itself.

*   **type** (string): The type of the webhook event. Always "TaskDelete".
*   **locationId** (string): The ID of the location (sub-account) where the task was deleted.
*   **id** (string): The unique ID of the deleted task.
*   **assignedTo** (string): The ID of the user to whom the task was assigned.
*   **body** (string): The detailed description or body of the deleted task.
*   **contactId** (string): The ID of the contact associated with the deleted task.
*   **title** (string): The title of the deleted task.
*   **dateAdded** (string): The date and time when the task was originally added (ISO 8601 format, e.g., "2021-11-26T12:41:02.193Z").
*   **dueDate** (string): The due date and time of the deleted task (ISO 8601 format, e.g., "2021-11-26T12:41:02.193Z").
