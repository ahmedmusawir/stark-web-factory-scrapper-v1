Here's a structured summary of the API documentation for "Create Agent Action":

---

### 1. ENDPOINT NAME:
Create Agent Action

### 2. CATEGORY:
Voice AI

### 3. HTTP METHOD:
POST

### 4. ENDPOINT URL:
`/voice-ai/actions`

### 5. FULL URL:
`https://services.leadconnectorhq.com/voice-ai/actions`

### 6. REQUIRED PARAMETERS:

*   **Header Parameters:**
    *   `Version` (string): API Version. Possible value: `2021-04-15`

*   **Body Parameters:**
    *   `agentId` (string): Agent ID to attach the action to.
    *   `locationId` (string): Location ID.
    *   `actionType` (string): Type of action. Possible values: `CALL_TRANSFER`, `DATA_EXTRACTION`, `IN_CALL_DATA_EXTRACTION`, `WORKFLOW_TRIGGER`, `SMS`, `APPOINTMENT_BOOKING`, `CUSTOM_ACTION`, `KNOWLEDGE_BASE`.
    *   `name` (string): Human-readable name for this action.
    *   `actionParameters` (object): Action parameters - structure varies by `actionType`.

    **Parameters within `actionParameters` (dependent on `actionType`):**

    *   **If `actionType` is `CALL_TRANSFER` (CallTransferActionParameters):**
        *   `triggerPrompt` (string): When to trigger this action during the call.
        *   `transferToType` (string): Type of transfer destination (currently only "number" is supported). Possible values: `number`.
        *   `transferToValue` (string): Phone number to transfer to. Must start with +, include country code, contain only numbers, and be 11-16 characters long.
        *   `triggerMessage` (string): Message to tell the caller before transferring.

    *   **If `actionType` is `DATA_EXTRACTION` (DataExtractionActionParameters):**
        *   `contactFieldId` (string): ID of the contact field to be updated with the extracted data.
        *   `description` (string): Description of what data to extract.
        *   `examples` (string[]): Example values to help Agent understand the expected format. At least one example is required, maximum 5 examples allowed.

    *   **If `actionType` is `IN_CALL_DATA_EXTRACTION` (InCallDataExtractionActionParameters):**
        *   `contactFieldId` (string): ID of the contact field to be updated with the extracted data.
        *   `description` (string): Description of what data to extract.
        *   `examples` (string[]): Example values to help Agent understand the expected format. At least one example is required, maximum 5 examples allowed.

    *   **If `actionType` is `WORKFLOW_TRIGGER` (WorkflowTriggerParameters):**
        *   `triggerPrompt` (string): When to trigger this workflow.
        *   `triggerMessage` (string): Message to tell the caller.
        *   `workflowId` (string): Workflow ID to trigger.

    *   **If `actionType` is `SMS` (SMSParameters):**
        *   `triggerPrompt` (string): When to send the SMS.
        *   `triggerMessage` (string): Message to tell the caller.
        *   `messageBody` (string): SMS message content to send.

    *   **If `actionType` is `APPOINTMENT_BOOKING` (AppointmentBookingActionParameters):**
        *   `calendarId` (string): Calendar ID to book appointments in.
        *   `daysOfOfferingDates` (number): Number of days ahead to offer booking dates.
        *   `slotsPerDay` (number): Number of available slots per day.
        *   `hoursBetweenSlots` (number): Hours between available slots.

    *   **If `actionType` is `CUSTOM_ACTION` (CustomActionParameters):**
        *   `triggerPrompt` (string): When to call the custom API.
        *   `triggerMessage` (string): Message to tell the caller.
        *   `apiDetails` (object): API endpoint configuration.
            *   `url` (string): API endpoint URL.
            *   `method` (string): HTTP method. Possible values: `POST`, `GET`.
        *   **Required fields within `apiDetails.headers` (if included):**
            *   `key` (string): HTTP header name.
            *   `value` (string): HTTP header value.
        *   **Required fields within `apiDetails.parameters` (if included):**
            *   `name` (string): Parameter name.

    *   **If `actionType` is `KNOWLEDGE_BASE` (KnowledgeBaseParameters):**
        *   `triggerPrompt` (string): When to query the knowledge base.
        *   `knowledgeBaseId` (string): Knowledge base ID to query.

### 7. OPTIONAL PARAMETERS:

*   **Body Parameters:**

    *   **If `actionType` is `CALL_TRANSFER` (CallTransferActionParameters):**
        *   `hearWhisperMessage` (boolean): Whether to play whisper message to the receiving party. Default example: `true`.

    *   **If `actionType` is `DATA_EXTRACTION` (DataExtractionActionParameters):**
        *   `overwriteExistingValue` (boolean): Whether to overwrite existing field value if already set. Default value: `false`.

    *   **If `actionType` is `IN_CALL_DATA_EXTRACTION` (InCallDataExtractionActionParameters):**
        *   `overwriteExistingValue` (boolean): Whether to overwrite existing field value if already set. Default value: `false`.

    *   **If `actionType` is `CUSTOM_ACTION` (CustomActionParameters):**
        *   `apiDetails.authenticationRequired` (boolean): Whether authentication is required.
        *   `apiDetails.authenticationValue` (string): Authentication token or API key (required if `authenticationRequired` is `true`).
        *   `apiDetails.headers` (object[]): HTTP headers to include (array of objects, each with `key` and `value`).
        *   `apiDetails.parameters` (object[]): API parameters to send (array of objects, each with `name`, `description`, `type`, `example`).
            *   `description` (string): Parameter description.
            *   `type` (string): Parameter type.
            *   `example` (string): Example parameter value.
        *   `apiDetails.selectedPaths` (string[]): Selected response paths to extract from API response. Required: at least 1 value if the method is `GET`. Should be empty if the method is `POST`.

### 8. AUTHENTICATION:

*   **Required Scope(s):** `voice-ai-agent-goals.write`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** Bearer
*   **Bearer Format:** JWT
*   **In:** Header (Authorization header)

### 9. RESPONSE FORMAT:

*   **Status Code:** `201 Created`
*   **Content Type:** `application/json`
*   **Schema:**
    *   `id` (string): Unique identifier for the created action.
    *   `actionType` (string): Type of action.
    *   `name` (string): Human-readable name for this action.
    *   `actionParameters` (object): Action parameters - structure varies by `actionType` (reflecting the specific action type's parameters as detailed in the request body).
*   **Example (for CALL_TRANSFER):**
    ```json
    {
      "id": "507f1f77bcf86cd799439011",
      "actionType": "CALL_TRANSFER",
      "name": "Transfer to Manager",
      "actionParameters": {
        "triggerPrompt": "When the caller asks to speak to a manager",
        "transferToType": "number",
        "transferToValue": "+12345678901",
        "triggerMessage": "Let me transfer you to a manager right away",
        "hearWhisperMessage": true
      }
    }
    ```
*   **Error Responses:**
    *   `400 Bad Request` (`statusCode`, `message`)
    *   `401 Unauthorized` (`statusCode`, `message`, `error`)
    *   `422 Unprocessable Entity` (`statusCode`, `message`, `error`)

### 10. PURPOSE:
This endpoint creates a new action for a voice AI agent, defining specific behaviors and capabilities for the agent during calls based on the specified action type and parameters.
