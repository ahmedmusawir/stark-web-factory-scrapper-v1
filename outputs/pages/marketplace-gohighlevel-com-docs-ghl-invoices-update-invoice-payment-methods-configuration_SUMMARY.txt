Here's a structured summary of the provided API documentation:

### 1. ENDPOINT NAME:
Update Template Payment Methods Configuration

### 2. CATEGORY:
Invoice Template

### 3. HTTP METHOD:
PATCH

### 4. ENDPOINT URL:
`/invoices/template/:templateId/payment-methods-configuration`

### 5. FULL URL:
`https://services.leadconnectorhq.com/invoices/template/:templateId/payment-methods-configuration`

### 6. REQUIRED PARAMETERS:

*   **Header Parameters:**
    *   Version (string): API Version. Possible values: `2021-07-28`

*   **Path Parameters:**
    *   templateId (string): Template Id. Example: `6578278e879ad2646715ba9c`

*   **Body Parameters:**
    *   altId (string): Location Id / company Id based on altType. Example: `6578278e879ad2646715ba9c`
    *   altType (string): Alt Type. Possible values: `location`. Example: `location`
    *   paymentMethods (object): Payment Methods for Invoices (contains nested `stripe` object).
        *   stripe (object): Payment Method (contains nested `enableBankDebitOnly` boolean).
            *   enableBankDebitOnly (boolean): Enable Bank Debit Only. Example: `false`

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`, `Agency Token`
*   **Scheme:** Bearer (JWT)
*   **Location:** `header`

### 9. RESPONSE FORMAT:

*   **200 OK (Successful Response):**
    *   **Content-Type:** `application/json`
    *   **Schema:**
        *   `_id` (string): Template Id. Example: `6578278e879ad2646715ba9c`
        *   `altId` (string): Location Id or Agency Id. Example: `6578278e879ad2646715ba9c`
        *   `altType` (string): Possible values: [`location`]
        *   `name` (string): Name of the Template. Example: `New Template`
        *   `businessDetails` (object): Business Details
            *   `logoUrl` (string): Business Logo URL. Example: `https://example.com/logo.png`
            *   `name` (string): Business Name. Example: `ABC Corp.`
            *   `phoneNo` (string): Business Phone Number. Example: `+1-214-559-6993`
            *   `address` (object): Business Address
                *   `addressLine1` (string): Address Line 1. Example: `9931 Beechwood`
                *   `addressLine2` (string): Address Line 2. Example: `Beechwood`
                *   `city` (string): City. Example: `St. Houston`
                *   `state` (string): State. Example: `TX`
                *   `countryCode` (string): Country Code. Example: `US`
                *   `postalCode` (string): Postal Code. Example: `559-6993`
            *   `website` (string): Business Website Link. Example: `wwww.example.com`
        *   `customValues` (string[]): Custom Values
        *   `currency` (string): Currency. Example: `USD`
        *   `discount` (object): Discount
            *   `value` (number): Discount Value. Default: `0`. Example: `10`
            *   `type` (string): Discount type. Possible values: [`percentage`, `fixed`]. Default: `percentage`. Example: `percentage`

        *   `items` (string[]): Invoice Items. Example: `[{"taxes":[],"_id":"c6tZZU0rJBf30ZXx9Gli","productId":"c6tZZU0rJBf30ZXx9Gli","priceId":"c6tZZU0rJBf30ZXx9Gli","currency":"USD","name":"Macbook Pro","qty":1,"amount":999}]`

        *   `total` (number): Total Amount. Example: `999`
        *   `createdAt` (string): created at. Example: `2023-12-12T09:27:42.355Z`
        *   `updatedAt` (string): updated at. Example: `2023-12-12T09:27:42.355Z`

This API updates the payment methods configuration for a specific invoice template identified by its ID.
