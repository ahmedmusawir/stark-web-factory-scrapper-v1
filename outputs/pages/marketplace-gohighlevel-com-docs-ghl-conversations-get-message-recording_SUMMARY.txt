Here is a structured summary of the API documentation:

### 1. ENDPOINT NAME
Get Recording by Message ID

### 2. CATEGORY
Conversations - Messages

### 3. HTTP METHOD
GET

### 4. ENDPOINT URL
`/conversations/messages/:messageId/locations/:locationId/recording`

### 5. FULL URL
`https://services.leadconnectorhq.com/conversations/messages/:messageId/locations/:locationId/recording`

### 6. REQUIRED PARAMETERS
*   **Header Parameters:**
    *   Version (string): API Version. Possible values: `2021-04-15`
*   **Path Parameters:**
    *   locationId (string): Location ID as string. Example: `tDtDnQdgm2LXpyiqYvZ6`
    *   messageId (string): Message ID as string. Example: `tDtDnQdgm2LXpyiqYvZ6`

### 7. OPTIONAL PARAMETERS
Not specified in documentation

### 8. AUTHENTICATION
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** Bearer (JWT)
*   **In:** Header (`Authorization: Bearer <TOKEN>`)

### 9. RESPONSE FORMAT
*   **200 OK (Success):**
    *   Returns the attached recording for the message.
    *   **Response Headers:**
        *   `Content-Type`: `audio/x-wav`
        *   `Content-Disposition`: `Attachment; filename=audio.wav`
*   **400 Bad Request:**
    *   `Content-Type`: `application/json`
    *   **Schema:**
        *   `statusCode` (number): Example: `400`
        *   `message` (string): Example: `Bad Request`
    *   **Example:** `{"statusCode":400,"message":"Bad Request"}`
*   **401 Unauthorized:**
    *   `Content-Type`: `application/json`
    *   **Schema:**
        *   `statusCode` (number): Example: `401`
        *   `message` (string): Example: `Invalid token: access token is invalid`
        *   `error` (string): Example: `Unauthorized`
    *   **Example:** `{"statusCode":401,"message":"Invalid token: access token is invalid","error":"Unauthorized"}`

### 10. PURPOSE
This endpoint retrieves the audio recording associated with a specific message by its message ID and location ID.
