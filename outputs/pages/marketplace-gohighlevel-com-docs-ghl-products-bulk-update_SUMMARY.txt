Here's a structured summary of the API documentation for "Bulk Update Products":

### 1. ENDPOINT NAME:
Bulk Update Products

### 2. CATEGORY:
Products

### 3. HTTP METHOD:
POST

### 4. ENDPOINT URL:
`/products/bulk-update`

### 5. FULL URL:
`https://services.leadconnectorhq.com/products/bulk-update`

### 6. REQUIRED PARAMETERS:

*   **Header Parameters:**
    *   `Version` (string): API Version. Possible values: [`2021-07-28`]

*   **Body Parameters:**
    *   `altId` (string): Location Id or Agency Id. Example: `6578278e879ad2646715ba9c`
    *   `altType` (string): Possible values: [`location`]
    *   `type` (string): Type of bulk update operation. Possible values: [`bulk-update-price`, `bulk-update-availability`, `bulk-update-product-collection`, `bulk-delete-products`, `bulk-update-currency`]. Example: `bulk-update-price`
    *   `productIds` (string[]): Array of product IDs. Example: `["5f8d0d55b54764421b7156c1"]`

### 7. OPTIONAL PARAMETERS:

*   **Body Parameters:**
    *   `filters` (object): Filters to apply when `selectAll` is true.
        *   `collectionIds` (string[]): Filter by collection IDs. Example: `["5f8d0d55b54764421b7156c1", "5f8d0d55b54764421b7156c2"]`
        *   `productType` (string): Filter by product type. Example: `one-time`
        *   `availableInStore` (boolean): Filter by availability status. Example: `true`
        *   `search` (string): Filter by search term. Example: `blue t-shirt`
    *   `price` (object): Price update configuration.
        *   `type` (string): Type of price update. Possible values: [`INCREASE_BY_AMOUNT`, `REDUCE_BY_AMOUNT`, `SET_NEW_PRICE`, `INCREASE_BY_PERCENTAGE`, `REDUCE_BY_PERCENTAGE`]. *Required if `price` object is included.* Example: `INCREASE_BY_AMOUNT`
        *   `value` (number): Value to update (amount or percentage based on type). *Required if `price` object is included.* Example: `100`
        *   `roundToWhole` (boolean): Round to nearest whole number. Example: `true`
    *   `compareAtPrice` (object): Compare at price update configuration.
        *   `type` (string): Type of price update. Possible values: [`INCREASE_BY_AMOUNT`, `REDUCE_BY_AMOUNT`, `SET_NEW_PRICE`, `INCREASE_BY_PERCENTAGE`, `REDUCE_BY_PERCENTAGE`]. *Required if `compareAtPrice` object is included.* Example: `INCREASE_BY_AMOUNT`
        *   `value` (number): Value to update (amount or percentage based on type). *Required if `compareAtPrice` object is included.* Example: `100`
        *   `roundToWhole` (boolean): Round to nearest whole number. Example: `true`
    *   `availability` (boolean): New availability status. Example: `true`
    *   `collectionIds` (string[]): Array of collection IDs. Example: `["string"]`
    *   `currency` (string): Currency code. Example: `USD`

### 8. AUTHENTICATION:

*   **Scope(s):** `products.write`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token` (Bearer Token, JWT format)

### 9. RESPONSE FORMAT:

*   **Successful Response (201 Created):**
    *   **Schema:**
        ```json
        {
          "status": boolean,
          "message": string
        }
        ```
    *   **Example:**
        ```json
        {
          "status": true,
          "message": "Successfully created"
        }
        ```
*   **Error Responses:**
    *   `400 Bad Request`:
        ```json
        {"statusCode":400,"message":"Bad Request"}
        ```
    *   `401 Unauthorized`:
        ```json
        {"statusCode":401,"message":"Invalid token: access token is invalid","error":"Unauthorized"}
        ```
    *   `422 Unprocessable Entity`:
        ```json
        {"statusCode":422,"message":["Unprocessable Entity"],"error":"Unprocessable Entity"}
        ```

### 10. PURPOSE:
This API allows for bulk updating of products, including their price, availability, collections, and currency, or performing bulk deletion of products.
