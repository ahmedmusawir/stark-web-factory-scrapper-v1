Here's a structured summary of the "Attach Tiktok profile" API documentation:

---

### 1. ENDPOINT NAME:
Attach Tiktok profile

### 2. CATEGORY:
Social Planner - Oauth | Tiktok

### 3. HTTP METHOD:
POST

### 4. ENDPOINT URL:
`/social-media-posting/oauth/:locationId/tiktok/accounts/:accountId`

### 5. FULL URL:
`https://services.leadconnectorhq.com/social-media-posting/oauth/:locationId/tiktok/accounts/:accountId`

### 6. REQUIRED PARAMETERS:

*   **Header Parameters:**
    *   `Version` (string): API Version. Possible values: `2021-07-28`

*   **Path Parameters:**
    *   `locationId` (string): Account Location Id
    *   `accountId` (string): Account Id

*   **Body Parameters (application/json):**
    *   `type` (string): The type of social media entity. Possible values: `page`, `group`, `profile`, `location`, `business`.
    *   `originId` (string): The unique ID of the Tiktok profile/entity from the origin platform.
    *   `name` (string): The display name of the Tiktok profile/entity.
    *   `avatar` (string): The URL of the Tiktok profile/entity's avatar/profile picture.

### 7. OPTIONAL PARAMETERS:

*   **Body Parameters (application/json):**
    *   `verified` (boolean): Indicates if the Tiktok profile/entity is verified.
    *   `username` (string): The username of the Tiktok profile/entity.

### 8. AUTHENTICATION:
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** Bearer (JWT)
*   **In:** Header (Authorization)

### 10. PURPOSE:
This endpoint is used to attach a TikTok profile (either personal or business) to a specific sub-account location within the HighLevel platform, making it available for social media posting and management.
