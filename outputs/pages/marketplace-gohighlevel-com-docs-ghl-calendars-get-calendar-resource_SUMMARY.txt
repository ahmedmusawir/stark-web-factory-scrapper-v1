Here's a structured summary of the API documentation for "Get Calendar Resource":

### 1. ENDPOINT NAME:
Get Calendar Resource

### 2. CATEGORY:
Calendars

### 3. HTTP METHOD:
GET

### 4. ENDPOINT URL:
`/calendars/resources/:resourceType/:id`

### 5. FULL URL:
`https://services.leadconnectorhq.com/calendars/resources/:resourceType/:id`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters:**
    *   `Version` (string): API Version. Possible values: `2021-04-15`
*   **Path Parameters:**
    *   `resourceType` (string): Calendar Resource Type. Possible values: `equipments`, `rooms`
    *   `id` (string): Calendar Resource ID

### 7. OPTIONAL PARAMETERS:
Not specified in documentation for the request.

### 8. AUTHENTICATION:
*   **Scope(s):** `calendars/resources.readonly`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** Bearer (JWT)
*   **In:** Header (`Authorization` header)

### 9. RESPONSE FORMAT:
**Status Code:** `200` (OK)
**Content Type:** `application/json`

**Schema:**
```json
{
  "locationId": "string",
  "name": "yoga room",
  "resourceType": "equipments",
  "isActive": true,
  "description": "string",
  "quantity": 0,
  "outOfService": 0,
  "capacity": 85,
  "calendarIds": ["Jsj0xnlDDjw0SuvX1J13", "oCM5feFC86FAAbcO7lJK"]
}
```
**Details of Response Fields:**
*   `locationId` (string, required): Location ID of the resource
*   `name` (string, required): Name of the resource (e.g., `yoga room`)
*   `resourceType` (string, required): Type of the resource. Possible values: `equipments`, `rooms`
*   `isActive` (boolean, required): Whether the resource is active
*   `description` (string, optional): Description of the resource
*   `quantity` (number, optional): Quantity of the resource
*   `outOfService` (number, optional): Indicates if the resource is out of service (e.g., `0`)
*   `capacity` (number, optional): Capacity of the resource (e.g., `85`)
*   `calendarIds` (string[], required): Array of Calendar IDs (e.g., `["Jsj0xnlDDjw0SuvX1J13", "oCM5feFC86FAAbcO7lJK"]`)

**Error Responses:**
*   **400 Bad Request:**
    *   Schema: `{"statusCode": 400, "message": "Bad Request"}`
*   **401 Unauthorized:**
    *   Schema: `{"statusCode": 401, "message": "Invalid token: access token is invalid", "error": "Unauthorized"}`

### 10. PURPOSE:
This endpoint retrieves a specific calendar resource (room or equipment) by its ID.
