Here's the structured summary of the API documentation:

### 1. ENDPOINT NAME:
Get Social Media Statistics

### 2. CATEGORY:
Social Planner (sub-category Statistics)

### 3. HTTP METHOD:
POST

### 4. ENDPOINT URL:
`/social-media-posting/statistics`

### 5. FULL URL:
`https://services.leadconnectorhq.com/social-media-posting/statistics`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters:**
    *   Version (string): API Version (Possible values: `2021-07-28`)
*   **Query Parameters:**
    *   locationId (string): Location ID (Example: `w37swmmLbA02zgqKPpxITe2`)
*   **Body Parameters:**
    *   profileIds (string[]): Array of connected social media account IDs to fetch analytics for. This can be found as 'profileId' in /accounts api. (Possible values: `>= 1` items in array. Example: `["67a5a9aa776c837de4aa5b12"]`)

### 7. OPTIONAL PARAMETERS:
*   **Body Parameters:**
    *   platforms (string[]): Array of social media platforms to filter analytics by. If not provided, all platforms will be included. NOTE: Linkedin (PAGE only) and Tiktok (BUSINESS only) are supported. (Possible values: `facebook`, `instagram`, `linkedin`, `google`, `pinterest`, `youtube`, `tiktok`. Example: `["facebook","instagram"]`)

### 8. AUTHENTICATION:
*   Authentication method: Not explicitly stated, but common for API 2.0. The 401 response suggests 'Invalid token: access token is invalid', implying a token-based authentication (e.g., OAuth 2.0 via a Bearer token in the Authorization header).
*   Required Scopes: Not specified in documentation.

### 10. PURPOSE:
This endpoint retrieves analytics data for multiple social media accounts, providing metrics for the last 7 days with a comparison to the previous 7 days, and supports filtering by platforms and specific connected accounts.
