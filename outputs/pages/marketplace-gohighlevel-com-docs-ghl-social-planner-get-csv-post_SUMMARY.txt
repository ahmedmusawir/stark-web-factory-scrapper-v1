Here's a structured summary of the API documentation for "Get CSV Post":

### 1. ENDPOINT NAME:
Get CSV Post

### 2. CATEGORY:
Social Planner - CSV

### 3. HTTP METHOD:
GET

### 4. ENDPOINT URL:
`/social-media-posting/:locationId/csv/:id`

### 5. FULL URL:
`https://services.leadconnectorhq.com/social-media-posting/:locationId/csv/:id`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters:**
    *   Version (string): API Version. Possible values: [`2021-07-28`]
*   **Path Parameters:**
    *   locationId (string): Example: `sdfdsfdsfEWEsdfsdsW32dd`
    *   id (string): CSV Id. Example: `65f92e55cc884f0d0845e447`

### 7. OPTIONAL PARAMETERS:
*   **Query Parameters:**
    *   skip (string): Example: `0`
    *   limit (string): Example: `10`

### 8. AUTHENTICATION:
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Bearer Format:** `JWT`
*   **Description:** Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account.

### 10. PURPOSE:
This endpoint retrieves the details of posts associated with a specific CSV upload for social media planning within a given location.
