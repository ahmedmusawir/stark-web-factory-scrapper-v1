Here is a structured summary of the provided API documentation:

### 1. ENDPOINT NAME
Delete an active post and schedule the next one

### 2. CATEGORY
Social Planner / Category Queue

### 3. HTTP METHOD
DELETE

### 4. ENDPOINT URL
`/social-media-posting/category/queues/:postId/active-post`

### 5. FULL URL
`https://services.leadconnectorhq.com/social-media-posting/category/queues/:postId/active-post`

### 6. REQUIRED PARAMETERS
*   **Header Parameters:**
    *   `Version` (string): API Version. Possible values: [`2021-07-28`]
*   **Path Parameters:**
    *   `postId` (string): The ID of the post to delete.
*   **Query Parameters:**
    *   `locationId` (string): Location ID. Example: `609e126a1c4ae1001291e1b5`

### 7. OPTIONAL PARAMETERS
Not specified in documentation

### 8. AUTHENTICATION
Token-based authentication is implied. The `401 Unauthorized` response indicates an "Invalid token: access token is invalid". This typically means an OAuth 2.0 access token or similar bearer token is required in the Authorization header. Specific scopes are not mentioned.

### 9. RESPONSE FORMAT
**Successful Response (200 OK):**
*   **Status Code:** `200`
*   **Content Type:** `application/json`
*   **Schema:**
    ```json
    {
      "success": boolean,
      "statusCode": number,
      "results": {
        "message": string
      },
      "traceId": string
    }
    ```
*   **Example:**
    ```json
    {
      "success": true,
      "statusCode": 200,
      "results": {
        "message": "Current post deleted and next post scheduled successfully"
      },
      "traceId": "string"
    }
    ```

**Error Responses:**
*   **400 Bad Request:**
    ```json
    {"statusCode":400,"message":"Bad Request"}
    ```
*   **401 Unauthorized:**
    ```json
    {"statusCode":401,"message":"Invalid token: access token is invalid","error":"Unauthorized"}
    ```
*   **422 Unprocessable Entity:**
    ```json
    {"statusCode":422,"message":["Unprocessable Entity"],"error":"Unprocessable Entity"}
    ```

### 10. PURPOSE
This endpoint deletes a post that is currently scheduled in a social media category queue and automatically triggers the scheduling of the next available post in the queue.
