Here's a structured summary of the "Create Link" API documentation:

### 1. ENDPOINT NAME:
Create Link

### 2. CATEGORY:
Trigger Links

### 3. HTTP METHOD:
POST

### 4. ENDPOINT URL:
`/links/`

### 5. FULL URL:
`https://services.leadconnectorhq.com/links/`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters**:
    *   Version (string): API Version. Possible values: `2021-07-28`
*   **Body Parameters**:
    *   locationId (string): The ID of the sub-account (location). Example: `ve9EPM428h8vShlRW1KT`
    *   name (string): The name of the trigger link. Example: `first tag`
    *   redirectTo (string): The URL to redirect to when the trigger link is clicked. Example: `https://www.google.com/`

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:
*   **Scope(s)**: `links.write`
*   **Auth Method(s)**: `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s)**: `Sub-Account Token`
*   **Scheme**: Bearer (JWT)
*   **In**: Header (Authorization)

### 9. RESPONSE FORMAT:
**201 Successful response** (application/json)
```json
{
  "link": {
    "id": "n4AriwEnFrGh3tu08W0U",
    "name": "first tag",
    "redirectTo": "https://www.google.com/",
    "fieldKey": "{{trigger_link.n4AriwEnFrGh3tu08W0U}}",
    "locationId": "ve9EPM428h8vShlRW1KT"
  }
}
```
**Schema**:
*   **link** (object):
    *   **id** (string): Unique identifier for the created link.
    *   **name** (string): Name of the link.
    *   **redirectTo** (string): URL the link redirects to.
    *   **fieldKey** (string): Field key for the trigger link.
    *   **locationId** (string): ID of the location where the link was created.

### 10. PURPOSE:
This endpoint allows users to create a new trigger link within a specified sub-account, defining its name and redirect URL.
