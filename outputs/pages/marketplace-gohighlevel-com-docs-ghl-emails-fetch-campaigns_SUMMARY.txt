Here is a structured summary of the API documentation:

### 1. ENDPOINT NAME:
Get Campaigns

### 2. CATEGORY:
Email Campaigns

### 3. HTTP METHOD:
GET

### 4. ENDPOINT URL:
`/emails/schedule`

### 5. FULL URL:
`https://services.leadconnectorhq.com/emails/schedule`

### 6. REQUIRED PARAMETERS:
*   **Version** (string): API Version. Possible values: `2021-07-28` (Header Parameter)
*   **locationId** (string): Location ID to fetch campaigns from. Example: `ohjiah0wdg3bzmzacvd6` (Query Parameter)

### 7. OPTIONAL PARAMETERS:
*   **limit** (number): Maximum number of campaigns to return. Defaults to 10, maximum is 100. Example: `7` (Query Parameter)
*   **offset** (number): Number of campaigns to skip for pagination. Example: `0` (Query Parameter)
*   **status** (string): Filter by schedule status. Possible values: `active`, `pause`, `complete`, `cancelled`, `retry`, `draft`, `resend-scheduled`. Default value: `active` (Query Parameter)
*   **emailStatus** (string): Filter by email delivery status. Possible values: `all`, `not-started`, `paused`, `cancelled`, `processing`, `resumed`, `next-drip`, `complete`, `success`, `error`, `waiting`, `queued`, `queueing`, `reading`, `scheduled`. Default value: `complete` (Query Parameter)
*   **name** (string): Filter campaigns by name. Example: `Black Friday Campaign` (Query Parameter)
*   **parentId** (string): Filter campaigns by parent folder ID. Example: `folder123` (Query Parameter)
*   **limitedFields** (boolean): When true, returns only essential campaign fields like id, templateDataDownloadUrl, updatedAt, type, templateType, templateId, downloadUrl and isPlainText. When false, returns complete campaign data including meta information, bulkRequestStatusInfo, ABTestInfo, resendScheduleInfo and all other campaign properties. Example: `false` (Query Parameter)
*   **archived** (boolean): Filter archived campaigns. Example: `false` (Query Parameter)
*   **campaignsOnly** (boolean): Return only campaigns, excluding folders. Example: `false` (Query Parameter)
*   **showStats** (boolean): When true, returns campaign statistics including delivered count, opened count, clicked count and revenue if available for the campaign. When false, returns campaign data without statistics. Example: `true` (Query Parameter)

### 8. AUTHENTICATION:
*   **Scope(s)**: `emails/schedule.readonly`
*   **Auth Method(s)**: `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s)**: `Sub-Account Token`
*   **Scheme**: `bearer`
*   **Bearer Format**: `JWT`
*   **In**: `header`

### 10. PURPOSE:
This endpoint retrieves a list of email campaigns based on various filtering and pagination parameters for a specified location.
