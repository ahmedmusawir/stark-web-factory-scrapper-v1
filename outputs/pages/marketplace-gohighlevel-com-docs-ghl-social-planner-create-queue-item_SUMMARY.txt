Here's a structured summary of the API documentation:

### 1. ENDPOINT NAME:
Create a new item in a category queue

### 2. CATEGORY:
Social Planner - Category Queue

### 3. HTTP METHOD:
POST

### 4. ENDPOINT URL:
`/social-media-posting/category/queues/:queueId/create/item`

### 5. FULL URL:
`https://services.leadconnectorhq.com/social-media-posting/category/queues/:queueId/create/item`

### 6. REQUIRED PARAMETERS:

*   **Header Parameters:**
    *   `Version` (string): API Version (Possible values: `2021-07-28`)
*   **Path Parameters:**
    *   `queueId` (string)
*   **Body Parameters:**
    *   `locationId` (string): Location ID
    *   `modifiedPostPayload.media.url` (string): URL of media (within `media` array)
    *   `modifiedPostPayload.gmbPostDetails.startDate.startDate.year` (number): Year for GMB event start date
    *   `modifiedPostPayload.gmbPostDetails.startDate.startDate.month` (number): Month for GMB event start date
    *   `modifiedPostPayload.gmbPostDetails.startDate.startDate.day` (number): Day for GMB event start date
    *   `modifiedPostPayload.gmbPostDetails.startDate.startTime.hours` (number): Hours for GMB event start time
    *   `modifiedPostPayload.gmbPostDetails.startDate.startTime.minutes` (number): Minutes for GMB event start time
    *   `modifiedPostPayload.gmbPostDetails.startDate.startTime.seconds` (number): Seconds for GMB event start time
    *   `modifiedPostPayload.gmbPostDetails.endDate.endDate.year` (number): Year for GMB event end date
    *   `modifiedPostPayload.gmbPostDetails.endDate.endDate.month` (number): Month for GMB event end date
    *   `modifiedPostPayload.gmbPostDetails.endDate.endDate.day` (number): Day for GMB event end date
    *   `modifiedPostPayload.gmbPostDetails.endDate.endTime.hours` (number): Hours for GMB event end time
    *   `modifiedPostPayload.gmbPostDetails.endDate.endTime.minutes` (number): Minutes for GMB event end time
    *   `modifiedPostPayload.gmbPostDetails.endDate.endTime.seconds` (number): Seconds for GMB event end time
    *   `modifiedPostPayload.linkedinPostDetails.pdfTitle` (string): Title of the PDF for LinkedIn
    *   `modifiedPostPayload.linkedinPostDetails.postAsPdf` (boolean): If the LinkedIn post is to be posted as PDF
    *   `modifiedPostPayload.pinterestPostDetails.boardIds` (object): Mapping of OAuth IDs of connected accounts to board IDs for Pinterest
    *   `modifiedPostPayload.facebookPostDetails.type` (object): Post Type for Facebook (Possible values: `post`, `story`, `reel`)
    *   `modifiedPostPayload.instagramPostDetails.type` (object): Post Type for Instagram (Possible values: `post`, `story`, `reel`)

### 7. OPTIONAL PARAMETERS:

*   **Body Parameters:**
    *   `modifiedPostPayload` (object): New post details (container object)
        *   `accountIds` (string[]): Account Ids (OAuth only)
        *   `summary` (string): Post Content
        *   `media` (object[]): Post Media (array of objects)
            *   `caption` (string)
            *   `type` (string): e.g., `video/mp4` or `image/png`
            *   `thumbnail` (string)
            *   `defaultThumb` (string)
            *   `id` (string)
        *   `status` (object): Post status (Possible values: `null`, `in_progress`, `draft`, `failed`, `published`, `scheduled`, `in_review`, `notification_sent`, `deleted`)
        *   `scheduleDate` (string): Schedule Date
        *   `createdBy` (string): Created By
        *   `followUpComment` (string): Follow Up Comment on platform
        *   `ogTagsDetails` (object): Og Tags Meta Data
            *   `metaImage` (string): URL of the image for social media shares
            *   `metaLink` (string): The URL of the original webpage/article being shared
            *   `ogTitle` (string): The title of the content for social media shares
        *   `type` (object): Post Type (Possible values: `post`, `story`, `reel`) - *Note: top-level type, distinct from platform-specific types*
        *   `postApprovalDetails` (object): Post Approval Details
            *   `approver` (string): Approver ID
            *   `requesterNote` (string): Requester Notes
            *   `approverNote` (string): Approver Notes
            *   `approvalStatus` (object): Approval Status (Possible values: `pending`, `approved`, `rejected`, `not_required`)
        *   `scheduleTimeUpdated` (boolean): If schedule datetime is updated
        *   `tags` (string[]): Array of Tag Value IDs
        *   `categoryId` (string): Category Id
        *   `tiktokPostDetails` (object): Tiktok Post Details
            *   `privacyLevel` (object): Privacy level (Possible values: `PUBLIC_TO_EVERYONE`, `MUTUAL_FOLLOW_FRIENDS`, `SELF_ONLY`)
            *   `promoteOtherBrand` (boolean): Promote other brand
            *   `enableComment` (boolean): Enable comment
            *   `enableDuet` (boolean): Enable duet
            *   `enableStitch` (boolean): Enable stitch
            *   `videoDisclosure` (boolean): Video disclosure
            *   `promoteYourBrand` (boolean): Promote your brand
        *   `gmbPostDetails` (object): GMB Post Details
            *   `gmbEventType` (string): GMB Event Type (Possible values: `STANDARD`, `EVENT`, `OFFER`)
            *   `title` (string): Event Title
            *   `offerTitle` (string): Offer Title
            *   `startDate` (object): GMB Start Date/Time container
                *   `startDate` (object): GMB Start Date container
                *   `startTime` (object): GMB Start Time container
            *   `endDate` (object): GMB End Date/Time container
                *   `endDate` (object): GMB End Date container
                *   `endTime` (object): GMB End Time container
            *   `termsConditions` (string): Terms Condition Url
            *   `url` (string): Url
            *   `couponCode` (string): Coupon Code
            *   `redeemOnlineUrl` (string): Redeem Online Url
            *   `actionType` (object): Action Type (Possible values: `none`, `order`, `book`, `shop`, `learn_more`, `call`, `sign_up`)
        *   `userId` (string): User ID
        *   `linkedinPostDetails` (object): Linkedin Post Details (container)
        *   `pinterestPostDetails` (object): Pinterest Post Details (container)
            *   `title` (string): Title of the Pinterest Post
            *   `link` (string): Link associated with the Pinterest Post
        *   `facebookPostDetails` (object): Facebook Post Details (container)
        *   `instagramPostDetails` (object): Instagram Post Details (container)
            *   `collaborators` (object): Object mapping account IDs to arrays of associated usernames for collaboration.
        *   `youtubePostDetails` (object): Youtube Post Details
            *   `title` (string): Title
            *   `privacyLevel` (object): Youtube Privacy Level (Possible values: `private`, `public`, `unlisted`)
            *   `type` (object): Youtube Post Type (Possible values: `video`, `short`)
        *   `locationId` (string): Location Id (appears to be a redundant field within modifiedPostPayload, as a top-level locationId is required)
    *   `order` (number): Order for the new item in the queue. Defaults to end if not provided.
    *   `variations` (object[]): Variations (array of objects)
        *   `content` (string)
        *   `mentions` (object[])
        *   `ogTags` (object)
            *   `metaLink` (object)
            *   `metaImage` (object)
            *   `ogTitle` (object)
    *   `primaryImage` (string): Primary media URL (image) for the post.

### 8. AUTHENTICATION:
Not specified in documentation for this specific endpoint, but typically uses OAuth 2.0 based on the broader API documentation context (e.g., "Authorization" link in the sidebar).

### 10. PURPOSE:
This endpoint creates a new post item and adds it directly to a specified category queue, facilitating the addition of new queue items without requiring an existing published post.
