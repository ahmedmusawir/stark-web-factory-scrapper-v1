Here's a structured summary of the API documentation:

---

### 1. ENDPOINT NAME:
Fetch category queues for a location

### 2. CATEGORY:
Social Planner - Category Queue

### 3. HTTP METHOD:
POST

### 4. ENDPOINT URL:
`/social-media-posting/category/queues/list`

### 5. FULL URL:
`https://services.leadconnectorhq.com/social-media-posting/category/queues/list`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters:**
    *   `Version` (string): API Version. Possible value: `2021-07-28`
*   **Body Parameters:**
    *   `locationId` (string): Location ID

### 7. OPTIONAL PARAMETERS:
*   **Body Parameters:**
    *   `skip` (number): Number of items to skip
    *   `limit` (number): Maximum number of items to return

### 8. AUTHENTICATION:
Token-based (e.g., OAuth 2.0 Bearer Token). Indicated by a `401 Unauthorized` response with the message "Invalid token: access token is invalid". Specific scopes are not detailed in this documentation section.

### 10. PURPOSE:
This endpoint retrieves a paginated list of all category queues for a specified location, excluding any queues that have been marked as deleted.
