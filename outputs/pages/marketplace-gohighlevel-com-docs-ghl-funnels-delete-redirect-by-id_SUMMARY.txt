Here is a structured summary of the API documentation for "Delete Redirect By Id":

### ENDPOINT NAME
Delete Redirect By Id

### CATEGORY
Funnels (specifically under Redirects)

### HTTP METHOD
DELETE

### ENDPOINT URL
`/funnels/lookup/redirect/:id`

### FULL URL
`https://services.leadconnectorhq.com/funnels/lookup/redirect/:id`

### REQUIRED PARAMETERS
*   **Header Parameters:**
    *   `Version` (string): API Version. Possible values: `2021-07-28`
*   **Path Parameters:**
    *   `id` (string): The unique identifier of the redirect to be deleted.
*   **Query Parameters:**
    *   `locationId` (string): The ID of the location (sub-account) to which the redirect belongs. Example: `6p2RxpgtMKQwO3E6IUaT`

### OPTIONAL PARAMETERS
Not specified in documentation

### AUTHENTICATION
*   **Scope(s):** `funnels/redirect.write`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`

### RESPONSE FORMAT
*   **200 OK (Successful response):**
    *   Content Type: `application/json`
    *   Schema:
        ```json
        {
          "data": {
            "status": "ok"
          }
        }
        ```
    *   Description: URL redirect deleted successfully.
*   **422 Unprocessable Entity:**
    *   Description: The provided data is invalid or incomplete.

### PURPOSE
This endpoint allows the deletion of a specific URL redirect from the system using its unique identifier, effectively removing the redirect from a given sub-account.
