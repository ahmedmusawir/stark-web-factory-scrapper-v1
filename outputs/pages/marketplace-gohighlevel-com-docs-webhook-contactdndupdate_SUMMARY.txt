Here is a structured summary of the `ContactDndUpdate` webhook documentation:

## Structured API Summary

### 1. ENDPOINT NAME
ContactDndUpdate

### 2. CATEGORY
Webhook (specifically related to Contacts)

### 3. HTTP METHOD
Not applicable. This is a webhook event, meaning the HighLevel platform sends data to a pre-configured URL. Your server receives a POST request from HighLevel when this event occurs.

### 4. ENDPOINT URL
Not applicable. This refers to the URL of the documentation page. For webhooks, you configure *your* endpoint URL on the HighLevel platform to *receive* this event.

### 5. FULL URL
https://marketplace.gohighlevel.com/docs/webhook/ContactDndUpdate/index.html (This is the documentation URL, not the webhook callback URL.)

### 6. REQUIRED PARAMETERS
The following are fields included in the JSON payload sent by the webhook. The documentation does not explicitly distinguish between required and optional fields within the payload schema. All listed properties constitute the potential data structure received.

*   **type** (string): The type of webhook event, e.g., "ContactDndUpdate".
*   **locationId** (string): The unique identifier for the location (Sub-Account) where the event occurred.
*   **id** (string): The unique identifier of the contact.
*   **address1** (string): The primary address line of the contact.
*   **city** (string): The city of the contact's address.
*   **companyName** (string): The company name associated with the contact.
*   **country** (string): The country of the contact's address.
*   **source** (string): The source from which the contact was added (e.g., "xyz form").
*   **dateAdded** (string): The date and time when the contact was added (ISO 8601 format).
*   **dateOfBirth** (string): The contact's date of birth (ISO 8601 format).
*   **dnd** (boolean): Indicates whether Do Not Disturb is enabled for the contact (true/false).
*   **dndSettings** (object): An object containing DND settings for various communication channels.
    *   **SMS** (object): SMS DND settings.
        *   **status** (string): The DND status for SMS (e.g., "active", "inactive").
        *   **message** (string): A descriptive message for the SMS DND status.
        *   **code** (string): A status code for SMS DND.
    *   **Email** (object): Email DND settings.
        *   **status** (string): The DND status for Email.
        *   **message** (string): A descriptive message for the Email DND status.
        *   **code** (string): A status code for Email DND.
    *   **GMB** (object): Google My Business (GMB) DND settings.
        *   **status** (string): The DND status for GMB.
        *   **message** (string): A descriptive message for the GMB DND status.
        *   **code** (string): A status code for GMB DND.
    *   **FB** (object): Facebook DND settings.
        *   **status** (string): The DND status for Facebook.
        *   **message** (string): A descriptive message for the Facebook DND status.
        *   **code** (string): A status code for Facebook DND.
    *   **WhatsApp** (object): WhatsApp DND settings.
        *   **status** (string): The DND status for WhatsApp.
        *   **message** (string): A descriptive message for the WhatsApp DND status.
        *   **code** (string): A status code for WhatsApp DND.
    *   **Call** (object): Call DND settings.
        *   **status** (string): The DND status for Calls.
        *   **message** (string): A descriptive message for the Call DND status.
        *   **code** (string): A status code for Call DND.
*   **email** (string): The contact's email address.
*   **name** (string): The full name of the contact.
*   **firstName** (string): The first name of the contact.
*   **lastName** (string): The last name of the contact.
*   **phone** (string): The contact's phone number.
*   **postalCode** (string): The postal code of the contact's address.
*   **state** (string): The state of the contact's address.
*   **tags** (array): An array of strings representing tags associated with the contact.
*   **website** (string): The contact's website URL.
*   **attachments** (array): An array for attachments (currently shown as empty in example).
*   **assignedTo** (string): The ID of the user to whom the contact is assigned.
*   **customFields** (array): An array of objects representing custom fields for the contact.
    *   **id** (string): The unique identifier for the custom field.
    *   **value** (string, number, array, object): The value of the custom field, which can be of multiple types.

### 7. OPTIONAL PARAMETERS
Not specified in documentation. All fields provided in the schema are part of the potential webhook payload.

### 8. AUTHENTICATION
Not specified in documentation. For receiving webhooks, typically the authentication is managed by HighLevel sending the webhook to your pre-configured URL. You might implement signature verification on your end for security.

### 9. RESPONSE FORMAT
Not specified in documentation. For webhooks, your receiving server should generally respond with an HTTP 2xx status code (e.g., 200 OK) to acknowledge receipt of the payload.

### 10. PURPOSE
This webhook is called by the HighLevel platform whenever a contact's "Do Not Disturb" (DND) field is updated, providing the updated contact information.
