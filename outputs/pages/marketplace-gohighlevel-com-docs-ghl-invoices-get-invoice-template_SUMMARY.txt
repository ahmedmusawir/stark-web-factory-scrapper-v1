Here's a structured summary of the API documentation:

### 1. ENDPOINT NAME:
Get an template

### 2. CATEGORY:
Invoice

### 3. HTTP METHOD:
GET

### 4. ENDPOINT URL:
`/invoices/template/:templateId`

### 5. FULL URL:
`https://services.leadconnectorhq.com/invoices/template/:templateId`

### 6. REQUIRED PARAMETERS:

*   **Header Parameters:**
    *   `Version` (string): API Version. Possible values: `[2021-07-28]`
*   **Path Parameters:**
    *   `templateId` (string): Template Id. Example: `6578278e879ad2646715ba9c`
*   **Query Parameters:**
    *   `altId` (string): location Id / company Id based on altType. Example: `6578278e879ad2646715ba9c`
    *   `altType` (string): Alt Type. Possible values: `[location]`. Example: `location`

### 7. OPTIONAL PARAMETERS:
Not specified in documentation (All listed parameters are required.)

### 8. AUTHENTICATION:

*   **Scope(s):** `invoices/template.readonly`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`, `Agency Token`

### 9. RESPONSE FORMAT:

*   **Status Code:** `200 OK`
*   **Content Type:** `application/json`
*   **Schema (JSON Object):**
    *   `_id` (string, required): Template Id. Example: `6578278e879ad2646715ba9c`
    *   `altId` (string, required): Location Id or Agency Id. Example: `6578278e879ad2646715ba9c`
    *   `altType` (string, required): Possible values: `[location]`
    *   `name` (string, required): Name of the Template. Example: `New Template`
    *   `businessDetails` (object, optional): Business Details
        *   `logoUrl` (string, optional): Business Logo URL. Example: `https://example.com/logo.png`
        *   `name` (string, optional): Business Name. Example: `ABC Corp.`
        *   `phoneNo` (string, optional): Business Phone Number. Example: `+1-214-559-6993`
        *   `address` (object, optional): Business Address
            *   `addressLine1` (string, optional): Address Line 1. Example: `9931 Beechwood`
            *   `addressLine2` (string, optional): Address Line 2. Example: `Beechwood`
            *   `city` (string, optional): City. Example: `St. Houston`
            *   `state` (string, optional): State. Example: `TX`
            *   `countryCode` (string, optional): Country Code. Example: `US`
            *   `postalCode` (string, optional): Postal Code. Example: `559-6993`
        *   `website` (string, optional): Business Website Link. Example: `wwww.example.com`
    *   `customValues` (string[], optional): Custom Values
    *   `currency` (string, required): Currency. Example: `USD`
    *   `discount` (object, optional): Discount
        *   `value` (number, optional): Discount Value. Default value: `0`. Example: `10`
        *   `type` (string, required): Discount type. Possible values: `[percentage, fixed]`. Default value: `percentage`. Example: `percentage`
        *   `validOnProductIds` (string[], optional): Product Ids on which discount is applicable. Example: `[ '6579751d56f60276e5bd4154' ]`
    *   `items` (string[], required): Invoice Items. Example: `[{"taxes":[],"_id":"c6tZZU0rJBf30ZXx9Gli","productId":"c6tZZU0rJBf30ZXx9Gli","priceId":"c6tZZU0rJBf30ZXx9Gli","currency":"USD","name":"Macbook Pro","qty":1,"amount":999}]`
    *   `invoiceNumberPrefix` (string, optional): prefix for invoice number. Example: `INV-`
    *   `total` (number, required): Total Amount. Example: `999`
    *   `createdAt` (string, required): created at. Example: `2023-12-12T09:27:42.355Z`
    *   `updatedAt` (string, required): updated at. Example: `2023-12-12T09:27:42.355Z`

*   **Error Responses:**
    *   `400 Bad Request`: `{"statusCode":400,"message":"Bad Request"}`
    *   `401 Unauthorized`: `{"statusCode":401,"message":"Invalid token: access token is invalid","error":"Unauthorized"}`
    *   `422 Unprocessable Entity`: `{"statusCode":422,"message":["Unprocessable Entity"],"error":"Unprocessable Entity"}`

### 10. PURPOSE:
This API endpoint retrieves an invoice template by its ID.

Invoice, Template, Get, Retrieve, Read, Financial
