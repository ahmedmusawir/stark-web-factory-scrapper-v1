Here is a structured summary of the provided API documentation:

### 1. ENDPOINT NAME:
Update an existing knowledge base FAQ

### 2. CATEGORY:
Knowledge Base (Faqs)

### 3. HTTP METHOD:
PUT

### 4. ENDPOINT URL:
`/knowledge-bases/faqs/:id`

### 5. FULL URL:
`https://services.leadconnectorhq.com/knowledge-bases/faqs/:id`

### 6. REQUIRED PARAMETERS:

*   **Header Parameters:**
    *   Authorization (string): Access Token (Example: Bearer 9c48df2694a849b6089f9d0d3513efe)
    *   Version (string): API Version (Possible values: `2021-04-15`)
*   **Path Parameters:**
    *   id (string): faq ID as string (Example: 710KoEzy793Fxubft0bc)
*   **Body Parameters (application/json):**
    *   question (string): faq question as a string (Example: `What is the capital of France?`)
    *   answer (string): faq answer as a string (Example: `The capital of France is Paris.`)

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:
*   **Auth Method(s):** OAuth Access Token, Private Integration Token
*   **Token Type(s):** Sub-Account Token
*   **Authorization Header:** `Bearer <TOKEN>` (JWT bearer format)

### 9. RESPONSE FORMAT:

*   **200 OK (Success):**
    *   Content Type: `application/json`
    *   Schema:
        ```json
        {
          "success": true
        }
        ```
    *   Description: FAQ updated successfully.

### 10. PURPOSE:
This endpoint allows users to update the question and/or answer of an existing FAQ entry within a knowledge base.
