Here is a structured summary of the provided API documentation:

### 1. ENDPOINT NAME
Create an Agent

### 2. CATEGORY
Conversation AI (Agents)

### 3. HTTP METHOD
POST

### 4. ENDPOINT URL
`/conversation-ai/agents`

### 5. FULL URL
`https://services.leadconnectorhq.com/conversation-ai/agents`

### 6. REQUIRED PARAMETERS

*   **Header Parameters:**
    *   `Version` (string): API Version. Possible values: `2021-04-15`

*   **Body Parameters:**
    *   `name` (string): Name of the agent.
    *   `personality` (string): Personality traits of the agent.
    *   `goal` (string): The goal of the agent.
    *   `instructions` (string): Instructions for the agent.

### 7. OPTIONAL PARAMETERS

*   **Body Parameters:**
    *   `businessName` (string): Name of the business the agent represents.
    *   `mode` (string): Mode of operation - OFF, SUGGESTIVE, or AUTO_PILOT. Default: `off`. Possible values: [`off`, `suggestive`, `auto-pilot`]
    *   `channels` (string[]): Communication channels the agent can operate on. Possible values: [`IG`, `FB`, `SMS`, `WebChat`, `WhatsApp`, `Live_Chat`]
    *   `isPrimary` (boolean): Indicates if this agent is a primary agent. Default: `false`.
    *   `waitTime` (number): Wait time before agent responds (max 5 for minutes, 300 for seconds). Default: `2`.
    *   `waitTimeUnit` (string): Unit for wait time - SECONDS or MINUTES. Default: `seconds`. Possible values: [`minutes`, `seconds`]
    *   `sleepEnabled` (boolean): Indicates if sleep functionality is enabled. Default: `false`.
    *   `sleepTime` (number): Duration of sleep period (required if sleepEnabled is true). (max 2880 for minutes, 172800 for seconds, 48 for hours). Default: `2`.
    *   `sleepTimeUnit` (string): Unit of sleep time - HOURS, MINUTES, or SECONDS (required if sleepEnabled is true). Default: `hours`. Possible values: [`hours`, `minutes`, `seconds`]
    *   `autoPilotMaxMessages` (number): Maximum number of messages in auto-pilot mode before requiring human intervention. (max: 25, min: 1). Default: `25`.
    *   `knowledgeBaseIds` (string[]): Array of knowledge base IDs associated with this agent.
    *   `respondToImages` (boolean): Allow agent to respond to images. Default: `false`.
    *   `respondToAudio` (boolean): Allow agent to respond to audio. Default: `false`.

### 8. AUTHENTICATION

*   **Scope(s):** `conversation-ai.write`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** Bearer (JWT format) in the `Authorization` header.

### 9. RESPONSE FORMAT

*   **Status Code:** `201` (Successful response)
*   **Structure:** JSON object with the following properties:
    *   `id` (string): Unique identifier for the agent.
    *   `name` (string): Name of the agent.
    *   `businessName` (string): Name of the business the agent represents.
    *   `mode` (string): Current operating mode of the agent. Possible values: [`off`, `suggestive`, `auto-pilot`]
    *   `channels` (string[]): Communication channels the agent operates on. Possible values: [`IG`, `FB`, `SMS`, `WebChat`, `WhatsApp`, `Live_Chat`]
    *   `waitTime` (number): Wait time before agent responds.
    *   `waitTimeUnit` (string): Unit for wait time. Possible values: [`minutes`, `seconds`]
    *   `sleepEnabled` (boolean): Indicates if sleep functionality is enabled.
    *   `sleepTime` (number, optional): Duration of sleep period.
    *   `sleepTimeUnit` (string, optional): Unit of sleep time. Possible values: [`hours`, `minutes`, `seconds`]
    *   `actions` (object[]): List of actions associated with this agent. Each action object has:
        *   `id` (string): Unique identifier for the action.
        *   `type` (string): Type of action. Possible values: [`triggerWorkflow`, `updateContactField`, `appointmentBooking`, `stopBot`, `humanHandOver`, `advancedFollowup`, `transferBot`]
    *   `isPrimary` (boolean): Indicates if this agent is a primary agent.
    *   `autoPilotMaxMessages` (number): Maximum number of messages in auto-pilot mode before requiring human intervention.
    *   `goal` (string): The goal of the agent.
    *   `personality` (string): Personality traits of the agent.
    *   `instructions` (string): Instructions for the agent.
    *   `knowledgeBaseIds` (string[]): Array of knowledge base IDs associated with this agent.
*   **Example:**
    ```json
    {
      "id": "emp_123",
      "name": "John Doe",
      "businessName": "Tech Corp",
      "mode": "auto-pilot",
      "channels": ["SMS", "Live_Chat"],

      "sleepTime": 2,

      "goal": "Assist customers with inquiries",
      "personality": "Friendly and helpful",
      "instructions": "Provide excellent customer service",
      "knowledgeBaseIds": ["kb_123", "kb_456"]
    }
    ```

### 10. PURPOSE
This endpoint creates a new AI agent for a specific location, configuring it with a name, role, actions, and various behavior settings.
