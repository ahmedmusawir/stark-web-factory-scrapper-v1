Here's a structured summary of the API documentation:

### 1. ENDPOINT NAME:
Get notification

### 2. CATEGORY:
Calendars / Calendar Notifications

### 3. HTTP METHOD:
GET

### 4. ENDPOINT URL:
`/calendars/:calendarId/notifications/:notificationId`

### 5. FULL URL:
`https://services.leadconnectorhq.com/calendars/:calendarId/notifications/:notificationId`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters:**
    *   Version (string): API Version. Possible values: `2021-04-15`
*   **Path Parameters:**
    *   calendarId (string): Not specified in documentation
    *   notificationId (string): Not specified in documentation

### 7. OPTIONAL PARAMETERS:
None specified in documentation

### 8. AUTHENTICATION:
*   **Scope(s):** `calendars/events.readonly`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** `bearer` (JWT format)
*   **In:** `header`

### 10. PURPOSE:
This endpoint retrieves a specific calendar event notification by its `notificationId` within a given `calendarId`.
