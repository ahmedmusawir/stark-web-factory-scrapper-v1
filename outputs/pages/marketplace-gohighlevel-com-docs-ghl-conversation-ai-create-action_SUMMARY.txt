## STRUCTURED API SUMMARY

### 1. ENDPOINT NAME:
Attach Action to Agent

### 2. CATEGORY:
Conversation AI

### 3. HTTP METHOD:
POST

### 4. ENDPOINT URL:
`/conversation-ai/agents/:agentId/actions`

### 5. FULL URL:
`https://services.leadconnectorhq.com/conversation-ai/agents/:agentId/actions`

### 6. REQUIRED PARAMETERS:

*   **Header Parameters:**
    *   `Version` (string): API Version. Possible values: `2021-04-15`.

*   **Path Parameters:**
    *   `agentId` (string): The unique identifier for the AI agent.

*   **Body Parameters (Common to all action types):**
    *   `type` (string): The type of action to create. Possible values: `triggerWorkflow`, `updateContactField`, `appointmentBooking`, `stopBot`, `humanHandOver`, `advancedFollowup`, `transferBot`.
    *   `name` (string): The name of the action.
    *   `details` (object): Action-specific details. The structure depends on the `type` field.

*   **Body Parameters (Specific to `details` object based on `type`):**
    *   **If `type` is `triggerWorkflow` (triggerWorkflowDto):**
        *   `workflowIds` (string[]): Array of workflow IDs to trigger.
        *   `triggerCondition` (string): Condition that triggers the workflow.
    *   **If `type` is `updateContactField` (updateContactFieldDto):**
        *   `contactFieldId` (string): ID of the contact field in Contacts Table.
        *   `description` (string): Description of the contact field in Contacts Table.
    *   **If `type` is `appointmentBooking` (appointmentBookingDto):**
        *   `calendarId` (string): Calendar ID for appointment booking.
        *   `onlySendLink` (boolean): If true, only sends the appointment link without booking.
        *   `triggerWorkflow` (boolean): Whether to trigger a workflow after booking (cannot be true when `onlySendLink` is true).
        *   `sleepAfterBooking` (boolean): Whether to put the agent to sleep after booking (cannot be true when `onlySendLink` is true).
        *   `transferBot` (boolean): Whether to transfer to another agent after booking (cannot be true when `onlySendLink` is true).
        *   `rescheduleEnabled` (boolean): Whether to allow appointment rescheduling (cannot be true when `onlySendLink` is true). Default value: `false`.
        *   `cancelEnabled` (boolean): Whether to allow appointment cancellation (cannot be true when `onlySendLink` is true). Default value: `false`.
    *   **If `type` is `stopBot` (stopBotDto):**
        *   `stopBotDetectionType` (string): Type of stop bot detection - Goodbye or Custom. Possible values: `Goodbye`, `Custom`.
        *   `stopBotTriggerCondition` (string): Condition that triggers stopping the bot.
        *   `reactivateEnabled` (boolean): Whether the bot can be reactivated after being stopped.
        *   `enabled` (boolean): Whether this action is enabled for the agent.
        *   `stopBotExamples` (string[]): Example phrases that trigger stop bot action (minimum 2 required).
        *   `finalMessage` (string): Final message sent when stopping the bot.
    *   **If `type` is `humanHandOver` (humanHandOverDto):**
        *   `enabled` (boolean): Whether human handover action is enabled.
        *   `triggerCondition` (string): Condition that triggers human handover.
        *   `reactivateEnabled` (boolean): Whether the agent can be reactivated after handover.
        *   `finalMessage` (string): Final message sent when handing over to human.
        *   `handoverType` (string): Type of human handover detection. Possible values: `contactRequest`, `lackOfInformation`, `failedToResolveIssue`, `custom`.
    *   **If `type` is `advancedFollowup` (advancedFollowupDto):**
        *   `enabled` (boolean): Whether advanced followup is enabled.
        *   `scenarioId` (string): ID of the followup scenario. Possible values: `contactStoppedReplying`, `contactIsBusy`, `contactRequested`.
        *   `followupSequence` (object[]): Sequence of followup actions to perform.
            *   `id` (number): Unique identifier for this followup step.
            *   `followupTimeUnit` (string): Time unit for followup delay. Possible values: `days`, `hours`, `minutes`.
            *   `followupTime` (number): Time duration before followup (max: 60 minutes, 24 hours, or 180 days depending on unit).
        *   `followupSettings` (object): Additional settings for followup behavior.
            *   `dynamicChannelSwitching` (boolean): Whether to dynamically switch channels for followups. Default value: `true`.
    *   **If `type` is `transferBot` (transferBotDto):**
        *   `transferBotType` (string): Type of transfer - Default or Custom. Possible values: `Default`, `Custom`.
        *   `transferToBot` (string): ID of the bot/agent to transfer to.
        *   `enabled` (boolean): Whether this transfer action is enabled.

### 7. OPTIONAL PARAMETERS:

*   **Body Parameters (Specific to `details` object based on `type`):**
    *   **If `type` is `triggerWorkflow` (triggerWorkflowDto):**
        *   `triggerMessage` (string): Optional message to send when triggering the workflow.
    *   **If `type` is `updateContactField` (updateContactFieldDto):**
        *   `contactUpdateExamples` (string[]): Contact update examples in Contacts Table. Not required when using standard fields, Monetary or Date Custom fields. Default value: `[]`.
        *   `actionId` (string): Optional action ID reference.
    *   **If `type` is `appointmentBooking` (appointmentBookingDto):**
        *   `workflowIds` (string[]): Workflow IDs to trigger after booking (required when `triggerWorkflow` is true).
        *   `sleepTimeUnit` (string): Unit for sleep time (required when `sleepAfterBooking` is true). Possible values: `days`, `hours`, `minutes`.
        *   `sleepTime` (number): Sleep duration (required when `sleepAfterBooking` is true).
        *   `transferAgent` (string): Agent ID to transfer to (required when `transferBot` is true).
    *   **If `type` is `stopBot` (stopBotDto):**
        *   `sleepTimeUnit` (string): Time unit for reactivation delay (required when `reactivateEnabled` is true). Possible values: `days`, `hours`, `minutes`.
        *   `sleepTime` (number): Time duration before reactivation (required when `reactivateEnabled` is true).
        *   `tags` (string[]): Tags to apply when stopping the bot.
    *   **If `type` is `humanHandOver` (humanHandOverDto):**
        *   `examples` (string[]): Example phrases that trigger human handover (required when `handoverType` is `custom` or `contactRequest`).
        *   `assignToUserId` (string): ID of the user to assign the conversation to.
        *   `skipAssignToUser` (boolean): Whether to skip assigning to a specific user.
        *   `createTask` (boolean): Whether to create a task when handing over.
        *   `sleepTimeUnit` (string): Time unit for reactivation delay (required when `reactivateEnabled` is true). Possible values: `days`, `hours`, `minutes`.
        *   `sleepTime` (number): Time duration before reactivation (required when `reactivateEnabled` is true).
        *   `tags` (string[]): Tags to apply during handover.
    *   **If `type` is `advancedFollowup` (advancedFollowupDto):**
        *   `followupSequence` (object[]):
            *   `aiEnabledMessage` (boolean): Whether to use AI to generate the followup message. Default value: `true`.
            *   `triggerWorkflow` (boolean): Whether to trigger a workflow during this followup. Default value: `false`.
            *   `customMessage` (string): Custom message to send (when `aiEnabledMessage` is false).
            *   `workflowId` (string): Workflow ID to trigger (when `triggerWorkflow` is true).
            *   `contactRequested` (boolean): Whether contact was requested in this followup.
        *   `followupSettings` (object):
            *   `followUpHours` (boolean): Whether to respect working hours for followups.
            *   `workingHours` (object[]): Working hours configuration for followups.
                *   `dayOfTheWeek` (number): Day of the week (0=Sunday, 1=Monday, etc.).
                *   `intervals` (object[]): Time intervals for this day.
                    *   `startHour` (number): Start hour (24-hour format).
                    *   `startMinute` (number): Start minute.
                    *   `endHour` (number): End hour (24-hour format).
                    *   `endMinute` (number): End minute.
            *   `timezoneToUse` (string): Timezone to use for followups, contact or location. Possible values: `contact`, `business`.
    *   **If `type` is `transferBot` (transferBotDto):**
        *   `transferBotTriggerCondition` (string): Condition that triggers the transfer (required for `Custom` type).
        *   `transferBotExamples` (string[]): Example phrases that trigger transfer (required for `Custom` type, minimum 2).

### 8. AUTHENTICATION:

*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`

This endpoint creates and attaches a new action for an AI agent, defining specific tasks or behaviors that the agent can perform, such as booking appointments, sending follow-ups, or collecting information.
