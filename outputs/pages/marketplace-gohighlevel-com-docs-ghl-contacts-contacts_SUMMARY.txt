*   The API adheres to the "Allow Duplicate Contact" setting at the Location level.
*   If configured to check both Email and Phone, the API prioritizes fields as per the setting.
*   If multiple existing contacts match (e.g., one by email, one by phone) and both are provided in an upsert request, the contact matching the *first* field in the configured sequence will be updated, ignoring the second to prevent duplication.
