Here's a structured summary of the API documentation for "Delete Custom Value":

### 1. ENDPOINT NAME:
Delete Custom Value

### 2. CATEGORY:
Sub-Account (Formerly location) / Custom Value

### 3. HTTP METHOD:
DELETE

### 4. ENDPOINT URL:
`/locations/:locationId/customValues/:id`

### 5. FULL URL:
`https://services.leadconnectorhq.com/locations/:locationId/customValues/:id`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters:**
    *   `Version` (string): API Version. Possible values: [`2021-07-28`]
*   **Path Parameters:**
    *   `locationId` (string): Location Id. Example: `ve9EPM428h8vShlRW1KT`
    *   `id` (string): Custom Value Id. Example: `kOBjMVAJhFuUeYIojVet`

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** Bearer (JWT)
*   **In:** Header (`Authorization` header)
*   **Description:** Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account.

### 9. RESPONSE FORMAT:
*   **Successful Response (200 OK):**
    *   **Content Type:** `application/json`
    *   **Schema:**
        ```json
        {
          "succeded": boolean
        }
        ```
    *   **Example:**
        ```json
        {"succeded":true}
        ```
*   **Error Responses:**
    *   **400 Bad Request:** `{"statusCode":400,"message":"Bad Request"}`
    *   **401 Unauthorized:** `{"statusCode":401,"message":"Invalid token: access token is invalid","error":"Unauthorized"}`
    *   **422 Unprocessable Entity:** `{"statusCode":422,"message":["Unprocessable Entity"],"error":"Unprocessable Entity"}`

### 10. PURPOSE:
This endpoint allows for the deletion of a specific custom value associated with a sub-account (location).
