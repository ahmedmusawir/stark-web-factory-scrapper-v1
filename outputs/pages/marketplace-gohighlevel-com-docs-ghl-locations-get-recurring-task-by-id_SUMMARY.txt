Here's a structured summary of the API documentation for "Get Recurring Task By Id":

---

### 1. ENDPOINT NAME:
Get Recurring Task By Id

### 2. CATEGORY:
Recurring Tasks (under Sub-Account/Location API)

### 3. HTTP METHOD:
GET

### 4. ENDPOINT URL:
`/locations/:locationId/recurring-tasks/:id`

### 5. FULL URL:
`https://services.leadconnectorhq.com/locations/:locationId/recurring-tasks/:id`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters:**
    *   `Version` (string): API Version. Possible values: `2021-07-28`
*   **Path Parameters:**
    *   `id` (string): Recurring Task Id. Example: `sx6wyHhbFdRXh302Lunr`
    *   `locationId` (string): Location Id. Example: `sx6wyHhbFdRXh302Lunr`

### 7. OPTIONAL PARAMETERS:
Not specified in documentation for the request.

### 8. AUTHENTICATION:
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** `bearer`
*   **Bearer Format:** `JWT`
*   **In:** `header`
*   **Description:** Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account.

### 9. RESPONSE FORMAT:

*   **Successful Response (Status Code: 200)**
    *   **Content-Type:** `application/json`
    *   **Schema:** An object containing a `recurringTask` object.
        *   `recurringTask` (object):
            *   `id` (string, required): Recurring Task Id. Example: `sx6wyHhbFdRXh302Lunr`
            *   `title` (string, required): Name of the task. Example: `Task Name`
            *   `description` (string, required): Description of the task. Example: `Task Description`
            *   `locationId` (string, required): Location Id. Example: `sx6wyHhbFdRXh302Lunr`
            *   `updatedAt` (string, required): Updated At. Example: `2021-04-15T10:00:00.000Z`
            *   `createdAt` (string, required): Created At. Example: `2021-04-15T10:00:00.000Z`
            *   `rruleOptions` (object, required): Recurring rules
                *   `intervalType` (string, required): Possible values: [`yearly`, `monthly`, `weekly`, `daily`, `hourly`]. Example: `monthly`
                *   `interval` (number, required). Example: `2`
                *   `startDate` (string, required): Start Date. Example: `2021-09-30T00:00:00.000Z`
                *   `endDate` (string, optional): End Date. Example: `2021-09-30T00:00:00.000Z`
                *   `dayOfMonth` (number, optional): 1, 2, 3, ..., 27, 31. Example: `15`
                *   `dayOfWeek` (string, optional): Possible values: [`MO`, `TU`, `WE`, `TH`, `FR`, `SA`, `SU`]. Example: `MO`
                *   `monthOfYear` (number, optional): 1, 2, ....., 11, 12. Example: `1`
                *   `count` (number, optional): Max number of task executions. Example: `10`
                *   `createTaskIfOverDue` (boolean, optional): Create Task If Over Due. Example: `true`
                *   `dueAfterSeconds` (number, required): Due after seconds. Example: `23404000`
            *   `totalOccurrence` (number, required): Total Occurrence. Example: `10`
            *   `deleted` (boolean, required): Deleted. Example: `false`
            *   `assignedTo` (string, optional): Assigned To. Example: `sx6wyHhbFdRXh302Lunr`
            *   `contactId` (string, optional): Contact Id. Example: `v5cEPM428h8vShlRW1KT`

*   **Error Responses:**
    *   **400 Bad Request:**
        *   `{"statusCode":400,"message":"Bad Request"}`
    *   **401 Unauthorized:**
        *   `{"statusCode":401,"message":"Invalid token: access token is invalid","error":"Unauthorized"}`

### 10. PURPOSE:
This endpoint retrieves the details of a specific recurring task by its ID within a given location (sub-account).
