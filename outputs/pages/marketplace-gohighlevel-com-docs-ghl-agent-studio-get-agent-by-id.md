# Get Agent
```
GET 
## https://services.leadconnectorhq.com/agent-studio/public-api/agents/:agentId

```

Gets a specific agent by its ID for the specified location. locationId is required parameter. The agent must have active status.
### Requirements
#### Auth Method(s)
`OAuth Access Token``Private Integration Token`
#### Token Type(s)
`Sub-Account Token`
## Request[​](https://marketplace.gohighlevel.com/docs/ghl/agent-studio/get-agent-by-id/index.html#request "Direct link to Request")
### Header Parameters
**Version** stringrequired
**Possible values:** [`2021-04-15`]
API Version


### Path Parameters
**agentId** stringrequired
Example: p1q2r3s4t5u6v7w8x9y0z1a2


### Query Parameters
**locationId** stringrequired
Example: C2QujeCh8ZnC7al2InWR
**source** string
Example: api
