# Subscriptions
Documentation for payments API
## [📄️ List SubscriptionsThe 'List Subscriptions' API allows to retrieve a paginated list of subscriptions. Customize your results by filtering subscriptions based on name, alt type, subscription status, payment mode, date range, type of source, contact, subscription id, entity id, contact or paginate through the list using the provided query parameters. This endpoint provides a straightforward way to explore and retrieve subscription information.](https://marketplace.gohighlevel.com/docs/ghl/payments/list-subscriptions)## [📄️ Get Subscription by IDThe 'Get Subscription by ID' API allows to retrieve information for a specific subscription using its unique identifier. Use this endpoint to fetch details for a single subscription based on the provided subscription ID.](https://marketplace.gohighlevel.com/docs/ghl/payments/get-subscription-by-id)
