Here's a structured summary of the "Update Estimate" API documentation:

### 1. ENDPOINT NAME
Update Estimate

### 2. CATEGORY
Invoice (specifically Estimate management)

### 3. HTTP METHOD
PUT

### 4. ENDPOINT URL
`/invoices/estimate/:estimateId`

### 5. FULL URL
`https://services.leadconnectorhq.com/invoices/estimate/:estimateId`

### 6. REQUIRED PARAMETERS

*   **Header Parameters:**
    *   `Version` (string): API Version (Possible values: `2021-07-28`)
*   **Path Parameters:**
    *   `estimateId` (string): Estimate Id (Example: `5f9d6d8b1b2d2c001f2d9e4b`)
*   **Body Parameters:**
    *   `altId` (string): Location Id or Agency Id (Example: `6578278e879ad2646715ba9c`)
    *   `altType` (string): Possible values: [`location`]
    *   `name` (string): Estimate Name (Example: `Home Service Estimate`)
    *   `businessDetails` (object): Business details object.
        *   *(Note: The `businessDetails` object itself is required, but its nested fields below are optional unless explicitly stated as `required` within the object's definition.)*
    *   `currency` (string): Currency code (Example: `USD`)
    *   `items` (object[]): An array of items for the estimate.
        *   `items[].name` (string): Invoice Item Name (Example: `ABC Product`)
        *   `items[].currency` (string): Currency (Example: `USD`)
        *   `items[].amount` (number): Product amount (Example: `999`)
        *   `items[].qty` (number): Product Quantity (Example: `1`)
        *   `items[].taxes[]._id` (string)
        *   `items[].taxes[].name` (string)
        *   `items[].taxes[].rate` (number)
    *   `discount` (object): Discount object.
        *   `discount.type` (string): Discount type (Possible values: [`percentage`, `fixed`], Default: `percentage`)
    *   `contactDetails` (object): Contact information to send the estimate to.
        *   `contactDetails.id` (string): Contact ID (Example: `6578278e879ad2646715ba9c`)
        *   `contactDetails.name` (string): Contact Name (Example: `Alex`)
        *   `contactDetails.phoneNo` (string): Contact Phone Number (Example: `+1234567890`)
        *   `contactDetails.email` (string): Contact Email (Example: `alex@example.com`)
        *   `contactDetails.additionalEmails[].email` (string)
    *   `sentTo` (object): Email and sent to details for the estimate.
        *   `sentTo.email` (string[]): Email Address (Example: `["alex@example.com"]`)
    *   `sendEstimateDetails` (object): When sending estimate directly while saving.
        *   `sendEstimateDetails.altId` (string): Location Id or Agency Id (Example: `6578278e879ad2646715ba9c`)
        *   `sendEstimateDetails.altType` (string): Possible values: [`location`]
        *   `sendEstimateDetails.action` (string): Possible values: [`sms_and_email`, `send_manually`, `email`, `sms`]
        *   `sendEstimateDetails.liveMode` (boolean): Livemode for estimate (Example: `true`)
        *   `sendEstimateDetails.userId` (string): Please ensure that the UserId corresponds to an authorized personnel... (Example: `6578278e879ad2646715ba9c`)
    *   `frequencySettings` (object): Frequency settings for the estimate.
        *   `frequencySettings.enabled` (boolean): Enabled for the frequency settings (Example: `true`)
        *   `frequencySettings.schedule` (object): Schedule setting for the estimate.
            *   `frequencySettings.schedule.rrule.intervalType` (string): Possible values: [`yearly`, `monthly`, `weekly`, `daily`, `hourly`, `minutely`, `secondly`] (Example: `monthly`)
            *   `frequencySettings.schedule.rrule.interval` (number): (Example: `2`)
            *   `frequencySettings.schedule.rrule.startDate` (string): Start date in YYYY-MM-DD format (Example: `2023-01-01`)
    *   `attachments` (object[]): Attachments for the invoice.
        *   `attachments[].id` (string): Id of the file selected (Example: `6241712be68f7a98102ba272`)
        *   `attachments[].name` (string): Name of the file (Example: `Electronics.pdf`)
        *   `attachments[].url` (string): URL of the file (Example: `https://example.com/digital-delivery`)
        *   `attachments[].type` (string): Type of the file
        *   `attachments[].size` (number): Size of the file (Example: `10000`)
    *   `autoInvoice` (object): Auto invoice for the estimate.
        *   `autoInvoice.enabled` (boolean): Enable Auto Invoice (Example: `true`)
    *   `miscellaneousCharges` (object): Miscellaneous charges for the estimate.
        *   `miscellaneousCharges.charges` (array[]): Charges for the processing fee.
        *   `miscellaneousCharges.paidCharges[].name` (string): Name of the processing fee (Example: `Processing Fee`)
        *   `miscellaneousCharges.paidCharges[].charge` (number): Charge for the processing fee (Example: `10`)
        *   `miscellaneousCharges.paidCharges[].amount` (number): Amount of the processing fee (Example: `10`)
        *   `miscellaneousCharges.paidCharges[]._id` (string): Id of the processing fee (Example: `673d01d7d547648a8dab6211`)
    *   `paymentScheduleConfig` (object): Payment Schedule Config for the estimate.
        *   `paymentScheduleConfig.type` (string): Payment Schedule Type (Possible values: [`fixed`, `percentage`])
        *   `paymentScheduleConfig.dateConfig` (object): Due date type configuration.
            *   `paymentScheduleConfig.dateConfig.depositDateType` (string): Deposit date type (Possible values: [`estimate_accepted`, `custom`])
            *   `paymentScheduleConfig.dateConfig.scheduleDateType` (string): Payment Schedule Date Type (Possible values: [`regular_interval`, `custom`])
        *   `paymentScheduleConfig.schedules` (array[]): Payment Schedule Items
