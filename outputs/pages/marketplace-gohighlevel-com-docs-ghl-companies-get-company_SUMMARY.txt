### API Documentation Summary

**1. ENDPOINT NAME:** Get Company

**2. CATEGORY:** Companies

**3. HTTP METHOD:** GET

**4. ENDPOINT URL:** `/companies/:companyId`

**5. FULL URL:** `https://services.leadconnectorhq.com/companies/:companyId`

**6. REQUIRED PARAMETERS:**
*   **Header Parameters:**
    *   `Version` (string): API Version. Possible values: `2021-07-28`
*   **Path Parameters:**
    *   `companyId` (string): The unique identifier of the company. Example: `ve9EPM428h8vShlRW1KT`

**7. OPTIONAL PARAMETERS:**
*   Not specified in documentation

**8. AUTHENTICATION:**
*   **Scope(s):** `companies.readonly`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Agency Token`
