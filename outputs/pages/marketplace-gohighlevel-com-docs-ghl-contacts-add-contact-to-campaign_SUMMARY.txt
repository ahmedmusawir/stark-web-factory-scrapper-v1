Here is a structured summary of the API documentation:

### 1. ENDPOINT NAME:
Add Contact to Campaign

### 2. CATEGORY:
Contacts - Campaigns

### 3. HTTP METHOD:
POST

### 4. ENDPOINT URL:
`/contacts/:contactId/campaigns/:campaignId`

### 5. FULL URL:
`https://services.leadconnectorhq.com/contacts/:contactId/campaigns/:campaignId`

### 6. REQUIRED PARAMETERS:
*   **Version** (string): API Version. Possible values: `2021-07-28` (Header Parameter)
*   **contactId** (string): Contact Id. Example: `3bZD1nQzbul0MCancbQD` (Path Parameter)
*   **campaignId** (string): Campaigns Id. Example: `Y2I9XM7aO1hncuSOlc9L` (Path Parameter)
*   **Body** (object): An empty object `{}` is required for the request body. (Body Parameter)

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:
*   **Required Scope(s):** `contacts.write`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** `bearer`
*   **Bearer Format:** `JWT`
*   **In:** `header`
*   **Description:** Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account.

### 9. RESPONSE FORMAT:
**Successful response (HTTP 201 Created):**
```json
{
  "succeded": true
}
```
*   **succeded** (boolean): Indicates if the operation was successful. Example: `true`

**Error Responses:**
*   **400 Bad Request:**
    ```json
    {"statusCode":400,"message":"Bad Request"}
    ```
*   **401 Unauthorized:**
    ```json
    {"statusCode":401,"message":"Invalid token: access token is invalid","error":"Unauthorized"}
    ```
*   **422 Unprocessable Entity:**
    ```json
    {"statusCode":422,"message":["Unprocessable Entity"],"error":"Unprocessable Entity"}
    ```

### 10. PURPOSE:
This endpoint adds a specified contact to a specified campaign.
