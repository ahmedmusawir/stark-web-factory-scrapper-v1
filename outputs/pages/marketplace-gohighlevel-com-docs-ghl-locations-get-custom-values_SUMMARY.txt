Here is the structured summary of the API documentation:

### 1. ENDPOINT NAME:
Get Custom Values

### 2. CATEGORY:
Sub-Account (Formerly Location) / Custom Value

### 3. HTTP METHOD:
GET

### 4. ENDPOINT URL:
`/locations/:locationId/customValues`

### 5. FULL URL:
`https://services.leadconnectorhq.com/locations/:locationId/customValues`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters:**
    *   Version (string): API Version. Possible values: `2021-07-28`
*   **Path Parameters:**
    *   locationId (string): Location Id (e.g., `ve9EPM428h8vShlRW1KT`)

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:
*   **Scope(s):** `locations/customValues.readonly`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** `bearer` (bearerFormat: JWT)
*   **In:** `header`

### 9. RESPONSE FORMAT:
*   **Status Code:** `200` (Successful response)
*   **Content Type:** `application/json`
*   **Schema:**
    ```json
    {
      "customValues": [
        {
          "id": "string",
          "name": "string",
          "fieldKey": "string",
          "value": "string",
          "locationId": "string"
        }
      ]
    }
    ```
*   **Example:**
    ```json
    {
      "customValues": [
        {
          "id": "rWQ709Pb62syqGLceg1x",
          "name": "Custom Field",
          "fieldKey": "{{ custom_values.custom_field }}",
          "value": "Value",
          "locationId": "rWQ709Pb6dasyqGLceg1x"
        }
      ]
    }
    ```
*   **Error Responses:**
    *   `400 Bad Request`: `{"statusCode":400,"message":"Bad Request"}`
    *   `401 Unauthorized`: `{"statusCode":401,"message":"Invalid token: access token is invalid","error":"Unauthorized"}`

### 10. PURPOSE:
This endpoint retrieves a list of all custom values associated with a specific location (sub-account).
