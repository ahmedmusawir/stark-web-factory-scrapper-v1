Here's a structured summary of the API documentation:

### 1. ENDPOINT NAME
Fetch items from a category queue

### 2. CATEGORY
Social Planner - Category Queue

### 3. HTTP METHOD
POST

### 4. ENDPOINT URL
`/social-media-posting/category/queues/:queueId/items`

### 5. FULL URL
`https://services.leadconnectorhq.com/social-media-posting/category/queues/:queueId/items`

### 6. REQUIRED PARAMETERS
*   **Header:**
    *   `Version` (string): API Version. Possible values: [`2021-07-28`]
*   **Path:**
    *   `queueId` (string): The unique identifier of the category queue.
*   **Body:**
    *   `locationId` (string): Location ID. Example: `609e126a1c4ae1001291e1b5`

### 7. OPTIONAL PARAMETERS
*   **Body:**
    *   `skip` (number): Number of items to skip. Example: `0`
    *   `limit` (number): Maximum number of items to return. Example: `10`
    *   `errorFilter` (boolean): To return only queue items with errors. Example: `true`

### 8. AUTHENTICATION
Token-based authentication is implied by the `401 Unauthorized` response with message "Invalid token: access token is invalid".
No specific scopes or authentication methods (e.g., OAuth 2.0 Bearer token) are explicitly described, but an `Authorization` header with a valid access token is expected.

**Error Responses:**
*   `400 Bad Request`: `{"statusCode":400,"message":"Bad Request"}`
*   `401 Unauthorized`: `{"statusCode":401,"message":"Invalid token: access token is invalid","error":"Unauthorized"}`
*   `422 Unprocessable Entity`: `{"statusCode":422,"message":["Unprocessable Entity"],"error":"Unprocessable Entity"}`

### 10. PURPOSE
This endpoint retrieves a paginated list of items within a specific category queue, with an optional filter to show only items that have errors.
