### STRUCTURED SUMMARY FOR "Delete File or Folder" API

**1. ENDPOINT NAME:** Delete File or Folder

**2. CATEGORY:** Media Storage / Medias

**3. HTTP METHOD:** DELETE

**4. ENDPOINT URL:** `/medias/:id`

**5. FULL URL:** `https://services.leadconnectorhq.com/medias/:id`

**6. REQUIRED PARAMETERS:**
*   `- Version (string):` API Version (Possible values: [`2021-07-28`])
*   `- id (string):` ID of the file or folder to delete.
*   `- altType (string):` AltType (Possible values: [`location`])
*   `- altId (string):` location Id

**7. OPTIONAL PARAMETERS:** Not specified in documentation

**8. AUTHENTICATION:**
*   **Scope(s):** `medias.write`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Bearer Format:** JWT

**9. RESPONSE FORMAT:**
*   **Status Code:** `200`
*   **Description:** Successful response
*   **Structure:** Not explicitly detailed beyond "Successful response"

**10. PURPOSE:** Deletes a specific file or folder from the media storage.

**11. TAGS:** Media, Storage, Delete, File, Folder, Medias, Sub-Account, `medias.write`
