### 8. AUTHENTICATION:
HighLevel API supports two primary types of authorization:

*   **Private Integration Token:**
    *   **Purpose:** Primarily for internal purposes, accessing API endpoints for internal data synchronization, custom reporting dashboards, or automated tasks within your own system.
    *   **When to use:** If you don't require webhooks or custom design/pages, and need to access only one sub-account at a time.
    *   **Reference:** [Private Integrations Token](https://marketplace.gohighlevel.com/docs/Authorization/PrivateIntegrationsToken)

*   **OAuth 2.0 Flow:**
    *   **Purpose:** Designed for full-scale integrations intended for public use, requiring advanced security, standardized authorization management, and features like webhooks and custom modules.
    *   **When to use:** For third-party applications, creating custom conversation providers/workflow actions and triggers, or services requiring secure user authorization.
    *   **Reference:** [OAuth 2.0 Flow](https://marketplace.gohighlevel.com/docs/Authorization/OAuth2.0)
