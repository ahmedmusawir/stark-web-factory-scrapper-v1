## STRUCTURED API SUMMARY

### 1. ENDPOINT NAME:
Create Agent

### 2. CATEGORY:
Voice AI Agents

### 3. HTTP METHOD:
POST

### 4. ENDPOINT URL:
`/voice-ai/agents`

### 5. FULL URL:
`https://services.leadconnectorhq.com/voice-ai/agents`

### 6. REQUIRED PARAMETERS:

*   **Header Parameters:**
    *   `Version` (string): API Version.
        *   Possible values: [`2021-04-15`]

*   **Body Parameters:**
    *   `locationId` (string): Unique identifier for the location where this agent will operate.
    *   `sendPostCallNotificationTo` (object): Configuration for post-call email notifications to various recipients.
        *   `admins` (boolean): Enables post-call notifications to all admin users in the location.
        *   `allUsers` (boolean): Enables post-call notifications to all users in the location.
        *   `contactAssignedUser` (boolean): Enables post-call notifications to the user assigned to the contact.
        *   `specificUsers` (string[]): Array of specific user IDs to receive post-call notifications.
        *   `customEmails` (string[]): Array of custom email addresses to receive post-call notifications.
    *   `agentWorkingHours` (object[]): Time intervals defining when the agent accepts calls, organized by day of week.
        *   `dayOfTheWeek` (number): Day of the week for this working hours configuration (Monday=1 to Sunday=7).
            *   Possible values: [`1`, `2`, `3`, `4`, `5`, `6`, `7`]
        *   `intervals` (object[]): Array of time intervals when the agent is available on this day.
            *   `startHour` (number): Starting hour of the working interval in 24-hour format (0-23).
                *   Possible values: `<= 23`
            *   `endHour` (number): Ending hour of the working interval in 24-hour format (0-23).
                *   Possible values: `<= 23`
            *   `startMinute` (number): Starting minute of the working interval (0-59).
                *   Possible values: `<= 59`
            *   `endMinute` (number): Ending minute of the working interval (0-59).
                *   Possible values: `<= 59`
    *   `translation` (object): Language translation settings including enablement flag and target language code.
        *   `enabled` (boolean): Enables language translation for agent conversations.

### 7. OPTIONAL PARAMETERS:

*   **Body Parameters:**
    *   `agentName` (string): Display name for the voice AI agent, between 1-40 characters. Default: "My Agent {random 3 digit number}".
        *   Possible values: `non-empty` and `<= 40 characters`
    *   `businessName` (string): Name of the business this agent represents. Default: Uses location name.
        *   Possible values: `non-empty`
    *   `welcomeMessage` (string): Initial greeting spoken when the agent answers calls. Default: Auto generated.
        *   Possible values: `non-empty` and `<= 190 characters`
    *   `agentPrompt` (string): Custom instructions defining the agent's behavior and personality. Default: Basic prompt generated automatically.
    *   `voiceId` (string): Identifier for the speech synthesis voice from available voice options. Default: Auto generated.
    *   `language` (VoiceAILanguage string): Language code for the agent's speech and understanding. Default: "en-US".
        *   Possible values: [`en-US`, `pt-BR`, `es`, `fr`, `de`, `it`, `nl-NL`, `multi`]
    *   `patienceLevel` (PatienceLevel string): Tolerance level for caller response delays. Default: "high".
        *   Possible values: [`low`, `medium`, `high`]
    *   `maxCallDuration` (number): Maximum call duration in seconds, between 180-900 (3-15 minutes). Default: 300 seconds (5 minutes).
        *   Possible values: `>= 180` and `<= 900`
    *   `sendUserIdleReminders` (boolean): Enables automatic reminders when callers are silent. Default: `true`.
    *   `reminderAfterIdleTimeSeconds` (number): Seconds to wait before sending idle reminders, between 1-20. Default: 8 seconds.
        *   Possible values: `>= 1` and `<= 20`
    *   `inboundNumber` (string): Phone number for receiving inbound calls to this agent. Default: `null`.
    *   `numberPoolId` (string): Identifier for the number pool managing phone number allocation. Default: `null`.
    *   `callEndWorkflowIds` (string[]): Array of workflow IDs to trigger automatically when calls end. Default: `[]`.
        *   Possible values: `<= 10`
    *   `timezone` (string): IANA timezone identifier affecting working hours and scheduling. Default: Location timezone.
        *   Possible values: Value must match regular expression `^[A-Za-z_]+/[A-Za-z_]+$`
    *   `isAgentAsBackupDisabled` (boolean): Prevents this agent from being used as a fallback option. Default: `false` (Available as backup agent).
    *   `translation.language` (string): Target language code for translation (e.g., "es" for Spanish, "fr" for French).
        *   Rules: (1) `translation.enabled` can only be `true` if the agent's language is not `en-US`; (2) when enabled, `translation.language` must be either the agent's language or `en-US`; (3) when enabled, `translation.language` is required.

### 8. AUTHENTICATION:

*   **Scopes:** `voice-ai-agents.write`
*   **Auth Methods:** `OAuth Access Token`, `Private Integration Token`
*   **Token Types:** `Sub-Account Token`

### 9. RESPONSE FORMAT:

*   **Successful Response (201 Created):**
    *   **Content Type:** `application/json`
    *   **Schema:**
        *   `id` (string): Unique identifier for the created agent.
        *   `locationId` (string): Unique identifier for the location where this agent operates.
        *   `agentName` (string): Display name of the voice AI agent.
        *   `businessName` (string): Name of the business this agent represents.
        *   `welcomeMessage` (string): Greeting message spoken when the agent answers calls.
        *   `agentPrompt` (string): Custom instructions defining the agent's behavior.
        *   `voiceId` (string): Identifier for the speech synthesis voice being used.
        *   `language` (string): Language code for the agent's speech and understanding.
        *   `patienceLevel` (string): Current tolerance level for caller response delays.
        *   `maxCallDuration` (number): Maximum call duration in seconds, between 180-900.
        *   `sendUserIdleReminders` (boolean): Indicates whether automatic idle reminders are enabled.
        *   `reminderAfterIdleTimeSeconds` (number): Seconds to wait before sending idle reminders, between 1-20.
        *   `inboundNumber` (string, optional): Phone number for receiving inbound calls.
        *   `numberPoolId` (string, optional): Identifier for the number pool managing this agent's phone allocation.
        *   `callEndWorkflowIds` (string[]): Array of workflow IDs triggered automatically when calls end.
        *   `sendPostCallNotificationTo` (object): Current post-call notification settings.
            *   `admins` (boolean): Send notifications to admins.
            *   `allUsers` (boolean): Send notifications to all users.
            *   `contactAssignedUser` (boolean): Send notifications to contact assigned user.
            *   `specificUsers` (string[]): Specific user IDs to notify.
            *   `customEmails` (string[]): Custom email addresses to notify.
        *   `agentWorkingHours` (object[]): Time intervals when the agent accepts calls.
            *   `dayOfTheWeek` (number): Day of the week for this working hours configuration (Monday=1 to Sunday=7).
            *   `intervals` (object[]): Array of time intervals.
                *   `startHour` (number): Starting hour of the working interval in 24-hour format (0-23).
                *   `endHour` (number): Ending hour of the working interval in 24-hour format (0-23).
                *   `startMinute` (number): Starting minute of the working interval (0-59).
                *   `endMinute` (number): Ending minute of the working interval (0-59).
        *   `timezone` (string): IANA timezone identifier for working hours and scheduling.
        *   `isAgentAsBackupDisabled` (boolean): Indicates whether this agent is excluded from backup scenarios.
        *   `translation` (object): Current language translation settings.
            *   `enabled` (boolean): Whether translation is enabled.
            *   `language` (string, optional): Translation language code.

### 10. PURPOSE:
This endpoint allows you to create a new voice AI agent with customizable configuration and settings for a specific location.
