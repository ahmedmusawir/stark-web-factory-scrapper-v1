Here is a structured summary of the "Delete shipping carrier" API documentation:

### 1. ENDPOINT NAME:
Delete shipping carrier

### 2. CATEGORY:
Store

### 3. HTTP METHOD:
DELETE

### 4. ENDPOINT URL:
`/store/shipping-carrier/:shippingCarrierId`

### 5. FULL URL:
`https://services.leadconnectorhq.com/store/shipping-carrier/:shippingCarrierId`

### 6. REQUIRED PARAMETERS:
*   `shippingCarrierId` (string): ID of the shipping carrier that needs to be returned.
*   `altId` (string): Location Id or Agency Id.
*   `altType` (string): Possible values: `location`.

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:
*   **Auth Method(s)**: `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s)**: `Sub-Account Token`
*   **Scheme**: `bearer`
*   **Bearer Format**: `JWT`
*   **In**: `header`
*   **Description**: Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account.

### 9. RESPONSE FORMAT:
*   **Status Code**: `200 OK`
*   **Content Type**: `application/json`
*   **Schema**:
    *   `status` (boolean, required): Status of api action. (Example: `true`)
    *   `message` (string): Success message. (Example: `Successfully created`)
*   **Example**:
    ```json
    {"status":true,"message":"Successfully created"}
    ```

### 10. PURPOSE:
This endpoint allows users to delete a specific shipping carrier using its unique ID.
