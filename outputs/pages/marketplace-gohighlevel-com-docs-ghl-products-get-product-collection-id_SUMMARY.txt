Here is the structured summary of the API documentation:

### 1. ENDPOINT NAME:
Get Details about individual product collection

### 2. CATEGORY:
*   **Main Category:** Products
*   **Sub-Category:** Collections

### 3. HTTP METHOD:
GET

### 4. ENDPOINT URL:
`/products/collections/:collectionId`

### 5. FULL URL:
`https://services.leadconnectorhq.com/products/collections/:collectionId`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters:**
    *   `Version` (string): API Version. Possible values: [`2021-07-28`]
*   **Path Parameters:**
    *   `collectionId` (string): Collection Id
*   **Query Parameters:**
    *   `altId` (string): Location Id

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:
*   **Scope(s):** `products/collection.readonly`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Authorization Header Details:**
    *   **Name:** `Authorization`
    *   **Type:** `http`
    *   **Scheme:** `bearer`
    *   **Bearer Format:** `JWT`
    *   **In:** `header`
    *   **Description:** Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account.

### 9. RESPONSE FORMAT:

**Successful Response (200 OK):**
*   **Content Type:** `application/json`
*   **Schema:**
    ```json
    {
      "data": {}, // object, required: Collection Data
      "status": true // boolean, required: Status of the operation
    }
    ```
*   **Example:** `{"data":{},"status":true}`

**Error Responses:**
*   **400 Bad Request:**
    ```json
    {"statusCode":400,"message":"Bad Request"}
    ```
*   **401 Unauthorized:**
    ```json
    {"statusCode":401,"message":"Invalid token: access token is invalid","error":"Unauthorized"}
    ```
*   **422 Unprocessable Entity:**
    ```json
    {"statusCode":422,"message":["Unprocessable Entity"],"error":"Unprocessable Entity"}
    ```

### 10. PURPOSE:
This endpoint retrieves the details of a specific product collection identified by its ID.
