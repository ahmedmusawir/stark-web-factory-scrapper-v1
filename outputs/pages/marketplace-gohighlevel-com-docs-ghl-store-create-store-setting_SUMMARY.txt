## STRUCTURED API DOCUMENTATION SUMMARY

### 1. ENDPOINT NAME:
Create/Update Store Settings

### 2. CATEGORY:
Store

### 3. HTTP METHOD:
POST

### 4. ENDPOINT URL:
`/store/store-setting`

### 5. FULL URL:
`https://services.leadconnectorhq.com/store/store-setting`

### 6. REQUIRED PARAMETERS:
- `altId` (string): Location Id or Agency Id
- `altType` (string): Possible values: [`location`]
- `shippingOrigin.name` (string): Name of the store / company
- `shippingOrigin.country` (number): Country code (e.g., `US`, `CA`, etc. - extensive list provided in documentation)
- `shippingOrigin.city` (string): City name
- `shippingOrigin.street1` (string): Street address line 1
- `shippingOrigin.zip` (string): Zip code
- `storeOrderNotification.enabled` (boolean): Store order notification enabled
- `storeOrderNotification.subject` (string): Store order email subject
- `storeOrderNotification.emailTemplateId` (string): Email Template Id
- `storeOrderNotification.defaultEmailTemplateId` (string): Default Email Template Id
- `storeOrderFulfillmentNotification.enabled` (boolean): Store order fulfillment notification enabled
- `storeOrderFulfillmentNotification.subject` (string): Store order fulfillment email subject
- `storeOrderFulfillmentNotification.emailTemplateId` (string): Email Template Id
- `storeOrderFulfillmentNotification.defaultEmailTemplateId` (string): Default Email Template Id

### 7. OPTIONAL PARAMETERS:
- `shippingOrigin.state` (string): State code (e.g., `VA`, `AL`, `AK`, etc. - extensive list provided in documentation)
- `shippingOrigin.street2` (string): Street address line 2
- `shippingOrigin.phone` (string): Business Phone Number
- `shippingOrigin.email` (string): Email

### 8. AUTHENTICATION:
- Auth Method(s): `OAuth Access Token`, `Private Integration Token`
- Token Type(s): `Sub-Account Token`
- Scheme: `bearer`
- Bearer Format: `JWT`
