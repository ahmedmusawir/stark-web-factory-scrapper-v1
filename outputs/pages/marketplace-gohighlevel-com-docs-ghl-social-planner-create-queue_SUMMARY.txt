Here is a structured summary of the provided API documentation:

### 1. ENDPOINT NAME:
Create a category queue

### 2. CATEGORY:
Social Planner > Category Queue

### 3. HTTP METHOD:
POST

### 4. ENDPOINT URL:
`/social-media-posting/category/queues`

### 5. FULL URL:
`https://services.leadconnectorhq.com/social-media-posting/category/queues`

### 6. REQUIRED PARAMETERS:

*   **Header Parameters:**
    *   Version (string): API Version (Possible values: [`2021-07-28`])

*   **Body Parameters:**
    *   locationId (string): Location ID
    *   categoryId (string): Category ID
    *   timeSlots (object[]): An array of time slots
        *   dayOfWeek (number): Day of the week (0-6)
        *   time (string): Time in HH:mm format
    *   userId (string): User id

### 7. OPTIONAL PARAMETERS:

*   **Body Parameters:**
    *   enableFuturePosts (boolean): Enable Future Posts. Defaults to false.
    *   prioritizeNewContent (boolean): Prioritize New Content. Defaults to false.

### 8. AUTHENTICATION:
Not explicitly specified, but the 401 Unauthorized response ("Invalid token: access token is invalid") suggests standard API token/bearer authentication.

### 10. PURPOSE:
This endpoint creates a new queue for a specific category within a location, initializing it with existing published posts from that category or an empty post if none exist.
