Here's a structured summary of the provided API documentation:

### ENDPOINT NAME:
Get association by object keys

### CATEGORY:
Associations

### HTTP METHOD:
GET

### ENDPOINT URL:
`/associations/objectKey/:objectKey`

### FULL URL:
`https://services.leadconnectorhq.com/associations/objectKey/:objectKey`

### REQUIRED PARAMETERS:
*   `Version` (string): API Version. Possible values: [`2021-07-28`]
*   `objectKey` (string): Path parameter representing the object key. Example: `custom_objects.car`

### OPTIONAL PARAMETERS:
*   `locationId` (string): Query parameter representing the location ID. Example: `ve9EPM428h8vShlRW1KT`

### AUTHENTICATION:
*   **Scope(s)**: `associations.readonly`
*   **Auth Method(s)**: `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s)**: `Sub-Account Token`
*   **Header**: `Authorization: Bearer <TOKEN>` (bearerFormat: `JWT`)

### RESPONSE FORMAT:
**Status Code**: `200 OK`
**Content Type**: `application/json`

**Schema (Successful Response - 200)**:
*   `locationId` (string): Example: `string`
*   `id` (string): Example: `ve9EPM428h8vShlRW1KT`
*   `key` (string): First Objects Association Label (custom_objects.children). Example: `student`
*   `firstObjectLabel` (object): First Objects Association Label (custom_objects.children). Example: `student`
*   `firstObjectKey` (object): First Objects Key. Example: `custom_objects.children`
*   `secondObjectLabel` (object): Second Object Association Label (contact). Example: `Teacher`
*   `secondObjectKey` (object): Second Objects Key. Example: `contact`
*   `associationType` (object): Association Type can be USER_DEFINED or SYSTEM_DEFINED. Example: `USER_DEFINED`

**Example (JSON)**:
```json
{
  "locationId": "string",
  "id": "ve9EPM428h8vShlRW1KT",
  "key": "student",
  "firstObjectLabel": "student",
  "firstObjectKey": "custom_objects.children",
  "secondObjectLabel": "Teacher",
  "secondObjectKey": "contact",
  "associationType": "USER_DEFINED"
}
```

### PURPOSE:
This endpoint retrieves an association by object keys, such as contacts, custom objects, and opportunities.

Associations, GET, Retrieve, Object Keys, Custom Objects, Contacts, Opportunities, Read-only
