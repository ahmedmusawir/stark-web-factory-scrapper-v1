### 6. REQUIRED PARAMETERS (Webhook Payload Fields)
*   **id** (string): Unique identifier for the association.
*   **associationType** (string): Specifies the type of association (e.g., `USER_DEFINED` or `SYSTEM_DEFINED`).
*   **firstObjectKey** (string): Key representing the first object in the association.
*   **firstObjectLabel** (string): Human-readable label for the first object.
*   **firstObjectToSecondObjectCardinality** (string): Indicates the relationship between the first and second object (e.g., `MANY_TO_MANY`).
*   **secondObjectKey** (string): Key representing the second object in the association.
*   **secondObjectLabel** (string): Human-readable label for the second object.
*   **secondObjectToFirstObjectCardinality** (string): Defines the reverse relationship between objects.
*   **key** (string): Unique key assigned to the association.
*   **locationId** (string): Identifies the location associated with the deleted association.
