Here's a structured summary of the API documentation:

### 1. ENDPOINT NAME:
List Products

### 2. CATEGORY:
Products

### 3. HTTP METHOD:
GET

### 4. ENDPOINT URL:
`/products/`

### 5. FULL URL:
`https://services.leadconnectorhq.com/products/`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters:**
    *   `Version` (string): API Version.
        *   Possible values: [`2021-07-28`]
*   **Query Parameters:**
    *   `locationId` (string): LocationId is the id of the sub-account.
        *   Example: `3SwdhCu3svxI8AKsPJt6`

### 7. OPTIONAL PARAMETERS:
*   **Query Parameters:**
    *   `limit` (number): The maximum number of items to be included in a single page of results.
        *   Default value: `0`
        *   Example: `20`
    *   `offset` (number): The starting index of the page, indicating the position from which the results should be retrieved.
        *   Default value: `0`
        *   Example: `0`
    *   `search` (string): The name of the product for searching.
        *   Example: `Awesome product`
    *   `collectionIds` (string): Filter by product category Ids. Supports comma separated values.
    *   `collectionSlug` (string): The slug value of the collection by which the collection would be searched.
    *   `expand` (string[]): Name of an entity whose data has to be fetched along with product. Possible entities are tax, stripe and paypal. If not mentioned, only ID will be returned in case of taxes.
    *   `productIds` (string[]): List of product ids to be fetched.
    *   `storeId` (string): Fetch and project products based on the storeId.
        *   Example: `3SwdhCu3svxI8AKsPJt6`
    *   `includedInStore` (boolean): Separate products by which are included in the store and which are not.
    *   `availableInStore` (boolean): If the product is included in the online store.
    *   `sortOrder` (string): The order of sort which should be applied for the date.
        *   Possible values: [`asc`, `desc`]
        *   Example: `desc`

### 8. AUTHENTICATION:
*   **Scope(s):** `products.readonly`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`, `Agency Token`
*   **Scheme:** `bearer`
*   **Bearer Format:** `JWT`
*   **In:** `header`
*   **Description:** Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account.

### 9. RESPONSE FORMAT:
*   **Successful Response (200 OK):**
    *   **Content Type:** `application/json`
    *   **Schema:** An object containing `products` (an array of product objects) and `total` (an array containing a total count object).
        *   `products` (object[]): An array of products. Each product object includes:
            *   `_id` (string): Unique identifier for the product.
            *   `description` (string): Product description.
            *   `variants` (object[]): An array of product variants, each with `id`, `name`, and an array of `options` (each with `id`, `name`).
            *   `locationId` (string): Unique identifier for the location.
            *   `name` (string): Name of the product.
            *   `productType` (string): Type of the product (e.g., `PHYSICAL`).
            *   `availableInStore` (boolean): Indicates availability in-store.
            *   `createdAt` (date-time): Creation timestamp.
            *   `updatedAt` (date-time): Last update timestamp.
            *   `statementDescriptor` (string): Statement descriptor.
            *   `image` (string): URL for the product image.
            *   `collectionIds` (string[]): Array of category Ids.
            *   `isTaxesEnabled` (boolean): Indicates if taxes are enabled. Default: `false`.
            *   `taxes` (string[]): Array of IDs of taxes (or `ProductTaxDto` if `tax` expanded).
            *   `automaticTaxCategoryId` (string): Tax category ID for automatic tax calculation.
            *   `label` (object): Product label details (with `title`, `startDate`, `endDate`).
            *   `slug` (string): Product slug for navigation.
        *   `total` (object[]): An array of objects, each with:
            *   `total` (number): Total number of products.
*   **Error Responses:**
    *   `400 Bad Request`: `{"statusCode":400,"message":"Bad Request"}`
    *   `401 Unauthorized`: `{"statusCode":401,"message":"Invalid token: access token is invalid","error":"Unauthorized"}`
    *   `422 Unprocessable Entity`: `{"statusCode":422,"message":["Unprocessable Entity"],"error":"Unprocessable Entity"}`

### 10. PURPOSE:
The "List Products" API allows to retrieve a paginated list of products, customizable by filtering products based on name or by paginating through the list using query parameters, providing a straightforward way to explore and retrieve product information.
