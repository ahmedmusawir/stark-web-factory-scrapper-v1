# Get Agent
```
GET 
## https://services.leadconnectorhq.com/voice-ai/agents/:agentId

```

Retrieve detailed configuration and settings for a specific voice AI agent
### Requirements
#### Scope(s)
`voice-ai-agents.readonly`
#### Auth Method(s)
`OAuth Access Token``Private Integration Token`
#### Token Type(s)
`Sub-Account Token`
## Request[​](https://marketplace.gohighlevel.com/docs/ghl/voice-ai/get-agent/index.html#request "Direct link to Request")
### Header Parameters
**Version** stringrequired
**Possible values:** [`2021-04-15`]
API Version


### Path Parameters
**agentId** stringrequired
Unique agent identifier
Example: 507f1f77bcf86cd799439011


### Query Parameters
**locationId** stringrequired
Location ID
Example: LOC123456789ABCDEF
