## STRUCTURED SUMMARY

### 1. ENDPOINT NAME:
Get Tags

### 2. CATEGORY:
Sub-Account (formerly Location) Tags

### 3. HTTP METHOD:
GET

### 4. ENDPOINT URL:
`/locations/:locationId/tags`

### 5. FULL URL:
`https://services.leadconnectorhq.com/locations/:locationId/tags`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters:**
    *   Version (string): API Version. Possible values: `2021-07-28`
*   **Path Parameters:**
    *   locationId (string): Location Id. Example: `ve9EPM428h8vShlRW1KT`

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:
*   **Scope(s):** `locations/tags.readonly`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** `bearer`
*   **Bearer Format:** `JWT`
*   **In:** `header`
*   **Description:** Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account.

### 9. RESPONSE FORMAT:
*   **Status Code:** `200` (Successful response)
*   **Content Type:** `application/json`
*   **Schema:**
    ```json
    {
      "tags": [
        {
          "name": "string",
          "locationId": "string",
          "id": "string"
        }
      ]
    }
    ```
*   **Example:**
    ```json
    {"tags":[{"name":"minim aliquip anim","locationId":"ve9EPM428h8vShlRW1KT","id":"flGwEuzsfJOia1i1ikRN"}]}
    ```
*   **Error Responses:**
    *   `400 Bad Request`
    *   `401 Unauthorized`
    *   `422 Unprocessable Entity`

### 10. PURPOSE:
This endpoint retrieves all tags associated with a specific Sub-Account (formerly Location).
