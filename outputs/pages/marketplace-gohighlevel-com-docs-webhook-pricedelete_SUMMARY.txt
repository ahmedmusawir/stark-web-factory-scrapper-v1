Webhook (specifically related to Price)

Webhook Event (The HighLevel system sends an HTTP POST request to a configured endpoint on the client's side).

Not applicable (This is a webhook event sent *from* HighLevel. The client provides a URL for HighLevel to post to).

Not applicable (This is a webhook event sent *from* HighLevel. The client provides a URL for HighLevel to post to).

### 6. REQUIRED PARAMETERS (Payload of the Webhook Event)
*   _id (string): The unique identifier of the deleted price.
*   membershipOffers (array of objects): An array of membership offers associated with the price.
    *   label (string): The label of the membership offer.
    *   value (string): The value associated with the membership offer.
    *   _id (string): The unique identifier of the membership offer.
*   variantOptionIds (array of strings): An array of IDs for variant options related to the price.
*   locationId (string): The unique identifier of the location where the price was deleted.
*   product (string): The unique identifier of the product to which this price belongs.
*   userId (string): The unique identifier of the user who performed the deletion.
*   name (string): The name of the price (e.g., "Red / S").
*   type (string): The type of the price (e.g., "one_time").
*   currency (string): The currency of the price (e.g., "INR").
*   amount (number): The price amount (in the smallest currency unit, e.g., cents).
*   recurring (object): Details if the price is recurring.
    *   interval (string): The billing interval (e.g., "day").
    *   intervalCount (number): The number of intervals (e.g., 1 for "every day").
*   createdAt (string): ISO 8601 timestamp when the price was created.
*   updatedAt (string): ISO 8601 timestamp when the price was last updated.
*   compareAtPrice (number): A comparison price, if available.
*   trackInventory (null): Indicates if inventory is tracked for this price. In this webhook payload, it's explicitly null.
*   availableQuantity (number): The quantity currently available for this price.
*   allowOutOfStockPurchases (boolean): Indicates whether purchases are allowed when out of stock.

### 7. OPTIONAL PARAMETERS
Not specified in documentation (All fields in the schema are part of the webhook payload when the event is triggered).

Not specified in documentation for this particular webhook event. (General webhook security practices, like signature verification, might be covered in the main Webhook Integration Guide).

### 9. RESPONSE FORMAT
When HighLevel sends this webhook, the receiving server is expected to return an HTTP 2xx (e.g., 200 OK) status code to acknowledge successful receipt of the payload. The content of the response body from the receiving server is not dictated by HighLevel for this webhook.

### 10. PURPOSE
This webhook informs subscribed applications or services whenever a price object is successfully deleted within the HighLevel platform, providing full details of the deleted price.
