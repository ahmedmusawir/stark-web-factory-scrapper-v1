Here's a structured summary of the API documentation for "Search Agents":

### 1. ENDPOINT NAME:
Search Agents

### 2. CATEGORY:
Conversation AI - Agents

### 3. HTTP METHOD:
GET

### 4. ENDPOINT URL:
`/conversation-ai/agents/search`

### 5. FULL URL:
`https://services.leadconnectorhq.com/conversation-ai/agents/search`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters:**
    *   `Version` (string): API Version. Possible values: `2021-04-15`.

### 7. OPTIONAL PARAMETERS:
*   **Query Parameters:**
    *   `startAfter` (string): Start after is the agent id to start after, Serving as skip, send empty when first page. Example: `Exampleee123`.
    *   `limit` (number): Records per page. Example: `1`.
    *   `query` (string): query to search on agent name, must be provided in lowercase. Example: `booking`.

### 8. AUTHENTICATION:
*   **Scope(s):** `conversation-ai.readonly`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** `bearer` (JWT)
*   **In:** `header`

### 9. RESPONSE FORMAT:
**Status Code:** `200 OK`
**Content Type:** `application/json`

**Schema:**
*   `agents` (array of objects): List of agents matching the search criteria.
    *   `id` (string): Unique identifier for the agent.
    *   `name` (string): Name of the agent.
    *   `businessName` (string, optional): Name of the business the agent represents.
    *   `mode` (string): Current operating mode of the agent. Possible values: `off`, `suggestive`, `auto-pilot`.
    *   `channels` (array of strings): Communication channels the agent operates on.
    *   `waitTime` (number): Wait time before agent responds.
    *   `waitTimeUnit` (string): Unit for wait time. Possible values: `minutes`, `seconds`.
    *   `sleepEnabled` (boolean): Indicates if sleep functionality is enabled.
    *   `sleepTime` (number, optional): Duration of sleep period.
    *   `sleepTimeUnit` (string, optional): Unit of sleep time. Possible values: `hours`, `minutes`, `seconds`.
    *   `actions` (array of objects): List of actions associated with this agent.
    *   `isPrimary` (boolean): Indicates if this agent is a primary agent.
    *   `autoPilotMaxMessages` (number, optional): Maximum number of messages in auto-pilot mode before requiring human intervention.
    *   `goal` (object, optional): Goal configuration for the agent.
    *   `knowledgeBaseIds` (array of strings, optional): Array of knowledge base IDs associated with this agent.
    *   `createdAt` (string): Timestamp when the agent was created (ISO 8601 format).
    *   `updatedAt` (string): Timestamp when the agent was last updated (ISO 8601 format).
*   `totalCount` (number): Total number of agents in the location (unfiltered count).
*   `count` (number): Number of agents in the current response (filtered/paginated count).

**Example:**

  "agents": [
    {
      "id": "emp_123",

### 10. PURPOSE:
Searches for AI agents based on various criteria including name, status, and configuration, supporting advanced filtering and full-text search capabilities.
