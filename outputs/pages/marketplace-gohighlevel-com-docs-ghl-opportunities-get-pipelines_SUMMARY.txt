Here's the structured summary of the API documentation:

### API Documentation Summary

**1. ENDPOINT NAME:** Get Pipelines

**2. CATEGORY:** Opportunities

**3. HTTP METHOD:** GET

**4. ENDPOINT URL:** `/opportunities/pipelines`

**5. FULL URL:** `https://services.leadconnectorhq.com/opportunities/pipelines`

**6. REQUIRED PARAMETERS:**
*   **Header Parameters:**
    *   `Version` (string): API Version. Possible values: `2021-07-28`
*   **Query Parameters:**
    *   `locationId` (string): Unique identifier for the location (sub-account). Example: `ve9EPM428h8vShlRW1KT`

**7. OPTIONAL PARAMETERS:**
*   Not specified in documentation

**8. AUTHENTICATION:**
*   **Scope(s):** `opportunities.readonly`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** Bearer (JWT)
*   **In:** Header
*   **Description:** Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account.

**9. RESPONSE FORMAT:**

*   **Successful Response (200 OK):** `application/json`
    ```json
    {
      "pipelines": [
        {
          "id": "aWdODOBVOlH1RUFKWQke",
          "name": "new pipeline",
          "stages": [
            [null]
          ],
          "showInFunnel": false,
          "showInPieChart": true,
          "locationId": "dsjddjkndadqaja"
        }
      ]
    }
    ```
    **Schema:**
    *   `pipelines` (array of objects)
        *   `id` (string): Example: `aWdODOBVOlH1RUFKWQke`
        *   `name` (string): Example: `new pipeline`
        *   `stages` (array of arrays): Example: `[[null]]`
        *   `showInFunnel` (boolean): Example: `false`
        *   `showInPieChart` (boolean): Example: `true`
        *   `locationId` (string): Example: `dsjddjkndadqaja`

*   **Error Responses:**
    *   **400 Bad Request:** `{"statusCode":400,"message":"Bad Request"}`
    *   **401 Unauthorized:** `{"statusCode":401,"message":"Invalid token: access token is invalid","error":"Unauthorized"}`

**10. PURPOSE:** This endpoint retrieves a list of all opportunity pipelines associated with a specific location (sub-account).
