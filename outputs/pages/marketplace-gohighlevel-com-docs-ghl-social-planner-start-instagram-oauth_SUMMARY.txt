Here's a structured summary of the provided API documentation:

### 1. ENDPOINT NAME
Starts OAuth For Instagram Account

### 2. CATEGORY
Social Planner - Instagram OAuth

### 3. HTTP METHOD
GET

### 4. ENDPOINT URL
`/social-media-posting/oauth/instagram/start`

### 5. FULL URL
`https://services.leadconnectorhq.com/social-media-posting/oauth/instagram/start`

### 6. REQUIRED PARAMETERS
*   **Header Parameters:**
    *   `Version` (string): API Version. Possible values: `2021-07-28`
*   **Query Parameters:**
    *   `locationId` (string): Location Id (Example: `w37swmmLbA02zgqKPpxITe2`)
    *   `userId` (string): User Id (Example: `u37swmmLbA02zgqKPpxITe2`)

### 7. OPTIONAL PARAMETERS
*   **Query Parameters:**
    *   `page` (string): Page (Example: `integration`)
    *   `reconnect` (string): Reconnect (Example: `true`)

### 8. AUTHENTICATION
*   **Scope(s):** `socialplanner/oauth.readonly`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** Bearer (JWT)
*   **Location:** `Authorization` header
*   **Description:** Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account.

### 9. RESPONSE FORMAT
This endpoint initiates an OAuth flow, redirecting the user to the Instagram login screen. A direct JSON response from this specific GET request is not provided for a successful outcome. Instead, upon successful Instagram login, the parent window should listen for a `message` event containing the following data:

*   **Event Data Response (from `window.postMessage`):**
    *   `actionType` (string): Ex: `"close"`
    *   `page` (string): Ex: `"social-media-posting"`
    *   `platform` (string): Ex: `"instagram"`
    *   `placement` (string): Ex: `"placement"`
    *   `accountId` (string): Ex: `"658a9b6833b91e0ecb8f3958"`
    *   `reconnectAccounts` (string[]): Ex: `["658a9b6833b91e0ecb834acd", "efd2daa9b6833b91e0ecb8f3511"]`

*   **Error Responses:**
    *   **400 Bad Request:**
        ```json
        {"statusCode":400, "message":"Bad Request"}
        ```
    *   **401 Unauthorized:**
        ```json
        {"statusCode":401, "message":"Invalid token: access token is invalid", "error":"Unauthorized"}
        ```
    *   **422 Unprocessable Entity:**
        ```json
        {"statusCode":422, "message":["Unprocessable Entity"], "error":"Unprocessable Entity"}
        ```

### 10. PURPOSE
Initiates the OAuth flow for connecting an Instagram Professional Account by navigating the user to the Instagram login screen, and upon successful authentication, returns account-related event data via a window message listener.
