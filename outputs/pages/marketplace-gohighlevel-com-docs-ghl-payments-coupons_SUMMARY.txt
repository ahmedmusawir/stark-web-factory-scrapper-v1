### 2. ENDPOINT NAME: Create Coupon

*   **HTTP METHOD:** POST
*   **ENDPOINT URL:** Not explicitly detailed in the provided documentation. Assumed relative API path: `/payments/coupons`
*   **FULL URL:** Not explicitly detailed in the provided documentation. Assumed format: `[API_BASE_URL]/payments/coupons`
*   **REQUIRED PARAMETERS:** Not explicitly detailed in the provided documentation. Expected parameters for creating a coupon might include:
    *   `name` (string): Name of the coupon.
    *   `code` (string): Unique promotional code.
    *   `discountType` (enum): Type of discount (e.g., `PERCENTAGE`, `FIXED_AMOUNT`).
    *   `discountValue` (number): The value of the discount.
    *   `validFrom` (datetime): Start date/time of coupon validity.
    *   `validUntil` (datetime): End date/time of coupon validity.
    *   `usageLimit` (integer): Maximum number of times the coupon can be used overall.
    *   `appliesTo` (array of strings/objects): Products or services the coupon applies to.
*   **OPTIONAL PARAMETERS:** Not explicitly detailed in the provided documentation. Could include `minPurchaseAmount`, `maxRedemptionsPerCustomer`, etc.
*   **PURPOSE:** Creates a new promotional coupon with customizable parameters such as discount amount, validity period, usage limits, and applicable products, enabling the setup of promotional offers and special discounts.

*   **OPTIONAL PARAMETERS:** Not explicitly detailed in the provided documentation. Expected parameters would mirror those from `Create Coupon` that are intended for modification.
*   **PURPOSE:** Modifies existing coupon details such as discount values, validity periods, usage limits, and other promotional parameters, allowing for adjustment or extension of promotional offers.
