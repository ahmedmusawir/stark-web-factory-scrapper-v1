Here's a structured summary of the API documentation:

### 1. ENDPOINT NAME:
Fetch available categories for a queue

### 2. CATEGORY:
Social Planner (specifically, Category Queue)

### 3. HTTP METHOD:
GET

### 4. ENDPOINT URL:
`/social-media-posting/category/queues/available-categories`

### 5. FULL URL:
`https://services.leadconnectorhq.com/social-media-posting/category/queues/available-categories`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters:**
    *   Version (string): API Version. Possible values: [`2021-07-28`]
*   **Query Parameters:**
    *   locationId (string): Location ID (Example: `609e126a1c4ae1001291e1b5`)

### 7. OPTIONAL PARAMETERS:
*   **Query Parameters:**
    *   skip (string): Number of items to skip (Example: `0`)
    *   limit (string): Maximum number of items to return (Example: `10`)
    *   q (string): Search query (Example: `Marketing`)

### 8. AUTHENTICATION:
Authentication is implied by the presence of 401 Unauthorized responses ("Invalid token: access token is invalid"). Specific scopes or detailed authentication methods (e.g., OAuth 2.0 grant types) are not explicitly specified for this endpoint, but it's part of the HighLevel API 2.0 which uses OAuth 2.0.

### 9. RESPONSE FORMAT:
*   **Status Code:** 200 (Successfully retrieved available categories)
*   **Content Type:** `application/json`
*   **Schema Example:**
    ```json
    {
      "success": true,
      "statusCode": 200,
      "results": {
        "message": "Available categories fetched successfully",
        "categories": [
          {
            "deleted": false,
            "_id": "65cb3d2f68baa617aa0c286e",
            "name": "Facebook Reel",
            "locationId": "fvg1TXIiVxGcdOaL0riG",
            "primaryColor": "#004EEB",
            "secondaryColor": "#EFF4FF",
            "createdBy": "SQ6d63Va2PUbWEZ9k0TD",
            "createdAt": "2024-02-13T09:58:07.129Z",
            "updatedAt": "2024-02-13T09:58:07.129Z",
            "publishedPostsCount": 80,
            "status": "in_queue"
          }
        ],
        "meta": {
          "count": "100"
        }
      },
      "traceId": "string"
    }
    ```
    *   `success` (boolean): Indicates if the request was successful.
    *   `statusCode` (number): HTTP status code.
    *   `results` (object): Contains the actual data and a message.
        *   `message` (string): A descriptive message about the operation.
        *   `categories` (array of objects): A list of category objects. Each object includes:
            *   `deleted` (boolean): Indicates if the category is deleted.
            *   `_id` (string): Category ID.
            *   `name` (string): Name of the category.
            *   `locationId` (string): Location ID.
            *   `primaryColor` (string): Primary color of the category.
            *   `secondaryColor` (string): Secondary color of the category.
            *   `createdBy` (string): ID of the user who created the category.
            *   `createdAt` (string): Creation timestamp (ISO 8601).
            *   `updatedAt` (string): Last update timestamp (ISO 8601).
            *   `publishedPostsCount` (number): Number of published posts in this category.
            *   `status` (string): Availability status of the category. Possible values: [`available`, `in_queue`].
        *   `meta` (object): Contains metadata about the results.
            *   `count` (string): Total count of items.
    *   `traceId` (string): A unique identifier for the request trace.

### 10. PURPOSE:
This endpoint retrieves a list of available categories for a specified location, indicating whether each category is currently associated with a queue or not.
