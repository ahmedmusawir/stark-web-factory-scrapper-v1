### 2. CATEGORY:
Users

### 3. HTTP METHOD:

### 4. ENDPOINT URL:
`/users/`

### 5. FULL URL:
`https://services.leadconnectorhq.com/users/`

### 6. REQUIRED PARAMETERS:

*   **Header Parameters:**
    *   Version (string): API Version.
        *   Possible values: [`2021-07-28`]

*   **Body Parameters:**
    *   companyId (string): The ID of the company. Example: `ve9EPM428h8vShlRW1KT`
    *   firstName (string): The first name of the user. Example: `John`
    *   lastName (string): The last name of the user. Example: `Deo`
    *   email (string): The email address of the user. Example: `john@deo.com`
    *   password (string): The password for the user. Example: `*******`
    *   type (string): The type of user account. Example: `account`
    *   role (string): The role of the user. Example: `admin`
    *   locationIds (string[]): An array of location IDs the user is associated with. Example: `["C2QujeCh8ZnC7al2InWR"]`

### 10. PURPOSE:
