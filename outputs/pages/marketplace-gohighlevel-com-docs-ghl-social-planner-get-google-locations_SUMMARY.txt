### STRUCTURED SUMMARY

1.  **ENDPOINT NAME**: Get google business locations

2.  **CATEGORY**: Social Planner | Google Business

3.  **HTTP METHOD**: GET

4.  **ENDPOINT URL**: `/social-media-posting/oauth/:locationId/google/locations/:accountId`

5.  **FULL URL**: `https://services.leadconnectorhq.com/social-media-posting/oauth/:locationId/google/locations/:accountId`

6.  **REQUIRED PARAMETERS**:
    *   **Header Parameters**:
        *   Version (string): API Version. Possible values: [`2021-07-28`]
    *   **Path Parameters**:
        *   locationId (string): Account Location Id. Example: `w37swmmLbA02zgqKPpxITe2`
        *   accountId (string): Account Id. Example: `w37swmmLbA02zgqKPpxITe`

7.  **OPTIONAL PARAMETERS**: Not specified in documentation

8.  **AUTHENTICATION**:
    *   **Auth Method(s)**: `OAuth Access Token`, `Private Integration Token`
    *   **Token Type(s)**: `Sub-Account Token`
    *   **Scheme**: Bearer JWT in header
    *   **Description**: Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account.
