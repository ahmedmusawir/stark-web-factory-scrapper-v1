Here is a structured summary of the provided API documentation:

### 1. ENDPOINT NAME:
Get all authors

### 2. CATEGORY:
Blogs

### 3. HTTP METHOD:
GET

### 4. ENDPOINT URL:
/blogs/authors

### 5. FULL URL:
https://services.leadconnectorhq.com/blogs/authors

### 6. REQUIRED PARAMETERS:
*   **Version** (string): API Version
    *   Possible values: [`2021-07-28`]
*   **locationId** (string): Location Id
    *   Example: `ve9EPM428h8vShlRW1KT`
*   **limit** (number): Number of authors to show in the listing
    *   Example: `5`
*   **offset** (number): Number of authors to skip in listing
    *   Example: `0`

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:
*   **Required Scope(s)**: `blogs/author.readonly`
*   **Auth Method(s)**: `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s)**: `Sub-Account Token`
*   **Scheme**: `bearer`
*   **Bearer Format**: `JWT`
*   **In**: `header`
*   **Description**: Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account.
