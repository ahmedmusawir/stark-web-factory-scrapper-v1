Here is a structured summary of the provided API documentation:

---

### 1. ENDPOINT NAME:
Attach linkedin pages and profile

### 2. CATEGORY:
Social Planner (Sub-category: OAuth | LinkedIn)

### 3. HTTP METHOD:
POST

### 4. ENDPOINT URL:
`/social-media-posting/oauth/:locationId/linkedin/accounts/:accountId`

### 5. FULL URL:
`https://services.leadconnectorhq.com/social-media-posting/oauth/:locationId/linkedin/accounts/:accountId`

### 6. REQUIRED PARAMETERS:

*   **Header Parameters:**
    *   `Version` (string): API Version. Possible values: `2021-07-28`

*   **Path Parameters:**
    *   `locationId` (string): Account Location Id.
    *   `accountId` (string): Account Id.

*   **Body Parameters (application/json):**
    *   `type` (string): The type of LinkedIn entity to attach. Possible values: `page`, `group`, `profile`, `location`, `business`
    *   `originId` (string): The unique identifier from LinkedIn for the page/profile.
    *   `name` (string): The name of the LinkedIn page or profile.
    *   `avatar` (string): URL to the avatar/profile picture.
    *   `urn` (string): The Universal Resource Name (URN) for the LinkedIn entity.

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** Bearer (JWT)
*   **In:** Header (`Authorization` header)

### 10. PURPOSE:
This endpoint allows a user to attach a LinkedIn page or profile, identified by its origin ID and URN, to a specific HighLevel account location within the social media planner.
