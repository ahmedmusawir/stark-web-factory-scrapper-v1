# Prices
Documentation for products API
## [📄️ Create Price for a ProductThe 'Create Price for a Product' API allows adding a new price associated with a specific product to the system. Use this endpoint to create a price with the specified details for a particular product. Ensure that the required information is provided in the request payload.](https://marketplace.gohighlevel.com/docs/ghl/products/create-price-for-product)## [📄️ List Prices for a ProductThe 'List Prices for a Product' API allows retrieving a paginated list of prices associated with a specific product. Customize your results by filtering prices or paginate through the list using the provided query parameters.](https://marketplace.gohighlevel.com/docs/ghl/products/list-prices-for-product)## [📄️ List InventoryThe 'List Inventory API allows the user to retrieve a paginated list of inventory items. Use this endpoint to fetch details for multiple items in the inventory based on the provided query parameters.](https://marketplace.gohighlevel.com/docs/ghl/products/get-list-inventory)## [📄️ Update InventoryThe Update Inventory API allows the user to bulk update the inventory for multiple items. Use this endpoint to update the available quantity and out-of-stock purchase settings for multiple items in the inventory.](https://marketplace.gohighlevel.com/docs/ghl/products/update-inventory)## [📄️ Get Price by ID for a ProductThe 'Get Price by ID for a Product' API allows retrieving information for a specific price associated with a particular product using its unique identifier. Use this endpoint to fetch details for a single price based on the provided price ID and product ID.](https://marketplace.gohighlevel.com/docs/ghl/products/get-price-by-id-for-product)## [📄️ Update Price by ID for a ProductThe 'Update Price by ID for a Product' API allows modifying information for a specific price associated with a particular product using its unique identifier. Use this endpoint to update details for a single price based on the provided price ID and product ID.](https://marketplace.gohighlevel.com/docs/ghl/products/update-price-by-id-for-product)## [📄️ Delete Price by ID for a ProductThe 'Delete Price by ID for a Product' API allows deleting a specific price associated with a particular product using its unique identifier. Use this endpoint to remove a price from the system.](https://marketplace.gohighlevel.com/docs/ghl/products/delete-price-by-id-for-product)
