Here is a structured summary of the API documentation:

### 1. ENDPOINT NAME:
Delete tag

### 2. CATEGORY:
Sub-Account (Formerly Location) Tags

### 3. HTTP METHOD:
DELETE

### 4. ENDPOINT URL:
`/locations/:locationId/tags/:tagId`

### 5. FULL URL:
`https://services.leadconnectorhq.com/locations/:locationId/tags/:tagId`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters:**
    *   Version (string): API Version. Possible values: `2021-07-28`
*   **Path Parameters:**
    *   locationId (string): Location Id. Example: `ve9EPM428h8vShlRW1KT`
    *   tagId (string): Tag Id. Example: `flGwEuzsfJOia1i1ikRN`

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** `Bearer` (JWT)
*   **In:** `header`
*   **Description:** Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account.

### 9. RESPONSE FORMAT:
**200 OK (Successful response)**
*   **Content Type:** `application/json`
*   **Schema:**
    *   succeded (boolean): Example: `true`
*   **Example:**
    ```json
    {"succeded":true}
    ```

**400 Bad Request**
*   **Content Type:** `application/json`
*   **Schema:**
    *   statusCode (number): Example: `400`
    *   message (string): Example: `Bad Request`
*   **Example:**
    ```json
    {"statusCode":400,"message":"Bad Request"}
    ```

**401 Unauthorized**
*   **Content Type:** `application/json`
*   **Schema:**
    *   statusCode (number): Example: `401`
    *   message (string): Example: `Invalid token: access token is invalid`
    *   error (string): Example: `Unauthorized`
*   **Example:**
    ```json
    {"statusCode":401,"message":"Invalid token: access token is invalid","error":"Unauthorized"}
    ```

**422 Unprocessable Entity**
*   **Content Type:** `application/json`
*   **Schema:**
    *   statusCode (number): Example: `422`
    *   message (string[]): Example: `["Unprocessable Entity"]`
    *   error (string): Example: `Unprocessable Entity`
*   **Example:**
    ```json
    {"statusCode":422,"message":["Unprocessable Entity"],"error":"Unprocessable Entity"}
    ```

### 10. PURPOSE:
This endpoint allows for the deletion of a specific tag associated with a sub-account (formerly location) using its unique ID.
