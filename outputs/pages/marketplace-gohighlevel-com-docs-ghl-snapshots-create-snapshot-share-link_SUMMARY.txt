Here is a structured summary of the API documentation for "Create Snapshot Share Link":

### 1. ENDPOINT NAME:
Create Snapshot Share Link

### 2. CATEGORY:
Snapshots

### 3. HTTP METHOD:
POST

### 4. ENDPOINT URL:
/snapshots/share/link

### 5. FULL URL:
https://services.leadconnectorhq.com/snapshots/share/link

### 6. REQUIRED PARAMETERS:
*   **Header Parameters:**
    *   Version (string): API Version. Possible values: [`2021-07-28`]
*   **Query Parameters:**
    *   companyId (string): Not specified in documentation (typically a company identifier)
*   **Body Parameters:**
    *   snapshot_id (string): id for snapshot to be shared
    *   share_type (string): Type of share link to generate. Possible values: [`link`, `permanent_link`, `agency_link`, `location_link`]

### 7. OPTIONAL PARAMETERS:
*   **Body Parameters:**
    *   relationship_number (string): Comma separated Relationship number of Agencies to create agency restricted share link. Example: `0-128-926,1-208-926,2-008-926`
    *   share_location_id (string): Comma separated Sub-Account ids to create sub-account restricted share link. Example: `l1C08ntBrFjLS0elLIYU, U1C08ntBrFjLS0elKIYP`

### 8. AUTHENTICATION:
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Agency Token`
*   **Header:** `Authorization: Bearer <TOKEN>`
*   **Description:** Use the Access Token generated with user type as Agency (OR) Personal Integration Token from Agency.

### 9. RESPONSE FORMAT:
*   **Successful Response (201 Created):**
    *   Content Type: `application/json`
    *   Schema:
        *   id (string): id for shared snapshot
        *   shareLink (string): Share Link for snapshot
    *   Example:
        ```json
        {
          "id": "1eM2UgkfaECOYyUdCo9Pa",
          "shareLink": "https://affiliates.gohighlevel.com/?share=1eM2UgkfaECOYyUdCo9Pa"
        }
        ```
*   **Error Responses:**
    *   **400 Bad Request:**
        ```json
        {
          "statusCode": 400,
          "message": "Bad Request"
        }
        ```
    *   **401 Unauthorized:**
        ```json
        {
          "statusCode": 401,
          "message": "Invalid token: access token is invalid",
          "error": "Unauthorized"
        }
        ```

### 10. PURPOSE:
This endpoint creates a share link for a given snapshot based on the specified sharing type and optional restrictions.
