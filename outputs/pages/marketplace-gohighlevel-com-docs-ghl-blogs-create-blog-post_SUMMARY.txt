Here's a structured summary of the "Create Blog Post" API documentation:

### 1. ENDPOINT NAME:
Create Blog Post

### 2. CATEGORY:
Blogs

### 3. HTTP METHOD:
POST

### 4. ENDPOINT URL:
`/blogs/posts`

### 5. FULL URL:
`https://services.leadconnectorhq.com/blogs/posts`

### 6. REQUIRED PARAMETERS:

*   **Header Parameters:**
    *   `Version` (string): API Version. Possible values: `2021-07-28`

*   **Body Parameters:**
    *   `title` (string): The title of your blog post.
    *   `locationId` (string): The ID of the location where the blog post will be created.
    *   `blogId` (string): The ID of the blog site, which can be found from the blog site dashboard link.
    *   `imageUrl` (string): The URL of the main image for the blog post.
    *   `description` (string): A short description of the blog post.
    *   `rawHTML` (string): The HTML content of your blog post.
    *   `status` (string): The publication status of the blog post. Possible values: `DRAFT`, `PUBLISHED`, `SCHEDULED`, `ARCHIVED`.
    *   `imageAltText` (string): Alternative text for the blog image.
    *   `categories` (string[]): An array of category IDs for the blog post, obtainable from the category get API call.
    *   `author` (string): The author ID for the blog post, obtainable from the author get API call.
    *   `urlSlug` (string): The URL slug for the blog post.
    *   `publishedAt` (string): The timestamp when the blog post is published (ISO timestamp format).

### 7. OPTIONAL PARAMETERS:

*   **Body Parameters:**
    *   `tags` (string[]): An array of tags associated with the blog post.
    *   `canonicalLink` (string): The canonical link for the blog post.

### 8. AUTHENTICATION:

*   **Scope(s):** `blogs/post.write`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** `bearer`
*   **Bearer Format:** `JWT`
*   **In:** `header`
*   **Description:** Use an Access Token generated with user type as Sub-Account OR a Private Integration Token of a Sub-Account.

### 9. RESPONSE FORMAT:

*   **Successful Response (200 OK):**
    *   **Content Type:** `application/json`
    *   **Structure:** An object containing a `data` field.
        *   `data` (object):
            *   `categories` (string[], required): Array of category IDs associated with the blog post.
            *   `tags` (string[]): Array of tags associated with the blog post.
            *   `archived` (boolean, required): Indicates whether the blog post is archived.
            *   `_id` (string, required): Unique identifier of the blog post.
            *   `title` (string, required): Title of the blog post.
            *   `description` (string, required): Description of the blog post.
            *   `imageUrl` (string, required): URL of the image associated with the blog post.
            *   `status` (string, required): Publication status of the blog post (`PUBLISHED`).
            *   `imageAltText` (string, required): Alternative text for the blog post image.
            *   `urlSlug` (string, required): URL slug for the blog post.
            *   `canonicalLink` (string): Canonical link of the blog post.
            *   `author` (string): Identifier of the author of the blog post.
            *   `publishedAt` (string, required): Timestamp when the blog post was published (ISO timestamp).
            *   `updatedAt` (string, required): Timestamp when the blog post was last updated (ISO timestamp).

*   **Error Responses:**
    *   `400 Bad Request`: `{"statusCode":400,"message":"Bad Request"}`
    *   `401 Unauthorized`: `{"statusCode":401,"message":"Invalid token: access token is invalid","error":"Unauthorized"}`
    *   `422 Unprocessable Entity`: `{"statusCode":422,"message":["Unprocessable Entity"],"error":"Unprocessable Entity"}`

### 10. PURPOSE:
The "Create Blog Post" API allows you to create a new blog post for any specified blog site.
