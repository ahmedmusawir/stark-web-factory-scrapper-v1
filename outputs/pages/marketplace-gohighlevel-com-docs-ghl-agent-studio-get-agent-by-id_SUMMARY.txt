## STRUCTURED API SUMMARY

### 1. ENDPOINT NAME:
Get Agent

### 2. CATEGORY:
AI Agent Studio

### 3. HTTP METHOD:
GET

### 4. ENDPOINT URL:
`/agent-studio/public-api/agents/:agentId`

### 5. FULL URL:
`https://services.leadconnectorhq.com/agent-studio/public-api/agents/:agentId`

### 6. REQUIRED PARAMETERS:
-   **Version** (string): API Version. Possible values: [`2021-04-15`]
-   **agentId** (string): Example: `p1q2r3s4t5u6v7w8x9y0z1a2`
-   **locationId** (string): Example: `C2QujeCh8ZnC7al2InWR`

### 7. OPTIONAL PARAMETERS:
-   **source** (string): Example: `api`

### 8. AUTHENTICATION:
-   **Auth Method(s)**: `OAuth Access Token`, `Private Integration Token`
-   **Token Type(s)**: `Sub-Account Token`
-   **Scheme**: Bearer
-   **Format**: JWT
-   **Location**: Header (`Authorization` header)

### 9. RESPONSE FORMAT:
**Status Code**: `200`
**Content Type**: `application/json`

**Schema**:
-   **success** (boolean): Success status (e.g., `true`)
-   **message** (string): Response message (e.g., `Agent retrieved successfully`)
-   **agent** (object): Agent metadata
    -   **agentId** (string): Agent ID (e.g., `p1q2r3s4t5u6v7w8x9y0z1a2`)
    -   **name** (string): Agent name (e.g., `Marketing Assistant`)
    -   **description** (string): Agent description (e.g., `AI agent specialized in marketing strategy and content creation`)
    -   **locationId** (string): Location ID (e.g., `C2QujeCh8ZnC7al2InWR`)
    -   **status** (string): Agent status (always "active") (e.g., `active`)
    -   **createdAt** (string): Creation timestamp (e.g., `2024-01-15T10:30:00.000Z`)
    -   **updatedAt** (string): Last update timestamp (e.g., `2024-02-20T14:45:00.000Z`)

**Example (200 OK)**:
```json
{
  "success": true,
  "message": "Agent retrieved successfully",
  "agent": {
    "agentId": "p1q2r3s4t5u6v7w8x9y0z1a2",
    "name": "Marketing Assistant",
    "description": "AI agent specialized in marketing strategy and content creation",
    "locationId": "C2QujeCh8ZnC7al2InWR",
    "status": "active",
    "createdAt": "2024-01-15T10:30:00.000Z",
    "updatedAt": "2024-02-20T14:45:00.000Z"
  }
}
```
**Error Responses (examples provided):**
-   `400 Bad Request`: `{"statusCode":400,"message":"Bad Request"}` (e.g., `locationId` is required)
-   `401 Unauthorized`: `{"statusCode":401,"message":"Invalid token: access token is invalid","error":"Unauthorized"}`
-   `404 Not Found`: (Agent not found or not available message)
-   `422 Unprocessable Entity`: `{"statusCode":422,"message":["Unprocessable Entity"],"error":"Unprocessable Entity"}`
-   `500 Internal Server Error`: `{"statusCode":500,"message":"Internal Server Error"}`

### 10. PURPOSE:
This endpoint retrieves a specific AI agent by its ID for a given location, provided the agent is active.
