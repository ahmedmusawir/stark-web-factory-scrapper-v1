Here's a structured summary of the API documentation:

---

### 1. ENDPOINT NAME:
Reset an item in a queue

### 2. CATEGORY:
Social Planner, Category Queue

### 3. HTTP METHOD:
PUT

### 4. ENDPOINT URL:
`/social-media-posting/category/queues/:queueId/items/:itemId/reset`

### 5. FULL URL:
`https://services.leadconnectorhq.com/social-media-posting/category/queues/:queueId/items/:itemId/reset`

### 6. REQUIRED PARAMETERS:

*   **Header Parameters:**
    *   `Version` (string): API Version. Possible values: [`2021-07-28`]
*   **Path Parameters:**
    *   `queueId` (string)
    *   `itemId` (string)
*   **Body Parameters (application/json):**
    *   `locationId` (string): Location ID. Example: `609e126a1c4ae1001291e1b5`

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:
Implied token-based authentication (e.g., OAuth 2.0 Bearer Token) as indicated by the 401 Unauthorized response: "Invalid token: access token is invalid". Specific scopes or detailed authentication methods are not explicitly mentioned.
