Here is a structured summary of the API documentation for "List Coupons":

### 1. ENDPOINT NAME:
List Coupons

### 2. CATEGORY:
Payments (Sub-category: Coupons)

### 3. HTTP METHOD:
GET

### 4. ENDPOINT URL:
`/payments/coupon/list`

### 5. FULL URL:
`https://services.leadconnectorhq.com/payments/coupon/list`

### 6. REQUIRED PARAMETERS:
*   **Version** (string): API Version (Possible values: `2021-07-28`) - *Header Parameter*
*   **altId** (string): Location Id (Example: `BQdAwxa0ky1iK2sstLGJ`) - *Query Parameter*
*   **altType** (string): Alt Type (Possible values: `location`) - *Query Parameter*

### 7. OPTIONAL PARAMETERS:
*   **limit** (number): Maximum number of coupons to return (Default value: `100`, Example: `10`) - *Query Parameter*
*   **offset** (number): Number of coupons to skip for pagination (Default value: `0`, Example: `0`) - *Query Parameter*
*   **status** (string): Filter coupons by status (Possible values: `scheduled`, `active`, `expired`, Example: `active`) - *Query Parameter*
*   **search** (string): Search term to filter coupons by name or code (Example: `DEAL50`) - *Query Parameter*

### 8. AUTHENTICATION:
*   **Scope(s):** `payments/coupons.readonly`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** `bearer`
*   **Bearer Format:** `JWT`
*   **In:** `header` (specifically the `Authorization` header)

### 9. RESPONSE FORMAT:

#### Successful Response (200 OK):
*   **Content Type:** `application/json`
*   **Schema:**
    *   `data`: `object[]` - Array of coupon objects.
        *   `_id` (string): Unique MongoDB identifier for the coupon.
        *   `usageCount` (number): Number of times the coupon has been used.
        *   `limitPerCustomer` (number): Maximum number of times a customer can use this coupon (0 for unlimited).
        *   `altId` (string): Location Id.
        *   `altType` (string): Type of entity (e.g., `location`).
        *   `name` (string): Display name of the coupon.
        *   `code` (string): Redemption code for the coupon.
        *   `discountType` (string): Type of discount (`percentage` or `amount`).
        *   `discountValue` (number): Value of the discount.
        *   `status` (string): Current status of the coupon (`scheduled`, `active`, `expired`).
        *   `startDate` (string): Date when the coupon becomes active (ISO 8601 format).
        *   `endDate` (string, optional): End date when the coupon expires (ISO 8601 format).
        *   `applyToFuturePayments` (boolean): Indicates if the coupon applies to future recurring payments.
        *   `applyToFuturePaymentsConfig` (object, optional): Configuration for how the coupon applies to future payments.
            *   `type` (string): Type of future payments configuration (`forever` or `fixed`).
            *   `duration` (number, optional): Duration value for fixed type configurations.
            *   `durationType` (string, optional): Duration type for fixed configurations (e.g., `months`).
        *   `userId` (string, optional): User ID associated with the coupon.
        *   `createdAt` (string): Creation timestamp (ISO 8601 format).
        *   `updatedAt` (string): Last update timestamp (ISO 8601 format).
    *   `totalCount` (number): Total number of coupons matching the query criteria.
    *   `traceId` (string): Unique identifier for tracing this API request.

#### Error Response (422 Unprocessable Entity):
*   **Content Type:** `application/json`
*   **Schema:**
    *   `statusCode` (number): HTTP status code (e.g., `422`).
    *   `message` (string[]): Array of error messages (e.g., `["Unprocessable Entity"]`).
    *   `error` (string): A general error description (e.g., `Unprocessable Entity`).

### 10. PURPOSE:
The "List Coupons" API allows you to retrieve a list of all coupons available in your location, providing details on promotional offers and special discounts for customers.
