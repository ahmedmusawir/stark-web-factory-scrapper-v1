Here is a structured summary of the API documentation for "Get Notes":

### 1. ENDPOINT NAME:
Get Notes

### 2. CATEGORY:
Calendars (specifically, Appointment Notes)

### 3. HTTP METHOD:
GET

### 4. ENDPOINT URL:
`/calendars/appointments/:appointmentId/notes`

### 5. FULL URL:
`https://services.leadconnectorhq.com/calendars/appointments/:appointmentId/notes`

### 6. REQUIRED PARAMETERS:
*   `Version` (string): API Version. Possible values: `2021-04-15` (Header Parameter)
*   `appointmentId` (string): Appointment ID (Path Parameter)
*   `limit` (number): Limit of notes to fetch. Possible values: `<= 20` (Query Parameter)
*   `offset` (number): Offset of notes to fetch (Query Parameter)

### 7. OPTIONAL PARAMETERS:
Not specified in documentation. All listed parameters are required.

### 8. AUTHENTICATION:
*   **Scope(s):** `calendars/events.readonly`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** `bearer`
*   **Bearer Format:** `JWT`
*   **In:** `header` (Authorization header)

### 9. RESPONSE FORMAT:
**Successful Response (200 OK):**
*   **Content Type:** `application/json`
*   **Schema:**
    *   `notes` (array of objects)
        *   `id` (string)
        *   `body` (string)
        *   `userId` (string)
        *   `dateAdded` (string)
        *   `contactId` (string)
        *   `createdBy` (object)
            *   `id` (string)
            *   `name` (string)
    *   `hasMore` (boolean)
*   **Example:**
    ```json
    {
      "notes": [
        {
          "id": "HGPcayliwcdoUFzvbTok",
          "body": "lorem ipsum",
          "userId": "TUcmRxWrjqzJS8EjkxNK",
          "dateAdded": "2021-07-08T12:02:11.285Z",
          "contactId": "TUcmRxWrjqzJS8EjkxNK",
          "createdBy": {
            "id": "TUcmRxWr",
            "name": "John Doe"
          }
        }
      ],
      "hasMore": true
    }
    ```

**Error Responses:**
*   **400 Bad Request:**
    *   Schema: `statusCode` (number), `message` (string)
    *   Example: `{"statusCode":400,"message":"Bad Request"}`
*   **401 Unauthorized:**
    *   Schema: `statusCode` (number), `message` (string), `error` (string)
    *   Example: `{"statusCode":401,"message":"Invalid token: access token is invalid","error":"Unauthorized"}`

### 10. PURPOSE:
This endpoint retrieves a list of notes associated with a specific appointment.

Calendars, Appointments, Notes, Get, Fetch, Read, Appointment Notes, Calendar Events, GHL.
