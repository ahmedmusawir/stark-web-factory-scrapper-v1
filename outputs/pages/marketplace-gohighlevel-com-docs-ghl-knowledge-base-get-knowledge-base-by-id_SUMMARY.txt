Here's a structured summary of the API documentation:

### 1. ENDPOINT NAME:
Get knowledge base by ID

### 2. CATEGORY:
Knowledge Base

### 3. HTTP METHOD:
GET

### 4. ENDPOINT URL:
`/knowledge-bases/:knowledgeBaseId`

### 5. FULL URL:
`https://services.leadconnectorhq.com/knowledge-bases/:knowledgeBaseId`

### 6. REQUIRED PARAMETERS:
*   **knowledgeBaseId** (string): The ID of the knowledge base to retrieve.
*   **Authorization** (string): Access Token. Example: `Bearer 9c48df2694a849b6089f9d0d3513efe`
*   **Version** (string): API Version. Possible values: [`2021-04-15`]

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:
*   **Auth Method(s)**: `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s)**: `Sub-Account Token`
*   **Authorization Header**: Scheme `bearer`, format `JWT`

### 9. RESPONSE FORMAT:
**Status Code**: `200`
**Content Type**: `application/json`

**Schema**:
```json
{
  "success": true,
  "data": {
    "id": "Arc9QRauPKkSuMJO8D0m",
    "name": "KB for Bot Training",
    "nameLowerCase": "kb for bot training",
    "locationId": "qIyivCmsuEOSnyoFYEej",
    "deleted": false,
    "createdAt": "2025-08-01T07:50:41.244Z",
    "updatedAt": "2025-08-01T10:05:58.694Z",
    "kbMetadata": {
      "faqs": 2,
      "urls": 64,
      "richText": 0,
      "files": 0,
      "webSearches": 0,
      "tables": 0
    },
    "isDefault": false
  }
}
```
**Details**:
*   **success** (boolean, required): Success status of the operation.
*   **data** (object): Knowledge base details.
    *   **id** (string, required): Knowledge base ID.
    *   **name** (string, required): Knowledge base name.
    *   **nameLowerCase** (string, required): Knowledge base name in lowercase.
    *   **locationId** (string, required): Location ID.
    *   **deleted** (boolean, required): Whether the knowledge base is deleted.
    *   **createdAt** (string, required): Date when knowledge base was created.
    *   **updatedAt** (string, required): Date when knowledge base was last updated.
    *   **kbMetadata** (object, required): Knowledge base metadata with content counts.
        *   **faqs** (number, required): Number of FAQs in the knowledge base.
        *   **urls** (number, required): Number of URLs in the knowledge base.
        *   **richText** (number, required): Number of rich text documents in the knowledge base.
        *   **files** (number, required): Number of files in the knowledge base.
        *   **webSearches** (number, required): Number of web search configs in the knowledge base.
        *   **tables** (number, required): Number of tables in the knowledge base.
    *   **isDefault** (boolean, optional): Whether the knowledge base is default or not.

### 10. PURPOSE:
This endpoint retrieves the details of a specific knowledge base using its unique ID.
