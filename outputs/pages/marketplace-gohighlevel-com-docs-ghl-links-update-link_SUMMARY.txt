## STRUCTURED SUMMARY

### 1. ENDPOINT NAME:
Update Link

### 2. CATEGORY:
Trigger Links

### 3. HTTP METHOD:
PUT

### 4. ENDPOINT URL:
`/links/:linkId`

### 5. FULL URL:
`https://services.leadconnectorhq.com/links/:linkId`

### 6. REQUIRED PARAMETERS:
- **Header Parameters:**
    - Version (string): API Version. Possible values: [`2021-07-28`]
- **Path Parameters:**
    - linkId (string): Link Id
- **Body Parameters (application/json):**
    - name (string): The new name for the trigger link. Example: `first tag`
    - redirectTo (string): The URL to redirect to. Example: `https://www.google.com/`

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:
- **Scope(s):** `links.write`
- **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
- **Token Type(s):** `Sub-Account Token`
- **Scheme:** `bearer`
- **Bearer Format:** `JWT`
- **In:** `header`
- **Description:** Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account.

### 9. RESPONSE FORMAT:
**Status Code:** `201` (Successful response)
**Content Type:** `application/json`
**Schema:**
```json
{
  "link": {
    "id": "string",
    "name": "string",
    "redirectTo": "string",
    "fieldKey": "string",
    "locationId": "string"
  }
}
```
**Example:**
```json
{"link":{"id":"n4AriwEnFrGh3tu08W0U","name":"first tag","redirectTo":"https://www.google.com/","fieldKey":"{{trigger_link.n4AriwEnFrGh3tu08W0U}}","locationId":"ve9EPM428h8vShlRW1KT"}}
```

### 10. PURPOSE:
This endpoint updates an existing trigger link with new name and redirect URL by its unique identifier.
