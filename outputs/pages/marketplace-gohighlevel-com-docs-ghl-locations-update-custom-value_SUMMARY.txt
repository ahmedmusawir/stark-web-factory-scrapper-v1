## STRUCTURED SUMMARY

### 1. ENDPOINT NAME:
Update Custom Value

### 2. CATEGORY:
Sub-Account (Location) Custom Values

### 3. HTTP METHOD:
PUT

### 4. ENDPOINT URL:
`/locations/:locationId/customValues/:id`

### 5. FULL URL:
`https://services.leadconnectorhq.com/locations/:locationId/customValues/:id`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters**:
    *   `Version` (string): API Version (Possible values: `2021-07-28`)
*   **Path Parameters**:
    *   `locationId` (string): Location Id
    *   `id` (string): Custom Value Id
*   **Body Parameters**:
    *   `name` (string): Custom Field Name
    *   `value` (string): Value

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:
*   **Auth Method(s)**: `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s)**: `Sub-Account Token`
*   **Scheme**: `bearer`
*   **Format**: `JWT`
*   **In**: `header`
*   **Description**: Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account.

### 9. RESPONSE FORMAT:
**Successful Response (200 OK):**
*   **Content Type**: `application/json`
*   **Structure**:
    ```json
    {
      "customValue": {
        "id": "string",
        "name": "string",
        "fieldKey": "string",
        "value": "string",
        "locationId": "string"
      }
    }
    ```
**Error Responses:**
*   **400 Bad Request**:
    ```json
    {"statusCode":400,"message":"Bad Request"}
    ```
*   **401 Unauthorized**:
    ```json
    {"statusCode":401,"message":"Invalid token: access token is invalid","error":"Unauthorized"}
    ```
*   **422 Unprocessable Entity**:
    ```json
    {"statusCode":422,"message":["Unprocessable Entity"],"error":"Unprocessable Entity"}
    ```

### 10. PURPOSE:
This endpoint is used to update an existing custom value associated with a specific location (sub-account).
