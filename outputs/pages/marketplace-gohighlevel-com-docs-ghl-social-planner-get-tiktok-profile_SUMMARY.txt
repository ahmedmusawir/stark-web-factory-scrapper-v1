Here is a structured summary of the provided API documentation:

### 1. ENDPOINT NAME:
Get Tiktok profile

### 2. CATEGORY:
Social Planner

### 3. HTTP METHOD:
GET

### 4. ENDPOINT URL:
`/social-media-posting/oauth/:locationId/tiktok/accounts/:accountId`

### 5. FULL URL:
`https://services.leadconnectorhq.com/social-media-posting/oauth/:locationId/tiktok/accounts/:accountId`

### 6. REQUIRED PARAMETERS:
*   `Version` (string): API Version. Possible values: `2021-07-28`. (Header Parameter)
*   `locationId` (string): Account Location Id. Example: `w37swmmLbA02zgqKPpxITe2`. (Path Parameter)
*   `accountId` (string): Account Id. Example: `w37swmmLbA02zgqKPpxIT`. (Path Parameter)

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** Bearer (JWT)
*   **Header:** `Authorization: Bearer <TOKEN>`

### 9. RESPONSE FORMAT:

#### 200 Successful response
*   **Content Type:** `application/json`
*   **Schema:**
    *   `success` (boolean): Success or Failure. Example: `true`
    *   `statusCode` (number): Status Code. Example: `200`
    *   `message` (string): Message. Example: `Fetched Tiktok Account`
    *   `results` (object): Requested Results
        *   `profile` (array of objects): Tiktok Profile
            *   `id` (string): Id. Example: `w37swmmLbA02zgqKPpxITe`
            *   `name` (string): Name of account. Example: `Account Name`
            *   `username` (string): Username of account. Example: `User_name`
            *   `avatar` (string): Avatar of profile account. Example: `w37swmmLbA02zgqKPpxITe`
            *   `verified` (boolean): Is verified. Example: `true`
            *   `isConnected` (boolean): Is connected. Example: `true`
            *   `type` (object): Tiktok Account Type must be one of the following values: business, profile. Example: `BUSINESS`
*   **Example:**
    ```json
    {
      "success": true,
      "statusCode": 200,
      "message": "Fetched Tiktok Account",
      "results": {
        "profile": [
          {
            "id": "w37swmmLbA02zgqKPpxITe",
            "name": "Account Name",
            "username": "User_name",
            "avatar": "w37swmmLbA02zgqKPpxITe",
            "verified": true,
            "isConnected": true,
            "type": "BUSINESS"
          }
        ]
      }
    }
    ```

#### Error Responses:
*   **400 Bad Request:**
    *   `statusCode` (number): `400`
    *   `message` (string): `Bad Request`
*   **401 Unauthorized:**
    *   `statusCode` (number): `401`
    *   `message` (string): `Invalid token: access token is invalid`
    *   `error` (string): `Unauthorized`
*   **422 Unprocessable Entity:**
    *   `statusCode` (number): `422`
    *   `message` (string[]): `["Unprocessable Entity"]`
    *   `error` (string): `Unprocessable Entity`

### 10. PURPOSE:
This endpoint retrieves the profile information for a specified TikTok account linked to a given location.
