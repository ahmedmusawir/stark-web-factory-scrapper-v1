# Orders
Documentation for payments API
## [📄️ List OrdersThe 'List Orders' API allows to retrieve a paginated list of orders. Customize your results by filtering orders based on name, alt type, order status, payment mode, date range, type of source, contact, funnel products or paginate through the list using the provided query parameters. This endpoint provides a straightforward way to explore and retrieve order information.](https://marketplace.gohighlevel.com/docs/ghl/payments/list-orders)## [📄️ Get Order by IDThe 'Get Order by ID' API allows to retrieve information for a specific order using its unique identifier. Use this endpoint to fetch details for a single order based on the provided order ID.](https://marketplace.gohighlevel.com/docs/ghl/payments/get-order-by-id)## [📄️ Record Order PaymentThe 'Record Order Payment' API allows to record a payment for an order. Use this endpoint to record payment for an order and update the order status to 'Paid'.](https://marketplace.gohighlevel.com/docs/ghl/payments/record-order-payment)
