Here's a structured summary of the API documentation for "Get all relations By record Id":

### 1. ENDPOINT NAME:
Get all relations By record Id

### 2. CATEGORY:
Associations

### 3. HTTP METHOD:
GET

### 4. ENDPOINT URL:
`/associations/relations/:recordId`

### 5. FULL URL:
`https://services.leadconnectorhq.com/associations/relations/:recordId`

### 6. REQUIRED PARAMETERS:
*   **recordId** (string): The ID of the record to get relations for.
*   **Version** (string): API Version. Possible values: [`2021-07-28`]
*   **locationId** (string): Your Sub Account's ID. Example: `clF1LD04GTUKN3b3XuOj`
*   **skip** (number): Offset for pagination. Example: `10`
*   **limit** (number): Number of records to return. Example: `100`

### 7. OPTIONAL PARAMETERS:
*   **associationIds** (string[]): A list of association IDs to filter the relations.

### 8. AUTHENTICATION:
*   **Scope(s):** `associations/relation.readonly`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** `bearer`
*   **Bearer Format:** `JWT`
*   **In:** `header`
*   **Description:** Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account.

### 9. RESPONSE FORMAT:

#### 200 OK (Successful response)
*   **Content-Type:** `application/json`
*   **Schema:**
    *   **locationId** (string): Example: `string`
    *   **id** (string): Example: `ve9EPM428h8vShlRW1KT`
    *   **key** (string): First Objects Association Label (custom_objects.children). Example: `student`
    *   **firstObjectLabel** (string): First Objects Association Label (custom_objects.children). Example: `student`
    *   **firstObjectKey** (string): First Objects Key. Example: `custom_objects.children`
    *   **secondObjectLabel** (string): Second Object Association Label (contact). Example: `Teacher`
    *   **secondObjectKey** (string): Second Objects Key. Example: `contact`
    *   **associationType** (string): Association Type can be USER_DEFINED or SYSTEM_DEFINED. Example: `USER_DEFINED`
*   **Example:**
    ```json
    {"locationId":"string","id":"ve9EPM428h8vShlRW1KT","key":"student","firstObjectLabel":"student","firstObjectKey":"custom_objects.children","secondObjectLabel":"Teacher","secondObjectKey":"contact","associationType":"USER_DEFINED"}
    ```

#### Error Responses:
*   **400 Bad Request:**
    *   `statusCode` (number): `400`
    *   `message` (string): `Bad Request`
*   **401 Unauthorized:**
    *   `statusCode` (number): `401`
    *   `message` (string): `Invalid token: access token is invalid`
    *   `error` (string): `Unauthorized`
*   **422 Unprocessable Entity:**
    *   `statusCode` (number): `422`
    *   `message` (string[]): `["Unprocessable Entity"]`
    *   `error` (string): `Unprocessable Entity`

### 10. PURPOSE:
This endpoint allows retrieval of all relations associated with a specific record ID within a given sub-account.
