Here is a structured summary of the API documentation:

### 1. ENDPOINT NAME:
Get Custom Menu Links

### 2. CATEGORY:
Custom menus

### 3. HTTP METHOD:
GET

### 4. ENDPOINT URL:
`/custom-menus/`

### 5. FULL URL:
`https://services.leadconnectorhq.com/custom-menus/`

### 6. REQUIRED PARAMETERS:
*   **Version** (string): API Version (Possible values: `2021-07-28`)

### 7. OPTIONAL PARAMETERS:
*   **locationId** (string): Unique identifier of the location
*   **skip** (number): Number of items to skip for pagination (Default: `0`)
*   **limit** (number): Maximum number of items to return (Possible values: `>= 1`, Default: `20`)
*   **query** (string): Search query to filter custom menus by name, supports partial || full names
*   **showOnCompany** (boolean): Filter to show only agency-level menu links. When omitted, fetches both agency and sub-account menu links. Ignored if locationId is provided.

### 8. AUTHENTICATION:
*   **Scope(s):** `custom-menu-link.readonly`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Agency Token`
*   **Scheme:** Bearer
*   **Bearer Format:** JWT
*   **In:** Header

### 9. RESPONSE FORMAT:
*   **Status Code:** `200 OK`
*   **Content Type:** `application/json`
*   **Schema:**
    *   **customMenus** (array of objects): Array of custom menu links
        *   **id** (string): Unique identifier for the custom menu
        *   **icon** (object): Icon information for the menu item
            *   **name** (string): Name of the icon
            *   **fontFamily** (string): Font family of the icon (Possible values: `fab`, `fas`, `far`)
        *   **title** (string): Title of the custom menu
        *   **url** (string): URL of the custom menu
        *   **order** (number): Order of the custom menu
        *   **showOnCompany** (boolean): Filter to show only agency-level menu links. When omitted, fetches both agency and sub-account menu links. Ignored if locationId is provided
        *   **showOnLocation** (boolean): Whether the menu must be displayed for sub-accounts level
        *   **showToAllLocations** (boolean): Whether the menu must be displayed to all sub-accounts
        *   **locations** (string[]): List of sub-account IDs where the menu should be shown. This list is applicable only when showOnLocation is true and showToAllLocations is false
        *   **openMode** (string): Mode for opening the menu link (Possible values: `iframe`, `new_tab`, `current_tab`)
        *   **userRole** (string): Which user-roles should the menu be accessible to? (Possible values: `all`, `admin`, `user`)
        *   **allowCamera** (boolean): Indicates if camera access is allowed for this menu
        *   **allowMicrophone** (boolean): Indicates if microphone access is allowed for this menu
    *   **totalLinks** (number): Total number of custom menu records

### 10. PURPOSE:
This endpoint fetches a collection of custom menus based on specified criteria, allowing clients to retrieve custom menu configurations, including menu items, categories, and associated metadata, with options for filtering, sorting, and pagination.
