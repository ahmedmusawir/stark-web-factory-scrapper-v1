Here is a structured summary of the API documentation for "Create Shipping Carrier":

### 1. ENDPOINT NAME
Create Shipping Carrier

### 2. CATEGORY
Store

### 3. HTTP METHOD
POST

### 4. ENDPOINT URL
`/store/shipping-carrier`

### 5. FULL URL
`https://services.leadconnectorhq.com/store/shipping-carrier`

### 6. REQUIRED PARAMETERS
*   **altId** (string): Location Id or Agency Id. Example: `6578278e879ad2646715ba9c`
*   **altType** (string): Possible values: `location`
*   **name** (string): Name of the shipping carrier. Example: `FedEx`
*   **callbackUrl** (string): The URL endpoint that GHL needs to retrieve shipping rates. This must be a public URL. Example: `https://example.com/get-shipping-rates`
*   **services** (object[]): An array of available shipping carrier services.
    *   **services[].name** (string): Name of the shipping carrier service. Example: `Priority Mail Express International`
    *   **services[].value** (string): Value of the shipping carrier service. Example: `PriorityMailExpressInternational`

### 7. OPTIONAL PARAMETERS
*   **allowsMultipleServiceSelection** (boolean): The seller can choose multiple services while creating shipping rates if this is true. Example: `true`

### 8. AUTHENTICATION
*   **Auth Method(s)**: `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s)**: `Sub-Account Token`
*   **Scheme**: Bearer (JWT) in the `Authorization` header.

### 9. RESPONSE FORMAT
*   **201 Created (Successful response)**:
    *   **Schema**:
        *   `status` (boolean): Status of api action. Example: `true`
        *   `message` (string): Success message. Example: `Successfully created`
        *   `data` (object): Shipping carrier data
            *   `altId` (string): Location Id or Agency Id. Example: `6578278e879ad2646715ba9c`
            *   `altType` (string): Possible values: `location`
            *   `name` (string): Name of the shipping carrier. Example: `FedEx`
            *   `callbackUrl` (string): The URL endpoint that GHL needs to retrieve shipping rates. This must be a public URL. Example: `https://example.com/get-shipping-rates`
            *   `services` (object[]): An array of available shipping carrier services (each object has `name` and `value`).
            *   `allowsMultipleServiceSelection` (boolean): The seller can choose multiple services while creating shipping rates if this is true. Example: `true`
            *   `_id` (string): The unique identifier for the product. Example: `655b33a82209e60b6adb87a5`
            *   `marketplaceAppId` (string): The unique identifier for the marketplace app. Example: `655b33a82209e60b6adb87a5`
            *   `createdAt` (string): Created at timestamp. Example: `2023-12-12T09:27:42.355Z`
            *   `updatedAt` (string): Updated at timestamp. Example: `2023-12-12T09:27:42.355Z`
*   **400 Bad Request**:
    *   **Schema**: `statusCode` (number), `message` (string)
*   **401 Unauthorized**:
    *   **Schema**: `statusCode` (number), `message` (string), `error` (string)
*   **422 Unprocessable Entity**:
    *   **Schema**: `statusCode` (number), `message` (string[]), `error` (string)

### 10. PURPOSE
The "Create Shipping Carrier" API allows adding a new shipping carrier to the GoHighLevel store.
