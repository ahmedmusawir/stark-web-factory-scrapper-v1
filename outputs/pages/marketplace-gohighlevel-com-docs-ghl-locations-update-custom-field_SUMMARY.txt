Here's a structured summary of the API documentation for "Update Custom Field":

---

### 1. ENDPOINT NAME:
Update Custom Field

### 2. CATEGORY:
Sub-Account (Formerly Location) - Custom Field

### 3. HTTP METHOD:
PUT

### 4. ENDPOINT URL:
`/locations/:locationId/customFields/:id`

### 5. FULL URL:
`https://services.leadconnectorhq.com/locations/:locationId/customFields/:id`

### 6. REQUIRED PARAMETERS:

*   **Header Parameters:**
    *   `Version` (string): API Version. Possible values: [`2021-07-28`]
*   **Path Parameters:**
    *   `locationId` (string): Location Id. Example: `ve9EPM428h8vShlRW1KT`
    *   `id` (string): Custom Field Id. Example: `00NhGCcN1tlO8ZHcu7Wb`
*   **Body Parameters (application/json):**
    *   `name` (string): The new name for the custom field. Example: `Custom Field`

### 7. OPTIONAL PARAMETERS:

*   **Body Parameters (application/json):**
    *   `placeholder` (string): Placeholder text for the custom field. Example: `Placeholder Text`
    *   `acceptedFormat` (string[]): An array of file formats accepted for file custom fields. Example: `[".pdf",".docx",".jpeg"]`
    *   `isMultipleFile` (boolean): Indicates if multiple files can be uploaded for a file custom field. Example: `false`
    *   `maxNumberOfFiles` (number): Maximum number of files allowed for a file custom field. Example: `2`
    *   `textBoxListOptions` (object[]): An array of objects for custom field list options. Each object contains:
        *   `label` (string): The label for the list option. Example: `First`
        *   `prefillValue` (string): The prefill value for the list option. Example: ``
    *   `position` (number): The display position of the custom field. Default value: `0`. Example: `0`
    *   `model` (string): The model to which the custom field belongs. Possible values: [`contact`, `opportunity`]. Example: `opportunity`

### 8. AUTHENTICATION:

*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** `Bearer` (JWT)
*   **In:** `header` (Authorization)

### 9. RESPONSE FORMAT:

*   **Successful Response (200 OK):**
    *   **Content Type:** `application/json`
    *   **Schema:**
        ```json
        {
          "customField": {
            "id": "string",
            "name": "string",
            "fieldKey": "string",
            "placeholder": "string",
            "dataType": "string",
            "position": "number",
            "picklistOptions": "string[]",
            "picklistImageOptions": "string[]",
            "isAllowedCustomOption": "boolean",
            "isMultiFileAllowed": "boolean",
            "maxFileLimit": "number",
            "locationId": "string",
            "model": "string" // Possible values: [`contact`, `opportunity`]
          }
        }
        ```
    *   **Example:**
        ```json
        {"customField":{"id":"3sv6UEo51C9Bmpo1cKTq","name":"pincode","fieldKey":"contact.pincode","placeholder":"Pin code","dataType":"TEXT","position":0,"picklistOptions":["first option"],"picklistImageOptions":[],"isAllowedCustomOption":false,"isMultiFileAllowed":true,"maxFileLimit":4,"locationId":"3sv6UEo51C9Bmpo1cKTq","model":"opportunity"}}
        ```
*   **Error Responses:**
    *   `400 Bad Request`: `{ "statusCode": 400, "message": "Bad Request" }`
    *   `401 Unauthorized`: `{ "statusCode": 401, "message": "Invalid token: access token is invalid", "error": "Unauthorized" }`
    *   `422 Unprocessable Entity`: `{ "statusCode": 422, "message": ["Unprocessable Entity"], "error": "Unprocessable Entity" }`

### 10. PURPOSE:
This endpoint allows you to update the details of an existing custom field associated with a specific sub-account (formerly location).
