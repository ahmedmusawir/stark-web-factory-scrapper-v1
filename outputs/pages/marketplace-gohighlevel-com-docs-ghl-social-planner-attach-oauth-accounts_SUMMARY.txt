Here's a structured summary of the API documentation for "Attach oauth accounts":

### 1. ENDPOINT NAME:
Attach oauth accounts

### 2. CATEGORY:
Social Planner | OAuth | Generic

### 3. HTTP METHOD:
POST

### 4. ENDPOINT URL:
`/social-media-posting/oauth/:locationId/:platform/accounts/:accountId`

### 5. FULL URL:
`https://services.leadconnectorhq.com/social-media-posting/oauth/:locationId/:platform/accounts/:accountId`

### 6. REQUIRED PARAMETERS:

*   **Header Parameters:**
    *   **Authorization** (string): Access Token (Example: `Bearer 9c48df2694a849b6089f9d0d3513efe`)
    *   **Version** (string): API Version (Possible values: `2021-07-28`)
*   **Path Parameters:**
    *   **locationId** (string): Account Location Id (Example: `w37swmmLbA02zgqKPpxITe2`)
    *   **platform** (string): Platform (Possible values: `google`, `facebook`, `instagram`, `linkedin`, `tiktok`, `youtube`, `pinterest`) (Example: `facebook`)
    *   **accountId** (string): Account Id (Example: `w37swmmLbA02zgqKPpxITe2`)
*   **Body Parameters (Platform-Specific):**
    *   **For Facebook:**
        *   **type** (string): Must be `page` (Example: `page`)
        *   **originId** (string) (Example: `244405****11687`)
        *   **name** (string) (Example: `JOHN_DEO`)
        *   **avatar** (string) (Example: `https://storage.googleapis.com/2ad21ebc23/test`)
    *   **For Instagram:**
        *   **originId** (string) (Example: `244405****11687`)
        *   **name** (string) (Example: `JOHN_DEO`)
        *   **avatar** (string)
    *   **For Google Business Account:**
        *   **pageId** (string) (Example: `234234234242sd`)
        *   **location** (object): If provided, the following sub-fields are required:
            *   **name** (string): Location name
            *   **title** (string): Location title
        *   **account** (object): If provided, the following sub-fields are required:
            *   **name** (string): Account name identifier
            *   **accountName** (string): Display name of the account
            *   **type** (string): Type of the account
            *   **verificationState** (string): State of account verification
            *   **vettedState** (string): Vetting state of the account
    *   **For Pinterest:**
        *   **originId** (string) (Example: `244405****11687`)
        *   **name** (string) (Example: `Ayush`)
        *   **avatar** (string)
    *   **For Tiktok:**
        *   **type** (string): Account type (Possible values: `page`, `group`, `profile`, `location`, `business`)
        *   **originId** (string) (Example: `244405****11687`)
        *   **name** (string) (Example: `JOHN_DEO`)
        *   **avatar** (string)
    *   **For YouTube:**
        *   **type** (string): Account type (Possible values: `profile`)
        *   **originId** (string) (Example: `244405****11687`)
        *   **name** (string) (Example: `Ayush`)
        *   **avatar** (string): Avatar URL
    *   **For LinkedIn:**
        *   **type** (string): Account type (Possible values: `page`, `group`, `profile`, `location`, `business`)
        *   **originId** (string) (Example: `244405****11687`)
        *   **name** (string) (Example: `JOHN_DEO`)
        *   **avatar** (string)
        *   **urn** (string)

### 7. OPTIONAL PARAMETERS:

*   **Body Parameters (Platform-Specific):**
    *   **For Google Business Account (within `location` object):**
        *   **storeCode** (string): Store code
        *   **storefrontAddress** (object): Storefront address details
        *   **metadata** (object): Additional metadata
        *   **maxLocation** (boolean): Whether this is a max location
        *   **isVerified** (boolean): Whether the location is verified
        *   **isConnected** (boolean): Whether the location is connected
    *   **For Tiktok:**
        *   **verified** (boolean): Verification status (Example: `true`)
        *   **username** (string) (Example: `@ayush`)
    *   **For YouTube:**
        *   **verified** (boolean): Verification status (Example: `true`)
        *   **username** (string) (Example: `@ayush`)
        *   **websiteUrl** (string): Website URL (Example: `https://www.website.com`)
        *   **companyId** (string): Company ID (Example: `companyId`)
        *   **originAccountType** (string): Origin account type

### 8. AUTHENTICATION:
*   **Method:** Bearer Token in the `Authorization` header.
*   **Token Type:** Access Token.
*   **Scopes:** Not specified in documentation.

### 9. RESPONSE FORMAT:

*   **201 Created (or 200 OK for LinkedIn):** Successful response - Account attached. Response structure varies by platform but generally includes:
    *   `success` (boolean): `true`
    *   `statusCode` (number): `201` (or `200` for LinkedIn)
    *   `message` (string): e.g., `Added Facebook Account`
    *   `results` (object): Contains details of the attached account, including `_id`, `oAuthId`, `locationId`, `originId`, `platform`, `type`, `name`, `avatar`, `meta` (object with platform-specific data), `active`, `deleted`, `createdAt`, `updatedAt`.
    *   **Example (Facebook):**
        ```json
        {
          "success": true,
          "statusCode": 201,
          "message": "Added Facebook Account",
          "results": {
            "_id": "65f2d989a4f2f1e5322c3856",
            "oAuthId": "u37swmmLbA02zgqKPpxITe2",
            "locationId": "u37swmmLbA02zgqKPpxITe2",
            "originId": "u37swmmLbA02zgqKPpxITe2",
            "platform": "facebook",
            "type": "page",
            "name": "Account Name",
            "avatar": "u37swmmLbA02zgqKPpxITe2",
            "meta": { /* ... */ },
            "active": true,
            "deleted": true,
            "createdAt": "2024-03-14T11:03:37.015Z",
            "updatedAt": "2024-03-14T11:03:37.015Z"
          }
        }
        ```

*   **400 Bad Request:**
    *   `statusCode` (number): `400`
    *   `message` (string): `Bad Request`
*   **401 Unauthorized:**
    *   `statusCode` (number): `401`
    *   `message` (string): `Invalid token: access token is invalid`
    *   `error` (string): `Unauthorized`
*   **422 Unprocessable Entity:**
    *   `statusCode` (number): `422`
    *   `message` (string[]): `["Unprocessable Entity"]`
    *   `error` (string): `Unprocessable Entity`

### 10. PURPOSE:
This endpoint is used to attach a social media account (like Facebook, Instagram, Google Business Profile, LinkedIn, TikTok, YouTube, or Pinterest) associated with an OAuth integration to a specific location within the HighLevel platform.
