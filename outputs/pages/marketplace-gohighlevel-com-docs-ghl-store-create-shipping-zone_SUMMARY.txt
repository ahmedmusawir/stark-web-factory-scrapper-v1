Here's a structured summary of the API documentation for "Create Shipping Zone":

### 1. ENDPOINT NAME
Create Shipping Zone

### 2. CATEGORY
Store

### 3. HTTP METHOD
POST

### 4. ENDPOINT URL
/store/shipping-zone

### 5. FULL URL
https://services.leadconnectorhq.com/store/shipping-zone

### 6. REQUIRED PARAMETERS
*   **Request Body (application/json)**
    *   `altId` (string): Location Id or Agency Id
    *   `altType` (string): Possible values: [`location`]
    *   `name` (string): Name of the shipping zone
    *   `countries` (object[]): List of countries that are available
        *   `code` (string): Country code (e.g., `US`, `CA`). Possible values include a comprehensive list of ISO 3166-1 alpha-2 codes.

### 7. OPTIONAL PARAMETERS
*   **Request Body (application/json)**
    *   `countries[].states` (object[]): List of states that are available for a given country. If states is empty, then all states for that country are available.
        *   `code` (string): State code (e.g., `VA`, `AL`). Possible values include a comprehensive list of state/province codes.

### 8. AUTHENTICATION
*   **Auth Method(s)**: `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s)**: `Sub-Account Token`
*   **Scheme**: `bearer`
*   **Bearer Format**: `JWT`
*   **In**: `header`
*   **Description**: Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account.
