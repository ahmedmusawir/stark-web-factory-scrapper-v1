Here is a structured summary of the provided API documentation:

### 1. ENDPOINT NAME:
Add Contact to Workflow

### 2. CATEGORY:
Contacts

### 3. HTTP METHOD:
POST

### 4. ENDPOINT URL:
`/contacts/:contactId/workflow/:workflowId`

### 5. FULL URL:
`https://services.leadconnectorhq.com/contacts/:contactId/workflow/:workflowId`

### 6. REQUIRED PARAMETERS:

*   **Header Parameters:**
    *   `Version` (string): API Version. Possible values: [`2021-07-28`]

*   **Path Parameters:**
    *   `contactId` (string): Contact Id. Example: `sx6wyHhbFdRXh302LLNR`
    *   `workflowId` (string): Workflow Id. Example: `sx6wyHhbFdRXh302LLNR`

*   **Body Parameters (application/json):**
    *   `eventStartTime` (string): The start time for the event in the workflow. Example: `2021-06-23T03:30:00+01:00`

### 7. OPTIONAL PARAMETERS:
Not specified in documentation
