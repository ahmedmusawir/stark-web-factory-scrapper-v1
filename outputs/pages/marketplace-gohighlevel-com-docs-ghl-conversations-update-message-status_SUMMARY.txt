Here is a structured summary of the API documentation for "Update message status":

### 1. ENDPOINT NAME:
Update message status

### 2. CATEGORY:
Conversations / Messages

### 3. HTTP METHOD:
PUT

### 4. ENDPOINT URL:
`/conversations/messages/:messageId/status`

### 5. FULL URL:
`https://services.leadconnectorhq.com/conversations/messages/:messageId/status`

### 6. REQUIRED PARAMETERS:

*   **Header Parameters:**
    *   `Version` (string): API Version. Possible values: [`2021-04-15`]
*   **Path Parameters:**
    *   `messageId` (string): Message Id. Example: `ve9EPM428h8vShlRW1KT`
*   **Body Parameters:**
    *   `status` (string): Message status. Possible values: [`delivered`, `failed`, `pending`, `read`]. Example: `read`
    *   `error.code` (string): Error Code (Required if `error` object is provided). Example: `1`
    *   `error.type` (string): Error Type (Required if `error` object is provided). Example: `saas`
    *   `error.message` (string): Error Message (Required if `error` object is provided). Example: `There was an error from the provider`

### 7. OPTIONAL PARAMETERS:

*   **Body Parameters:**
    *   `error` (object): Error object from the conversation provider.
    *   `emailMessageId` (string): Email message Id. Example: `ve9EPM428h8vShlRW1KT`
    *   `recipients` (string[]): Email delivery status for additional email recipients.

### 8. AUTHENTICATION:

*   **Scope(s):** `conversations/message.write`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** `bearer`
*   **Bearer Format:** `JWT`
*   **In:** `header` (Authorization header)

### 9. RESPONSE FORMAT:

*   **200 OK (application/json)**:
    *   `conversationId` (string): Conversation ID. (required)
    *   `emailMessageId` (string): This contains the email message id (only for Email type). Use this ID to send inbound replies to GHL to create a threaded email.
    *   `messageId` (string): This is the main Message ID. (required)
    *   `messageIds` (string[]): When sending via the GMB channel, a list of `messageIds` is returned.
    *   `msg` (string): Additional response message when sending a workflow message.
    *   **Example:**
        ```json
        {
          "conversationId": "ABC12h2F6uBrIkfXYazb",
          "emailMessageId": "rnGyqh2F6uBrIkfhFo9A",
          "messageId": "t22c6DQcTDf3MjRhwf77",
          "messageIds": ["string"],
          "msg": "Message queued successfully."
        }
        ```

### 10. PURPOSE:
This endpoint allows you to update the status of a specific message within a conversation by posting the necessary fields.
