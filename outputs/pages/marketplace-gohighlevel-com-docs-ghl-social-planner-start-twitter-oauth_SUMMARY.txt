### API Documentation Summary

**1. ENDPOINT NAME:** Starts OAuth For Twitter Account

**2. CATEGORY:** Social Planner (specifically Oauth | Twitter)

**3. HTTP METHOD:** GET

**4. ENDPOINT URL:** `/social-media-posting/oauth/twitter/start`

**5. FULL URL:** `https://services.leadconnectorhq.com/social-media-posting/oauth/twitter/start`

**6. REQUIRED PARAMETERS:**
   - `Version` (string): API Version. Possible values: `2021-07-28` (Header Parameter)
   - `locationId` (string): Location Id. Example: `w37swmmLbA02zgqKPpxITe2` (Query Parameter)
   - `userId` (string): User Id. Example: `u37swmmLbA02zgqKPpxITe2` (Query Parameter)

**7. OPTIONAL PARAMETERS:**
   - `page` (string): Page. Example: `integration` (Query Parameter)
   - `reconnect` (string): Reconnect. Example: `true` (Query Parameter)

**8. AUTHENTICATION:**
   - **Scope(s):** `socialplanner/oauth.readonly`
   - **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
   - **Token Type(s):** `Sub-Account Token`
   - **Description:** Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account.

**9. RESPONSE FORMAT:**
   - **200 (Successful Response):** Not specified in documentation (no schema or example for 200)
   - **400 (Bad Request):**
     - Schema:
       - `statusCode` (number): Example: `400`
       - `message` (string): Example: `Bad Request`
     - Example: `{"statusCode":400,"message":"Bad Request"}`
   - **401 (Unauthorized):**
     - Schema:
       - `statusCode` (number): Example: `401`
       - `message` (string): Example: `Invalid token: access token is invalid`
       - `error` (string): Example: `Unauthorized`
     - Example: `{"statusCode":401,"message":"Invalid token: access token is invalid","error":"Unauthorized"}`
   - **422 (Unprocessable Entity):**
     - Schema:
       - `statusCode` (number): Example: `422`
       - `message` (string[]): Example: `["Unprocessable Entity"]`
       - `error` (string): Example: `Unprocessable Entity`
     - Example: `{"statusCode":422,"message":["Unprocessable Entity"],"error":"Unprocessable Entity"}`

**10. PURPOSE:** This endpoint initiates the OAuth process for connecting a Twitter account to the Social Planner, though it is currently deprecated and Twitter (X) support has been removed as of December 4, 2024.
