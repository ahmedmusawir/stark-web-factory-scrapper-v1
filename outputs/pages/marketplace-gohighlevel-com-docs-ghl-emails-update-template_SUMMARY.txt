Here is a structured summary of the API documentation:

### 1. ENDPOINT NAME:
Update a template

### 2. CATEGORY:
Email Templates

### 3. HTTP METHOD:
POST

### 4. ENDPOINT URL:
`/emails/builder/data`

### 5. FULL URL:
`https://services.leadconnectorhq.com/emails/builder/data`

### 6. REQUIRED PARAMETERS:

*   **Header Parameters:**
    *   `Version` (string): API Version. Possible values: [`2021-07-28`]

*   **Body Parameters:**
    *   `locationId` (string): The ID of the sub-account (location). Example: `ve9EPM428h8vShlRW1KT`
    *   `templateId` (string): The ID of the email template to update. Example: `zYy3YOUuHxgomU1uYJty`
    *   `updatedBy` (string): The ID of the user who is updating the template. Example: `zYy3YOUuHxgomU1uYJty`
    *   `elements` (string[]): Not specified further in description, but required.
    *   `attrs` (object): Not specified further in description, but required.
    *   `templateSettings` (object): Not specified further in description, but required.
    *   `html` (string): The HTML content of the email template. Example: `""`
    *   `editorType` (string): The type of editor used for the template. Possible values: [`html`, `builder`]

### 7. OPTIONAL PARAMETERS:

*   **Body Parameters:**
    *   `dnd` (object): Not specified further in description.
    *   `previewText` (string): The preview text for the email. Example: `zYy3YOUuHxgomU1uYJty`
    *   `isPlainText` (boolean): Indicates if the email is plain text. Example: `false`

### 8. AUTHENTICATION:

*   **Scope(s):** `emails/builder.write`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** Bearer (JWT)
*   **In:** Header (Authorization header)

### 9. RESPONSE FORMAT:

*   **Status Code:** `201` (Success)
*   **Content Type:** `application/json`
*   **Schema:**
    ```json
    {
      "ok": "true",
      "traceId": "0c52e980-41f6-4be7-8c4b-32332ss",
      "previewUrl": "https://example.com",
      "templateDownloadUrl": "https://example.com"
    }
    ```
    *   `ok` (string): Indicates success. Example: `true`
    *   `traceId` (string): A unique trace ID for the request. Example: `0c52e980-41f6-4be7-8c4b-32332ss`
    *   `previewUrl` (string): URL to preview the updated template. Example: `https://example.com`
    *   `templateDownloadUrl` (string): URL to download the template data. Example: `https://example.com`

### 10. PURPOSE:
This endpoint allows you to update an existing email template within a specified location (sub-account).
