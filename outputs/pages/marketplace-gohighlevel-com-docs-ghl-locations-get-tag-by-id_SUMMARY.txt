Here is a structured summary of the API documentation for "Get tag by id":

### 1. ENDPOINT NAME:
Get tag by id

### 2. CATEGORY:
Sub-Account (formerly Location) / Tags

### 3. HTTP METHOD:
GET

### 4. ENDPOINT URL:
`/locations/:locationId/tags/:tagId`

### 5. FULL URL:
`https://services.leadconnectorhq.com/locations/:locationId/tags/:tagId`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters:**
    *   Version (string): API Version. Possible values: `2021-07-28`
*   **Path Parameters:**
    *   locationId (string): Location Id. Example: `ve9EPM428h8vShlRW1KT`
    *   tagId (string): Tag Id. Example: `flGwEuzsfJOia1i1ikRN`

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** Bearer (JWT)
*   **In:** Header (Authorization)
*   **Description:** Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account.

### 9. RESPONSE FORMAT:
*   **200 OK (Successful response):**
    *   Content-Type: `application/json`
    *   Schema:
        ```json
        {
          "tag": {
            "name": "string",
            "locationId": "string",
            "id": "string"
          }
        }
        ```
    *   Example:
        ```json
        {"tag":{"name":"minim aliquip anim","locationId":"ve9EPM428h8vShlRW1KT","id":"flGwEuzsfJOia1i1ikRN"}}
        ```
*   **Error Responses:**
    *   `400 Bad Request` (application/json)
    *   `401 Unauthorized` (application/json)
    *   `422 Unprocessable Entity` (application/json)

### 10. PURPOSE:
This endpoint retrieves a specific tag associated with a sub-account (formerly location) by its ID.
