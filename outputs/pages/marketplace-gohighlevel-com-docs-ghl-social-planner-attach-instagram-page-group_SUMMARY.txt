Here's a structured summary of the API documentation:

### 1. ENDPOINT NAME:
Attach Instagram Professional Accounts

### 2. CATEGORY:
Social Planner

### 3. HTTP METHOD:
POST

### 4. ENDPOINT URL:
`/social-media-posting/oauth/:locationId/instagram/accounts/:accountId`

### 5. FULL URL:
`https://services.leadconnectorhq.com/social-media-posting/oauth/:locationId/instagram/accounts/:accountId`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters:**
    *   `Version` (string): API Version. Possible values: [`2021-07-28`]
*   **Path Parameters:**
    *   `locationId` (string): Account Location Id. Example: `w37swmmLbA02zgqKPpxITe2`
    *   `accountId` (string): Account Id. Example: `w37swmmLbA02zgqKPpxITe`
*   **Body Parameters:**
    *   `pageId` (string): Example: `234234234242sd`

### 7. OPTIONAL PARAMETERS:
*   **Body Parameters:**
    *   `originId` (string): Example: `244405****11687`
    *   `name` (string): Example: `JOHN_DEO`
    *   `avatar` (string): No example, just "string"

### 8. AUTHENTICATION:
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Authorization Header:** `Bearer <TOKEN>` (JWT format)
*   **Description:** Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account.

### 9. RESPONSE FORMAT:
*   **Successful Response (201 Created):**
    *   **Content Type:** `application/json`
    *   **Structure:**
        ```json
        {
          "success": boolean,
          "statusCode": number,
          "message": string,
          "results": {
            "_id": string,
            "oAuthId": string,
            "oldId": string,
            "locationId": string,
            "originId": string,
            "platform": string (e.g., "instagram"),
            "type": string (e.g., "profile"),
            "name": string,
            "avatar": string,
            "meta": object, // Contains detailed information about the page and account
            "active": boolean,
            "deleted": boolean,
            "createdAt": date-time,
            "updatedAt": date-time
          }
        }
        ```
    *   **Example Message:** `"Added Instagram Account"`

*   **Error Responses:**
    *   **400 Bad Request:** `{"statusCode":400,"message":"Bad Request"}`
    *   **401 Unauthorized:** `{"statusCode":401,"message":"Invalid token: access token is invalid","error":"Unauthorized"}`
    *   **422 Unprocessable Entity:** `{"statusCode":422,"message":["Unprocessable Entity"],"error":"Unprocessable Entity"}`

### 10. PURPOSE:
This endpoint allows users to attach an Instagram Professional Account to a specific sub-account location within the HighLevel platform.
