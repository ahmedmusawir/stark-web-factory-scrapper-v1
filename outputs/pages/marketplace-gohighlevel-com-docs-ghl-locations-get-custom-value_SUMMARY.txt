Here is the structured summary of the API documentation:

### 1. ENDPOINT NAME:
Get Custom Value

### 2. CATEGORY:
Sub-Account (Formerly location), Custom Value

### 3. HTTP METHOD:
GET

### 4. ENDPOINT URL:
`/locations/:locationId/customValues/:id`

### 5. FULL URL:
`https://services.leadconnectorhq.com/locations/:locationId/customValues/:id`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters:**
    *   `Version` (string): API Version (Possible values: `2021-07-28`)
*   **Path Parameters:**
    *   `locationId` (string): Location Id
    *   `id` (string): Custom Value Id

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** Bearer (JWT)
*   **Description:** Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account.

### 9. RESPONSE FORMAT:
**Status Code:** `200 OK`
**Content Type:** `application/json`
**Structure:**
```json
{
  "customValue": {
    "id": "string",
    "name": "string",
    "fieldKey": "string",
    "value": "string",
    "locationId": "string"
  }
}
```
**Example:**
```json
{"customValue":{"id":"rWQ709Pb62syqGLceg1x","name":"Custom Field","fieldKey":"{{ custom_values.custom_field }}","value":"Value","locationId":"rWQ709Pb6dasyqGLceg1x"}}
```

### 10. PURPOSE:
This endpoint retrieves the details of a specific custom value associated with a given sub-account (formerly location).

Sub-Account, Location, Custom Value, Get, Retrieve, Read, API, Data, Custom Field
