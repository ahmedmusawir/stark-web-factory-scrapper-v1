```
1. ENDPOINT NAME: Fetch Product Store Stats

2. CATEGORY: Products

3. HTTP METHOD: GET

4. ENDPOINT URL: /products/store/:storeId/stats

5. FULL URL: https://services.leadconnectorhq.com/products/store/:storeId/stats

6. REQUIRED PARAMETERS:
   - Version (string): API Version. Possible values: [`2021-07-28`]
   - storeId (string): Products related to the store. Example: `3SwdhCu3svxI8AKsPJt6`
   - altId (string): Location Id or Agency Id. Example: `6578278e879ad2646715ba9c`
   - altType (string): Possible values: [`location`]

7. OPTIONAL PARAMETERS:
   - search (string): The name of the product for searching. Example: `Awesome product`
   - collectionIds (string): Filter by product collection Ids. Supports comma separated values. Example: `65c2789a812e52f9bd6ec577,65c2789a812e52de9a6ec576`

8. AUTHENTICATION:
   - Required Scope(s): `products.readonly`
   - Auth Method(s): `OAuth Access Token`, `Private Integration Token`
   - Token Type(s): `Sub-Account Token`
   - Authorization Header: `Authorization: Bearer <TOKEN>`
   - Description: Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account.

9. RESPONSE FORMAT:
   - **Successful Response (200 OK):**
     - Content-Type: `application/json`
     - Schema:
       - `totalProducts` (number): Total number of products. Example: `100`
       - `includedInStore` (number): Number of products included in the store. Example: `80`
       - `excludedFromStore` (number): Number of products excluded from the store. Example: `20`
     - Example:
       ```json
       {"totalProducts":100,"includedInStore":80,"excludedFromStore":20}
       ```
   - **Error Responses:**
     - **400 Bad Request:**
       - Schema: `statusCode` (number), `message` (string)
       - Example: `{"statusCode":400,"message":"Bad Request"}`
     - **401 Unauthorized:**
       - Schema: `statusCode` (number), `message` (string), `error` (string)
       - Example: `{"statusCode":401,"message":"Invalid token: access token is invalid","error":"Unauthorized"}`
     - **422 Unprocessable Entity:**
       - Schema: `statusCode` (number), `message` (string[]), `error` (string)
       - Example: `{"statusCode":422,"message":["Unprocessable Entity"],"error":"Unprocessable Entity"}`

10. PURPOSE: API to fetch the total number of products, included in the store, and excluded from the store and other stats.

11. TAGS: Products, Store, Stats, Fetch, Get, Product Management, E-commerce, Inventory, Analytics, HighLevel

12. CODE EXAMPLES:
    - Available for: cURL, nodejs, python, php, java, go, ruby, powershell.
```
