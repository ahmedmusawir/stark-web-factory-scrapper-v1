Here's a structured summary of the "Create Association" API documentation:

### 1. ENDPOINT NAME:
Create Association

### 2. CATEGORY:
Associations

### 3. HTTP METHOD:
POST

### 4. ENDPOINT URL:
`/associations/`

### 5. FULL URL:
`https://services.leadconnectorhq.com/associations/`

### 6. REQUIRED PARAMETERS:
*   **Header Parameters:**
    *   `Version` (string): API Version. Possible values: [`2021-07-28`]
*   **Body Parameters:**
    *   `locationId` (string): Description not provided. (Example: `string`)
    *   `key` (string): Association's Unique key. (Example: `student_teacher`)
    *   `firstObjectLabel` (object): First Objects Association Label (custom_objects.children). (Example: `student`)
    *   `firstObjectKey` (object): First Objects Key. (Example: `custom_objects.children`)
    *   `secondObjectLabel` (object): Second Object Association Label (contact). (Example: `Teacher`)
    *   `secondObjectKey` (object): Second Objects Key. (Example: `contact`)

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:
*   **Scope(s)**: `associations.write`
*   **Auth Method(s)**: `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s)**: `Sub-Account Token`
*   **Scheme**: Bearer (JWT)

### 9. RESPONSE FORMAT:

*   **Status Code**: `201` (Successful response)
*   **Content Type**: `application/json`
*   **Schema**:
    *   `locationId` (string): Description not provided. (Example: `string`)
    *   `id` (string): Description not provided. (Example: `ve9EPM428h8vShlRW1KT`)
    *   `key` (string): First Objects Association Label (custom_objects.children). (Example: `student`)
    *   `firstObjectLabel` (object): First Objects Association Label (custom_objects.children). (Example: `student`)
    *   `firstObjectKey` (object): First Objects Key. (Example: `custom_objects.children`)
    *   `secondObjectLabel` (object): Second Object Association Label (contact). (Example: `Teacher`)
    *   `secondObjectKey` (object): Second Objects Key. (Example: `contact`)
    *   `associationType` (object): Association Type can be USER_DEFINED or SYSTEM_DEFINED. (Example: `USER_DEFINED`)
*   **Example JSON (201 Success)**:
    ```json
    {"locationId":"string","id":"ve9EPM428h8vShlRW1KT","key":"student","firstObjectLabel":"student","firstObjectKey":"custom_objects.children","secondObjectLabel":"Teacher","secondObjectKey":"contact","associationType":"USER_DEFINED"}
    ```
*   **Error Responses**:
    *   `400 Bad Request`: `{"statusCode":400,"message":"Bad Request"}`
    *   `401 Unauthorized`: `{"statusCode":401,"message":"Invalid token: access token is invalid","error":"Unauthorized"}`
    *   `422 Unprocessable Entity`: `{"statusCode":422,"message":["Unprocessable Entity"],"error":"Unprocessable Entity"}`

### 10. PURPOSE:
Allows you to create contact-contact and contact-custom object associations, with more planned for the future.
