Here is a structured summary of the provided API documentation:

### 1. ENDPOINT NAME:
Delete a knowledge base

### 2. CATEGORY:
Knowledge Base

### 3. HTTP METHOD:
DELETE

### 4. ENDPOINT URL:
`/knowledge-bases/:knowledgeBaseId`

### 5. FULL URL:
`https://services.leadconnectorhq.com/knowledge-bases/:knowledgeBaseId`

### 6. REQUIRED PARAMETERS:
*   **Authorization** (string): Access Token
*   **Version** (string): API Version (Possible values: `2021-04-15`)
*   **knowledgeBaseId** (string): The ID of the knowledge base to delete.

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:
*   **Auth Method(s)**: `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s)**: `Sub-Account Token`
*   **Details**: Use the Access Token generated with user type as Sub-Account (OR) Private Integration Token of Sub-Account. The token should be passed in the `Authorization` header with a `Bearer` scheme.

### 9. RESPONSE FORMAT:
*   **Success (200 OK)**:
    *   **Content Type**: `application/json`
    *   **Schema**:
        ```json
        {
          "success": true
        }
        ```
*   **Bad Request (400)**:
    *   **Content Type**: `application/json`
    *   **Schema**:
        ```json
        {
          "statusCode": 400,
          "message": "Bad Request"
        }
        ```
*   **Unauthorized (401)**:
    *   **Content Type**: `application/json`
    *   **Schema**:
        ```json
        {
          "statusCode": 401,
          "message": "Invalid token: access token is invalid",
          "error": "Unauthorized"
        }
        ```

### 10. PURPOSE:
This endpoint is used to delete an existing knowledge base by its unique identifier.
