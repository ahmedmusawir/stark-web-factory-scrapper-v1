Here's a structured summary of the "Get Conversation" API documentation:

### 1. ENDPOINT NAME:
Get Conversation

### 2. CATEGORY:
Conversations

### 3. HTTP METHOD:
GET

### 4. ENDPOINT URL:
`/conversations/:conversationId`

### 5. FULL URL:
`https://services.leadconnectorhq.com/conversations/:conversationId`

### 6. REQUIRED PARAMETERS:
*   `Version` (string): API Version. Possible values: `[2021-04-15]`.
*   `conversationId` (string): Conversation ID as string. Example: `tDtDnQdgm2LXpyiqYvZ6`.

### 7. OPTIONAL PARAMETERS:
Not specified in documentation

### 8. AUTHENTICATION:
*   **Scope(s):** `conversations.readonly`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** Bearer (JWT)

### 9. RESPONSE FORMAT:
**Status Code:** `200`
**Content Type:** `application/json`
**Schema:**
*   `contactId` (string, required): Unique identifier of the contact associated with this conversation. Example: `ve9EPM428kjkvShlRW1KT`.
*   `locationId` (string, required): Unique identifier of the business location where this conversation takes place. Example: `ve9EPM428kjkvShlRW1KT`.
*   `deleted` (boolean, required): Flag indicating if this conversation has been moved to trash/deleted. Example: `false`.
*   `inbox` (boolean, required): Flag indicating if this conversation is currently in the main inbox view. Example: `true`.
*   `type` (number, required): Communication channel type for this conversation: 1 (Phone), 2 (Email), 3 (Facebook Messenger), 4 (Review), 5 (Group SMS), 6 (Internal Chat - coming soon). Example: `0`.
*   `unreadCount` (number, required): Number of messages in this conversation that have not been read by the user. Example: `1`.
*   `assignedTo` (string, optional): Unique identifier of the team member currently responsible for handling this conversation. Example: `ve9EPM428kjkvShlRW1KT`.
*   `id` (string, required): Unique identifier for this specific conversation thread. Example: `ve9EPM428kjkvShlRW1KT`.
*   `starred` (boolean, optional): Flag indicating if this conversation has been marked as important/starred by the user. Example: `true`.

**Example:**
```json
{"contactId":"ve9EPM428kjkvShlRW1KT","locationId":"ve9EPM428kjkvShlRW1KT","deleted":false,"inbox":true,"type":0,"unreadCount":1,"assignedTo":"ve9EPM428kjkvShlRW1KT","id":"ve9EPM428kjkvShlRW1KT","starred":true}
```

### 10. PURPOSE:
This endpoint retrieves the details of a specific conversation using its unique conversation ID.

### 11. TAGS:
Conversations, Get, Retrieve, Read, Conversation ID, Details, HighLevel, API, Chat.

Code examples are available for `curl`, `nodejs`, `python`, `php`, `java`, `go`, `ruby`, and `powershell`. A `curl` example is provided in the documentation.
