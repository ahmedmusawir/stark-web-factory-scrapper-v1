Here is a structured summary of the API documentation for the "Delete Relation" endpoint:

### 1. ENDPOINT NAME
Delete Relation

### 2. CATEGORY
Associations

### 3. HTTP METHOD
DELETE

### 4. ENDPOINT URL
`/associations/relations/:relationId`

### 5. FULL URL
`https://services.leadconnectorhq.com/associations/relations/:relationId`

### 6. REQUIRED PARAMETERS
*   **Header Parameters:**
    *   `Version` (string): API Version. Possible values: `2021-07-28`
*   **Path Parameters:**
    *   `relationId` (string): The unique identifier of the relation to be deleted.
*   **Query Parameters:**
    *   `locationId` (string): Your Sub Account's ID. Example: `clF1LD04GTUKN3b3XuOj`

### 7. OPTIONAL PARAMETERS
Not specified in documentation

### 8. AUTHENTICATION
*   **Scope(s):** `associations/relation.write`
*   **Auth Method(s):** `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s):** `Sub-Account Token`
*   **Scheme:** `bearer` (JWT format)
*   **In:** `header` (Authorization header)

### 9. RESPONSE FORMAT

#### 200 Successful response
*   **Content-Type:** `application/json`
*   **Schema:**
    *   `locationId` (string, required): Example: `string`
    *   `id` (string, required): Example: `ve9EPM428h8vShlRW1KT`
    *   `key` (string, required): First Objects Association Label (custom_objects.children). Example: `student`
    *   `firstObjectLabel` (object, required): First Objects Association Label (custom_objects.children). Example: `student`
    *   `firstObjectKey` (object, required): First Objects Key. Example: `custom_objects.children`
    *   `secondObjectLabel` (object, required): Second Object Association Label (contact). Example: `Teacher`
    *   `secondObjectKey` (object, required): Second Objects Key. Example: `contact`
    *   `associationType` (object, required): Association Type can be USER_DEFINED or SYSTEM_DEFINED. Example: `USER_DEFINED`
*   **Example (JSON):**
    ```json
    {
      "locationId": "string",
      "id": "ve9EPM428h8vShlRW1KT",
      "key": "student",
      "firstObjectLabel": "student",
      "firstObjectKey": "custom_objects.children",
      "secondObjectLabel": "Teacher",
      "secondObjectKey": "contact",
      "associationType": "USER_DEFINED"
    }
    ```

#### Error Responses
*   **400 Bad Request:**
    *   Schema: `statusCode` (number), `message` (string)
    *   Example: `{"statusCode":400,"message":"Bad Request"}`
*   **401 Unauthorized:**
    *   Schema: `statusCode` (number), `message` (string), `error` (string)
    *   Example: `{"statusCode":401,"message":"Invalid token: access token is invalid","error":"Unauthorized"}`
*   **422 Unprocessable Entity:**
    *   Schema: `statusCode` (number), `message` (string[]), `error` (string)
    *   Example: `{"statusCode":422,"message":["Unprocessable Entity"],"error":"Unprocessable Entity"}`

### 10. PURPOSE
This endpoint allows you to delete an existing relation between associated entities within a specific sub-account.
