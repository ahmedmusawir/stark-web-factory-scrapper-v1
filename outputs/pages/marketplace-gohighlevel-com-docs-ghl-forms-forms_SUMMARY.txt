*   **ENDPOINT NAME:** Upload files to custom fields
*   **CATEGORY:** Forms
*   **HTTP METHOD:** Inferred: POST (based on "Post the necessary fields")
*   **ENDPOINT URL:** Not specified in this documentation snippet; only a documentation link is provided.
*   **FULL URL:** Not specified in this documentation snippet; only a documentation link is provided.
*   **REQUIRED PARAMETERS:**
    *   `<custom_field_id>_<file_id>` (buffer): The file content. The key format must be '< custom_field_id >_< file_id >', where `custom_field_id` is the ID of your custom field and `file_id` is a randomly generated ID (or UUID). Support for multiple file uploads is available by providing multiple fields in this format. File size is limited to 50 MB.
        Allowed file types: PDF, DOCX, DOC, JPG, JPEG, PNG, GIF, CSV, XLSX, XLS, MP4, MPEG, ZIP, RAR, TXT, SVG.
