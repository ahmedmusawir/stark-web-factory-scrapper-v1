Here's a structured summary of the API documentation for "Get notifications":

---

### 1. ENDPOINT NAME:
Get notifications

### 2. CATEGORY:
Calendars, Calendar Notifications

### 3. HTTP METHOD:
GET

### 4. ENDPOINT URL:
`/calendars/:calendarId/notifications`

### 5. FULL URL:
`https://services.leadconnectorhq.com/calendars/:calendarId/notifications`

### 6. REQUIRED PARAMETERS:
*   **Version** (string): API Version. Possible values: [`2021-04-15`] (Header Parameter)
*   **calendarId** (string): Calendar ID (Path Parameter)

### 7. OPTIONAL PARAMETERS:
*   **isActive** (boolean): Filter by active status (Query Parameter)
*   **deleted** (boolean): Filter by deleted status (Query Parameter)
*   **limit** (number): Number of records to return. Default value: `100` (Query Parameter)
*   **skip** (number): Number of records to skip. Default value: `0` (Query Parameter)

### 8. AUTHENTICATION:
*   **Scope(s)**: `calendars/events.readonly`
*   **Auth Method(s)**: `OAuth Access Token`, `Private Integration Token`
*   **Token Type(s)**: `Sub-Account Token`
*   **Scheme**: `bearer` with `JWT` format, passed `in: header` as `Authorization: Bearer <TOKEN>`.

### 9. RESPONSE FORMAT:

*   **200 OK (Successful response)**
    *   **Content Type**: `application/json`
    *   **Schema**: An array of notification objects.
        *   `_id` (string): Notification ID
        *   `receiverType` (string): Possible values: [`contact`, `guest`, `assignedUser`, `emails`, `phoneNumbers`]
        *   `additionalEmailIds` (string[]): Array of additional email IDs
        *   `additionalPhoneNumbers` (string[]): Array of additional phone numbers
        *   `channel` (string): Possible values: [`email`, `inApp`, `sms`, `whatsapp`]
        *   `notificationType` (string): Possible values: [`booked`, `confirmation`, `cancellation`, `reminder`, `followup`, `reschedule`]
        *   `isActive` (boolean)
        *   `additionalWhatsappNumbers` (string[]): Array of additional WhatsApp numbers
        *   `templateId` (string)
        *   `body` (string)
        *   `subject` (string)
        *   `afterTime` (object[]): Array of objects
            *   `timeOffset` (number)
            *   `unit` (string)
        *   `beforeTime` (object[]): Array of objects
            *   `timeOffset` (number)
            *   `unit` (string)
        *   `selectedUsers` (string[]): Array of selected user IDs
        *   `deleted` (boolean)

*   **400 Bad Request**
    *   **Content Type**: `application/json`
    *   **Schema**: `{"statusCode": 400, "message": "Bad Request"}`

*   **401 Unauthorized**
    *   **Content Type**: `application/json`
    *   **Schema**: `{"statusCode": 401, "message": "Invalid token: access token is invalid", "error": "Unauthorized"}`

### 10. PURPOSE:
This endpoint retrieves a list of calendar notifications for a specific calendar, with optional filtering by active or deleted status, and pagination.

### 11. TAGS:
Calendars, Notifications, Get, Read, Events, Calendar Notifications, Sub-Account, Query, List
