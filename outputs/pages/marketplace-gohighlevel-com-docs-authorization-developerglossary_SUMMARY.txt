Not specified for *this document*. However, the document *defines* several authentication-related terms:

*   **OAuth (Open Authorization):** Industry-standard protocol for secure app authorization.
*   **Scopes:** Define specific permissions and access rights required by an app (e.g., [Gohighlevel's OAuth Scopes](https://marketplace.gohighlevel.com/docs/Authorization/Scopes)).

*   **API Key:** Unique identifier or code for API access and authentication.
