Here's a structured summary of the AppUninstall Webhook documentation:

### 1. ENDPOINT NAME:
AppUninstall

### 2. CATEGORY:
Webhook

### 3. HTTP METHOD:
Not applicable. This describes an event payload sent *from* HighLevel *to* a pre-configured URL, not a client-callable API endpoint with a specific HTTP method.

### 4. ENDPOINT URL:
Not applicable. This is an event webhook payload, not an API endpoint path to call.

### 5. FULL URL:
`https://marketplace.gohighlevel.com/docs/webhook/AppUninstall` (This is the documentation URL)

### 6. REQUIRED PARAMETERS (in webhook payload):
*   `type` (string): The type of event. This will always be `"UNINSTALL"`.
*   `appId` (string): The unique identifier of the app that was uninstalled.
*   *One of the following must be present, depending on the level of app uninstallation:*
    *   `companyId` (string): The ID of the company/agency if the app was uninstalled at the agency level.
    *   `locationId` (string): The ID of the location (sub-account) if the app was uninstalled at the location level.

### 7. OPTIONAL PARAMETERS:
Not specified in documentation. All parameters defined in the schema and examples are essential for the event payload.

### 8. AUTHENTICATION:
Not specified in documentation. Webhooks typically rely on verification mechanisms (e.g., shared secrets, signatures) configured on the receiving server to ensure authenticity, rather than client-side authentication headers.

### 9. RESPONSE FORMAT:
The documentation describes the *payload* of the webhook event. It does not specify the expected *response format* from the receiving server, though typically an HTTP 200 OK status code is sent to acknowledge successful receipt of the webhook.

*   **Payload Structure:** JSON object
*   **Payload Example (Location Level App Uninstall):**
    ```json
    {
      "type": "UNINSTALL",
      "appId": "ve9EPM428h8vShlRW1KT",
      "locationId": "otg8dTQqGLh3Q6iQI55w"
    }
    ```
*   **Payload Example (Agency Level App Uninstall):**
    ```json
    {
      "type": "UNINSTALL",
      "appId": "ve9EPM428h8vShlRW1KT",
      "companyId": "otg8dTQqGLh3Q6iQI55w"
    }
    ```

### 10. PURPOSE:
This webhook is triggered and sent to an integrated system whenever a Marketplace app is uninstalled, providing details about the uninstalled app and the context (company or location) of the uninstallation.
