## How we compress the work

1. **Architect packages it.** Reconcile current repo truth and existing project decisions; complete the supplied master acceptance spec and build instructions; Tony approves one build campaign.
2. **Claudy builds it.** Work continuously through Capture and Prepare, with engineering tests and contract checks inside the run. Keep the journal and evidence current. Hand off one complete candidate.
3. **SOL + Cody QA it.** SOL owns one master QA plan; Cody executes it in long batches. Claudy repairs; Cody retests; SOL certifies.
4. **Astra + Fable review it.** Separate review sessions inspect the same frozen candidate. Architect proposes dispositions; Tony rules, with SOL advising on verification.
5. **One RRM closes accepted findings.** Architect packages the repairs together; Claudy executes; Cody verifies repairs and required regression under SOL; Astra performs targeted final confirmation. Cleanup, closeout, and Tony's merge finish the campaign.

No routine independent QA gate after each internal BIM or between Capture and Prepare. Engineer tests remain mandatory. Product/contract decisions that cannot be resolved inside approved instructions still return to the Architect/Director. Interrupted sessions resume from durable checkpoints.
