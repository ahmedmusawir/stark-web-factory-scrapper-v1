## Lessons Learned

- The recon's "discover.py breaks from root" inference was wrong: `python path/to/script.py` puts the script's dir on sys.path, so the flat import worked. Verify CWD/import claims by running, not reasoning.

- A grep-proof file matches its own pattern; the `g[h]l` bracket idiom keeps the record clean.
- Unpinned transitive deps drift on a pip re-resolve (chardet 5.2→7.6 tripped a requests warning). Capture `pip freeze` immediately and pin the offender.
