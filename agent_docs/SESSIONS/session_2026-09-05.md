## Lessons Learned

- A wrapper script outside the repo needs the repo root on `sys.path` explicitly; `python -m` semantics do not carry over. Cost one instant, network-free failed attempt.
- crawl4ai (Playwright strategy) never fails a 4xx/5xx page — status must be read off `result.status_code` explicitly if a stop-on-403/429 rule matters.
